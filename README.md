# Підготовка до колоквіумів і сесії (1 курс, фізфак)

Сайт: https://evge14n.github.io/uni-prep/ - працює на телефоні, встановлюється як застосунок і після
першого відкриття працює без інтернету.

Що всередині: два колоквіуми (аналітична геометрія, матаналіз), чотири іспити, чотири заліки.
У кожному розділі - теорія простою мовою, означення і теореми (з доведеннями), задачі з покроковим
розвʼязанням, шпаргалка, відео з таймкодом і тести (таймер, пояснення, «лише помилки», картки).

Матеріал - власні конспекти, задачі й тести. Числові відповіді тестів перевіряються скриптом.

## Як зібрати і перевірити

```
python tools/build.py              # content/ -> site/ (і перевірка заборонених символів)
python tools/verify_quizzes.py     # структура тестів + перерахунок чисел (sympy)
python tools/check_videos.py       # відео: структура (--online: чи відкривається кожне)
python tools/e2e.py [адреса]       # headless-браузер: 390 і 1440 px, консоль, офлайн
```

Сайт - статичні файли в `site/` (без сервера), викладаються на GitHub Pages.
