## Тема 1. Матриці, обернена матриця, ранг

### Закінчити речення

- **З1.** Матриця, в якої кількість рядків дорівнює кількості стовпців, називається → **квадратною**.
- **З2.** Квадратна матриця, в якої a_ij = 0 при i ≠ j, називається → **діагональною**.
- **З3.** Діагональна матриця, в якої a_ii = 1, називається → **одиничною** (позначають E).
- **З4.** Матриця, в якої всі елементи дорівнюють нулю, називається → **нульовою**.
- **З5.** Якщо в матриці A замінити рядки на стовпці, то одержимо матрицю, яка називається → **транспонованою** (Aᵀ).
- **З6.** Квадратна матриця A = (a_ij), для якої a_ij = a_ji для всіх i, j = 1, 2, ..., n, називається → **симетричною**.
- **З7.** Квадратна матриця A = (a_ij), для якої a_ij = -a_ji для всіх i, j, називається → **антисиметричною** (у лекціях ще «кососиметричною»).
- **З8.** Матриця, в якої a_ij = 0 при i > j, називається → **верхньою трикутною** (нулі під діагоналлю).
- **З9.** Матриця, в якої a_ij = 0 при i < j, називається → **нижньою трикутною** (нулі над діагоналлю).
- **З10.** Дві матриці, одна з яких отримана з іншої за допомогою елементарних перетворень, називаються → **еквівалентними** (A ~ B).
- **З11.** Матриця, у якої: якщо в i-му рядку перший ненульовий елемент стоїть на k-му місці, то в (i+1)-му рядку перші k елементів - нулі; якщо i-й рядок нульовий, то (i+1)-й теж нульовий, називається → **східчастою**.
- **З14.** Матриця, визначник якої дорівнює нулю, називається → **виродженою**.
- **З15.** Матриця, визначник якої не дорівнює нулю, називається → **невиродженою**.
- **З16.** Найвищий порядок відмінних від нуля мінорів матриці A називається → **рангом матриці** (rang A).

### Сформулювати означення

- **О1. Матриця.** Прямокутна таблиця з m·n чисел, яка має m рядків і n стовпців; кажуть «матриця розміру m×n». Елемент a_ij стоїть в i-му рядку і j-му стовпці.
- **О2. Квадратна матриця.** Матриця, в якої кількість рядків дорівнює кількості стовпців (m = n); n - її порядок.
- **О3. Діагональна матриця.** Квадратна матриця, в якої a_ij = 0 для всіх i ≠ j (ненульові можуть бути лише елементи головної діагоналі).
- **О4. Одинична матриця.** Діагональна матриця, в якої всі діагональні елементи дорівнюють 1 (a_ii = 1). Позначають E. Для будь-якої A: A·E = E·A = A.
- **О5. Транспонована матриця.** Матриця Aᵀ, яку отримують з A заміною рядків на стовпці зі збереженням їх порядку: (Aᵀ)_ij = a_ji. Якщо A має розмір m×n, то Aᵀ - n×m.
- **О6. Симетрична матриця.** Квадратна матриця, для якої a_ij = a_ji для всіх i, j (тобто Aᵀ = A).
- **О7. Антисиметрична (кососиметрична) матриця.** Квадратна матриця, для якої a_ij = -a_ji для всіх i, j. Звідси на діагоналі нулі: a_ii = -a_ii ⇒ a_ii = 0.
- **О8. Верхня трикутна матриця.** Квадратна матриця, в якої a_ij = 0 при i > j (усі елементи під головною діагоналлю - нулі).
- **О9. Нижня трикутна матриця.** Квадратна матриця, в якої a_ij = 0 при i < j (усі елементи над головною діагоналлю - нулі).
- **О10. Еквівалентні матриці.** Матриці A і B, які отримують одну з іншої за допомогою елементарних перетворень. Пишуть A ~ B.
- **О11. Елементарні перетворення матриці.** 1) перестановка двох рядків (стовпців); 2) множення рядка (стовпця) на ненульове число; 3) додавання до одного рядка (стовпця) іншого рядка (стовпця), помноженого на число.
- **О12. Східчаста матриця.** Матриця, у якої: 1) якщо в i-му рядку перший ненульовий елемент стоїть на k-му місці, то в (i+1)-му рядку перші k елементів дорівнюють нулю; 2) якщо i-й рядок нульовий, то й (i+1)-й рядок нульовий.
- **О19. Вироджена і невироджена матриця.** Квадратна матриця, визначник якої дорівнює нулю, - вироджена; визначник якої не дорівнює нулю - невироджена.
- **О20. Обернена матриця.** Матриця A⁻¹ того самого порядку, що й квадратна матриця A, для якої A·A⁻¹ = A⁻¹·A = E. Вона існує тоді і тільки тоді, коли A невироджена.
- **О21. Формула оберненої матриці.** A⁻¹ = (1/det A)·Ã, де Ã - приєднана матриця: на місці (i, j) стоїть алгебраїчне доповнення A_ji (тобто матриця доповнень, транспонована).

```
         1    ⎛A₁₁ A₂₁ ... Aₙ₁⎞
A⁻¹ = ───── · ⎜A₁₂ A₂₂ ... Aₙ₂⎟
      det A   ⎜... ...  ... ...⎟
              ⎝A₁ₙ A₂ₙ ... Aₙₙ⎠
```

- **О22. Матричні рівняння.** Рівняння A·X = B, X·A = B, A·X·C = B, де A, B, C - відомі матриці, X - невідома. Розв'язки (якщо A, C невироджені): X = A⁻¹·B; X = B·A⁻¹; X = A⁻¹·B·C⁻¹.
- **О23. Ранг матриці по мінорах.** Найвищий (максимальний) порядок відмінних від нуля мінорів матриці A: існує ненульовий мінор порядку r, а всі мінори порядку r + 1 (якщо є) дорівнюють нулю.
- **О24. Ранг матриці по рядках.** Максимальна кількість лінійно незалежних рядків матриці.
- **О25. Ранг матриці по стовпцях.** Максимальна кількість лінійно незалежних стовпців матриці. (Теорема: ранги по рядках, по стовпцях і по мінорах рівні.)

## Тема 2. Визначники

### Закінчити речення

- **З12.** Визначник (n-1)-го порядку, який одержуємо з визначника матриці A n-го порядку шляхом викреслення i-го рядка та j-го стовпця, називається → **мінором M_ij елемента a_ij**.
- **З13.** Визначник, утворений з елементів, які стоять на перетині довільних k рядків та k стовпців матриці A, називається → **мінором k-го порядку** матриці A.

### Сформулювати означення

- **О13. Визначник другого порядку.**

```
│a₁₁ a₁₂│
│a₂₁ a₂₂│ = a₁₁·a₂₂ - a₁₂·a₂₁
```

- **О14. Визначник третього порядку** (правило трикутників):

```
│a₁₁ a₁₂ a₁₃│
│a₂₁ a₂₂ a₂₃│ =
│a₃₁ a₃₂ a₃₃│
= a₁₁a₂₂a₃₃ + a₁₂a₂₃a₃₁ + a₁₃a₂₁a₃₂
- a₁₃a₂₂a₃₁ - a₁₁a₂₃a₃₂ - a₁₂a₂₁a₃₃
```

- **О15. Визначник n-го порядку.** Число, яке дорівнює сумі n! доданків. Кожен доданок - добуток n елементів, узятих по одному з кожного рядка і кожного стовпця: a₁ⱼ₁·a₂ⱼ₂·...·aₙⱼₙ, де (j₁, j₂, ..., jₙ) - перестановка номерів стовпців. Доданок береться зі знаком (-1)^N, де N - кількість інверсій у перестановці (парна - «+», непарна - «-»).
- **О16. Мінор елемента матриці.** Мінор M_ij елемента a_ij - визначник (n-1)-го порядку, який отримують з визначника матриці викресленням i-го рядка і j-го стовпця.
- **О17. Алгебраїчне доповнення.** Число A_ij = (-1)^(i+j)·M_ij.
- **О18. Мінор k-го порядку.** Визначник, утворений з елементів, які стоять на перетині довільних k рядків і k стовпців матриці A.

## Тема 3. Системи лінійних рівнянь

### Закінчити речення

- **З17.** Система лінійних рівнянь, в якої кількість рівнянь дорівнює кількості невідомих, називається → **квадратною**.
- **З18.** Система лінійних рівнянь, в якої всі вільні члени дорівнюють нулю, називається → **однорідною**.
- **З19.** Сукупність чисел, яка перетворює всі рівняння системи на тотожності, називається → **розв'язком системи**.
- **З20.** Система, яка має хоча б один розв'язок, називається → **сумісною**.
- **З21.** Система, яка не має жодного розв'язку, називається → **несумісною**.
- **З22.** Система, яка має лише один розв'язок, називається → **визначеною**.
- **З23.** Система, яка має безліч розв'язків, називається → **невизначеною**.
- **З24.** Системи, множини розв'язків яких співпадають, називаються → **рівносильними (еквівалентними)**.

### Сформулювати означення

- **О26. Система лінійних рівнянь.** Система m рівнянь з n невідомими вигляду

```
a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = b₁
a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ = b₂
...
aₘ₁x₁ + aₘ₂x₂ + ... + aₘₙxₙ = bₘ
```

a_ij - коефіцієнти, b_i - вільні члени. Матриця з a_ij - основна матриця A, з дописаним стовпцем b - розширена (A│b).

- **О27. Однорідна і неоднорідна система.** Однорідна - усі вільні члени дорівнюють нулю (b = 0); неоднорідна - хоча б один вільний член не нуль.
- **О28. Розв'язок системи.** Впорядкований набір з n чисел, який при підстановці замість невідомих перетворює всі рівняння системи на правильні числові рівності (тотожності).
- **О29. Сумісна і несумісна система.** Сумісна має хоча б один розв'язок; несумісна не має жодного.
- **О30. Визначена і невизначена система.** Визначена має лише один розв'язок; невизначена - безліч розв'язків.
- **О31. Теорема Кронекера-Капеллі.** Система лінійних рівнянь сумісна тоді і тільки тоді, коли ранг її основної матриці дорівнює рангу розширеної матриці: rang A = rang (A│b).
- **О32. Теорема Крамера.** Якщо визначник Δ квадратної системи n рівнянь з n невідомими не дорівнює нулю, то система має єдиний розв'язок xᵢ = Δᵢ / Δ (i = 1, ..., n), де Δᵢ - визначник, отриманий з Δ заміною i-го стовпця стовпцем вільних членів.
- **О33. Рівносильні системи.** Системи, множини розв'язків яких збігаються (у лекціях - «еквівалентні»).
- **О34. Елементарні перетворення системи.** 1) перестановка двох рівнянь; 2) множення рівняння на ненульове число; 3) додавання до одного рівняння іншого, помноженого на число. Вони переводять систему в рівносильну.

## Тема 4. Вектори

### Закінчити речення

- **З25.** Вектор, початок і кінець якого співпадають, називається → **нульовим (нуль-вектором)**.
- **З26.** Вектор, довжина якого дорівнює одиниці, називається → **одиничним** (нормованим, ортом).
- **З27.** Вектори, які лежать на одній або на паралельних прямих, називаються → **колінеарними**.
- **З28.** Вектори, які є колінеарними, однаково напрямленими і мають однакову довжину, називаються → **рівними**.
- **З29.** Вектори, які лежать в одній або в паралельних площинах, називаються → **компланарними**.
- **З30.** Вектор, початок якого співпадає з початком вектора a, кінець - з кінцем вектора b, за умови, що початок b співпадає з кінцем a, називається → **сумою векторів a і b** (a + b).
- **З31.** Вектор, який треба додати до вектора b, щоб дістати вектор a, називається → **різницею векторів a і b** (a - b).
- **З32.** Вектор a = λ₁a₁ + λ₂a₂ + ... + λₙaₙ називається → **лінійною комбінацією векторів a₁, ..., aₙ**.
- **З33.** Сукупність точки (початку координат) та векторів бази називається → **декартовою системою координат**.
- **З34.** Система координат, вектори бази якої одиничні та взаємно перпендикулярні, називається → **прямокутною декартовою системою координат**.

### Сформулювати означення

- **О35. Вектор.** Напрямлений відрізок: відрізок, у якого вказано, яка точка початок, а яка кінець. Має довжину і напрям.
- **О36. Довжина вектора.** Довжина (модуль) вектора - довжина відрізка, який зображає вектор: |a| = |AB|.
- **О37. Нуль-вектор.** Вектор, початок і кінець якого збігаються. Позначають 0, довжина 0, напрям не визначений.
- **О38. Одиничний вектор.** Вектор, довжина якого дорівнює одиниці.
- **О39. Колінеарні вектори.** Вектори, які лежать на одній прямій або на паралельних прямих.
- **О40. Компланарні вектори.** Вектори, які лежать в одній площині або в паралельних площинах.
- **О41. Сума векторів.** Вектор c, початок якого збігається з початком вектора a, а кінець - з кінцем вектора b, за умови, що початок b збігається з кінцем a: c = a + b (правило трикутника).
- **О42. Різниця векторів.** Вектор d, який треба додати до вектора b, щоб одержати вектор a: d = a - b.
- **О43. Добуток вектора на скаляр.** Вектор b = λ·a, колінеарний до a, довжиною |b| = |λ|·|a|; напрям b збігається з напрямом a, якщо λ > 0, і протилежний, якщо λ < 0.
- **О44. Лінійна комбінація системи векторів.** Вектор λ₁a₁ + λ₂a₂ + ... + λₖaₖ, де λ₁, ..., λₖ - числа.
- **О45. Проекція вектора на вісь.** Проекція вектора AB на вісь l - довжина вектора A₁B₁ (A₁, B₁ - проекції точок A і B на вісь), узята зі знаком «+», якщо напрям A₁B₁ збігається з напрямом осі, і зі знаком «-», якщо протилежний. Формула: пр_l a = |a|·cos φ.

## Тема 5. Скалярний, векторний і мішаний добутки

### Закінчити речення

- **З35.** Число, яке дорівнює добутку довжин двох векторів на косинус кута між ними, називається → **скалярним добутком**.
- **З36.** Якщо скалярний добуток двох векторів дорівнює нулю, то → **вектори перпендикулярні** (або хоч один з них нульовий).
- **З37.** Вектор, перпендикулярний до двох заданих векторів, довжина якого дорівнює добутку їх довжин на синус кута між ними, і такий, що три вектори утворюють праву трійку, називається → **векторним добутком**.
- **З38.** Якщо векторний добуток двох векторів дорівнює нулю, то → **вектори колінеарні** (або хоч один з них нульовий).
- **З39.** Площа паралелограма, побудованого на двох векторах, дорівнює → **модулю їх векторного добутку**: S = |[a, b]|.
- **З40.** Площа трикутника, побудованого на двох векторах, дорівнює → **половині модуля векторного добутку**: S = ½·|[a, b]|.
- **З41.** Число, яке дорівнює скалярному добутку векторного добутку двох векторів та третього вектора, називається → **мішаним добутком**.
- **З42.** Об'єм паралелепіпеда, побудованого на трьох векторах, дорівнює → **модулю мішаного добутку**: V = |(a, b, c)|.
- **З43.** Об'єм піраміди, побудованої на трьох векторах, дорівнює → **шостій частині модуля мішаного добутку**: V = ⅙·|(a, b, c)|.

### Сформулювати означення

- **О46. Скалярний добуток.** Число, яке дорівнює добутку довжин двох векторів на косинус кута між ними: (a, b) = |a|·|b|·cos φ.
- **О47. Скалярний добуток у координатах.** (a, b) = aₓbₓ + a_y b_y + a_z b_z.
- **О48. Довжина вектора в координатах.** |a| = √(a, a) = √(aₓ² + a_y² + a_z²).
- **О49. Векторний добуток.** Вектор c = [a, b], який: 1) має довжину |c| = |a|·|b|·sin φ; 2) перпендикулярний до площини векторів a і b; 3) напрямлений так, що a, b, c утворюють праву трійку.
- **О50. Векторний добуток у координатах.**

```
         │ i   j   k  │
[a, b] = │ aₓ  a_y a_z│
         │ bₓ  b_y b_z│
= (a_y b_z - a_z b_y; -(aₓb_z - a_z bₓ);
   aₓb_y - a_y bₓ)
```

- **О51. Геометричний зміст векторного добутку.** Модуль векторного добутку дорівнює площі паралелограма, побудованого на векторах a і b як на сторонах: S = |[a, b]|. Площа трикутника - половина.
- **О52. Мішаний добуток.** Число (a, b, c) = ([a, b], c) - скалярний добуток векторного добутку a і b на вектор c.
- **О53. Мішаний добуток у координатах.**

```
            │aₓ a_y a_z│
(a, b, c) = │bₓ b_y b_z│
            │cₓ c_y c_z│
```

- **О54. Геометричний зміст мішаного добутку.** Модуль мішаного добутку дорівнює об'єму паралелепіпеда, побудованого на векторах a, b, c; об'єм піраміди (тетраедра) - ⅙ від нього. Мішаний добуток дорівнює нулю ⇔ вектори компланарні.

## Тема 6. Пряма на площині

### Закінчити речення

- **З44.** Ненульовий вектор, паралельний до прямої, називається → **напрямним вектором прямої**.
- **З45.** Ненульовий вектор, перпендикулярний до прямої на площині, називається → **нормальним вектором прямої**.
- **З46.** Перпендикуляр, опущений з початку координат на пряму на площині, називається → **нормаллю прямої** (у лекціях саме так; його довжина p стоїть у нормальному рівнянні).

### Сформулювати означення і формули

- **О55. Напрямний вектор прямої.** Ненульовий вектор, паралельний до прямої: s = (l; m).
- **О56. Нормальний вектор прямої.** Ненульовий вектор, перпендикулярний до прямої: n = (A; B).
- **О57. Канонічне рівняння прямої на площині.** (x - x₀)/l = (y - y₀)/m, де M₀(x₀; y₀) - точка прямої, s = (l; m) - напрямний вектор.
- **О58. Параметричне рівняння.** x = x₀ + l·t, y = y₀ + m·t, t ∈ ℝ.
- **О59. Рівняння прямої через дві точки** M₁(x₁; y₁), M₂(x₂; y₂): (x - x₁)/(x₂ - x₁) = (y - y₁)/(y₂ - y₁).
- **О60. Пряма через точку M₀ перпендикулярно до вектора n = (A; B):** A(x - x₀) + B(y - y₀) = 0.
- **О61. Напрямний і нормальний вектори прямої Ax + By + C = 0:** n = (A; B), s = (-B; A) (або (B; -A)).
- **О62. Нормальне рівняння прямої.** x·cos α + y·sin α - p = 0, де p ≥ 0 - довжина нормалі (відстань від O до прямої), α - кут нормалі з віссю Ox. З загального: ділимо на ±√(A² + B²), знак протилежний до знака C.
- **О63. Кут між прямими, заданими канонічними рівняннями:** cos φ = (l₁l₂ + m₁m₂) / (√(l₁² + m₁²)·√(l₂² + m₂²)).
- **О64. Кут між прямими, заданими загальними рівняннями:** cos φ = (A₁A₂ + B₁B₂) / (√(A₁² + B₁²)·√(A₂² + B₂²)).
- **О65. Кут між прямими з кутовими коефіцієнтами:** tg φ = (k₂ - k₁)/(1 + k₁k₂).
- **О66. Загальні рівняння:** паралельні ⇔ A₁/A₂ = B₁/B₂; перпендикулярні ⇔ A₁A₂ + B₁B₂ = 0.
- **О67. Канонічні рівняння:** паралельні ⇔ l₁/l₂ = m₁/m₂; перпендикулярні ⇔ l₁l₂ + m₁m₂ = 0.
- **О68. Кутові коефіцієнти:** паралельні ⇔ k₁ = k₂; перпендикулярні ⇔ k₁·k₂ = -1.
- **О69. Відстань від точки M₀(x₀; y₀) до прямої Ax + By + C = 0:** d = │A·x₀ + B·y₀ + C│ / √(A² + B²).

## Тема 7. Площина

### Закінчити речення (площина π: Ax + By + Cz + D = 0)

- **З47.** Ненульовий вектор, перпендикулярний до площини, називається → **нормальним вектором площини**.
- **З48.** Якщо π проходить через початок координат, то → **D = 0**.
- **З49.** Якщо π паралельна до осі Ox, то → **A = 0**.
- **З50.** Якщо π паралельна до осі Oy, то → **B = 0**.
- **З51.** Якщо π паралельна до осі Oz, то → **C = 0**.
- **З52.** Якщо π паралельна до площини xOy, то → **A = 0 і B = 0** (рівняння Cz + D = 0).
- **З53.** Якщо π паралельна до площини xOz, то → **A = 0 і C = 0** (By + D = 0).
- **З54.** Якщо π паралельна до площини yOz, то → **B = 0 і C = 0** (Ax + D = 0).
- **З55.** Якщо π проходить через вісь Ox, то → **A = 0 і D = 0**.
- **З56.** Якщо π проходить через вісь Oy, то → **B = 0 і D = 0**.
- **З57.** Якщо π проходить через вісь Oz, то → **C = 0 і D = 0**.

> Як запамʼятати: «паралельна осі» - немає змінної цієї осі. «Через вісь» - немає змінної і
> немає D. «Паралельна площині xOy» - лишилась тільки z.

### Сформулювати означення і формули

- **О70. Площина через точку M₀(x₀; y₀; z₀) перпендикулярно до вектора n = (A; B; C):** A(x - x₀) + B(y - y₀) + C(z - z₀) = 0.
- **О71. Площина через три точки:**

```
│x - x₁   y - y₁   z - z₁ │
│x₂ - x₁  y₂ - y₁  z₂ - z₁│ = 0
│x₃ - x₁  y₃ - y₁  z₃ - z₁│
```

- **О72. Кут між площинами:** cos φ = (A₁A₂ + B₁B₂ + C₁C₂) / (√(A₁² + B₁² + C₁²)·√(A₂² + B₂² + C₂²)).
- **О73. Умови:** паралельні ⇔ A₁/A₂ = B₁/B₂ = C₁/C₂; перпендикулярні ⇔ A₁A₂ + B₁B₂ + C₁C₂ = 0.
- **О74. Відстань від точки до площини:** d = │Ax₀ + By₀ + Cz₀ + D│ / √(A² + B² + C²).

## Тема 8. Пряма в просторі, пряма і площина

У цій темі «Закінчити речення» немає, лише означення.

- **О75. Канонічне рівняння прямої в просторі:** (x - x₀)/a₁ = (y - y₀)/a₂ = (z - z₀)/a₃, де M₀(x₀; y₀; z₀) - точка, a = (a₁; a₂; a₃) - напрямний вектор.
- **О76. Параметричне рівняння:** x = x₀ + a₁t, y = y₀ + a₂t, z = z₀ + a₃t.
- **О77. Пряма через дві точки:** (x - x₁)/(x₂ - x₁) = (y - y₁)/(y₂ - y₁) = (z - z₁)/(z₂ - z₁).
- **О78. Загальне рівняння прямої** - пряма як перетин двох непаралельних площин:

```
⎧ A₁x + B₁y + C₁z + D₁ = 0
⎩ A₂x + B₂y + C₂z + D₂ = 0
```

- **О79. Напрямний вектор прямої, заданої загальним рівнянням:** a = [n₁, n₂] - векторний добуток нормалей двох площин.
- **О80. Кут між прямими в просторі:** cos φ = (a₁b₁ + a₂b₂ + a₃b₃) / (√(a₁² + a₂² + a₃²)·√(b₁² + b₂² + b₃²)).
- **О81. Умови:** паралельні ⇔ a₁/b₁ = a₂/b₂ = a₃/b₃; перпендикулярні ⇔ a₁b₁ + a₂b₂ + a₃b₃ = 0.
- **О82. Кут між прямою і площиною** (синус, бо кут з нормаллю доповнює його до 90°): sin φ = │A·a₁ + B·a₂ + C·a₃│ / (√(A² + B² + C²)·√(a₁² + a₂² + a₃²)).
- **О83. Умови:** пряма ∥ площині ⇔ A·a₁ + B·a₂ + C·a₃ = 0 (a ⟂ n); пряма ⟂ площині ⇔ A/a₁ = B/a₂ = C/a₃ (a ∥ n).

## Тема 9. Криві другого порядку (можливо, якщо встигнуть на лекціях)

### Закінчити речення

- **З58.** Лінії, рівняння яких у прямокутній декартовій системі координат на площині є рівняннями другого степеня відносно x та y, називаються → **кривими (лініями) другого порядку**.
- **З59.** Множина точок площини, які знаходяться на однаковій відстані від фіксованої точки, називається → **колом**.
- **З60.** Відрізок, який сполучає дві точки кола і проходить через його центр, називається → **діаметром**.
- **З61.** Множина точок площини, сума відстаней від яких до двох фіксованих точок є величина стала, називається → **еліпсом**.
- **З62.** Відношення відстані між фокусами еліпса до довжини його великої осі називається → **ексцентриситетом еліпса**.
- **З63.** Прямі, перпендикулярні до великої осі еліпса, розміщені симетрично відносно центра на відстані a/ε від нього, називаються → **директрисами еліпса**.
- **З64.** Множина точок площини, різниця відстаней від яких до двох фіксованих точок є величина стала, називається → **гіперболою**.
- **З65.** Відношення відстані між фокусами гіперболи до довжини її дійсної осі називається → **ексцентриситетом гіперболи**.
- **З66.** Рівняння x²/a² + y²/b² = 1 називається → **канонічним рівнянням еліпса**.
- **З67.** Рівняння x²/a² - y²/b² = 1 називається → **канонічним рівнянням гіперболи**.
- **З68.** Множина точок площини, відстань від яких до фіксованої точки дорівнює відстані до фіксованої прямої, називається → **параболою**.

### Сформулювати означення і формули

- **О84. Коло.** Множина точок площини, відстані від яких до заданої точки (центра) однакові й дорівнюють R. Рівняння (x - x₀)² + (y - y₀)² = R².
- **О85. Діаметр кола.** Відрізок, який сполучає дві точки кола і проходить через центр; довжина 2R.
- **О86. Еліпс.** Множина точок площини, сума відстаней від яких до двох фіксованих точок (фокусів) стала: r₁ + r₂ = 2a (2a > 2c - відстані між фокусами).
- **О87. Ексцентриситет еліпса.** Число ε = c/a (відношення відстані між фокусами 2c до великої осі 2a). Для еліпса 0 ≤ ε < 1.
- **О88. Директриси еліпса.** Дві прямі, перпендикулярні до великої осі, розташовані симетрично відносно центра на відстані a/ε від нього: x = ±a/ε.
- **О89. Гіпербола.** Множина точок площини, модуль різниці відстаней від яких до двох фіксованих точок (фокусів) сталий: │r₁ - r₂│ = 2a (2a < 2c).
- **О90. Ексцентриситет гіперболи.** ε = c/a > 1 (відстань між фокусами до довжини дійсної осі).
- **О91. Директриси гіперболи.** Прямі, перпендикулярні до дійсної осі, на відстані a/ε від центра: x = ±a/ε.
- **О92. Асимптоти гіперболи** x²/a² - y²/b² = 1: y = ±(b/a)·x.
- **О93. Парабола.** Множина всіх точок площини, рівновіддалених від фіксованої прямої (директриси) і фіксованої точки (фокуса), яка не лежить на цій прямій.
- **О94. Канонічне рівняння еліпса:** x²/a² + y²/b² = 1, b² = a² - c².
- **О95. Канонічне рівняння гіперболи:** x²/a² - y²/b² = 1, b² = c² - a².
- **О96. Канонічне рівняння параболи:** y² = 2px (фокус F(p/2; 0), директриса x = -p/2). Також x² = 2py.
- **О97. Полярне рівняння кривих другого порядку:** r = p / (1 - ε·cos φ), p - полярний параметр (половина хорди через фокус, перпендикулярної до полярної осі). ε < 1 - еліпс, ε = 1 - парабола, ε > 1 - гіпербола. Для еліпса і гіперболи p = b²/a.
