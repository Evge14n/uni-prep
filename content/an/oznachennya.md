## Тема 10. Поверхні другого порядку

### Закінчити речення (усі «Поверхня, задана рівнянням ..., називається ...»)

- **З69.** x²/a² + y²/b² + z²/c² = 1 → **еліпсоїдом**.
- **З70.** x²/a² + y²/b² - z²/c² = 1 → **однопорожнинним гіперболоїдом**.
- **З71.** x²/a² + y²/b² - z²/c² = -1 → **двопорожнинним гіперболоїдом**.
- **З72.** x²/a² + y²/b² - z²/c² = 0 → **еліптичним конусом** (конусом другого порядку).
- **З73.** x²/a² + y²/b² = 2pz → **еліптичним параболоїдом**.
- **З74.** x²/a² - y²/b² = 2pz → **гіперболічним параболоїдом**.
- **З75.** x²/a² + y²/b² = 1 → **еліптичним циліндром**.
- **З76.** x²/a² - y²/b² = 1 → **гіперболічним циліндром**.
- **З77.** x² = 2py → **параболічним циліндром**.

### Сформулювати і намалювати (О98-О106)

«Намалювати» = показати форму. Найпростіше - через перерізи площинами z = h, x = 0, y = 0.

- **О98. Еліпсоїд:** x²/a² + y²/b² + z²/c² = 1. Замкнена поверхня, симетрична відносно всіх
  координатних площин; a, b, c - півосі. Перерізи z = h (│h│ < c) - еліпси, що меншають до
  точки при h = ±c. Якщо a = b = c - сфера.
- **О99. Однопорожнинний гіперболоїд:** x²/a² + y²/b² - z²/c² = 1. «Котушка»: при z = h -
  еліпси x²/a² + y²/b² = 1 + h²/c² (найменший - «горло» при z = 0), при x = 0 і y = 0 -
  гіперболи. Одна суцільна поверхня.
- **О100. Двопорожнинний гіперболоїд:** x²/a² + y²/b² - z²/c² = -1. Дві окремі «чаші» з
  вершинами (0; 0; ±c). При │h│ < c переріз z = h порожній, при │h│ > c - еліпси.
- **О101. Еліптичний конус:** x²/a² + y²/b² - z²/c² = 0. Два конуси зі спільною вершиною в O.
  Перерізи z = h - еліпси, при x = 0 - дві прямі z = ±(c/b)y.
- **О102. Еліптичний параболоїд:** x²/a² + y²/b² = 2pz (p > 0). «Чаша» з вершиною в O,
  відкрита вгору. z = h > 0 - еліпси, x = 0 і y = 0 - параболи.
- **О103. Гіперболічний параболоїд:** x²/a² - y²/b² = 2pz. «Сідло». z = h - гіперболи
  (при h = 0 - дві прямі), x = 0 і y = 0 - параболи, одна гілками вгору, інша вниз.
- **О104. Еліптичний циліндр:** x²/a² + y²/b² = 1. Твірні паралельні Oz, напрямна - еліпс у
  площині xOy. Немає z ⇒ для будь-якого z той самий еліпс.
- **О105. Гіперболічний циліндр:** x²/a² - y²/b² = 1. Твірні ∥ Oz, напрямна - гіпербола.
- **О106. Параболічний циліндр:** x² = 2py. Твірні ∥ Oz, напрямна - парабола («жолоб»).

## Д1. Властивості визначників n-го порядку

**Формулювання** (методичка с. 10-11, формули (2.4)-(2.10)). Тут A_ij = (-1)^(i+j)·M_ij.

1. Визначник не змінюється при транспонуванні (заміні рядків стовпцями).
2. Перестановка двох (сусідніх) рядків або стовпців змінює знак визначника.
3. Визначник з двома однаковими рядками (стовпцями) дорівнює нулю.
4. Якщо всі елементи рядка (стовпця) помножити на λ, визначник помножиться на λ (спільний
   множник можна винести).
5. Якщо всі елементи рядка (стовпця) - нулі, визначник дорівнює нулю.
6. Якщо два рядки (стовпці) пропорційні, визначник дорівнює нулю.
7. Визначник не зміниться, якщо до рядка (стовпця) додати інший рядок (стовпець), помножений
   на одне й те саме число.
8. Якщо i-й рядок - лінійна комбінація λ·(b_i1, ..., b_in) + μ·(c_i1, ..., c_in), то
   Δ = λ·Δ₁ + μ·Δ₂, де в Δ₁ i-й рядок - b, у Δ₂ - c, решта рядків ті самі.
9. Визначник трикутної матриці (нулі над або під головною діагоналлю) = a₁₁·a₂₂·...·aₙₙ.
10. Якщо нулі під (над) побічною діагоналлю, то Δ = (-1)^(n(n-1)/2)·a₁ₙ·a₂,ₙ₋₁·...·aₙ₁.
11. Розклад: Δ = a_i1·A_i1 + a_i2·A_i2 + ... + a_in·A_in (за рядком), так само за стовпцем.
12. Сума добутків елементів рядка на алгебраїчні доповнення ІНШОГО рядка дорівнює нулю:
    a_i1·A_k1 + ... + a_in·A_kn = 0 при i ≠ k (так само для стовпців).
13. det(A·B) = det A · det B.

**Що це означає простими словами:** 3, 5, 6 - миттєва відповідь «нуль»; 7 - головний
інструмент, ним роблять нулі; 9 - мета (звести до трикутного); 11 - знижує порядок на 1.

**Типова пастка на іспиті:** сплутати 11 і 12. У 11 доповнення ТОГО САМОГО рядка - виходить Δ;
у 12 - іншого рядка, і завжди 0. Ще пастка: «помножили рядок на λ» - визначник множиться на λ,
а «помножили всю матрицю n×n на λ» - на λⁿ.

## Д2. Скалярний добуток у координатах

**Формулювання.** Якщо a = (aₓ; a_y; a_z), b = (bₓ; b_y; b_z) у прямокутній системі, то
(a, b) = aₓbₓ + a_y b_y + a_z b_z.

**Що це означає:** множимо однойменні координати й додаємо. З цього: |a| = √(aₓ² + a_y² + a_z²).

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Розкладаємо за ортами: a = aₓi + a_y j + a_z k, b = bₓi + b_y j + b_z k.

**Крок 2.** Скалярний добуток дистрибутивний і числа можна виносити (властивості
(a + b, c) = (a, c) + (b, c), (λa, b) = λ(a, b)), тому розкриваємо дужки - 9 доданків:

```
(a, b) = aₓbₓ(i,i) + aₓb_y(i,j)
       + aₓb_z(i,k) + a_y bₓ(j,i)
       + a_y b_y(j,j) + a_y b_z(j,k)
       + a_z bₓ(k,i) + a_z b_y(k,j)
       + a_z b_z(k,k)
```

**Крок 3.** Орти одиничні: (i, i) = |i|·|i|·cos 0 = 1, так само (j, j) = (k, k) = 1.

**Крок 4.** Орти попарно перпендикулярні: (i, j) = 1·1·cos 90° = 0, так само (j, k) = (i, k) = 0.

**Крок 5.** Лишаються три доданки: (a, b) = aₓbₓ + a_y b_y + a_z b_z.

**Крок 6.** Окремо: (a, a) = |a|² ⇒ |a| = √(aₓ² + a_y² + a_z²).

</details>

**Типова пастка:** забути пояснити, ЧОМУ (i, j) = 0 і (i, i) = 1 - за це знімають бали.

## Д3. Векторний добуток у координатах

**Формулювання.** [a, b] = (a_y b_z - a_z b_y)·i - (aₓb_z - a_z bₓ)·j + (aₓb_y - a_y bₓ)·k, тобто
визначник з рядків (i, j, k), (aₓ, a_y, a_z), (bₓ, b_y, b_z).

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Таблиця добутків ортів (з означення: довжина 1·1·sin 90° = 1, права трійка):

```
[i, i] = [j, j] = [k, k] = 0   (sin 0 = 0)
[i, j] = k    [j, k] = i    [k, i] = j
[j, i] = -k   [k, j] = -i   [i, k] = -j
```

Мінус - бо [b, a] = -[a, b].

**Крок 2.** Розкриваємо дужки (векторний добуток дистрибутивний, числа виносяться, але
ПОРЯДОК множників зберігаємо):

```
[a, b] = aₓbₓ[i,i] + aₓb_y[i,j]
       + aₓb_z[i,k] + a_y bₓ[j,i]
       + a_y b_y[j,j] + a_y b_z[j,k]
       + a_z bₓ[k,i] + a_z b_y[k,j]
       + a_z b_z[k,k]
```

**Крок 3.** Підставляємо таблицю:

```
= aₓb_y·k - aₓb_z·j - a_y bₓ·k + a_y b_z·i
  + a_z bₓ·j - a_z b_y·i
```

**Крок 4.** Групуємо при i, j, k:

```
= (a_y b_z - a_z b_y)·i
- (aₓb_z - a_z bₓ)·j
+ (aₓb_y - a_y bₓ)·k
```

**Крок 5.** Це рівно розклад визначника │i j k; aₓ a_y a_z; bₓ b_y b_z│ за першим рядком
(знаки +, -, +).

</details>

**Типова пастка:** [i, k] = -j, а не j. Через це перед j у формулі стоїть мінус.

## Д4. Мішаний добуток у координатах

**Формулювання.** (a, b, c) = визначник 3×3 з рядків a, b, c.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** За означенням (a, b, c) = ([a, b], c).

**Крок 2.** З Д3: [a, b] = (a_y b_z - a_z b_y; -(aₓb_z - a_z bₓ); aₓb_y - a_y bₓ).

**Крок 3.** Скалярно множимо на c за Д2 (однойменні координати):

```
(a, b, c) = cₓ·(a_y b_z - a_z b_y)
          - c_y·(aₓb_z - a_z bₓ)
          + c_z·(aₓb_y - a_y bₓ)
```

**Крок 4.** Це розклад за ТРЕТІМ рядком визначника

```
│aₓ a_y a_z│
│bₓ b_y b_z│
│cₓ c_y c_z│
```

бо A₃₁ = +│a_y a_z; b_y b_z│, A₃₂ = -│aₓ a_z; bₓ b_z│, A₃₃ = +│aₓ a_y; bₓ b_y│.

</details>

**Наслідки:** |(a, b, c)| = V паралелепіпеда; (a, b, c) = 0 ⇔ компланарні; циклічна
перестановка не змінює знак, перестановка двох векторів - змінює (властивість 2 визначника).

## Д5. Канонічне рівняння еліпса

**Формулювання.** Еліпс (r₁ + r₂ = 2a, фокуси F₁(-c; 0), F₂(c; 0), a > c) у такій системі
координат має рівняння x²/a² + y²/b² = 1, де b² = a² - c².

**Що це означає:** з геометричного означення «сума відстаней стала» робимо рівняння без коренів.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Систему вибираємо так: вісь Ox через фокуси, O - середина F₁F₂. Тоді F₁(-c; 0),
F₂(c; 0). Для точки M(x; y):

```
r₁ = √((x + c)² + y²)
r₂ = √((x - c)² + y²)
```

**Крок 2.** З означення r₁ + r₂ = 2a. Переносимо один корінь праворуч:

```
√((x+c)² + y²) = 2a - √((x-c)² + y²)
```

**Крок 3.** Підносимо до квадрата:

```
(x+c)² + y² = 4a² - 4a√((x-c)² + y²)
            + (x-c)² + y²
```

**Крок 4.** (x + c)² - (x - c)² = 4xc, тому 4xc = 4a² - 4a√((x-c)² + y²). Ділимо на 4:

```
a√((x-c)² + y²) = a² - cx
```

**Крок 5.** Ще раз до квадрата:

```
a²(x² - 2cx + c² + y²) = a⁴ - 2a²cx + c²x²
```

**Крок 6.** -2a²cx скорочується з обох боків. Групуємо:

```
(a² - c²)x² + a²y² = a²(a² - c²)
```

**Крок 7.** Оскільки a > c, число a² - c² > 0, позначаємо його b². Маємо b²x² + a²y² = a²b².

**Крок 8.** Ділимо на a²b²: x²/a² + y²/b² = 1.

</details>

**Типова пастка:** забути пояснити, чому можна позначити b² = a² - c² (бо a > c, тобто
2a більше відстані між фокусами).

## Д6. Канонічне рівняння гіперболи

**Формулювання.** Гіпербола (│r₁ - r₂│ = 2a, фокуси (±c; 0), c > a): x²/a² - y²/b² = 1,
b² = c² - a².

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Система та сама, що для еліпса: r₁ = √((x+c)² + y²), r₂ = √((x-c)² + y²).

**Крок 2.** │r₁ - r₂│ = 2a ⇒ r₁ - r₂ = ±2a ⇒ √((x+c)² + y²) = ±2a + √((x-c)² + y²).

**Крок 3.** До квадрата і зводимо подібні (як у Д5): 4xc = 4a² ± 4a√((x-c)² + y²) ⇒

```
∓a√((x-c)² + y²) = a² - cx
```

**Крок 4.** Ще раз до квадрата (знак ∓ зникає):

```
a²((x-c)² + y²) = a⁴ - 2a²cx + c²x²
```

**Крок 5.** Групуємо, але тепер переносимо так, щоб коефіцієнт був додатний:

```
(c² - a²)x² - a²y² = a²(c² - a²)
```

**Крок 6.** У гіперболи c > a (у трикутнику F₁MF₂ різниця сторін менша за третю сторону:
2a < 2c), тому c² - a² > 0, позначаємо b². Маємо b²x² - a²y² = a²b².

**Крок 7.** Ділимо на a²b²: x²/a² - y²/b² = 1.

</details>

**Типова пастка:** написати b² = a² - c², як в еліпса. У гіперболи навпаки: b² = c² - a².

## Д7. Канонічне рівняння параболи

**Формулювання.** Парабола з фокусом F(p/2; 0) і директрисою x = -p/2 (p - відстань від фокуса
до директриси) має рівняння y² = 2px.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Систему вибираємо так: вісь Ox через фокус перпендикулярно до директриси, вісь Oy
через середину перпендикуляра з фокуса на директрису. Тоді F(p/2; 0), директриса x = -p/2.

**Крок 2.** Для точки M(x; y): відстань до фокуса r = √((x - p/2)² + y²), відстань до
директриси d = x + p/2.

**Крок 3.** З означення r = d:

```
√((x - p/2)² + y²) = x + p/2
```

**Крок 4.** До квадрата:

```
x² - px + p²/4 + y² = x² + px + p²/4
```

**Крок 5.** x² і p²/4 скорочуються: y² = 2px.

</details>

**Типова пастка:** фокус (p/2; 0), а не (p; 0). Для y² = 8x: 2p = 8, p = 4, фокус (2; 0).

## Д8. Директоріальна властивість кривих другого порядку

**Формулювання** (лекції, теорема 3.5.1). Відношення відстані r від будь-якої точки кривої до
фокуса до відстані d від цієї точки до відповідної директриси стале і дорівнює ексцентриситету:
r/d = ε.

**Що це означає:** еліпс, гіпербола і парабола - це одна родина: множина точок з r/d = ε.
ε < 1 - еліпс, ε = 1 - парабола, ε > 1 - гіпербола.

<details markdown="1"><summary>Доведення</summary>

**Крок 1 (фокальні радіуси еліпса).** Для точки еліпса y² = b²(1 - x²/a²). Тоді

```
r₁² = (x+c)² + y²
    = x² + 2cx + c² + b² - b²x²/a²
```

c² + b² = a², а 1 - b²/a² = c²/a², тому r₁² = (c²/a²)x² + 2cx + a² = (a + (c/a)x)².
Отже r₁ = a + εx (додатне, бо │x│ ≤ a, ε < 1). Так само r₂ = a - εx.

**Крок 2 (еліпс).** Директриси x = ±a/ε. Відстані від M до лівої і правої:
d₁ = x + a/ε, d₂ = a/ε - x. Тоді

```
r₁/d₁ = (a + εx)/(x + a/ε)
      = ε(a + εx)/(εx + a) = ε
r₂/d₂ = (a - εx)/(a/ε - x) = ε
```

**Крок 3 (гіпербола, права гілка).** Аналогічно r₁ = εx + a, r₂ = εx - a, d₁ = x + a/ε,
d₂ = x - a/ε. Множимо чисельник і знаменник на ε - знову ε. Ліва гілка: r₁ = -εx - a,
r₂ = a - εx, d₁ = -a/ε - x, d₂ = a/ε - x, відношення теж ε.

**Крок 4 (парабола).** За означенням r = d = x + p/2, тому r/d = 1 = ε.

</details>

**Типова пастка:** брати директрису «не свою»: для правого фокуса - права директриса x = a/ε.

## Д9. Полярне рівняння кривих другого порядку

**Формулювання.** Якщо полюс - у фокусі (лівому для еліпса, правому для гіперболи), полярна
вісь - вісь Ox, то крива має рівняння r = p/(1 - ε·cos φ), де p - полярний параметр.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Через фокус F проводимо хорду, перпендикулярну до полярної осі, її довжина 2p.
Верхній кінець хорди P має полярні координати (p; π/2). Число p - полярний параметр.

**Крок 2.** Для точки P за Д8: p/d₁ = ε, де d₁ - відстань від P до директриси. P стоїть прямо
над фокусом, тому d₁ = відстань від фокуса до директриси = p/ε.

**Крок 3.** Беремо довільну точку M(r; φ) кривої. A - точка перетину осі з директрисою,
B - основа перпендикуляра з M на вісь. Відстань від M до директриси:

```
d = AB = AF + FB = p/ε + r·cos φ
```

**Крок 4.** За Д8 r/d = ε:

```
r = ε(p/ε + r·cos φ) = p + ε·r·cos φ
```

**Крок 5.** Переносимо: r(1 - ε·cos φ) = p ⇒ r = p/(1 - ε·cos φ).

**Крок 6.** Для еліпса і гіперболи p - половина хорди через фокус: підставляємо x = -c у
x²/a² + y²/b² = 1 ⇒ y² = b²(1 - c²/a²) = b⁴/a² ⇒ p = b²/a.
