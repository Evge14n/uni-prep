# Шпаргалка: іспит

Теми 1-8 коротко - [шпаргалка Колоквіуму 1](#/u/an-k1/shpargalka). Тут решта.

```
КРИВІ                        ε
еліпс  x²/a²+y²/b²=1  c²=a²-b²  c/a<1
гіпер. x²/a²-y²/b²=1  c²=a²+b²  c/a>1
  асимптоти y = ±(b/a)x
парабола y²=2px F(p/2;0) x=-p/2  ε=1
директриси x = ±a/ε;  r/d = ε (Д8)
полярне r = p/(1 - ε cos φ), p = b²/a
фокальні радіуси еліпса r = a ± εx

ПОВЕРХНІ
++ + = 1   еліпсоїд
++ - = 1   однопорожнинний гіперболоїд
++ - = -1  двопорожнинний гіперболоїд
++ - = 0   еліптичний конус
++ = 2pz   еліптичний параболоїд
+- = 2pz   гіперболічний параболоїд
++ = 1     еліптичний циліндр (нема z)
+- = 1     гіперболічний циліндр
x² = 2py   параболічний циліндр

ДОВЕДЕННЯ (план)
Д2 i·i=1, i·j=0 ⇒ Σ aᵢbᵢ
Д3 [i,j]=k [j,k]=i [k,i]=j, [i,k]=-j
Д4 ([a,b],c) = розклад за 3-м рядком
Д5 r₁+r₂=2a: корінь праворуч, ², ²,
   b²=a²-c² (a>c)
Д6 те саме, b²=c²-a² (c>a)
Д7 √((x-p/2)²+y²) = x+p/2 ⇒ y²=2px
Д8 r₁=a+εx, d₁=x+a/ε ⇒ r/d=ε
Д9 d = p/ε + r cos φ, r = εd

АЛГОРИТМИ
A⁻¹: det, 9 доповнень, ТРАНСПОНУВАТИ,
     /det, перевірка A·A⁻¹ = E
Гаус: (A│b) → східчаста, вільних n-r
симетрична точка: H, потім M' = 2H-M
f(A): число c → c·E
```
