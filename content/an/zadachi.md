Повні квадрати: (x² - 4x + 4) + (y² + 6y + 9) = 3 + 4 + 9 ⇒ (x - 2)² + (y + 3)² = 16.
Центр (2; -3), R = 4.

</details>

**Задача 6.** Що за поверхня 4x² + 9y² - 36z² = 36? Переріз площиною z = 1.

<details markdown="1"><summary>Розвʼязання</summary>

Ділимо на 36: x²/9 + y²/4 - z²/1 = 1 - один мінус, праворуч 1 ⇒ **однопорожнинний гіперболоїд**.
z = 1: x²/9 + y²/4 = 2 - еліпс.

</details>

**Задача 7.** Що за поверхні: а) x² - y² = 4z; б) x² + y² = z²; в) y² = 4x; г) x² + y² - z² = -1?

<details markdown="1"><summary>Розвʼязання</summary>

**а)** z у 1-му степені, знаки при квадратах різні - гіперболічний параболоїд («сідло»).

**б)** x² + y² - z² = 0, праворуч 0 - конус.

**в)** немає z, парабола - параболічний циліндр.

**г)** праворуч -1 з одним мінусом - двопорожнинний гіперболоїд.

</details>

**Задача 8.** Обернена до A = (1 2 0; 0 1 1; 1 0 1).

<details markdown="1"><summary>Розвʼязання</summary>

det A = 1·(1 - 0) - 2·(0 - 1) + 0 = 3. Доповнення, поставлені транспоновано:

```
      1 ⎛ 1  -2   2⎞
A⁻¹ = ─ ⎜ 1   1  -1⎟
      3 ⎝-1   2   1⎠
```

Перевірка: (1 2 0)·(1; 1; -1) = 3, /3 = 1 ✓.

</details>

**Задача 9.** Ранг матриці (1 2 -1 3; 2 4 -2 6; 3 1 2 4; 1 -3 4 -2).

<details markdown="1"><summary>Розвʼязання</summary>

R2 = 2R1 ⇒ R2 - 2R1 = 0. R3 - 3R1 = (0 -5 5 -5), R4 - R1 = (0 -5 5 -5) - однакові. Лишається 2
ненульові рядки: **rang = 2**.

</details>

**Задача 10.** a = 2p - 3q, b = p + 2q, |p| = 2, |q| = 3, (p, q) = π/3. Площа паралелограма на a, b.

<details markdown="1"><summary>Розвʼязання</summary>

[a, b] = 2[p,p] + 4[p,q] - 3[q,p] - 6[q,q] = 4[p,q] + 3[p,q] = 7[p,q].
│[p,q]│ = 2·3·sin 60° = 3√3 ⇒ S = 21√3 ≈ 36,37. Пастка: -3[q,p] = +3[p,q].

</details>

**Задача 11.** Піраміда A(1; 2; 0), B(3; 0; -3), C(5; 2; 6), D(8; 4; -9). Обʼєм і висота з D.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** AB = (2; -2; -3), AC = (4; 0; 6), AD = (7; 2; -9), мішаний добуток -204 ⇒ V = 204/6 = 34.

**Крок 2.** [AB, AC] = (-12; -24; 8), модуль 28 ⇒ S(ABC) = 14.

**Крок 3.** V = ⅓·S·h ⇒ h = 3·34/14 = 51/7 ≈ 7,29.

</details>

**Задача 12.** Відстань між площинами 2x - 3y + z - 1 = 0 і 4x - 6y + 2z + 5 = 0.

<details markdown="1"><summary>Розвʼязання</summary>

Паралельні: 2/4 = -3/-6 = 1/2. Точка першої: x = y = 0 ⇒ z = 1. Відстань до другої:
│0 - 0 + 2 + 5│/√(16 + 36 + 4) = 7/√56 = √14/4 ≈ 0,94.

</details>
