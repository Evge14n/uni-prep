# Англійська - шпаргалка (1 екран)

```
PRESENT SIMPLE  завжди, звичка, розклад
  he works; Do / Does ...? don't / doesn't
  always, usually, every day, on Fridays
PRESENT CONT.   зараз, тимчасово, план
  am / is / are + -ing
  now, at the moment, Look!, this semester
БЕЗ CONT.: know, like, want, need,
  understand, believe, have (мати)

+ -ING: enjoy, avoid, finish, mind, miss,
  imagine, suggest, practise, fancy,
  feel like, look forward to, put off,
  admit, dislike, mention
+ TO: want, would like, decide, hope,
  plan, agree, afford, expect, manage,
  promise, refuse, offer, pretend, seem,
  learn, fail, intend, demand, attempt
ОБИДВА: begin, start, continue, like,
  love, hate, prefer, forget, remember

V1 після did / will / can / to
V2 yesterday, ago, last ...
V3 після have / has; was + V3 (пасив)
go-went-gone  take-took-taken
write-wrote-written  begin-began-begun
buy-bought  teach-taught  think-thought
```

## Пастки слів

```
take an exam - складати (йти на іспит)
pass an exam - скласти; fail - провалити
pillow - для сну; cushion - диванна
found-founded - заснувати
find-found-found - знайти
set off = set out - вирушати
go off - задзвонити (будильник)
make up for - надолужити
```
