## Частина 1. Означення

### Похідна і дотична (лекція 7)

**Приріст.** Нехай y = f(x) визначена на множині E, x₀ ∈ E. Надамо x₀ приросту Δx так, щоб
x₀ + Δx ∈ E. Тоді Δy = f(x₀ + Δx) - f(x₀) - відповідний приріст функції.

**Похідна.** Якщо існує **скінченна** границя

```
    f(x₀ + Δx) - f(x₀)       Δy
lim ────────────────── = lim ──,
Δx→0       Δx            Δx→0 Δx
```

то її називають похідною функції y = f(x) у точці x₀ і позначають f'(x₀) (або y'(x₀),
[[df // dx]](x₀), [[dy // dx]](x₀)). Отже, похідна - це границя відношення приросту функції до
приросту аргументу, коли приріст аргументу прямує до нуля.

**Нескінченна похідна.** Якщо в точці x₀ границя [[Δy // Δx]] дорівнює +∞ або -∞, кажуть, що в x₀
існує нескінченна похідна. Тоді дотична паралельна осі OY (α = π/2).

**Січна** - пряма через точки графіка M₀(x₀; f(x₀)) і M(x₀ + Δx; f(x₀ + Δx)).

**Дотична** (означення 3.2) до графіка y = f(x) в точці M₀(x₀; f(x₀)) - граничне положення
січної M₀M, коли Δx → 0 (коли M → M₀).

**Нормаль** (означення 3.3) - пряма через M₀(x₀; f(x₀)), перпендикулярна до дотичної.

**Геометричний зміст похідної**: f'(x₀) - кутовий коефіцієнт дотичної: f'(x₀) = k = tg α.

**Фізичний зміст.** Точка рухається за законом S = f(t). [[ΔS // Δt]] - середня швидкість за
час Δt, а v(t₀) = lim [[ΔS // Δt]] = S'(t₀) - миттєва швидкість у момент t₀.

**Односторонні похідні** (означення 3.4). Якщо існує скінченна границя
[[f(x₀ + Δx) - f(x₀) // Δx]] при Δx → +0 (при Δx → -0), її називають правою (лівою)
похідною в точці x₀ і позначають f'₊(x₀) (f'₋(x₀)).

**Теорема 3.1** (без номера в списку, але потрібна): f має похідну в x₀ ⇔ існують f'₊(x₀) і
f'₋(x₀) і вони рівні; тоді f'₊(x₀) = f'₋(x₀) = f'(x₀).

### Диференційовність (лекція 7)

**Диференційовна в точці** (означення 3.5). Нехай y = f(x) визначена на E, x₀ ∈ E. Функцію
називають диференційовною в точці x₀, якщо її приріст у цій точці можна записати у вигляді

```
Δy = A·Δx + α(Δx)·Δx,
```

де A - деяка стала, незалежна від Δx, а α(Δx) → 0, коли Δx → 0.
Те саме: Δy = A·Δx + o(Δx).

**Диференційовна на інтервалі** (a; b) (означення 3.6) - диференційовна в кожній точці інтервалу.

**Диференційовна на відрізку** [a; b] (означення 3.7) - диференційовна на (a; b), має праву
похідну в точці a і ліву похідну в точці b.

**Диференціювання** - процедура знаходження похідної.

### Диференціал (лекція 8)

**Диференціал** функції y = f(x) у точці x₀ - лінійна відносно Δx частина її приросту.
Позначають df(x₀): df(x₀) = A·Δx = f'(x₀)·Δx. Для незалежної змінної Δx = dx, тому
df(x₀) = f'(x₀)dx.

**Диференціал на проміжку.** Якщо f диференційовна в кожній точці проміжку E, вираз f'(x)dx
називають диференціалом функції і позначають dy: dy = f'(x)dx = y'dx. Це ще «перший диференціал»
або «диференціал першого порядку».

**Геометричний зміст диференціала**: df(x₀) - приріст ординати дотичної, проведеної в точці
M₀(x₀; f(x₀)), при прирості аргументу Δx.

**Фізичний зміст**: dS(t₀) = v(t₀)Δt - шлях, який пройшла б точка за час Δt, якби від моменту t₀
рухалась рівномірно з набутою в t₀ швидкістю.

**Інваріантність форми першого диференціала**: перший диференціал дорівнює добутку похідної
на диференціал аргументу (dy = f'(x)dx), незалежно від того, чи аргумент x - незалежна змінна,
чи функція іншої незалежної змінної.

**Гранична абсолютна і відносна похибки.** Якщо |Δx| ≤ α_x, то за граничну абсолютну похибку
функції беруть α_y = |y'|·α_x, а за граничну відносну δ_y = [[α_y // |y|]] = |[[y' // y]]|·α_x.

### Вищі порядки (лекція 9)

**Друга похідна** - похідна від похідної першого порядку: f''(x) = (f'(x))', також
[[d²y // dx²]] = [[d // dx]]([[dy // dx]]).

**Похідна n-го порядку** - похідна першого порядку від похідної (n - 1)-го порядку:
f⁽ⁿ⁾(x) = (f⁽ⁿ⁻¹⁾(x))'.

**Прискорення**: a(t) = lim [[Δv // Δt]] = S''(t) - фізичний зміст другої похідної.

**Диференціал другого порядку** - диференціал від першого диференціала, взятий при тому самому
прирості аргументу: d²y = d(dy).

**Диференціал n-го порядку** - диференціал від диференціала (n - 1)-го порядку при тому самому
прирості аргументу: dⁿy = d(dⁿ⁻¹y). Для незалежної x: dⁿy = f⁽ⁿ⁾(x)dxⁿ.

**Формула Лейбніца**: (uv)⁽ⁿ⁾ = Σ Cₙᵏ u⁽ⁿ⁻ᵏ⁾v⁽ᵏ⁾ (k від 0 до n), u⁽⁰⁾ = u, v⁽⁰⁾ = v.

### Теореми про середнє і Тейлор (лекція 10)

**Формула скінченних приростів**: f(b) - f(a) = f'(c)(b - a) (з теореми Лагранжа).
**Узагальнена формула скінченних приростів** - формула з теореми Коші.

**Многочлен Тейлора** функції f у точці x₀:

```
                f'(x₀)
Pₙ(x) = f(x₀) + ──────(x - x₀) + ...
                  1!
     f⁽ⁿ⁾(x₀)
   + ────────(x - x₀)ⁿ
        n!
```

Він і його похідні до n-го порядку в точці x₀ мають ті самі значення, що і f.

**Залишковий член**: rₙ(x) = f(x) - Pₙ(x). **Формула Тейлора**: f(x) = Pₙ(x) + rₙ(x).

**Залишковий член у формі Лагранжа**: rₙ(x) = [[f⁽ⁿ⁺¹⁾(c) // (n + 1)!]](x - x₀)ⁿ⁺¹, c лежить
між x і x₀ (c = x₀ + θ(x - x₀), 0 < θ < 1). **У формі Пеано**: rₙ(x) = o((x - x₀)ⁿ).

**Формула Маклорена** - формула Тейлора при x₀ = 0.

### Дослідження функції (лекція 11)

**Зростаюча в точці** x₀: існує окіл U_δ(x₀), такий що ∀x ∈ (x₀ - δ; x₀) f(x) < f(x₀),
а ∀x ∈ (x₀; x₀ + δ) f(x₀) < f(x). **Спадна в точці** - нерівності навпаки.

**Зростаюча на множині** E: ∀x₁, x₂ ∈ E з x₁ < x₂ виконується f(x₁) < f(x₂).
**Спадна**: з x₁ < x₂ випливає f(x₁) > f(x₂).

**Точка максимуму** x₀: існує окіл U_δ(x₀), що для будь-якого x з нього, x ≠ x₀,
виконується f(x) < f(x₀). **Точка мінімуму**: f(x) > f(x₀).
Максимуми і мінімуми - **точки локального екстремуму**.

**Стаціонарні точки** - точки, у яких похідна дорівнює нулю.
**Критичні точки** - стаціонарні точки і точки, у яких функція неперервна, але похідна не існує.

**Опуклий донизу** на E графік - лежить не нижче дотичної, проведеної в будь-якій точці E.
**Опуклий доверху** - лежить не вище дотичної в будь-якій точці E.

**Точка перегину** x₀ - якщо по різні сторони від точки (x₀; f(x₀)) графік має різну опуклість.

**Похила асимптота** y = kx + b при x → ∞: f(x) = kx + b + α(x), де α(x) → 0 при x → ∞.
Звідси k = lim [[f(x) // x]], b = lim (f(x) - kx).

**Горизонтальна асимптота** y = B: lim f(x) = B при x → +∞ (або x → -∞).

**Вертикальна асимптота** x = a: хоча б одна з односторонніх границь у точці a дорівнює
нескінченності.

## Частина 2. Теореми №21-37

### №21. Диференційовність ⇔ скінченна похідна

**Формулювання** (теорема 3.2, лекція 7). Для того, щоб функція f(x) була диференційовною в
точці x₀, необхідно і достатньо, щоб вона мала в цій точці скінченну похідну. При цьому A = f'(x₀).

**Що це означає простими словами.** «Диференційовна» (приріст = лінійна частина + дрібниця)
і «має скінченну похідну» - одне й те саме. Тому в задачах ці слова взаємозамінні.

<details markdown="1"><summary>Доведення</summary>

**Необхідність** (диференційовна ⇒ є похідна).

**Крок 1.** За означенням диференційовності Δy = A·Δx + α(Δx)·Δx, α(Δx) → 0.

**Крок 2.** Ділимо на Δx ≠ 0: [[Δy // Δx]] = A + α(Δx).

**Крок 3.** Переходимо до границі при Δx → 0. A - стала, α(Δx) → 0, тому
lim [[Δy // Δx]] = A.

**Крок 4.** Але ця границя за означенням і є f'(x₀). Отже, похідна існує, скінченна, і A = f'(x₀).

**Достатність** (є похідна ⇒ диференційовна).

**Крок 5.** Нехай lim [[Δy // Δx]] = f'(x₀) = A. Різниця між змінною і її границею - нескінченно
мала, тому [[Δy // Δx]] = A + α(Δx), де α(Δx) → 0 при Δx → 0.

**Крок 6.** Множимо на Δx: Δy = A·Δx + α(Δx)·Δx. Це і є означення диференційовності.

</details>

**Додаток (теорема 3.3, питання 22).** Якщо f диференційовна в x₀, то вона неперервна в x₀.
Доведення: з Δy = A·Δx + α(Δx)·Δx видно, що при Δx → 0 і Δy → 0, а це означення неперервності
в термінах приростів. Обернене **неправильне**: y = |x| неперервна в 0, але f'₊(0) = 1,
f'₋(0) = -1, похідної нема.

**Типова пастка на колоквіумі.** Забути слово «скінченну». y = ∛x у нулі має похідну +∞, але не
диференційовна. І переплутати напрям: «неперервна ⇒ диференційовна» - хибне твердження.

### №22. Похідна суми, добутку і частки

**Формулювання** (лекція 7). Якщо u(x) і v(x) мають похідні в точці x₀, то сума, добуток і частка
(при v(x₀) ≠ 0) теж мають похідні, і

```
(u + v)'(x₀) = u'(x₀) + v'(x₀)
(u·v)'(x₀) = u'(x₀)v(x₀) + u(x₀)v'(x₀)
 ⎛u⎞'       u'(x₀)v(x₀) - v'(x₀)u(x₀)
 ⎜─⎟ (x₀) = ─────────────────────────
 ⎝v⎠                v²(x₀)
```

Наслідок: (C·f)'(x₀) = C·f'(x₀).

**Що це означає простими словами.** Похідна суми - сума похідних. Для добутку «похідна першого
на другий плюс перший на похідну другого». Для частки те саме, але з мінусом і поділити на v².

<details markdown="1"><summary>Доведення</summary>

Позначимо Δu, Δv, Δy - прирости u, v, y у точці x₀ при прирості Δx.

**Сума. Крок 1.** y = u + v. Δy = (u(x₀ + Δx) + v(x₀ + Δx)) - (u(x₀) + v(x₀)) = Δu + Δv
(просто перегрупували доданки).

**Крок 2.** [[Δy // Δx]] = [[Δu // Δx]] + [[Δv // Δx]]. При Δx → 0 кожен доданок прямує до своєї
похідної (вони існують за умовою), а границя суми - сума границь. Маємо u'(x₀) + v'(x₀).

**Добуток. Крок 3.** y = u·v. Додаємо і віднімаємо u(x₀)v(x₀ + Δx):

```
Δy = u(x₀+Δx)v(x₀+Δx) - u(x₀)v(x₀)
   = Δu·v(x₀ + Δx) + u(x₀)·Δv
```

**Крок 4.** Ділимо на Δx: [[Δy // Δx]] = [[Δu // Δx]]·v(x₀ + Δx) + u(x₀)·[[Δv // Δx]].

**Крок 5.** Переходимо до границі. Тут потрібна **неперервність** v у x₀: вона випливає з
диференційовності (додаток до №21), тому v(x₀ + Δx) → v(x₀). Отримуємо u'(x₀)v(x₀) + u(x₀)v'(x₀).

**Частка. Крок 6.** v неперервна в x₀ і v(x₀) ≠ 0, тому є δ-окіл, де v(x) ≠ 0. Беремо |Δx| < δ.

**Крок 7.** Зводимо до спільного знаменника, додаємо і віднімаємо u(x₀)v(x₀):

```
     u(x₀+Δx)   u(x₀)
Δy = ──────── - ───── =
     v(x₀+Δx)   v(x₀)
     Δu·v(x₀) - u(x₀)·Δv
   = ───────────────────
      v(x₀)·v(x₀ + Δx)
```

**Крок 8.** Ділимо на Δx і переходимо до границі, знову з v(x₀ + Δx) → v(x₀):
[[Δy // Δx]] → [[u'(x₀)v(x₀) - u(x₀)v'(x₀) // v²(x₀)]].

</details>

**Типова пастка на колоквіумі.** (uv)' = u'·v' - неправильно. У частці переставити доданки
(uv' - u'v) - отримаєш похідну з протилежним знаком. І забути, що в доведенні добутку потрібна
неперервність v (беруть з диференційовності).

### №23. Похідна оберненої функції

**Формулювання** (лекція 7). Нехай y = f(x) неперервна і строго монотонна в деякому околі точки
x₀ і існує похідна f'(x₀) ≠ 0. Тоді обернена функція x = φ(y) (x = f⁻¹(y)) має похідну у
відповідній точці y₀ = f(x₀), і

```
          1                    1
φ'(y₀) = ──────,  тобто x'ᵧ = ───
         f'(x₀)                y'ₓ
```

**Що це означає простими словами.** Графік оберненої функції - той самий графік, тільки «з
іншого боку». Тому кут нахилу дотичної відносно іншої осі дає обернений коефіцієнт.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** f неперервна і строго монотонна біля x₀, тому за теоремою про обернену функцію
(лекція 6) обернена φ визначена, строго монотонна і неперервна біля y₀ = f(x₀).

**Крок 2.** Даємо y₀ приріст Δy ≠ 0. Приріст оберненої: Δx = φ(y₀ + Δy) - φ(y₀). Через строгу
монотонність Δx ≠ 0 (різним y відповідають різні x). Тому можна записати

```
Δx     1
── = ─────
Δy   Δy/Δx
```

**Крок 3.** φ неперервна, тому Δy → 0 ⇔ Δx → 0 (умови рівносильні).

**Крок 4.** Переходимо до границі при Δy → 0. Знаменник [[Δy // Δx]] → f'(x₀) ≠ 0, тому
lim [[Δx // Δy]] = [[1 // f'(x₀)]]. Отже, φ'(y₀) = [[1 // f'(x₀)]].

</details>

**Типова пастка на колоквіумі.** Пропущена умова f'(x₀) ≠ 0 (на нуль не ділять) або «строго
монотонна» (без неї оберненої може не бути). Приклад застосування: (arcsin x)' = [[1 // cos y]] =
[[1 // √(1 - x²)]], бо x = sin y, y ∈ (-π/2; π/2).

### №24. Похідна складеної функції

**Формулювання** (лекція 7). Нехай x = φ(t) має похідну в точці t₀, а y = f(x) має похідну в
точці x₀ = φ(t₀). Тоді складена функція y = f(φ(t)) має похідну в t₀:

```
(f(φ(t)))' = f'(φ(t₀))·φ'(t₀)
```

**Що це означає простими словами.** Швидкості множаться: якщо x міняється в 3 рази швидше за t,
а y в 2 рази швидше за x, то y міняється в 6 разів швидше за t.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Даємо t₀ приріст Δt. Нехай Δx - відповідний приріст x = φ(t), Δy - приріст y = f(x).

**Крок 2.** f має похідну в x₀, отже, диференційовна там (№21), і

```
Δy = f'(x₀)Δx + α(Δx)Δx,   (1)
α(Δx) → 0, коли Δx → 0.
```

(Якщо раптом Δx = 0, вважаємо α(0) = 0, тоді (1) теж правильна - це уточнення до лекції.)

**Крок 3.** Ділимо (1) на Δt:

```
Δy          Δx          Δx
── = f'(x₀)·── + α(Δx)·──   (2)
Δt          Δt          Δt
```

**Крок 4.** φ має похідну в t₀, тому lim [[Δx // Δt]] = φ'(t₀).

**Крок 5.** φ диференційовна, отже, неперервна: Δt → 0 ⇒ Δx → 0 ⇒ α(Δx) → 0.

**Крок 6.** Переходимо в (2) до границі при Δt → 0: другий доданок → 0·φ'(t₀) = 0. Лишається
y'(t₀) = f'(x₀)·φ'(t₀) = f'(φ(t₀))·φ'(t₀).

</details>

**Типова пастка на колоквіумі.** Забути множник «похідна внутрішньої»: (sin 3x)' = 3cos 3x, а не
cos 3x. І плутати sin³x = (sin x)³ з sin(x³): (sin³x)' = 3sin²x·cos x, (sin x³)' = 3x²·cos x³.

### №25. Теорема Ферма

**Формулювання** (лекція 10). Нехай функція y = f(x) неперервна на відрізку [a; b] і в точці x₀
цього інтервалу (тобто внутрішній, x₀ ∈ (a; b)) приймає своє найбільше або найменше значення.
Тоді, якщо існує похідна в цій точці, то вона дорівнює нулю: f'(x₀) = 0.

**Що це означає простими словами.** На «вершині гори» чи на «дні ями» (якщо там нема гострого
кута) дотична горизонтальна - паралельна осі OX.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Нехай для визначеності в x₀ найбільше значення. Тоді для будь-якого Δx, при якому
x₀ + Δx ∈ [a; b]:
Δy = f(x₀ + Δx) - f(x₀) ≤ 0 (жодне значення не більше за f(x₀)).

**Крок 2.** Дивимось на знак [[Δy // Δx]]: якщо Δx > 0, то [[Δy // Δx]] ≤ 0 (≤ 0 ділимо на додатне);
якщо Δx < 0, то [[Δy // Δx]] ≥ 0 (≤ 0 ділимо на відʼємне).

**Крок 3.** Граничний перехід у нерівностях: права границя (Δx → +0) ≤ 0, ліва (Δx → -0) ≥ 0.

**Крок 4.** За умовою похідна існує, тому обидві односторонні границі рівні f'(x₀). Число,
яке водночас ≤ 0 і ≥ 0, - це 0. Отже, f'(x₀) = 0. Для найменшого значення - так само.

</details>

**Типова пастка на колоквіумі.** Точка мусить бути **внутрішньою**. На кінці відрізка
найбільше значення може бути, а похідна там не нуль (f(x) = x на [0; 1], max у x = 1, f' = 1).
І умова «якщо існує похідна»: |x| має мінімум у 0, а похідної там нема.

### №26. Теорема Ролля

**Формулювання** (лекція 10). Нехай функція f(x): 1) визначена і неперервна на відрізку [a; b];
2) має похідну на інтервалі (a; b); 3) f(a) = f(b). Тоді існує точка c ∈ (a; b), що f'(c) = 0.

**Що це означає простими словами.** Якщо гладка крива почалася і закінчилася на одній висоті,
десь між кінцями є точка з горизонтальною дотичною (вершина або дно).
**Наслідок**: між двома нулями диференційовної функції є хоча б один нуль її похідної.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** f неперервна на [a; b], тому за **теоремою Вейєрштрасса** вона досягає на відрізку
найменшого m = f(x₁) і найбільшого M = f(x₂) значень, x₁, x₂ ∈ [a; b], і m ≤ f(x) ≤ M.

**Крок 2.** Випадок m = M: тоді f стала, y' = 0 у будь-якій точці (a; b). Готово.

**Крок 3.** Випадок m < M. Якби і x₁, і x₂ були кінцями відрізка, то f(x₁) = f(x₂) (бо
f(a) = f(b)), тобто m = M - а ми у випадку m < M. Тому хоча б одна з точок x₁ чи x₂ лежить
**всередині** (a; b).
Назвемо її c.

**Крок 4.** За умовою 2) у c існує похідна, а f набуває в c найбільшого (або найменшого)
значення. За **теоремою Ферма** f'(c) = 0.

</details>

**Типова пастка на колоквіумі.** Сплутати: неперервна на **відрізку**, похідна на **інтервалі**.
Пропустити умову f(a) = f(b) (без неї Ролль не працює: f(x) = x на [0; 1]). Приклад, де ламається
умова 2): f(x) = |x| на [-1; 1], f(-1) = f(1), але f' ніде не нуль.

### №27. Теорема Лагранжа. Наслідки

**Формулювання** (лекція 10). Нехай: 1) функція f(x) визначена і неперервна на відрізку [a; b];
2) має похідну на інтервалі (a; b). Тоді існує така точка c ∈ (a; b), що

```
f(b) - f(a) = f'(c)(b - a).
```

**Наслідок 1.** Якщо f неперервна на проміжку E і в усіх його внутрішніх точках f'(x) = 0, то f
стала на E.
**Наслідок 2.** Якщо f і g неперервні на E і в усіх внутрішніх точках f'(x) = g'(x), то
f(x) = g(x) + C.

**Що це означає простими словами.** Середня швидкість за весь шлях [[f(b) - f(a) // b - a]] хоча б в
один момент дорівнює миттєвій. Геометрично: є точка, де дотична паралельна хорді AB.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Допоміжна функція (від f віднімаємо хорду AB):

```
                     f(b) - f(a)
F(x) = f(x) - f(a) - ───────────(x - a)
                        b - a
```

**Крок 2.** Перевіряємо умови Ролля для F. 1) F неперервна на [a; b] - лінійна комбінація
неперервної f, сталих і лінійної функції (x - a).

**Крок 3.** 2) F'(x) = f'(x) - [[f(b) - f(a) // b - a]] існує в усіх точках (a; b).

**Крок 4.** 3) F(a) = f(a) - f(a) - 0 = 0; F(b) = f(b) - f(a) - (f(b) - f(a)) = 0. Отже,
F(a) = F(b).

**Крок 5.** За Роллем існує c ∈ (a; b), F'(c) = 0, тобто f'(c) - [[f(b) - f(a) // b - a]] = 0.
Звідси f(b) - f(a) = f'(c)(b - a).

**Наслідки** [у лекції без доведення - стандартне].

**Крок 6.** Наслідок 1: беремо будь-які x₁ < x₂ з E. На [x₁; x₂] виконані умови Лагранжа, тому
f(x₂) - f(x₁) = f'(c)(x₂ - x₁) = 0·(x₂ - x₁) = 0. Значить, усі значення однакові: f стала.

**Крок 7.** Наслідок 2: h(x) = f(x) - g(x) має h'(x) = f'(x) - g'(x) = 0, за наслідком 1 h = C.

</details>

**Типова пастка на колоквіумі.** Додати «зайву» умову f(a) = f(b) - це вже Ролль, у Лагранжа її
нема. Записати формулу без (b - a): f(b) - f(a) = f'(c) - неправильно.

### №28. Теорема Коші

**Формулювання** (лекція 10). Нехай: 1) функції f(x) і g(x) визначені і неперервні на [a; b];
2) існують похідні f'(x) і g'(x) на (a; b); 3) g'(x) ≠ 0 для всіх x ∈ (a; b). Тоді існує точка
c ∈ (a; b), така що

```
f(b) - f(a)   f'(c)
─────────── = ─────
g(b) - g(a)   g'(c)
```

**Що це означає простими словами.** Те саме, що Лагранж, але для двох функцій одночасно
(узагальнена формула скінченних приростів). При g(x) = x - рівно Лагранж.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Спершу g(a) ≠ g(b), інакше ділили б на нуль. Якби g(a) = g(b), то g задовольняла б
умови Ролля і десь g'(c) = 0. Але за умовою 3) g' ≠ 0 на (a; b). Отже, g(a) ≠ g(b).

**Крок 2.** Допоміжна функція:

```
F(x) = f(x) - f(a) - K·(g(x) - g(a)),

     f(b) - f(a)
K = ───────────  (стале число)
     g(b) - g(a)
```

**Крок 3.** F неперервна на [a; b] (різниця неперервних), диференційовна на (a; b) (різниця
диференційовних), F(a) = 0 і F(b) = f(b) - f(a) - (f(b) - f(a)) = 0.

**Крок 4.** За Роллем ∃c ∈ (a; b): F'(c) = 0, тобто f'(c) - [[f(b) - f(a) // g(b) - g(a)]]·g'(c) = 0.

**Крок 5.** g'(c) ≠ 0, ділимо на нього і отримуємо формулу Коші.

</details>

**Типова пастка на колоквіумі.** Пропустити умову g'(x) ≠ 0. «Довести» Коші, застосувавши
Лагранжа окремо до f і до g: вийдуть **різні** точки c₁ і c₂, а в теоремі c одна.

### №29. Теорема Лопіталя

**Формулювання** (0/0, лекція 10). Нехай: 1) f(x) і g(x) визначені в деякому околі точки a,
можливо, за винятком самої a; 2) lim f(x) = lim g(x) = 0 при x → a; 3) існують похідні f'(x),
g'(x) у цьому околі; 4) g'(x) ≠ 0 у цьому околі; 5) існує (скінченна чи нескінченна)
lim [[f'(x) // g'(x)]]. Тоді існує lim [[f(x) // g(x)]], причому

```
    f(x)       f'(x)
lim ──── = lim ─────
x→a g(x)   x→a g'(x)
```

Так само для ∞/∞ (умова 2: lim f = lim g = ∞) і для a = ∞, -∞, +∞, x₀ ± 0.

**Що це означає простими словами.** Коли і чисельник, і знаменник прямують до нуля, важить, хто
з них «швидше» прямує, а швидкість - це похідна.

<details markdown="1"><summary>Доведення (0/0)</summary>

**Крок 1.** Якщо f і g не визначені в a, довизначимо: f(a) = g(a) = 0. Тепер вони неперервні в a
(бо границі нулі).

**Крок 2.** Беремо будь-яку послідовність xₙ → a, xₙ ≠ a, з того околу. Для визначеності xₙ > a.
Розглядаємо відрізок [a; xₙ].

**Крок 3.** На [a; xₙ] f і g задовольняють усі умови **теореми Коші**, тому існує cₙ ∈ (a; xₙ):

```
f(xₙ) - f(a)   f'(cₙ)
──────────── = ──────
g(xₙ) - g(a)   g'(cₙ)
```

**Крок 4.** f(a) = g(a) = 0, тому [[f(xₙ) // g(xₙ)]] = [[f'(cₙ) // g'(cₙ)]].

**Крок 5.** a < cₙ < xₙ → a, тому cₙ → a (теорема про проміжну послідовність).

**Крок 6.** За умовою 5) і означенням границі за Гейне [[f'(cₙ) // g'(cₙ)]] → lim [[f'(x) // g'(x)]].
Значить, і [[f(xₙ) // g(xₙ)]] прямує до тієї самої границі.

**Крок 7.** Послідовність xₙ була довільна, тому за Гейне lim [[f(x) // g(x)]] = lim [[f'(x) // g'(x)]].

**Випадок a = ∞** (з лекції): заміна x = 1/z, z → 0, і вже доведений випадок 0/0; множники
(-1/z²) у чисельнику і знаменнику скорочуються.
Випадок ∞/∞ у лекції сформульовано без доведення.

</details>

**Типова пастка на колоквіумі.** Рахувати (f/g)' замість f'/g'. Застосувати без невизначеності
(lim (x + 1)/(x + 2) при x → 0 дорівнює 1/2, а «Лопіталь» дав би 1). Написати, що
lim f'/g' має бути обовʼязково **скінченною** - у лекції «скінченна чи нескінченна».

### №30. Ознака монотонності функції

**Формулювання** (теорема 1, лекція 11). Нехай y = f(x) має похідну на множині E (проміжку).
Якщо для довільного x ∈ E f'(x) > 0, то f монотонно зростає на E; якщо f'(x) < 0 - монотонно
спадає на E.

Ще в лекції: диференційовна на (a; b) функція неспадна (незростаюча) ⇔ ∀x ∈ (a; b)
f'(x) ≥ 0 (f'(x) ≤ 0).

**Що це означає простими словами.** Похідна - швидкість. Якщо вона весь час додатна, функція
весь час іде вгору.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Беремо будь-які x₁, x₂ ∈ E, x₁ < x₂. Відрізок [x₁; x₂] ⊂ E.

**Крок 2.** На [x₁; x₂] f задовольняє умови Лагранжа (має похідну, отже, неперервна), тому
∃c ∈ (x₁; x₂): f(x₂) - f(x₁) = f'(c)(x₂ - x₁).

**Крок 3.** Якщо f' > 0, то f'(c) > 0, і x₂ - x₁ > 0. Добуток двох додатних додатний, тому
f(x₂) - f(x₁) > 0, тобто f(x₂) > f(x₁). Це і є зростання.

**Крок 4.** Для f' < 0 так само: добуток відʼємний, f(x₂) < f(x₁) - спадання.

</details>

**Типова пастка на колоквіумі.** Обернене до строгої версії хибне: y = x³ строго зростає, але
f'(0) = 0. Тобто f' > 0 - достатня умова зростання, але не необхідна.

### №31. Необхідна умова екстремуму

**Формулювання** (теорема 2, лекція 11). Нехай y = f(x) визначена на E, x₀ - внутрішня точка E.
Нехай f має екстремум у x₀ і існує похідна в цій точці. Тоді f'(x₀) = 0.
**Наслідок**: якщо f має екстремум у x₀, то f'(x₀) = 0 або f'(x₀) не існує.

**Що це означає простими словами.** Екстремуми шукаємо лише серед критичних точок. Але не кожна
критична точка - екстремум.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** За означенням екстремуму є δ-окіл (x₀ - δ; x₀ + δ), у якому для всіх x ≠ x₀
виконується f(x) < f(x₀) (максимум) або f(x) > f(x₀) (мінімум).

**Крок 2.** Отже, на цьому околі f набуває в x₀ найбільшого (або найменшого) значення, і x₀ -
внутрішня точка околу.

**Крок 3.** Похідна в x₀ існує за умовою, тому за **теоремою Ферма** f'(x₀) = 0.

</details>

**Типова пастка на колоквіумі.** Сказати «f'(x₀) = 0 ⇒ екстремум». Контрприклад з лекції:
y = x⁵, y' = 5x⁴, y'(0) = 0, а екстремуму нема (функція зростає скрізь). І забути точки, де
похідної нема: |x| має мінімум у 0.

### №32. Перша достатня умова екстремуму

**Формулювання** (теорема 3, лекція 11). Нехай y = f(x) визначена і має похідну на E, x₀ ∈ E -
стаціонарна точка. Тоді: 1) якщо при переході через x₀ похідна міняє знак на протилежний, то x₀ -
точка екстремуму: з «+» на «-» - максимум, з «-» на «+» - мінімум; 2) якщо знак не міняється,
x₀ не є точкою екстремуму.
Теорема лишається вірною, якщо f неперервна в x₀, але не має там похідної.

**Що це означає простими словами.** Ішли вгору, потім вниз - були на вершині. Ішли вниз, потім
вгору - були на дні. Весь час вгору - ні вершини, ні дна.

<details markdown="1"><summary>Доведення</summary>

Нехай f'(x₀) = 0, на (x₀ - δ; x₀) f' > 0, на (x₀; x₀ + δ) f' < 0.

**Крок 1.** Беремо будь-яке x₁ ∈ (x₀ - δ; x₀). На [x₁; x₀] умови Лагранжа виконані:
f(x₀) - f(x₁) = f'(c₁)(x₀ - x₁), c₁ ∈ (x₁; x₀).

**Крок 2.** f'(c₁) > 0 (c₁ лівіше x₀), x₀ - x₁ > 0, тому f(x₀) > f(x₁).

**Крок 3.** Беремо x₂ ∈ (x₀; x₀ + δ). Лагранж на [x₀; x₂]: f(x₂) - f(x₀) = f'(c₂)(x₂ - x₀).

**Крок 4.** f'(c₂) < 0, x₂ - x₀ > 0, тому f(x₂) < f(x₀).

**Крок 5.** І зліва, і справа значення менші за f(x₀) - це максимум. Зміна з «-» на «+» -
аналогічно, мінімум.

**Крок 6.** Знак не міняється, нехай f' > 0 з обох боків. Ті самі кроки дають f(x) < f(x₀) зліва
і f(x) > f(x₀) справа - функція зростає в точці x₀, екстремуму нема.

</details>

**Типова пастка на колоквіумі.** Сплутати напрям: «+ на -» - це **максимум**, а не мінімум. Якщо
не впевнений, намалюй стрілки ↗↘.

### №33. Друга достатня умова екстремуму

**Формулювання** (теорема 4, лекція 11). Нехай y = f(x) визначена і має похідну на E, x₀ ∈ E -
стаціонарна точка (f'(x₀) = 0), і існує f''(x₀). Тоді: якщо f''(x₀) > 0, x₀ - точка мінімуму;
якщо f''(x₀) < 0 - точка максимуму.

**Що це означає простими словами.** f'' > 0 - графік «усміхається» ∪, у стаціонарній точці дно.
f'' < 0 - «сумний» ∩, вершина. Якщо f''(x₀) = 0, ця умова нічого не каже.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** f''(x₀) > 0 означає, що функція f' зростає в точці x₀. (Чому: f''(x₀) - границя
[[f'(x) - f'(x₀) // x - x₀]] > 0, тому біля x₀ цей дріб додатний, тобто f'(x) - f'(x₀) має той самий
знак, що x - x₀. Це пояснення додано до лекції.)

**Крок 2.** Значить, є окіл (x₀ - δ; x₀ + δ): зліва f'(x) < f'(x₀), справа f'(x) > f'(x₀).

**Крок 3.** Але f'(x₀) = 0. Тому зліва f'(x) < 0, справа f'(x) > 0.

**Крок 4.** Похідна міняє знак з «-» на «+». За першою достатньою умовою (№32) x₀ - мінімум.

**Крок 5.** f''(x₀) < 0 - аналогічно, знак з «+» на «-», максимум.

</details>

**Типова пастка на колоквіумі.** Переплутати: f'' > 0 - **мінімум** (не максимум). І вважати,
що при f''(x₀) = 0 екстремуму точно нема: y = x⁴ має f''(0) = 0 і мінімум у 0. Тоді треба
перша умова або третя (№34).

### №34. Третя достатня умова екстремуму

**Формулювання** (теорема 5, лекція 11). Нехай y = f(x) визначена на E, x₀ ∈ E - стаціонарна точка,
f має неперервні похідні до n-го порядку включно в околі x₀, причому
f'(x₀) = f''(x₀) = ... = f⁽ⁿ⁻¹⁾(x₀) = 0, а f⁽ⁿ⁾(x₀) ≠ 0. Тоді:
1) n парне (n = 2k) - екстремум: f⁽²ᵏ⁾(x₀) > 0 - мінімум, f⁽²ᵏ⁾(x₀) < 0 - максимум;
2) n непарне (n = 2k - 1) - екстремуму нема.

**Що це означає простими словами.** Дивимось на першу ненульову похідну. Парний порядок -
поводиться як x², x⁴ (дно або вершина). Непарний - як x³, x⁵ (проходить наскрізь).

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Пишемо формулу Тейлора в точці x₀ із залишком у формі Лагранжа. Похідні до (n - 1)-ї
у x₀ нулі, тому від усієї формули лишається тільки залишок:

```
f(x) - f(x₀) =

  f⁽ⁿ⁾(x₀ + θ(x - x₀))
= ────────────────────·(x - x₀)ⁿ
           n!

0 < θ < 1
```

(у лекції в останньому множнику (x₀ - x)ⁿ - на висновок це не впливає.)

**Крок 2.** f⁽ⁿ⁾ неперервна в x₀ і f⁽ⁿ⁾(x₀) ≠ 0, тому є окіл, де знак f⁽ⁿ⁾(x₀ + θ(x - x₀)) такий
самий, як знак f⁽ⁿ⁾(x₀) (стійкість знака неперервної функції).

**Крок 3.** n парне: (x - x₀)ⁿ > 0 і зліва, і справа. Права частина має сталий знак = знак
f⁽ⁿ⁾(x₀). Якщо він «+», то f(x) > f(x₀) навколо - мінімум; якщо «-» - максимум.

**Крок 4.** n непарне: (x - x₀)ⁿ міняє знак при переході через x₀, тому f(x) - f(x₀) зліва і
справа різних знаків - екстремуму нема.

</details>

**Типова пастка на колоквіумі.** Забути, що це для **стаціонарної** точки і що похідні до (n - 1)-ї
всі нулі. Плутати парне/непарне: y = x³ (n = 3, непарне) - екстремуму нема.

### №35. Достатня умова опуклості

**Формулювання** (теорема 6, лекція 11). Нехай y = f(x) має похідну другого порядку на E. Якщо
f''(x) > 0, графік опуклий донизу; якщо f''(x) < 0 - опуклий доверху.

**Що це означає простими словами.** f'' > 0 - нахил дотичної весь час росте, графік вигинається
вгору, як чашка ∪, і лежить над своїми дотичними.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Нехай f'' > 0 на E. Беремо будь-яку x₀ ∈ E і пишемо формулу Тейлора для n = 1 із
залишком Лагранжа:

```
f(x) = f(x₀) + f'(x₀)(x - x₀)
        f''(ξ)
      + ──────(x - x₀)²,
          2!
ξ між x і x₀
```

**Крок 2.** Дотична в x₀: y = f(x₀) + f'(x₀)(x - x₀) - це рівно перші два доданки.

**Крок 3.** Віднімаємо: f(x) - y = [[f''(ξ) // 2!]](x - x₀)² > 0, бо f''(ξ) > 0 і квадрат
додатний (x ≠ x₀).

**Крок 4.** Отже, f(x) > y: графік вище дотичної. x₀ і x довільні - графік опуклий донизу на E.
Для f'' < 0 - нерівність навпаки, опуклий доверху.

</details>

**Типова пастка на колоквіумі.** Переплутати назви: у лекції «опуклий донизу» = ∪ = f'' > 0. У
методичці те саме звуть «опукла вниз». Завжди малюй поруч ∪ або ∩.

### №36. Необхідна умова точки перегину

**Формулювання** (теорема 7, лекція 11). Нехай y = f(x) має похідну другого порядку, неперервну в
деякому околі точки x₀, і x₀ - точка перегину графіка. Тоді f''(x₀) = 0.

**Що це означає простими словами.** У точці, де «чашка» переходить у «купол», друга похідна (якщо
вона неперервна) дорівнює нулю.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Від супротивного: нехай f''(x₀) ≠ 0, для визначеності f''(x₀) > 0.

**Крок 2.** f'' неперервна біля x₀, тому за теоремою про стійкість знака неперервної функції є
δ-окіл, де f''(x) > 0 для всіх x ∈ (x₀ - δ; x₀ + δ).

**Крок 3.** За №35 графік у всьому цьому околі опуклий донизу - по обидва боки від x₀ опуклість
однакова.

**Крок 4.** Отже, x₀ не точка перегину - суперечність з умовою. Для f''(x₀) < 0 аналогічно.
Тому f''(x₀) = 0.

</details>

**Типова пастка на колоквіумі.** Обернене хибне: y = x⁴, f''(x) = 12x², f''(0) = 0, але перегину
нема - графік опуклий донизу скрізь. f''(x₀) = 0 - лише «кандидат».

### №37. Достатня умова точки перегину

**Формулювання** (теорема 8, лекція 11). Нехай y = f(x) має похідну другого порядку в деякому околі
точки x₀ і f''(x₀) = 0. Якщо по різні сторони від x₀ друга похідна f''(x) має різні знаки, то точка
(x₀; f(x₀)) є точкою перегину графіка.
Зауваження: теорема лишається вірною, якщо f'(x₀) існує, а f''(x₀) не існує, але f'' міняє знак.

**Що це означає простими словами.** Перевіряємо кандидата: зліва ∪, справа ∩ (або навпаки) -
перегин є.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Нехай зліва від x₀ f'' має один знак, справа - інший.

**Крок 2.** За №35 зліва графік має одну опуклість, справа - протилежну.

**Крок 3.** За означенням точки перегину (різна опуклість по різні боки) (x₀; f(x₀)) - точка
перегину.

**Крок 4.** Якщо f'' **не** міняє знак, крива в околі або вся опукла донизу (f'' > 0), або вся
доверху (f'' < 0) - перегину нема.

</details>

**Типова пастка на колоквіумі.** У лекції точкою перегину названо x₀, а в теоремі перегин -
точка графіка (x₀; f(x₀)). Тому про всяк випадок пиши обидві координати: x = 2, точка (2; f(2)). І «перегин» у точці розриву:
y = 1/(x + 1)³ міняє опуклість при x = -1, але точки перегину нема - функція там не визначена.
