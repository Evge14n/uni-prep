## Тема 1. Похідна: означення, геометричний і фізичний зміст

**Суть.** Беремо точку x₀ і трохи зсуваємо її на Δx. Функція змінюється на
Δy = f(x₀ + Δx) - f(x₀). Відношення [[Δy // Δx]] - це «середня швидкість зміни» функції.
Якщо Δx робити все меншим і цей дріб має **скінченну** границю, то ця границя і є похідна.

```
             f(x₀ + Δx) - f(x₀)
f'(x₀) = lim ──────────────────
         Δx→0        Δx
```

**Геометричний зміст.** Січна через точки M₀ і M, коли M ковзає до M₀, переходить у дотичну.
Похідна - це **кутовий коефіцієнт** дотичної: f'(x₀) = k = tg α, де α - кут дотичної з віссю OX.

```
дотична:  y = f'(x₀)(x - x₀) + y₀

                  1
нормаль:  y = - ──────(x - x₀) + y₀
                f'(x₀)
(нормаль - коли f'(x₀) ≠ 0)
```

Нормаль перпендикулярна до дотичної, тому її кутовий коефіцієнт k₁ = -1/k.

Якщо [[Δy // Δx]] → +∞ або -∞, кажуть, що похідна **нескінченна**. Тоді дотична
вертикальна (паралельна OY), α = π/2. Але «диференційовна» така функція не є (див. тему 2).

**Фізичний зміст.** Точка рухається по прямій, S = f(t) - шлях. Тоді середня швидкість
за час Δt дорівнює [[ΔS // Δt]], а миттєва швидкість v(t₀) = S'(t₀). Прискорення - друга
похідна: a(t) = S''(t) (лекція 9). У лекції ще є «хімічний» зміст (швидкість реакції
Q'(t₀)) і «економічний» (продуктивність праці f'(t₀)) - це та сама ідея: похідна = швидкість зміни.

**Односторонні похідні.** Якщо брати лише Δx → +0, отримаємо праву похідну f'₊(x₀),
лише Δx → -0 - ліву f'₋(x₀). Похідна в точці існує **тоді і лише тоді**, коли обидві
односторонні існують і рівні.

Приклад з лекції: y = |x| у точці 0.

```
               |Δx|   Δx
f'₊(0) = lim   ──── = ── = 1
        Δx→+0  Δx     Δx

               |Δx|   -Δx
f'₋(0) = lim   ──── = ─── = -1
        Δx→-0  Δx     Δx
```

1 ≠ -1, тому похідної в нулі нема (на графіку «кут»).

## Тема 2. Диференційовність і правила диференціювання

**Диференційовна функція** (лекція 7, означення 3.5): її приріст можна записати так

```
Δy = A·Δx + α(Δx)·Δx,
A - стала, не залежить від Δx,
α(Δx) → 0, коли Δx → 0.
```

Тобто приріст = «лінійна частина» A·Δx + «дрібниця» вищого порядку, o(Δx).

Дві важливі теореми:

1. f диференційовна в x₀ ⇔ f має в x₀ **скінченну** похідну, і тоді A = f'(x₀) (теорема №21).
2. Диференційовна в x₀ ⇒ неперервна в x₀. **Обернене хибне**: |x| неперервна в 0, але не
   диференційовна.

Диференційовна на інтервалі (a; b) - у кожній точці інтервалу. На відрізку [a; b] - на
інтервалі, плюс права похідна в a і ліва в b.

**Правила** (теорема №22). Якщо u і v мають похідні:

```
(u + v)' = u' + v'
(u·v)'   = u'·v + u·v'
(C·u)'   = C·u'

 ⎛ u ⎞'   u'·v - u·v'
 ⎜───⎟  = ───────────     (v ≠ 0)
 ⎝ v ⎠        v²
```

Пастка: (u·v)' ≠ u'·v'. У частці спершу u'·v, потім мінус u·v'. Переставиш - знак похідної
стане протилежним.

## Тема 3. Складена і обернена функція. Таблиця похідних

**Складена функція** (теорема №24): «похідна зовнішньої в точці внутрішньої, помножена на
похідну внутрішньої».

```
(f(φ(t)))' = f'(φ(t)) · φ'(t)
```

Приклад: (sin 3x)' = cos 3x · (3x)' = 3cos 3x. Найчастіша помилка - забути множник (3x)' = 3.

Для «матрьошки» з трьох функцій множимо три похідні: (sin³(2x))' = 3sin²(2x)·cos(2x)·2.

**Обернена функція** (теорема №23). Якщо y = f(x) неперервна і **строго монотонна** біля x₀,
існує f'(x₀) і **f'(x₀) ≠ 0**, то обернена x = φ(y) має похідну

```
            1                    1
φ'(y₀) = ───────,   тобто  x'ᵧ = ───
         f'(x₀)                  y'ₓ
```

Так у лекції виводять (arcsin x)' і (arctg x)': arcsin - обернена до sin y, тому
(arcsin x)' = 1/cos y = 1/√(1 - sin²y) = 1/√(1 - x²).

## Тема 4. Логарифмічна похідна, параметрична і неявна функція

**Логарифмічне диференціювання** - для y = u(x)^v(x), коли змінна і в основі, і в степені.
Ні формула (x^α)', ні (aˣ)' тут не підходить.

```
1) логарифмуємо:
   ln y = v·ln u
2) беремо похідну:
   y'/y = v'·ln u + v·u'/u
3) множимо на y:
   y' = u^v·(v'·ln u + v·u'/u)
```

Ліва частина: (ln y)' = y'/y - це похідна складеної функції, бо y = y(x).
Другий спосіб з лекції: u^v = e^(v·ln u), а далі похідна експоненти складеної функції.

Приклад: (xˣ)' = xˣ·(ln x + 1).

**Параметрично задана функція.** x = φ(t), y = ψ(t), φ'(t) ≠ 0:

```
       y'ₜ           (y'ₓ)'ₜ
y'ₓ = ────,  y''ₓₓ = ───────
       x'ₜ             x'ₜ
```

Друга похідна - це похідна від y'ₓ **по t**, ще раз поділена на x'ₜ. Пастка: y''ₓₓ ≠ y''ₜ / x''ₜ.

**Неявно задана функція** F(x; y) = 0. Диференціюємо обидві частини рівності по x і
памʼятаємо, що y = y(x). Тому, наприклад, (y²)' = 2y·y', (e^y)' = e^y·y', (xy)' = y + x·y'.
Потім виражаємо y'.

Приклад з методички: x² + y² = 4 ⇒ 2x + 2y·y' = 0 ⇒ y' = -x/y.

## Тема 5. Диференціал і наближені обчислення

**Диференціал** - лінійна відносно Δx частина приросту: df(x₀) = A·Δx = f'(x₀)·Δx.
Для незалежної змінної Δx = dx, тому

```
dy = f'(x)·dx,     f'(x) = dy/dx
```

Отже, похідна - це відношення диференціала функції до диференціала аргументу.

**Різниця Δy і dy.** Δy - справжній приріст графіка, dy - приріст **дотичної**
(геометричний зміст). Різниця - нескінченно мала вищого порядку, ніж Δx.

Приклад з лекції 8: y = 2x³ + 5x².

```
Δy = (6x² + 10x)Δx
   + Δx·((6x + 5)Δx + 2Δx²)
dy = (6x² + 10x)dx
```

**Фізичний зміст.** dS = v(t₀)·Δt - шлях, який пройшла б точка, якби весь час Δt їхала з
тією швидкістю, яка була в момент t₀.

**Властивості** (як правила похідних): d(u ± v) = du ± dv, d(u·v) = du·v + u·dv,
d(u/v) = [[du·v - dv·u // v²]], d(C·u) = C·du, d(u + C) = du.

**Наближені обчислення.** Якщо Δx мале, Δy ≈ dy:

```
f(x₀ + Δx) ≈ f(x₀) + f'(x₀)·Δx
```

Як вибирати: x₀ - «зручна» точка поруч, у якій f рахується точно (√1, ∛8, sin 30°),
Δx - маленький зсув. Приклад з лекції: √1,0003 ≈ 1 + 0,0003/2 = 1,00015.

**Похибки** (лекція 8): гранична абсолютна похибка функції α_y = |y'|·α_x, відносна
δ_y = |y'/y|·α_x. Для обʼєму кулі V = (4/3)πR³ виходить δ_V = 3·δ_R: щоб обʼєм мав
похибку 1,2 %, радіус треба міряти з похибкою 0,4 %.

**Інваріантність форми першого диференціала.** dy = f'(x)dx правильна і тоді, коли x -
незалежна змінна, і тоді, коли x = φ(t) - функція іншої змінної. Тобто форма першого
диференціала не залежить від того, що таке x.

## Тема 6. Похідні і диференціали вищих порядків. Формула Лейбніца

**Друга похідна** - похідна від першої: f''(x) = (f'(x))'. **n-та похідна** - похідна від
(n - 1)-ї: f⁽ⁿ⁾(x) = (f⁽ⁿ⁻¹⁾(x))'. Похідні від четвертої іноді пишуть римськими цифрами: y^IV, y^V.

Готові n-ті похідні з лекції 9 (корисно для Лейбніца і Тейлора):

```
(xⁿ)⁽ⁿ⁾ = n!,   (xⁿ)⁽ⁿ⁺¹⁾ = 0
(eˣ)⁽ⁿ⁾ = eˣ
(sin x)⁽ⁿ⁾ = sin(x + nπ/2)
(cos x)⁽ⁿ⁾ = cos(x + nπ/2)
                      (n - 1)!
(ln(1+x))⁽ⁿ⁾ = (-1)ⁿ⁻¹ ────────
                      (1 + x)ⁿ
```

Ще з методички: (1/(ax + b))⁽ⁿ⁾ = (-1)ⁿ·n!·aⁿ / (ax + b)ⁿ⁺¹ і (a^(kx))⁽ⁿ⁾ = kⁿ·lnⁿa·a^(kx).

**Формула Лейбніца** - n-та похідна добутку:

```
          n
(uv)⁽ⁿ⁾ = Σ  Cₙᵏ·u⁽ⁿ⁻ᵏ⁾·v⁽ᵏ⁾
         k=0
          n!
Cₙᵏ = ──────────,  u⁽⁰⁾ = u
      k!(n - k)!
```

Коефіцієнти ті самі, що в біномі Ньютона: (uv)'' = u''v + 2u'v' + uv'',
(uv)''' = u'''v + 3u''v' + 3u'v'' + uv'''.

Хитрість: за v бери многочлен (x², x³ + 2), бо його похідні швидко стають нулем, і з
суми лишається 2-4 доданки.

**Фізичний зміст другої похідної**: прискорення a(t) = S''(t).

**Диференціал другого порядку** d²y = d(dy), при тому самому прирості аргументу.

```
x - незалежна (d(dx) = 0):
  d²y = f''(x)·dx²
x = φ(t) - залежна (d²x ≠ 0):
  d²y = f''(x)·dx² + f'(x)·d²x
```

Форма різна, тобто **другий диференціал не інваріантний** (на відміну від першого).
Для незалежної x: dⁿy = f⁽ⁿ⁾(x)·dxⁿ.

## Тема 7. Теореми про середнє: Ферма, Ролля, Лагранжа, Коші

Ланцюжок: **Ферма → Ролль → Лагранж → Коші**. Кожну наступну доводять через попередню.

**Ферма.** Якщо у внутрішній точці x₀ функція набуває найбільшого або найменшого значення
і похідна там існує, то f'(x₀) = 0. Геометрично: дотична у «вершині» горизонтальна.

**Ролль.** f неперервна на **відрізку** [a; b], має похідну на **інтервалі** (a; b),
f(a) = f(b) ⇒ існує c ∈ (a; b), де f'(c) = 0. Наслідок: між двома нулями диференційовної
функції є нуль її похідної.

**Лагранж.** f неперервна на [a; b], має похідну на (a; b) ⇒ існує c ∈ (a; b):

```
f(b) - f(a) = f'(c)·(b - a)
```

Це **формула скінченних приростів**. Геометрично: є точка, де дотична паралельна хорді AB.
Наслідки: f' = 0 на проміжку ⇒ f стала; f' = g' ⇒ f = g + C.

**Коші.** f і g неперервні на [a; b], мають похідні на (a; b), **g'(x) ≠ 0** на (a; b) ⇒

```
f(b) - f(a)   f'(c)
─────────── = ─────,  c ∈ (a; b)
g(b) - g(a)   g'(c)
```

Якщо взяти g(x) = x, отримаємо Лагранжа.

| теорема | умови | що дає |
|---|---|---|
| Ферма | найбільше/найменше у внутрішній точці, f'(x₀) існує | f'(x₀) = 0 |
| Ролль | неперервна на [a; b], похідна на (a; b), f(a) = f(b) | f'(c) = 0 |
| Лагранж | неперервна на [a; b], похідна на (a; b) | f(b) - f(a) = f'(c)(b - a) |
| Коші | для f і g як у Лагранжа + g' ≠ 0 | відношення приростів = f'(c)/g'(c) |

## Тема 8. Правило Лопіталя

Для невизначеностей [[0 // 0]] і [[∞ // ∞]]:

```
    f(x)        f'(x)
lim ──── = lim  ─────
x→a g(x)   x→a  g'(x)
```

Умови: f, g визначені біля a (саму a можна виключити); lim f = lim g = 0 (або ∞);
є похідні f', g' біля a; **g'(x) ≠ 0**; границя справа **існує** (скінченна чи нескінченна).
Точка a може бути x₀, x₀ ± 0, ±∞.

**Головна пастка:** похідна чисельника і похідна знаменника **окремо**. Це не похідна частки!
І спершу переконайся, що є невизначеність: без неї Лопіталь дає неправильну відповідь.

Можна застосовувати кілька разів поспіль. Приклад з лекції:

```
    1 - cos 7x       7 sin 7x
lim ────────── = lim ──────── =
x→0    4x²      x→0     8x

      49 cos 7x   49
= lim ───────── = ──
  x→0     8       8
```

**Інші невизначеності** зводимо до 0/0 або ∞/∞:

| вид | що робимо |
|---|---|
| 0·∞ | f·g = f / (1/g) |
| ∞ - ∞ | спільний знаменник |
| 0⁰, 1^∞, ∞⁰ | u^v = e^(v·ln u), рахуємо границю показника |

Приклад: lim x→+0 x·ln x = lim [[ln x // 1/x]] = lim [[1/x // -1/x²]] = lim (-x) = 0.

## Тема 9. Формула Тейлора і Маклорена

**Ідея.** Замінити функцію многочленом, який у точці x₀ має те саме значення і ті самі похідні
до n-ї включно.

```
               f'(x₀)
f(x) = f(x₀) + ──────(x - x₀) + ...
                 1!
   f⁽ⁿ⁾(x₀)
 + ────────(x - x₀)ⁿ + rₙ(x)
      n!
```

Для многочлена степеня n залишку нема (rₙ = 0) - формула точна.

**Залишковий член:**

```
Лагранжа:
         f⁽ⁿ⁺¹⁾(c)
 rₙ(x) = ─────────(x - x₀)ⁿ⁺¹
         (n + 1)!
 c між x і x₀,
 c = x₀ + θ(x - x₀), 0 < θ < 1

Пеано:
 rₙ(x) = o((x - x₀)ⁿ)
```

Лагранжа - щоб **оцінити похибку числом**. Пеано - щоб знати лише порядок малості (для границь).

**Маклорен** - це Тейлор при x₀ = 0. П'ять формул з лекції 10 (вчити):

```
eˣ = 1 + x + x²/2! + x³/3!
     + ... + xⁿ/n! + rₙ

sin x = x - x³/3! + x⁵/5! - ...
  + (-1)ⁿ⁻¹x²ⁿ⁻¹/(2n - 1)! + r

cos x = 1 - x²/2! + x⁴/4! - ...
  + (-1)ⁿx²ⁿ/(2n)! + r

ln(1 + x) = x - x²/2 + x³/3 - ...
  + (-1)ⁿ⁻¹xⁿ/n + rₙ

(1 + x)^α = 1 + αx
  + α(α - 1)x²/2!
  + α(α - 1)(α - 2)x³/3! + ...
```

Як запамʼятати: у sin лише непарні степені, у cos - парні, знаки чергуються. У ln(1 + x)
у знаменнику **n**, а не n! (там немає факторіалів).

**Застосування.** Наближені значення (e ≈ 2,718, cos 5° ≈ 0,99619) і границі: розкладаємо
чисельник і знаменник і дивимось на перший доданок, що не скоротився.

> Увага: у лекції 10 у формулі (11) у залишку надруковано xⁿ⁻¹, має бути xⁿ⁺¹ (як у формулі (22)
> тієї ж лекції).

## Тема 10. Монотонність і екстремум

**Ознака монотонності** (теорема №30): f'(x) > 0 на E ⇒ f зростає на E; f'(x) < 0 ⇒ спадає.
Доводять через Лагранжа.

**Точка максимуму** x₀: є окіл, де для всіх x ≠ x₀ виконується f(x) < f(x₀).
**Мінімуму**: f(x) > f(x₀). Разом - точки локального екстремуму. «Локального» - бо порівнюємо
лише з точками поруч, а не з усією областю.

**Необхідна умова** (№31): в точці екстремуму f'(x₀) = 0 **або не існує**. Точки, де f' = 0 -
**стаціонарні**; стаціонарні плюс ті, де f неперервна, а f' нема - **критичні**.
Обернене хибне: y = x⁵, y'(0) = 0, а екстремуму нема (функція зростає скрізь).

**Достатні умови:**

```
I (№32): f' міняє знак у x₀
  + на -  ⇒ максимум
  - на +  ⇒ мінімум
  не міняє ⇒ екстремуму нема

II (№33): f'(x₀) = 0, f''(x₀) ≠ 0
  f''(x₀) > 0 ⇒ мінімум
  f''(x₀) < 0 ⇒ максимум

III (№34): f' = f'' = ... = f⁽ⁿ⁻¹⁾ = 0
  у x₀, f⁽ⁿ⁾(x₀) ≠ 0
  n парне ⇒ екстремум
   (f⁽ⁿ⁾ > 0 мін, < 0 макс)
  n непарне ⇒ екстремуму нема
```

Мнемоніка для II: f'' > 0 - «усмішка» ∪, внизу мінімум; f'' < 0 - «сум» ∩, вгорі максимум.

**Алгоритм пошуку екстремумів** (лекція 11):
1. Знайти критичні точки: розвʼязати f'(x) = 0, взяти корені всередині області; додати точки,
   де f' не існує.
2. Визначити знак f' на кожному проміжку між критичними точками.
3. За зміною знака визначити max/min і порахувати f у них.

**Найбільше і найменше значення на відрізку [a; b]**: порахувати f у критичних точках
всередині (a; b) **і на кінцях** a, b, вибрати найбільше і найменше число. Кінці часто
виграють - не забувай їх.

## Тема 11. Опуклість, перегин, асимптоти

**Опуклий донизу** (∪) на E - графік лежить **не нижче** будь-якої своєї дотичної.
**Опуклий доверху** (∩) - не вище дотичних. (У методичці те саме називають «опукла вниз»
і «опукла вгору».)

**Достатня умова** (№35): f'' > 0 на E ⇒ опуклий донизу; f'' < 0 ⇒ опуклий доверху.

**Точка перегину** - точка графіка, по різні боки від якої опуклість різна. У ній дотична
перетинає графік.
- Необхідна умова (№36): якщо f'' неперервна біля x₀ і x₀ - перегин, то f''(x₀) = 0.
- Достатня (№37): f''(x₀) = 0 (або f'' не існує) і f'' **міняє знак** при переході через x₀.
- Обернене до необхідної хибне: y = x⁴, f''(0) = 0, але перегину нема (опукла донизу скрізь).

**Асимптоти:**

```
вертикальна x = a:
  хоча б одна одностороння
  границя в a нескінченна

похила y = kx + b:
          f(x)
  k = lim ────,  b = lim (f(x) - kx)
      x→∞  x         x→∞

горизонтальна y = B:
  B = lim f(x) при x → +∞ (-∞)
```

Похилі шукай окремо для x → +∞ і x → -∞ - вони можуть бути різні. Якщо k = ∞ або
не існує, похилої нема. Горизонтальна - це похила з k = 0.

Де шукати вертикальні: точки, де знаменник 0, і межі області (ln x біля 0). Але якщо
границя скінченна (усувний розрив), асимптоти нема.
