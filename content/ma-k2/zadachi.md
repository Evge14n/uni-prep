## 1. Похідна за означенням

**Задача 1.** Знайдіть похідну f(x) = 1/x у точці x₀ = 2 за означенням.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Приріст функції:

```
       1        1     2 - (2 + Δx)
Δy = ────── - ─── = ────────────
     2 + Δx    2    2(2 + Δx)
          -Δx
     = ──────────
       2(2 + Δx)
```

**Крок 2.** Ділимо на Δx: [[Δy // Δx]] = [[-1 // 2(2 + Δx)]] (Δx скоротилось - так буде завжди).

**Крок 3.** Границя при Δx → 0: [[-1 // 2·2]] = -1/4.

**Відповідь:** f'(2) = -1/4. Перевірка за таблицею: (1/x)' = -1/x², при x = 2 це -1/4.

</details>

## 2. Правила диференціювання

**Задача 2.** y = [[2x + 1 // x² + 1]]. Знайдіть y'.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Частка: u = 2x + 1, u' = 2; v = x² + 1, v' = 2x.

**Крок 2.** За правилом (u/v)' = (u'v - uv')/v²:

```
     2(x² + 1) - (2x + 1)·2x
y' = ───────────────────────
           (x² + 1)²
```

**Крок 3.** Розкриваємо чисельник: 2x² + 2 - 4x² - 2x = -2x² - 2x + 2.

**Відповідь:** y' = [[2(1 - x - x²) // (x² + 1)²]].

</details>

<details markdown="1"><summary>Розвʼязання</summary>

**b) Крок 3.** Спершу спрощуємо логарифм (так легше): y = ln(x - 1) - ln(x + 1).

**Крок 4.** y' = [[1 // x - 1]] - [[1 // x + 1]] = [[(x + 1) - (x - 1) // (x - 1)(x + 1)]] = [[2 // x² - 1]].

У методичці цю саму функцію рахують «в лоб» через похідну частки - відповідь та сама, але довше.

**Відповідь:** a) -x/√(9 - x²); b) 2/(x² - 1).

## 5. Параметрична і неявна функція

**Задача 6.** x = t² + 1, y = t³ - t. Знайдіть y'ₓ і y''ₓₓ, обчисліть їх при t = 1.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** x'ₜ = 2t, y'ₜ = 3t² - 1.

**Крок 2.** y'ₓ = [[y'ₜ // x'ₜ]] = [[3t² - 1 // 2t]].

**Крок 3.** Для другої похідної спершу (y'ₓ)'ₜ - похідна по t від того, що вийшло:

```
          6t·2t - (3t² - 1)·2
(y'ₓ)'ₜ = ───────────────────
                 4t²
          6t² + 2   3t² + 1
        = ─────── = ───────
            4t²       2t²
```

**Крок 4.** Ділимо на x'ₜ = 2t: y''ₓₓ = [[3t² + 1 // 2t²·2t]] = [[3t² + 1 // 4t³]].

**Крок 5.** t = 1: y'ₓ = (3 - 1)/2 = 1; y''ₓₓ = (3 + 1)/4 = 1.

Пастка: y''ₓₓ ≠ y''ₜ/x''ₜ = 6t/2 = 3t (при t = 1 дало б 3 - неправильно).

</details>

**Задача 7.** Функція задана неявно: e^y + xy = e. Знайдіть y' і його значення в точці (0; 1).

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Перевіряємо точку: e¹ + 0·1 = e. Лежить на кривій.

**Крок 2.** Диференціюємо по x, памʼятаючи, що y = y(x):
(e^y)' = e^y·y', (xy)' = 1·y + x·y', (e)' = 0.

```
e^y·y' + y + x·y' = 0
```

**Крок 3.** Виносимо y': y'(e^y + x) = -y ⇒ y' = [[-y // e^y + x]].

**Крок 4.** У точці (0; 1): y' = [[-1 // e + 0]] = -1/e ≈ -0,368.

</details>

**Задача 24.** Асимптоти графіка y = [[x² - 3 // x + 2]].

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 4.** Для x → -∞ ті самі k = 1, b = -2.

**Відповідь:** x = -2 і y = x - 2.

</details>

**Задача 25.** Дослідіть функцію y = [[x² // x - 1]] і побудуйте графік.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1. Область.** x ≠ 1: D = (-∞; 1) ∪ (1; +∞).

**Крок 2. Перетин з осями.** x = 0 ⇒ y = 0. Точка (0; 0) - єдина.

**Крок 3. Парність.** Область не симетрична відносно 0 - ні парна, ні непарна. Не періодична.

**Крок 4. Розрив.** У x = 1: x → 1 + 0: 1/(+0) → +∞; x → 1 - 0: → -∞. Розрив другого роду,
x = 1 - вертикальна асимптота.

**Крок 5. Похила.** k = lim [[x² // x(x - 1)]] = 1; b = lim ([[x² // x - 1]] - x) = lim [[x // x - 1]] = 1.
Асимптота y = x + 1 (при x → ±∞).

**Крок 6. Монотонність.**

```
     2x(x - 1) - x²    x(x - 2)
y' = ────────────── = ────────
        (x - 1)²       (x - 1)²
```

y' = 0 при x = 0 і x = 2; не існує при x = 1 (не в області).

| x | (-∞; 0) | 0 | (0; 1) | (1; 2) | 2 | (2; +∞) |
|---|---|---|---|---|---|---|
| y' | + | 0 | - | - | 0 | + |
| y | ↗ | max 0 | ↘ | ↘ | min 4 | ↗ |

y(2) = 4/1 = 4.

**Крок 7. Опуклість.** y'' = [[2 // (x - 1)³]]. Нуля нема. x < 1: y'' < 0, ∩; x > 1: y'' > 0, ∪.
Опуклість міняється лише в x = 1, але там функція не визначена - **точок перегину нема**.

**Крок 8. Графік.** Ліва гілка: йде з -∞ під асимптотою y = x + 1, вершина (0; 0), падає до
-∞ біля x = 1. Права гілка: з +∞ біля x = 1, дно (2; 4), далі вгору над асимптотою y = x + 1.

**Задача 26.** Дослідіть функцію y = [[x // x² + 1]].

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Область - уся пряма (x² + 1 > 0). Розривів і вертикальних асимптот нема.

**Крок 2.** (0; 0) - перетин з осями. y(-x) = -y(x) - функція **непарна**, графік симетричний
відносно початку координат.

**Крок 3.** Горизонтальна асимптота: lim [[x // x² + 1]] = 0 при x → ±∞, тобто y = 0 (k = 0).

**Крок 4.** y' = [[(x² + 1) - x·2x // (x² + 1)²]] = [[1 - x² // (x² + 1)²]]. Нулі x = ±1.

| x | (-∞; -1) | -1 | (-1; 1) | 1 | (1; +∞) |
|---|---|---|---|---|---|
| y' | - | 0 | + | 0 | - |
| y | ↘ | min -1/2 | ↗ | max 1/2 | ↘ |

**Крок 5.** y'' = [[2x(x² - 3) // (x² + 1)³]]. Нулі x = 0, x = ±√3 ≈ ±1,732.

| x | (-∞; -√3) | (-√3; 0) | (0; √3) | (√3; +∞) |
|---|---|---|---|---|
| y'' | - | + | - | + |
| графік | ∩ | ∪ | ∩ | ∪ |

**Крок 6.** Знак міняється в кожній з трьох точок - три перегини:
(-√3; -√3/4), (0; 0), (√3; √3/4). √3/4 ≈ 0,433.

**Крок 7. Графік.** Іде з 0 (знизу від асимптоти y = 0) вниз до мінімуму (-1; -1/2), через (0; 0)
вгору до максимуму (1; 1/2), потім спадає до 0 при x → +∞.

</details>
