## Частина 1. Означення

### Множини і дійсні числа (лекція 1)

- **Множина** - сукупність об'єктів, об'єднаних спільною ознакою. «Множина» і «елемент» - вихідні, неозначувані поняття.
- **Підмножина:** A ⊂ B ≝ ∀a ∈ A ⇒ a ∈ B. ∅ - підмножина будь-якої множини.
- **Рівні множини** - ті, що складаються з тих самих елементів.
- **Об'єднання** A ∪ B = {x : x ∈ A ∨ x ∈ B}; **перетин** A ∩ B = {x : x ∈ A ∧ x ∈ B}; **різниця** A \ B = {x : x ∈ A ∧ x ∉ B}.
- **Декартів добуток:** A × B ≝ {(x; y) : x ∈ A ∧ y ∈ B} - множина впорядкованих пар.
- **ℝ** - множина, що складається більш ніж з одного елемента, для якої справджуються чотири групи аксіом: I додавання, II множення, III порядку, IV неперервності.
- Аксіоми III і IV на лекції лише названі **[нема конспекту - звір з лекцією]**:

```
III. a ≤ b або b ≤ a;
     a ≤ b, b ≤ a ⇒ a = b;
     a ≤ b, b ≤ c ⇒ a ≤ c;
     a ≤ b ⇒ a + c ≤ b + c;
     0 ≤ a, 0 ≤ b ⇒ 0 ≤ a·b
IV.  A, B ⊂ ℝ непорожні,
     ∀a ∈ A ∀b ∈ B: a ≤ b  ⇒
     ∃c ∈ ℝ: a ≤ c ≤ b
```

- **Обмежена зверху** множина X: ∃M ∀x ∈ X: x ≤ M (M - верхня межа). Знизу: ∃m ∀x ∈ X: x ≥ m.
- **Точна верхня межа** sup X = M: 1) ∀x ∈ X: x ≤ M; 2) ∀ε > 0 ∃x ∈ X: x > M - ε.
- **Точна нижня межа** inf X = m: 1) ∀x ∈ X: x ≥ m; 2) ∀ε > 0 ∃x ∈ X: x < m + ε.
- max X, min X - найбільший і найменший **елемент** множини; існують лише тоді, коли sup (inf) належить X.

### Послідовності (лекції 2-3)

- **Границя.** Число a називають границею числової послідовності {xₙ}, якщо для довільного додатного ε знайдеться номер n_ε такий, що для всіх елементів з номером n > n_ε виконується нерівність |xₙ - a| < ε.

```
lim xₙ = a  ≝
∀ε > 0 ∃n_ε ∈ ℕ ∀n ∈ ℕ, n > n_ε:
          |xₙ - a| < ε
```

- **ε-окіл** точки a - проміжок (a - ε; a + ε).
- Якщо {xₙ} має границю - послідовність **збіжна**, якщо ні - **розбіжна**.
- **Нескінченно мала:** {αₙ} - н.м. ≝ lim αₙ = 0.
- **Нескінченно велика:** ∀E > 0 ∃n_E ∀n > n_E: |xₙ| > E.
- **Обмежена:** ∃C ∀n: |xₙ| ≤ C.
- **Монотонні:** зростаюча ⇔ ∀n: xₙ < xₙ₊₁; неспадна ⇔ xₙ ≤ xₙ₊₁; спадна ⇔ xₙ > xₙ₊₁; незростаюча ⇔ xₙ ≥ xₙ₊₁. Перші і треті - строго монотонні, другі і четверті - нестрого.
- **Підпослідовність:** якщо n₁ < n₂ < ... < n_k < ... - зростаюча послідовність натуральних чисел, то x_{n₁}, x_{n₂}, ..., x_{n_k}, ... - підпослідовність {xₙ}.
- **Часткова границя:** якщо lim x_{n_k} = a (число, +∞ або -∞), то a - часткова границя {xₙ}. L - множина всіх часткових границь. Верхня границя = sup L, нижня = inf L.
- **Фундаментальна:** ∀ε > 0 ∃n_ε ∈ ℕ ∀n > n_ε ∀m > n_ε: |xₙ - xₘ| < ε (інакше: ∀p ∈ ℕ: |xₙ₊ₚ - xₙ| < ε).

### Функція і границя функції (лекція 4)

- **Функція.** Нехай X, Y ⊂ ℝ і відомий закон f, за яким кожному x з X відповідає єдиний елемент y з Y. Тоді на X задана функція y = f(x); X - область визначення, Y - множина значень.
- **Границя за Коші:** lim f(x) = A при x → x₀ ≝ ∀ε > 0 ∃δ > 0 ∀x: 0 < |x - x₀| < δ ⇒ |f(x) - A| < ε.
- **Границя за Гейне:** для будь-якої послідовності {xₙ}: xₙ → x₀, xₙ ≠ x₀ ⇒ f(xₙ) → A.
- **У нескінченності:** ∀ε > 0 ∃Δ > 0 ∀x: |x| > Δ ⇒ |f(x) - A| < ε.
- **Однобічні:** f(x₀ - 0) - границя при x → x₀, x < x₀ (ліва); f(x₀ + 0) - при x > x₀ (права).
- **Нескінченно мала функція:** lim α(x) = 0 при x → a. **Нескінченно велика:** ∀M > 0 ∃δ > 0: |f(x)| > M при 0 < |x - a| < δ.
- **Порівняння** (α, β н.м. при x → a): lim α/β = 0 - α вищого порядку (α = o(β)); = C ≠ 0 - одного порядку; = 1 - **еквівалентні** (α ~ β).
- **Порядок:** α має порядок n відносно β, якщо lim α/βⁿ = C, 0 < |C| < ∞.
- Символ O **[не з лекції - звір з лекцією]**: α = O(β), якщо ∃C > 0: |α(x)| ≤ C·|β(x)| біля a.

### Неперервність (лекції 5-6)

- **Означення 4.1.** Функцію f(x) називають неперервною в точці x₀, якщо границя цієї функції в точці x₀ дорівнює значенню функції в точці x₀: lim f(x) = f(x₀).
- **Означення 4.2** (послідовності): для довільної послідовності {xₙ}, xₙ ∈ E, збіжної до x₀, відповідна послідовність значень функції збігається до f(x₀).
- **Означення 4.3** (ε-δ): ∀ε > 0 ∃δ(ε, x₀) > 0 ∀x: |x - x₀| < δ ⇒ |f(x) - f(x₀)| < ε.
- **Означення 4.4** (прирости): нескінченно малому приросту аргумента в точці x₀ відповідає нескінченно малий приріст функції: lim Δy = 0 при Δx → 0. Тут Δx = x - x₀, Δy = f(x₀ + Δx) - f(x₀).
- **Означення 4.5** (зліва і справа): границя зліва дорівнює границі справа і дорівнює значенню функції: f(x₀ - 0) = f(x₀ + 0) = f(x₀).
- **Неперервна зліва** в x₀: lim f(x) при x → x₀ - 0 дорівнює f(x₀); **справа** - аналогічно.
- **На інтервалі** (a; b) - неперервна в кожній точці інтервалу. **На відрізку** [a; b] - неперервна на (a; b), неперервна справа в a і зліва в b. **На множині** E - у кожній точці E.
- **Складена функція:** x = φ(t) визначена на T з множиною значень E, на E визначена y = f(x); тоді y = f(φ(t)) - складена функція, x - проміжна змінна.
- **Точка розриву** - точка, у якій функція не є неперервною.
- **Усувний розрив:** скінченні границі зліва і справа рівні між собою, але не дорівнюють f(x₀), або f(x₀) не існує.
- **Розрив зі скінченним стрибком:** скінченні границі зліва і справа не рівні між собою. Стрибок δ = f(x₀ + 0) - f(x₀ - 0).
- **Розриви першого роду** - точки усувного розриву і точки розриву зі скінченним стрибком.
- **Розрив другого роду:** хоча б одна з односторонніх границь не існує або рівна нескінченності.
- **Кусково-неперервна на [a; b]:** неперервна у всіх внутрішніх точках, крім, можливо, скінченної кількості точок розриву першого роду, і має односторонні границі в a і b.
- **Обернена функція:** якщо кожному y ∈ Y ставиться у відповідність єдиний x ∈ X, такий що y = f(x), то на Y задана обернена функція x = f⁻¹(y). Її графік симетричний графіку прямої функції відносно бісектриси першого і третього координатних кутів.
- **Рівномірно неперервна на E:** ∀ε > 0 ∃δ(ε) > 0 ∀x₁, x₂ ∈ E: |x₁ - x₂| < δ ⇒ |f(x₁) - f(x₂)| < ε.

- **Метрика** ρ(M₁, M₂) ≥ 0: 1) ρ = 0 ⇔ M₁ = M₂; 2) ρ(M₁, M₂) = ρ(M₂, M₁); 3) ρ(M₁, M₂) ≤ ρ(M₁, M₃) + ρ(M₃, M₂).
- **ℝⁿ** - координатний простір з відстанню ρ = √((x₁' - x₁'')² + ... + (xₙ' - xₙ'')²).
- **δ-окіл** точки M₀ - відкрита n-вимірна куля радіуса δ з центром M₀; без самої M₀ - проколений окіл.
- **Внутрішня точка** множини E: існує δ-окіл M, усі точки якого належать E.
- **Відкрита множина** - складається тільки зі своїх внутрішніх точок.
- **Ізольована (зовнішня) точка** - так у файлі лектора: існує δ-окіл M, усі точки якого не належать E. У підручниках «ізольована» означає інше (M ∈ E, а в околі нема інших точок E) - звір, що скаже лектор.
- **Межова точка:** у будь-якому δ-околі є точки, що належать E, і точки, що не належать.
- **Гранична точка:** будь-який окіл M містить хоча б одну точку E.
- **Замкнена множина** - містить усі свої межові точки.
- **Обмежена** - існує куля, що містить усі її точки.
- **Зв'язна** - будь-які дві точки можна з'єднати неперервною кривою, що повністю лежить у множині. **Область** - відкрита зв'язна множина; область разом з межею - замкнена область.

## Частина 3. Теореми з доведенням (№1-20, 38-39)

### Теорема №1. Обмеженість збіжної послідовності

**Формулювання.** Збіжна послідовність обмежена.

**Що це означає простими словами.** Якщо члени підходять до числа a, то вони не можуть утекти як завгодно далеко: усі сидять у якомусь проміжку [-M; M].

<details markdown="1"><summary>Доведення</summary>

> На лекції 2 теорему записали без доведення. Нижче стандартне доведення [нема конспекту - звір з лекцією].

**Крок 1.** Нехай lim xₙ = a. В означенні границі беремо конкретне ε = 1: знайдеться n₁, що для всіх n > n₁ виконується |xₙ - a| < 1.

**Крок 2.** Для таких n за нерівністю трикутника: |xₙ| = |(xₙ - a) + a| ≤ |xₙ - a| + |a| < 1 + |a|.

**Крок 3.** Членів з номерами 1, ..., n₁ скінченна кількість, серед їх модулів є найбільший. Беремо M = max(|x₁|, ..., |x_{n₁}|, 1 + |a|).

**Крок 4.** Тоді |xₙ| ≤ M для всіх n: для перших n₁ - бо M не менше їх модулів, для решти - з кроку 2. Отже {xₙ} обмежена.

</details>

**Типова пастка на іспиті.** Обернене хибне: xₙ = (-1)ⁿ обмежена, але розбіжна. Обмеженість - необхідна, але не достатня умова збіжності.

### Теорема №2. Єдиність границі

**Формулювання.** Якщо {xₙ} має границю, то ця границя єдина.

**Що це означає простими словами.** Послідовність не може одночасно підходити до двох різних чисел: околи двох різних точок можна взяти такими малими, що вони не перетинаються.

<details markdown="1"><summary>Доведення</summary>

> Стандартне, від супротивного [нема конспекту - звір з лекцією].

**Крок 1.** Нехай lim xₙ = a і lim xₙ = b, a ≠ b. Беремо ε = |a - b|/2 > 0.

**Крок 2.** З означення границі: ∃n₁ ∀n > n₁: |xₙ - a| < ε; ∃n₂ ∀n > n₂: |xₙ - b| < ε.

**Крок 3.** Беремо n > max(n₁, n₂), тоді обидві нерівності виконуються одночасно.

**Крок 4.** |a - b| = |(a - xₙ) + (xₙ - b)| ≤ |xₙ - a| + |xₙ - b| < 2ε = |a - b|. Вийшло |a - b| < |a - b| - суперечність. Отже a = b.

</details>

**Типова пастка на іспиті.** ε треба взяти саме |a - b|/2 (половина відстані), а не «довільне»: з довільним ε суперечності не буде.

### Теорема №3. Границя суми, добутку і частки послідовностей

**Формулювання.** Нехай {xₙ} і {yₙ} збігаються, lim xₙ = a, lim yₙ = b. Тоді {xₙ ± yₙ}, {xₙ·yₙ}, {xₙ/yₙ} (за умови yₙ ≠ 0 і b ≠ 0) теж збігаються, і їх границі a ± b, a·b, a/b.

**Що це означає простими словами.** Границю можна «рахувати по частинах», якщо кожна частина має скінченну границю, а знаменник не прямує до нуля.

<details markdown="1"><summary>Доведення</summary>

> Ідея з лекції 2 - теорема про зв'язок границі і н.м. Самі викладки стандартні [нема конспекту - звір з лекцією].

**Крок 1.** За теоремою про зв'язок границі і нескінченно малої: xₙ = a + αₙ, yₙ = b + βₙ, де αₙ, βₙ - нескінченно малі.

**Крок 2 (сума).** xₙ + yₙ = (a + b) + (αₙ + βₙ). Сума н.м. - н.м., тому за тією ж теоремою lim (xₙ + yₙ) = a + b. Різниця - так само.

**Крок 3 (добуток).** xₙ·yₙ = (a + αₙ)(b + βₙ) = ab + (a·βₙ + b·αₙ + αₙ·βₙ). У дужках: н.м. на число, н.м. на число, добуток н.м. - усе н.м. Отже lim xₙyₙ = ab.

**Крок 4 (частка, підготовка).** Оскільки yₙ → b ≠ 0, беремо ε = |b|/2: з деякого номера |yₙ - b| < |b|/2, звідки |yₙ| > |b|/2. Тоді |1/(b·yₙ)| < 2/b², тобто 1/(b·yₙ) обмежена.

**Крок 5 (частка).** xₙ/yₙ - a/b = (b·xₙ - a·yₙ)/(b·yₙ) = (b·αₙ - a·βₙ)/(b·yₙ) (бо b(a + αₙ) - a(b + βₙ) = bαₙ - aβₙ). Чисельник н.м., множник 1/(b·yₙ) обмежений, добуток н.м. на обмежену - н.м. Отже xₙ/yₙ → a/b.

</details>

**Типова пастка на іспиті.** Забути умову lim yₙ ≠ 0. Саме при b = 0 виникають невизначеності 0/0 і ∞/∞.

### Теорема №4. Про проміжну послідовність

**Формулювання.** Якщо xₙ ≤ yₙ ≤ zₙ (починаючи з деякого номера) і lim xₙ = lim zₙ = a, то lim yₙ = a.

**Що це означає простими словами.** Якщо послідовність затиснута між двома, що йдуть до одного числа, вона теж туди йде.

<details markdown="1"><summary>Доведення</summary>

> Стандартне [нема конспекту - звір з лекцією].

**Крок 1.** Беремо довільне ε > 0. Оскільки xₙ → a: ∃n₁ ∀n > n₁: a - ε < xₙ (з |xₙ - a| < ε).

**Крок 2.** Оскільки zₙ → a: ∃n₂ ∀n > n₂: zₙ < a + ε.

**Крок 3.** Для n > max(n₁, n₂) (і більших за номер, з якого діє нерівність): a - ε < xₙ ≤ yₙ ≤ zₙ < a + ε.

**Крок 4.** Отже |yₙ - a| < ε. Це означення того, що lim yₙ = a.

</details>

**Типова пастка на іспиті.** Крайні послідовності мусять мати **однакову** границю. Якщо xₙ → 0, а zₙ → 1, про yₙ нічого сказати не можна.

### Теорема №5. Граничний перехід у нерівностях для послідовностей

**Формулювання.** Якщо xₙ ≤ yₙ для всіх n (з деякого номера) і lim xₙ = a, lim yₙ = b, то a ≤ b. Наслідок: якщо xₙ ≥ c, то lim xₙ ≥ c.

**Що це означає простими словами.** Нерівність між членами зберігається для границь, але лише нестрога.

<details markdown="1"><summary>Доведення</summary>

> Стандартне, від супротивного [нема конспекту - звір з лекцією].

**Крок 1.** Припустимо a > b. Беремо ε = (a - b)/2 > 0.

**Крок 2.** З xₙ → a: з деякого номера xₙ > a - ε = (a + b)/2.

**Крок 3.** З yₙ → b: з деякого номера yₙ < b + ε = (a + b)/2.

**Крок 4.** Для номерів, більших за обидва: yₙ < (a + b)/2 < xₙ, тобто xₙ > yₙ. Це суперечить умові xₙ ≤ yₙ. Отже a ≤ b.

**Крок 5 (наслідок).** Беремо yₙ = c (стала послідовність, її границя c) і застосовуємо доведене.

</details>

**Типова пастка на іспиті.** Строга нерівність стає нестрогою: 0 < 1/n для всіх n, але lim 0 = lim 1/n = 0. Писати «xₙ < yₙ ⇒ lim xₙ < lim yₙ» - помилка.

### Теорема №6. Критерій Коші збіжності послідовності

**Формулювання.** Послідовність збіжна тоді і тільки тоді, коли вона фундаментальна.

**Що це означає простими словами.** Послідовність має границю ⇔ її далекі члени як завгодно близькі **один до одного**. Перевага - не треба знати саму границю.

<details markdown="1"><summary>Доведення (лекція 3)</summary>

**Крок 1 (необхідність, ⇒).** Нехай lim xₙ = a. Для ε/2: ∃n_ε ∀n > n_ε: |xₙ - a| < ε/2.

**Крок 2.** Для n, m > n_ε: |xₙ - xₘ| = |(xₙ - a) + (a - xₘ)| ≤ |xₙ - a| + |xₘ - a| < ε/2 + ε/2 = ε. Отже {xₙ} фундаментальна.

**Крок 3 (достатність, ⇐).** Нехай {xₙ} фундаментальна. Зафіксуємо m > n_ε. Тоді для всіх n > n_ε: xₘ - ε/2 < xₙ < xₘ + ε/2, тобто з цього номера члени лежать у проміжку, а перших членів скінченна кількість. Отже {xₙ} обмежена.

**Крок 4.** За теоремою Больцано-Вейєрштрасса (№7) з обмеженої {xₙ} можна виділити збіжну підпослідовність x_{n_k} → a.

**Крок 5.** Беремо k таке, що n_k > n_ε і |x_{n_k} - a| < ε/2. Тоді для n > n_ε: |xₙ - a| ≤ |xₙ - x_{n_k}| + |x_{n_k} - a| < ε/2 + ε/2 = ε (перша нерівність - фундаментальність з m = n_k). Отже lim xₙ = a.

</details>

**Типова пастка на іспиті.** У фундаментальності **обидва** номери n і m більші за n_ε. Умова |xₙ₊₁ - xₙ| → 0 (лише сусідні члени) не достатня: для 1 + 1/2 + ... + 1/n вона виконується, а послідовність розбіжна.

### Теорема №7. Теорема Больцано-Вейєрштрасса

**Формулювання.** З довільної обмеженої послідовності можна виділити збіжну підпослідовність.

**Що це означає простими словами.** Якщо безліч точок сидить на відрізку, то десь вони «згущуються», і до цього місця можна підійти підпослідовністю.

<details markdown="1"><summary>Доведення (лекція 3)</summary>

**Крок 1.** Послідовність обмежена: a ≤ xₙ ≤ b для всіх n.

**Крок 2.** Ділимо [a; b] навпіл. Хоча б в одній половині лежить безліч членів послідовності - беремо її, це [a₁; b₁].

**Крок 3.** Ділимо [a₁; b₁] навпіл, беремо половину з безліччю членів: [a₂; b₂]. І так далі. Отримали вкладені відрізки [a₁; b₁] ⊃ [a₂; b₂] ⊃ ..., довжина b_k - a_k = (b - a)/2ᵏ → 0.

**Крок 4.** З кожного [a_k; b_k] беремо член x_{n_k} так, щоб n_k > n_{k-1} (можна, бо там безліч членів). Отже a_k ≤ x_{n_k} ≤ b_k.

**Крок 5.** За принципом вкладених відрізків (№9) lim a_k = lim b_k = c.

**Крок 6.** За лемою про проміжну послідовність (№4) lim x_{n_k} = c. Збіжну підпослідовність знайдено.

</details>

**Типова пастка на іспиті.** Умова - **обмеженість**, а не збіжність чи монотонність. Сама послідовність може бути розбіжною: (-1)ⁿ розбіжна, а підпослідовність парних членів збігається до 1.

### Теорема №8. Теорема Вейєрштрасса про монотонну послідовність

**Формулювання.** Якщо {xₙ} монотонно зростає і обмежена зверху, то вона збіжна. Якщо {xₙ} монотонно спадає і обмежена знизу, то вона збіжна.

**Що це означає простими словами.** Послідовність, яка весь час росте, але впирається в «стелю», мусить до чогось підійти. І це «щось» - точна верхня межа.

<details markdown="1"><summary>Доведення (лекція 3)</summary>

**Крок 1.** Множина членів обмежена зверху, тому має точну верхню межу M = sup{xₙ} (це дає аксіома неперервності).

**Крок 2.** За означенням sup: 1) ∀n: xₙ ≤ M; 2) ∀ε > 0 ∃n_ε: x_{n_ε} > M - ε.

**Крок 3.** Послідовність зростає, тому для n > n_ε: xₙ > x_{n_ε}.

**Крок 4.** Збираємо: M - ε < x_{n_ε} < xₙ ≤ M < M + ε, тобто |xₙ - M| < ε для всіх n > n_ε.

**Крок 5.** Це означення границі: lim xₙ = M = sup xₙ. Для спадної, обмеженої знизу - так само з inf.

</details>

**Типова пастка на іспиті.** Потрібні **обидві** умови. xₙ = n монотонна, але не обмежена - розбіжна (→ +∞). (-1)ⁿ обмежена, але не монотонна - розбіжна. Саме цією теоремою доводять існування числа e: (1 + 1/n)ⁿ зростає і менше 3.

### Теорема №9. Принцип вкладених відрізків

**Формулювання.** Нехай [a₁; b₁] ⊃ [a₂; b₂] ⊃ ... ⊃ [aₙ; bₙ] ⊃ ... і lim (bₙ - aₙ) = 0. Тоді існує єдина точка c, що належить усім відрізкам.

**Що це означає простими словами.** Відрізки стискаються всередину один одного, довжина йде до нуля - і в «серцевині» лишається рівно одна точка.

<details markdown="1"><summary>Доведення (лекція 3)</summary>

**Крок 1.** Відрізки вкладені, тому a₁ ≤ a₂ ≤ ... ≤ aₙ ≤ ... < b₁: ліві кінці не спадають і обмежені зверху числом b₁.

**Крок 2.** За теоремою Вейєрштрасса (№8) lim aₙ = c₁.

**Крок 3.** Так само b₁ ≥ b₂ ≥ ... > a₁: праві кінці не зростають і обмежені знизу, тому lim bₙ = c₂.

**Крок 4.** c₂ - c₁ = lim bₙ - lim aₙ = lim (bₙ - aₙ) = 0 (арифметика границь, №3), тому c₁ = c₂ = c. Оскільки aₙ ≤ c ≤ bₙ (aₙ росте до c, bₙ спадає до c), c належить усім відрізкам.

**Крок 5 (єдиність).** Якщо c' і c'' обидві належать усім відрізкам, то bₙ - aₙ ≥ |c' - c''|. Переходимо до границі (№5): 0 ≥ |c' - c''|, отже c' = c''.

</details>

**Типова пастка на іспиті.** Для **інтервалів** хибно: (0; 1/n) вкладені, довжини → 0, а спільної точки нема. Без умови «довжини → 0» спільна точка є, але не обов'язково одна.

### Теорема №10. Границя суми, добутку і частки функцій

**Формулювання.** Якщо lim f(x) = A і lim g(x) = B при x → x₀, то lim (f ± g) = A ± B, lim f·g = A·B, lim f/g = A/B (якщо B ≠ 0).

**Що це означає простими словами.** Те саме, що для послідовностей (№3), бо границя функції за Гейне - це границі послідовностей.

<details markdown="1"><summary>Доведення (лекція 4, через Гейне)</summary>

**Крок 1.** Беремо довільну послідовність xₙ → x₀, xₙ ≠ x₀.

**Крок 2.** За означенням Гейне f(xₙ) → A і g(xₙ) → B.

**Крок 3.** f(xₙ) і g(xₙ) - звичайні числові послідовності. За теоремою №3 f(xₙ) + g(xₙ) → A + B.

**Крок 4.** Послідовність xₙ була довільною, тому за означенням Гейне lim (f + g) = A + B.

**Крок 5.** Добуток і частка - «аналогічно» (так у лекції): у кроці 3 беремо границю добутку і частки послідовностей. Для частки ще треба, щоб g(xₙ) ≠ 0 біля x₀: оскільки B ≠ 0, функція g зберігає знак B у проколотому околі x₀.

</details>

**Типова пастка на іспиті.** Сказати «за теоремою про суму» для ∞ - ∞ або 0/0. Теорема працює лише для **скінченних** A, B і B ≠ 0.

### Теорема №11. Граничний перехід у нерівностях для функцій

**Формулювання.** Якщо f(x) ≤ g(x) у проколотому околі x₀ і lim f = A, lim g = B, то A ≤ B. Теорема 4.1 (про проміжну функцію): якщо f(x) ≤ h(x) ≤ g(x) біля x₀ і lim f = lim g = A, то lim h = A.

**Що це означає простими словами.** Нерівності і «затиск» переносяться з послідовностей на функції.

<details markdown="1"><summary>Доведення (лекція 4, через Гейне)</summary>

**Крок 1.** Беремо довільну xₙ → x₀, xₙ ≠ x₀. З деякого номера xₙ лежить у проколотому околі, де діє нерівність, тому f(xₙ) ≤ g(xₙ).

**Крок 2.** За Гейне f(xₙ) → A, g(xₙ) → B.

**Крок 3.** За теоремою №5 для послідовностей A ≤ B.

**Крок 4 (проміжна).** Для тієї ж xₙ: f(xₙ) ≤ h(xₙ) ≤ g(xₙ), крайні → A. За лемою про проміжну послідовність (№4) h(xₙ) → A.

**Крок 5.** xₙ довільна, тому за Гейне lim h = A.

</details>

**Типова пастка на іспиті.** Знову: f < g не дає A < B. Приклад: f = 0 і g = x² при x → 0, x ≠ 0: f < g, а обидві границі 0.

### Теорема №12. Перша важлива границя. Наслідки

**Формулювання.** lim sin x / x = 1 при x → 0. Наслідки: tg x / x → 1, arcsin x / x → 1, arctg x / x → 1.

**Що це означає простими словами.** Біля нуля синус майже дорівнює самому куту в радіанах: sin 0,01 = 0,0099998.

<details markdown="1"><summary>Доведення (лекція 4)</summary>

**Крок 1.** Коло радіуса 1, центр O, OA = 1 на осі, кут AOB = x, 0 < x < π/2 (радіани). MB = sin x (MB - перпендикуляр з B на OA), дотична в A перетинає промінь OB у C, AC = tg x.

**Крок 2.** Порівнюємо площі: трикутник OAB (½·sin x) лежить усередині сектора OAB (½·x), а сектор - усередині трикутника OAC (½·tg x). Звідси sin x < x < tg x.

**Крок 3.** Ділимо на sin x > 0: 1 < x / sin x < 1 / cos x. Перевертаємо: cos x < sin x / x < 1.

**Крок 4.** При x → 0+ маємо cos x → 1. sin x / x затиснуте між cos x і 1, за теоремою про проміжну функцію (№11) права границя дорівнює 1.

**Крок 5.** Ліва: x = -y, y → 0+: sin(-y)/(-y) = sin y / y → 1. Ліва і права рівні 1, тому lim sin x / x = 1.

**Крок 6 (наслідки).** tg x / x = (sin x / x)·(1/cos x) → 1·1 = 1. Для arcsin: y = arcsin x, x = sin y, y → 0, arcsin x / x = y / sin y → 1. Для arctg: y = arctg x, x = tg y, y / tg y → 1.

</details>

**Типова пастка на іспиті.** Границя 1 лише при x → 0 і лише в радіанах. При x → ∞ sin x / x → 0 (обмежена на н.м.).

### Теорема №13. Друга важлива границя. Наслідки

**Формулювання.** lim (1 + 1/x)ˣ = e при x → ∞ (і при x → +∞, і при x → -∞); інша форма: lim (1 + α)^(1/α) = e при α → 0. Наслідки (x → 0): logₐ(1 + x)/x → logₐ e, ln(1 + x)/x → 1, (aˣ - 1)/x → ln a, (eˣ - 1)/x → 1.

**Що це означає простими словами.** Невизначеність 1^∞ - не 1, а число e (якщо «маленьке» і степінь обернені одне до одного).

<details markdown="1"><summary>Доведення (лекція 4)</summary>

**Крок 1.** Знаємо з лекції 3: (1 + 1/n)ⁿ → e для натуральних n. Нехай x → +∞, x > 1, n = [x] (ціла частина). Тоді n ≤ x < n + 1 і 1/(n + 1) < 1/x ≤ 1/n.

**Крок 2.** Додаємо 1: 1 + 1/(n + 1) < 1 + 1/x ≤ 1 + 1/n. Основи більші за 1, тому підносимо меншу до меншого степеня, більшу до більшого: (1 + 1/(n + 1))ⁿ < (1 + 1/x)ˣ < (1 + 1/n)ⁿ⁺¹.

**Крок 3.** Ліва частина: (1 + 1/(n + 1))ⁿ⁺¹ / (1 + 1/(n + 1)) → e/1 = e. Права: (1 + 1/n)ⁿ·(1 + 1/n) → e·1 = e.

**Крок 4.** За теоремою про проміжну функцію (1 + 1/x)ˣ → e при x → +∞.

**Крок 5.** x → -∞: x = -y, y → +∞: (1 - 1/y)^(-y) = (y/(y - 1))ʸ = (1 + 1/(y - 1))ʸ⁻¹·(1 + 1/(y - 1)) → e·1 = e.

**Крок 6.** Заміна α = 1/x дає (1 + α)^(1/α) → e при α → 0.

**Крок 7 (наслідки).** logₐ(1 + x)/x = logₐ((1 + x)^(1/x)) → logₐ e (логарифм неперервний); при a = e це 1. Для (aˣ - 1)/x: y = aˣ - 1 → 0, x = logₐ(1 + y), тому (aˣ - 1)/x = y / logₐ(1 + y) → 1 / logₐ e = ln a.

</details>

**Типова пастка на іспиті.** Писати 1^∞ = 1. І забувати, що наслідки - теж частина відповіді (питання «Наслідки» є в самому формулюванні).

### Теорема №14. Неперервність складеної функції

**Формулювання.** Якщо функція x = φ(t) неперервна в точці t₀, а функція y = f(x) неперервна в точці x₀ = φ(t₀), то складена функція y = f(φ(t)) неперервна в точці t₀.

**Що це означає простими словами.** Неперервна від неперервної - неперервна. Тому lim f(φ(t)) = f(lim φ(t)): знак границі можна заносити під неперервну функцію.

<details markdown="1"><summary>Доведення (лекції 5-6, через послідовності)</summary>

**Крок 1.** Беремо довільну послідовність tₙ → t₀.

**Крок 2.** φ неперервна в t₀ (означення 4.2), тому φ(tₙ) → φ(t₀). Позначимо xₙ = φ(tₙ), x₀ = φ(t₀): xₙ → x₀.

**Крок 3.** f неперервна в x₀, тому f(xₙ) → f(x₀), тобто f(φ(tₙ)) → f(φ(t₀)).

**Крок 4.** Послідовність tₙ довільна, тому за означенням 4.2 f(φ(t)) неперервна в t₀.

</details>

**Типова пастка на іспиті.** Неперервність f потрібна саме в точці x₀ = φ(t₀), а не в t₀.

### Теорема №15. Неперервність суми, добутку і частки функцій

**Формулювання.** Якщо функції f(x) і g(x) неперервні в точці x₀, то їх сума, добуток та частка (якщо знаменник не рівний нулеві) неперервні в цій точці.

**Що це означає простими словами.** З неперервних «цеглинок» арифметикою отримуємо неперервні функції. Звідси неперервні многочлени і дробово-раціональні функції (там, де знаменник ≠ 0).

<details markdown="1"><summary>Доведення (лекція 5)</summary>

**Крок 1.** Неперервність у граничній формі (означення 4.1): lim f(x) = f(x₀), lim g(x) = g(x₀).

**Крок 2.** За теоремою про границю суми функцій (№10): lim (f + g) = lim f + lim g = f(x₀) + g(x₀). Це значення f + g у точці x₀, тобто f + g неперервна.

**Крок 3.** Добуток: lim f·g = lim f · lim g = f(x₀)·g(x₀).

**Крок 4.** Частка: lim f/g = lim f / lim g = f(x₀)/g(x₀), можна, бо g(x₀) ≠ 0.

</details>

**Типова пастка на іспиті.** Умова g(x₀) ≠ 0 для частки. 1/x - частка неперервних, але в 0 розривна.

### Теорема №16. Перша теорема Больцано-Коші

**Формулювання.** Нехай y = f(x) неперервна на відрізку [a; b] і на кінцях цього відрізка приймає різні за знаком значення (f(a)·f(b) < 0). Тоді існує така точка c ∈ (a; b), що f(c) = 0.

**Що це означає простими словами.** Неперервний графік, щоб перейти з-під осі Ox над неї, мусить її перетнути.

<details markdown="1"><summary>Доведення (лекція 6)</summary>

**Крок 1.** Ділимо [a; b] навпіл. Якщо f((a + b)/2) = 0 - теорему доведено. Якщо ні, [a₁; b₁] - та половина, на кінцях якої f має різні знаки: f(a₁)·f(b₁) < 0.

**Крок 2.** Ділимо [a₁; b₁] навпіл і так далі. Або на якомусь кроці f у середині = 0 (доведено), або отримуємо вкладені відрізки [aₙ; bₙ] з f(aₙ)·f(bₙ) < 0.

**Крок 3.** Довжина bₙ - aₙ = (b - a)/2ⁿ → 0. За принципом вкладених відрізків (№9) існує точка c, що належить усім [aₙ; bₙ].

**Крок 4.** Доводимо f(c) = 0 від супротивного. Нехай f(c) > 0. За теоремою про збереження знаку неперервної функції існує δ-окіл c, де f(x) > 0.

**Крок 5.** Починаючи з деякого n, відрізок [aₙ; bₙ] потрапляє в цей δ-окіл (бо містить c і має довжину → 0). Тоді f(aₙ) > 0 і f(bₙ) > 0, тобто f(aₙ)·f(bₙ) > 0. Суперечність з кроком 2.

**Крок 6.** Так само неможливо f(c) < 0. Отже f(c) = 0.

</details>

**Типова пастка на іспиті.** Без неперервності хибно: 1/x на [-1; 1] має f(-1) = -1 < 0 і f(1) = 1 > 0, а коренів нема (розрив у 0). І точка c лежить в **інтервалі** (a; b), не на кінцях.

### Теорема №17. Друга теорема Больцано-Коші

**Формулювання.** Нехай y = f(x) неперервна на відрізку [a; b], f(a) = A, f(b) = B. Тоді для довільного числа C, яке лежить між A і B, знайдеться c ∈ (a; b), що f(c) = C.

**Що це означає простими словами.** Неперервна функція не «перестрибує» значень: якщо була 2 і стала 5, то десь була і 3,7. Це теорема про проміжне значення.

<details markdown="1"><summary>Доведення (лекція 6)</summary>

**Крок 1.** Нехай A < C < B. Розглядаємо допоміжну функцію φ(x) = f(x) - C.

**Крок 2.** φ неперервна на [a; b] як різниця неперервної f і сталої C (№15).

**Крок 3.** На кінцях: φ(a) = A - C < 0, φ(b) = B - C > 0. Знаки різні.

**Крок 4.** За першою теоремою Больцано-Коші (№16) ∃c ∈ (a; b): φ(c) = 0.

**Крок 5.** φ(c) = f(c) - C = 0, тобто f(c) = C.

</details>

**Типова пастка на іспиті.** Не забути назвати допоміжну функцію і перевірити її неперервність - без цього перша теорема не застосовна.

### Теорема №18. Перша теорема Вейєрштрасса

**Формулювання.** Якщо функція f(x) неперервна на відрізку [a; b], то вона обмежена на цьому відрізку: ∃M > 0 ∀x ∈ [a; b]: |f(x)| ≤ M.

**Що це означає простими словами.** На відрізку неперервна функція не може «полетіти в нескінченність».

<details markdown="1"><summary>Доведення (лекція 6, від супротивного)</summary>

**Крок 1.** Припустимо, f необмежена на [a; b]. Тоді вона необмежена хоча б на одній половині - позначимо її [a₁; b₁].

**Крок 2.** Ділимо [a₁; b₁] навпіл, беремо половину, де f необмежена: [a₂; b₂], і так далі. Отримуємо вкладені відрізки з довжинами (b - a)/2ⁿ → 0, на кожному f необмежена.

**Крок 3.** За принципом вкладених відрізків (№9) є точка c, що належить усім [aₙ; bₙ].

**Крок 4.** f неперервна в c, тому (теорема 2 лекції 6) обмежена в деякому δ-околі (c - δ; c + δ).

**Крок 5.** З деякого n відрізки [aₙ; bₙ] лежать у цьому δ-околі, отже f на них обмежена. Це суперечить вибору відрізків (на кожному f необмежена).

</details>

**Типова пастка на іспиті.** Для інтервалу хибно: 1/x неперервна на (0; 1), але необмежена (при x → 0+ іде в +∞).

### Теорема №19. Друга теорема Вейєрштрасса

**Формулювання.** Неперервна на відрізку [a; b] функція досягає на цьому відрізку свого найбільшого і найменшого значення: ∃x₁, x₂ ∈ [a; b]: f(x₁) = min f, f(x₂) = max f.

**Що це означає простими словами.** sup значень не просто існує, а «береться» в якійсь точці відрізка. Тому на відрізку завжди є max і min.

<details markdown="1"><summary>Доведення (лекція 6, від супротивного)</summary>

**Крок 1.** За першою теоремою Вейєрштрасса (№18) f обмежена, тому існує M = sup f на [a; b].

**Крок 2.** Припустимо, M не досягається: f(x) < M для всіх x ∈ [a; b].

**Крок 3.** Тоді φ(x) = 1/(M - f(x)) має знаменник ≠ 0 на всьому відрізку і неперервна (№15).

**Крок 4.** За №18 φ обмежена: φ(x) ≤ μ для деякого μ > 0. Звідси M - f(x) ≥ 1/μ, тобто f(x) ≤ M - 1/μ.

**Крок 5.** Отже M - 1/μ - верхня межа значень f, менша за M. Це суперечить тому, що M - **точна** верхня межа. Отже ∃x₂: f(x₂) = M. Для найменшого - аналогічно.

</details>

**Типова пастка на іспиті.** На (0; 3) функція x² - 2x має inf -1 (досягається), але sup 3 не досягається (x = 3 викинули). Потрібен саме відрізок.

### Теорема №20. Існування і неперервність оберненої функції

**Формулювання.** Якщо функція y = f(x) визначена на відрізку [a; b] і є на цьому відрізку неперервною і зростаючою (спадною), то на відрізку [f(a); f(b)] ([f(b); f(a)]) існує обернена функція x = φ(y), яка теж неперервна і зростаюча (спадна).

**Що це означає простими словами.** Строго монотонна неперервна функція «розкручується назад» без проблем: кожне y дає рівно один x, і обернена теж неперервна. Так отримують arcsin, arctg, √x, ln x.

<details markdown="1"><summary>Доведення (лекція 6, для зростаючої)</summary>

**Крок 1 (існування).** A = f(a), B = f(b). За другою теоремою Больцано-Коші (№17) для кожного C ∈ [A; B] є хоча б одна c ∈ [a; b] з f(c) = C.

**Крок 2.** Інша точка c' ≠ c з f(c') = C неможлива: f зростає, тому при c' > c f(c') > f(c), а при c' < c f(c') < f(c).

**Крок 3.** Отже кожному C ∈ [A; B] відповідає рівно одна точка c - на [A; B] задана обернена функція x = φ(y).

**Крок 4 (зростання).** Від супротивного: нехай y₁ < y₂, а φ(y₁) ≥ φ(y₂), тобто x₁ ≥ x₂. f зростає, тому f(x₁) ≥ f(x₂), тобто y₁ ≥ y₂. Суперечність.

**Крок 5 (неперервність).** Нехай C ∈ (A; B), c = φ(C). Беремо мале ε > 0, щоб c - ε і c + ε належали [a; b]. Позначимо C₁ = f(c - ε), C₂ = f(c + ε), δ₁ = C - C₁ > 0, δ₂ = C₂ - C > 0, δ = min(δ₁, δ₂).

**Крок 6.** Якщо |y - C| < δ, то C₁ < y < C₂. φ зростає (крок 4), тому φ(C₁) < φ(y) < φ(C₂), тобто c - ε < φ(y) < c + ε, |φ(y) - c| < ε. Це неперервність φ у точці C за Коші. (У лекції останній рядок записано скорочено; у кінцях A, B - так само з одного боку.)

</details>

**Типова пастка на іспиті.** Забути «строго монотонна». y = x² на [-1; 1] неперервна, але не монотонна - оберненої нема (y = 1/4 дає x = ±1/2).

### Теорема №38. Диференційовність функції двох змінних: необхідні і достатні умови

> [ще не було на лекціях - звір з лекцією]. Стандартне формулювання і доведення з підручника.

**Формулювання.** z = f(x, y) **диференційовна** в точці (x₀; y₀), якщо Δz = A·Δx + B·Δy + α·Δx + β·Δy, де A, B - числа, α, β → 0 при Δx, Δy → 0.
- **Необхідні умови:** якщо f диференційовна в точці, то вона неперервна в ній і має частинні похідні, причому A = f'ₓ(x₀; y₀), B = f'ᵧ(x₀; y₀).
- **Достатня умова:** якщо частинні похідні f'ₓ, f'ᵧ існують в околі точки і неперервні в самій точці, то f диференційовна в цій точці.

**Що це означає простими словами.** Диференційовна = біля точки поверхню можна замінити площиною. Самих частинних похідних для цього мало, треба щоб вони були неперервними.

<details markdown="1"><summary>Доведення</summary>

**Крок 1 (неперервність).** З означення Δz = AΔx + BΔy + αΔx + βΔy → 0 при Δx, Δy → 0. Це і є неперервність (приріст функції → 0).

**Крок 2 (частинні похідні).** Беремо Δy = 0. Тоді частинний приріст Δₓz = A·Δx + α·Δx. Ділимо на Δx: Δₓz/Δx = A + α → A. Отже f'ₓ існує і дорівнює A. Так само з Δx = 0 отримуємо f'ᵧ = B.

**Крок 3 (достатня, розбиваємо приріст).** Δz = [f(x₀ + Δx, y₀ + Δy) - f(x₀, y₀ + Δy)] + [f(x₀, y₀ + Δy) - f(x₀, y₀)]. У першій дужці змінюється лише x, у другій - лише y.

**Крок 4.** До кожної дужки застосовуємо теорему Лагранжа (для функції однієї змінної): перша = f'ₓ(x₀ + θ₁Δx, y₀ + Δy)·Δx, друга = f'ᵧ(x₀, y₀ + θ₂Δy)·Δy, 0 < θ₁, θ₂ < 1.

**Крок 5.** Частинні похідні неперервні в (x₀; y₀), тому f'ₓ(x₀ + θ₁Δx, y₀ + Δy) = f'ₓ(x₀; y₀) + α, f'ᵧ(x₀, y₀ + θ₂Δy) = f'ᵧ(x₀; y₀) + β, де α, β → 0.

**Крок 6.** Підставляємо: Δz = f'ₓΔx + f'ᵧΔy + αΔx + βΔy. Це означення диференційовності.

</details>

**Типова пастка на іспиті.** Існування частинних похідних **не** гарантує диференційовності і навіть неперервності: f = xy/(x² + y²), f(0; 0) = 0 має f'ₓ(0; 0) = f'ᵧ(0; 0) = 0, але в (0; 0) розривна (по прямій y = x значення 1/2).

### Теорема №39. Похідна складних функцій двох змінних

> [ще не було на лекціях - звір з лекцією]. Стандартне доведення.

**Формулювання.** Нехай z = f(u, v) диференційовна в точці (u; v), а u = u(x, y), v = v(x, y) мають частинні похідні в точці (x; y). Тоді

```
z'ₓ = f'ᵤ·u'ₓ + f'ᵥ·v'ₓ
z'ᵧ = f'ᵤ·u'ᵧ + f'ᵥ·v'ᵧ
```

Окремий випадок z = f(x, y), x = x(t), y = y(t): dz/dt = f'ₓ·x'(t) + f'ᵧ·y'(t).

**Що це означає простими словами.** Ланцюжкове правило: по кожній проміжній змінній «похідна зовнішньої на похідну внутрішньої», і все складаємо.

<details markdown="1"><summary>Доведення</summary>

**Крок 1.** Даємо x приріст Δx, y не чіпаємо. Тоді u і v отримують прирости Δu = Δₓu, Δv = Δₓv.

**Крок 2.** f диференційовна, тому Δz = f'ᵤΔu + f'ᵥΔv + αΔu + βΔv, де α, β → 0 при Δu, Δv → 0.

**Крок 3.** Ділимо на Δx: Δz/Δx = f'ᵤ·Δu/Δx + f'ᵥ·Δv/Δx + α·Δu/Δx + β·Δv/Δx.

**Крок 4.** При Δx → 0: Δu/Δx → u'ₓ, Δv/Δx → v'ₓ (означення частинних похідних). Крім того Δu = (Δu/Δx)·Δx → u'ₓ·0 = 0, так само Δv → 0, тому α, β → 0.

**Крок 5.** Переходимо до границі: z'ₓ = f'ᵤ·u'ₓ + f'ᵥ·v'ₓ + 0 + 0. Для z'ᵧ - так само з приростом Δy.

</details>

**Типова пастка на іспиті.** Пропустити один доданок: z залежить від x **через обидві** u і v. Приклад: z = u²v, u = x + y, v = xy: z'ₓ = 2uv·1 + u²·y.
