# Шпаргалка: іспит з матаналізу

**Означення (умови не губити!)**

```
lim xₙ = a: ∀ε>0 ∃n_ε ∀n>n_ε: |xₙ-a|<ε
Коші f: ∀ε>0 ∃δ>0 ∀x:
  0<|x-x₀|<δ ⇒ |f(x)-A|<ε
Гейне: ∀xₙ→x₀, xₙ≠x₀ ⇒ f(xₙ)→A
неперервна: lim f(x) = f(x₀)
рівномірна: δ = δ(ε), ∀x₁,x₂ ∈ E
фундам.: |xₙ - xₘ| < ε, n,m > n_ε
sup X = M: x ≤ M; ∀ε ∃x > M - ε
```

**Збіжність:** збіжна ⇒ обмежена (не навпаки). Монотонна + обмежена ⇒ збіжна. Обмежена ⇒ є збіжна підпослідовність. Збіжна ⇔ фундаментальна. xₙ < yₙ ⇒ lim ≤ (нестрога!).

**Комплексні:** ρ = √(x² + y²); II чверть +π, III -π. zⁿ = ρⁿ(cos nφ + i sin nφ). Коренів n: (φ + 2πk)/n.

**Важливі границі і еквівалентні (x → 0)**

```
sin x/x → 1    (1 + 1/x)ˣ → e
x~sin x~tg x~arcsin x~arctg x
 ~ln(1+x)~eˣ-1;  aˣ-1 ~ x ln a
1 - cos x ~ x²/2
1^∞: u^v → e^(lim (u-1)·v)
```

Міняти можна множники, не доданки.

**Розриви:** усувний (границі рівні, ≠ f(x₀)), стрибок (скінченні, різні), разом - I роду. II роду - хоча б одна ∞ або нема.

**На ВІДРІЗКУ** (не інтервалі!): Больцано-Коші 1 (f(a)f(b) < 0 ⇒ корінь), 2 (усі проміжні), Вейєрштрасс 1 (обмежена), 2 (досягає max і min), Кантор (рівномірно неперервна). Обернена: неперервна + строго монотонна.

**Невизначеності:** 0/0 розклад; ∞/∞ ділити на старший; ∞-∞ спряжене; 1^∞ число e.
