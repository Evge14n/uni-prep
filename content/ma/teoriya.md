## Тема 1. Множини і дійсні числа (питання 1)

Множина і елемент - вихідні поняття, їх не означують. a ∈ A - «a належить A».

```
A ∪ B = { x : x ∈ A ∨ x ∈ B }
A ∩ B = { x : x ∈ A ∧ x ∈ B }
A \ B = { x : x ∈ A ∧ x ∉ B }
A × B = { (x; y) : x ∈ A ∧ y ∈ B }
```

- Об'єднання - через «або», перетин - через «і».
- A × B - множина **впорядкованих** пар, тому A × B ≠ B × A.
- Елементи пишемо через крапку з комою: {1; 2; 3}, щоб не плутати з десятковими дробами.

**ℝ** - множина, що складається більш ніж з одного елемента, для якої виконуються 4 групи аксіом: I додавання, II множення, III порядку, IV неперервності. Саме аксіома неперервності відрізняє ℝ від ℚ (без неї на прямій лишаються «дірки», наприклад √2).

**Межі множини.** sup X - найменша з верхніх меж, inf X - найбільша з нижніх.

```
sup X = M:
 1) ∀x ∈ X: x ≤ M
 2) ∀ε > 0 ∃x ∈ X: x > M - ε
```

Як каже лектор, inf і sup - «двері, які підпирають множину»: вони можуть належати множині, а можуть і ні. max і min - тільки елементи множини. Тому max існує лише тоді, коли sup ∈ X.

Приклад: X = {1; 1/2; 1/3; ...}: sup = max = 1, inf = 0, min нема (0 ∉ X).

**Метод математичної індукції** (практичне 2): база (n = 1 або найменше n), припущення (правильно для n = k), крок (доводимо для n = k + 1, обов'язково використовуючи припущення).

## Тема 2. Комплексні числа (питання 2)

```
z = x + i·y,   i² = -1
x = Re z,  y = Im z
ρ = |z| = √(x² + y²)
z = ρ·(cos φ + i·sin φ)  тригонометрична
z = ρ·e^(iφ)              показникова
```

Аргумент φ: малюй точку (x; y) і дивись на чверть. x > 0: φ = arctg(y/x); у II чверті додаємо π, у III віднімаємо π.

- Множення: модулі множимо, аргументи додаємо.
- Ділення: модулі ділимо, аргументи віднімаємо. В алгебраїчній формі - домножити на спряжене до знаменника.
- **Формула Муавра:** zⁿ = ρⁿ·(cos nφ + i·sin nφ).
- **Корінь n-го степеня** має рівно n значень:

```
ⁿ√z = ⁿ√ρ·(cos ψₖ + i·sin ψₖ),
ψₖ = (φ + 2πk)/n,
k = 0, 1, ..., n - 1
```

Корені лежать у вершинах правильного n-кутника на колі радіуса ⁿ√ρ.

Степені i повторюються з періодом 4: i, -1, -i, 1. Для i²⁰²³ ділимо 2023 на 4, остача 3, тому i²⁰²³ = -i.

## Тема 3. Границя послідовності (питання 3, 4, 5)

```
lim xₙ = a  ⇔
∀ε > 0 ∃n_ε ∈ ℕ ∀n > n_ε:
          |xₙ - a| < ε
```

**Геометричний зміст:** починаючи з номера n_ε + 1, усі члени лежать в ε-околі (a - ε; a + ε). Поза околом - лише скінченна кількість членів.

Властивості збіжних (у такому порядку їх доводять): границя єдина; збіжна послідовність обмежена (обернене хибне: (-1)ⁿ обмежена, але розбіжна).

**Нескінченно мала:** lim αₙ = 0. Це не «мала», а «прямує до нуля». Властивості: сума і добуток н.м. - н.м.; н.м. на число - н.м.; **н.м. на обмежену - н.м.** (тому sin n / n → 0).

**Нескінченно велика:** ∀E > 0 ∃n_E ∀n > n_E: |xₙ| > E. Якщо xₙ н.в., то 1/xₙ н.м., і навпаки (для αₙ ≠ 0).

**Зв'язок:** lim xₙ = a ⇔ xₙ = a + αₙ, де αₙ н.м.

**Арифметика:** границя суми, добутку, частки (якщо lim yₙ ≠ 0) дорівнює сумі, добутку, частці границь. Умова lim yₙ ≠ 0 обов'язкова, без неї виникає 0/0.

**Нерівності:** xₙ ≤ yₙ ⇒ lim xₙ ≤ lim yₙ. Строга нерівність переходить у **нестрогу** (0 < 1/n, а обидві границі 0). Лема про проміжну: xₙ ≤ yₙ ≤ zₙ, xₙ → a, zₙ → a ⇒ yₙ → a.

**Невизначеності:** 0/0, ∞/∞, ∞ - ∞, 0·∞, 1^∞, ∞⁰, 0⁰. Прийоми: ділити на старший степінь, домножити на спряжене, розкласти на множники, звести до числа e, заміна.

## Тема 4. Монотонні послідовності і число e (питання 6)

- Зростаюча: xₙ < xₙ₊₁ ∀n; неспадна: xₙ ≤ xₙ₊₁; спадна: xₙ > xₙ₊₁; незростаюча: xₙ ≥ xₙ₊₁.
- **Теорема Вейєрштрасса:** якщо послідовність монотонно зростає і обмежена зверху, то вона збіжна (і lim = sup). Спадна і обмежена знизу - збіжна (lim = inf).
- Для монотонної послідовності обмеженість - необхідна і достатня умова збіжності.

**Число e.** xₙ = (1 + 1/n)ⁿ зростає (біном Ньютона: кожна дужка (1 - k/n) росте з n) і обмежена числом 3 (k! ≥ 2ᵏ⁻¹). За Вейєрштрассом границя є, її позначили e ≈ 2,718281828.

## Тема 5. Вкладені відрізки, підпослідовності, Больцано-Вейєрштрасс (питання 7, 8)

**Принцип вкладених відрізків:** [a₁; b₁] ⊃ [a₂; b₂] ⊃ ..., і lim (bₙ - aₙ) = 0. Тоді існує **єдина** точка c, що належить усім відрізкам. Без умови «довжини → 0» точка є, але може бути не одна. Для інтервалів теорема хибна: (0; 1/n) не мають спільної точки.

**Підпослідовність:** x_{n₁}, x_{n₂}, ..., де n₁ < n₂ < ... Якщо xₙ → a, то будь-яка підпослідовність → a.

**Теорема Больцано-Вейєрштрасса:** з довільної обмеженої послідовності можна виділити збіжну підпослідовність. Ідея: ділимо відрізок навпіл і щоразу беремо половину, де безліч членів.

**Часткова границя** - границя підпослідовності (може бути ±∞). Верхня границя - sup усіх часткових, нижня - inf. Послідовність збіжна ⇔ верхня і нижня границі рівні.

## Тема 6. Фундаментальні послідовності, критерій Коші (питання 9)

```
{xₙ} фундаментальна ⇔
∀ε > 0 ∃n_ε ∀n > n_ε ∀m > n_ε:
          |xₙ - xₘ| < ε
```

**Критерій Коші:** послідовність збіжна ⇔ вона фундаментальна. Перевага: не треба знати саму границю. Розбіжність доводять запереченням: ∃ε > 0 ∀N ∃n, m > N: |xₙ - xₘ| ≥ ε (так доводять, що 1 + 1/2 + ... + 1/n розбіжна).

## Тема 7. Границя функції (питання 10, 11, 12, 13)

**За Коші (ε-δ):**

```
lim f(x) = A при x → x₀ ⇔
∀ε > 0 ∃δ > 0 ∀x:
 0 < |x - x₀| < δ ⇒ |f(x) - A| < ε
```

«0 <» означає: сама точка x₀ не враховується, f у ній може бути навіть не визначена.

**За Гейне:** для будь-якої послідовності xₙ → x₀, xₙ ≠ x₀ маємо f(xₙ) → A. Зручно доводити, що границі **нема**: знайти дві послідовності з різними f(xₙ). Приклад: sin(1/x) у нулі (xₙ = 1/(π/2 + 2πn) дає 1, yₙ = 1/(πn) дає 0).

**Теорема:** означення за Коші і за Гейне еквівалентні.

**Границя в нескінченності:** ∀ε > 0 ∃Δ > 0 ∀x: |x| > Δ ⇒ |f(x) - A| < ε.

**Однобічні:** f(x₀ - 0) - ліва (x → x₀, x < x₀), f(x₀ + 0) - права. Границя існує ⇔ ліва і права існують і рівні. Приклад: sgn x у нулі: зліва -1, справа 1, границі нема.

**Критерій Коші для функції:** скінченна границя в x₀ існує ⇔ ∀ε > 0 ∃δ > 0 ∀x', x'' з проколотого δ-околу x₀: |f(x') - f(x'')| < ε.

**Властивості:** границя єдина; функція зі скінченною границею обмежена біля x₀; якщо A > 0, то f > 0 біля x₀; f ≤ g ⇒ lim f ≤ lim g; теорема про проміжну функцію. Арифметика - як для послідовностей, лектор доводить через Гейне.

## Тема 8. Важливі границі (питання 14)

```
       sin x
 lim   ───── = 1
 x→0     x

 lim (1 + 1/x)ˣ = e
 x→∞

 lim (1 + x)^(1/x) = e
 x→0
```

Наслідки (x → 0): tg x / x → 1, arcsin x / x → 1, arctg x / x → 1, ln(1 + x)/x → 1, (eˣ - 1)/x → 1, (aˣ - 1)/x → ln a.

Швидке правило для 1^∞: якщо u → 1, v → ∞, то u^v → e^(lim (u - 1)·v). Наприклад ((x + 3)/(x - 1))^(2x) → e^(lim 4·2x/(x - 1)) = e⁸.

## Тема 9. Нескінченно малі і еквівалентні (питання 15)

α, β - нескінченно малі при x → a. Дивимось на C = lim α/β:

| C | Що це | Запис |
|---|---|---|
| 0 | α вищого порядку | α = o(β) |
| ∞ | β вищого порядку | β = o(α) |
| число ≠ 0 | одного порядку | α = O(β) |
| 1 | еквівалентні | α ~ β |

**Порядок** α відносно β: lim α/βᵏ = C, 0 < |C| < ∞. **Шкала н.м.:** x, x², x³, ... (при x → 0).

Таблиця (x → 0, замість x можна будь-яку u(x) → 0):

```
x ~ sin x ~ tg x ~ arcsin x
  ~ arctg x ~ ln(1 + x) ~ eˣ - 1
aˣ - 1 ~ x·ln a
1 - cos x ~ x²/2       [не з лекції]
(1 + x)ᵏ - 1 ~ k·x     [не з лекції]
```

**Правило заміни:** у границі частки і добутку множник можна замінити еквівалентним. **Доданки міняти не можна:** (tg x - sin x)/x³ → 1/2, а «x - x = 0» дає неправильну відповідь 0.

## Тема 10. Неперервність і точки розриву (питання 16, 17, 18)

f неперервна в точці x₀, якщо границя функції в точці x₀ дорівнює значенню функції в цій точці: lim f(x) = f(x₀). Це три умови: f(x₀) існує, границя існує і скінченна, вони рівні. Ще 4 рівносильні форми: через послідовності, ε-δ, через прирости (lim Δy = 0 при Δx → 0), через однобічні (f(x₀ - 0) = f(x₀ + 0) = f(x₀)).

- Сума, добуток, частка (знаменник ≠ 0) неперервних - неперервна.
- Складена функція з неперервних - неперервна: знак границі можна заносити під неперервну функцію.
- Усі елементарні функції неперервні там, де визначені.
- На відрізку [a; b]: неперервна на (a; b), справа в a, зліва в b.

**Класифікація розривів (як у лекції):**

| Вид | Однобічні границі |
|---|---|
| усувний | скінченні і рівні, але ≠ f(x₀) або f(x₀) нема |
| стрибок | скінченні, але різні; стрибок δ = f(x₀ + 0) - f(x₀ - 0) |
| II роду | хоча б одна нескінченна або не існує |

Усувний і стрибок разом - **розриви першого роду**. Приклади: sin x / x у 0 - усувний; sgn x у 0 - стрибок 2; 1/x і sin(1/x) у 0 - II роду.

Алгоритм: знайти «підозрілі» точки (знаменник 0, стик формул, межа області), у кожній порахувати ліву і праву границі окремо, порахувати f(x₀), назвати вид.

## Тема 11. Властивості неперервних на відрізку (питання 19)

Скрізь f **неперервна на відрізку [a; b]**. На інтервалі теореми хибні.

- **Больцано-Коші 1:** f(a)·f(b) < 0 ⇒ ∃c ∈ (a; b): f(c) = 0. (Так шукають корені поділом навпіл.)
- **Больцано-Коші 2:** f(a) = A, f(b) = B ⇒ для будь-якого C між A і B ∃c: f(c) = C.
- **Вейєрштрасс 1:** f обмежена на [a; b]. (1/x на (0; 1) необмежена - бо інтервал.)
- **Вейєрштрасс 2:** f досягає на [a; b] найбільшого і найменшого значень.
- **Обернена функція:** якщо f неперервна і зростає (спадає) на [a; b], то на [f(a); f(b)] існує обернена функція, теж неперервна і зростаюча (спадна).
- Перед ними - локальні теореми: неперервна в x₀ функція зберігає знак f(x₀) ≠ 0 і обмежена в околі x₀.

## Тема 12. Рівномірна неперервність, теорема Кантора (питання 20)

```
неперервна на E:
∀x₀ ∈ E ∀ε > 0 ∃δ(ε, x₀) > 0 ∀x:
 |x - x₀| < δ ⇒ |f(x) - f(x₀)| < ε

рівномірно неперервна на E:
∀ε > 0 ∃δ(ε) > 0 ∀x₁, x₂ ∈ E:
 |x₁ - x₂| < δ ⇒ |f(x₁) - f(x₂)| < ε
```

Різниця: у рівномірній δ залежить **тільки від ε** і годиться для всіх точок одразу.

**Теорема Кантора:** неперервна на відрізку функція рівномірно неперервна на цьому відрізку.

Приклади: 2x + 1 рівномірно неперервна на ℝ (δ = ε/2). 1/x на (0; 1) - ні (точки 1/n і 1/(n + 1) близькі, а значення різняться на 1). x² на ℝ - ні, а на [0; 2] - так (Кантор).

## Тема 14. Функції кількох змінних (питання 41-53)

> [ще не було на лекціях - звір з лекцією]. Означення про ℝⁿ (п. 41) - з файлу лектора «Вступ», решта - стандартне з підручника.

**ℝⁿ** - n-вимірний евклідів простір, відстань:

```
ρ(M', M'') =
 √((x₁' - x₁'')² + ... + (xₙ' - xₙ'')²)
```

δ-окіл точки M₀ - відкрита куля ρ(M, M₀) < δ. Внутрішня точка: є δ-окіл, що весь лежить у E. Відкрита множина - лише з внутрішніх точок. Межова точка: у будь-якому околі є точки з E і не з E. Замкнена множина містить усі свої межові точки. Область - відкрита зв'язна множина.

**Границя і неперервність** - як для однієї змінної, тільки |x - x₀| замінюємо на ρ. Границя не повинна залежати від шляху: xy/(x² + y²) у (0; 0) по y = 0 дає 0, по y = x дає 1/2, отже границі нема.

**Частинні похідні:** z'ₓ - похідна по x, коли y вважаємо сталим. Повний диференціал dz = z'ₓdx + z'ᵧdy. Неперервні частинні похідні ⇒ функція диференційовна.

**Неявна функція** F(x, y, z) = 0: z'ₓ = -F'ₓ/F'_z, z'ᵧ = -F'ᵧ/F'_z.

**Градієнт і похідна за напрямком:**

```
grad u = (u'ₓ; u'ᵧ; u'_z)
∂u/∂l = (grad u, l⁰),  l⁰ = l/|l|
max ∂u/∂l = |grad u|
```

Дотична площина до F(x, y, z) = 0 у M₀: F'ₓ(x - x₀) + F'ᵧ(y - y₀) + F'_z(z - z₀) = 0.

**Мішані похідні:** якщо z''ₓᵧ і z''ᵧₓ неперервні, вони рівні. d²z = z''ₓₓdx² + 2z''ₓᵧdxdy + z''ᵧᵧdy².

**Екстремум двох змінних:** необхідна умова z'ₓ = 0, z'ᵧ = 0. Достатня: A = z''ₓₓ, B = z''ₓᵧ, C = z''ᵧᵧ, Δ = AC - B².

```
Δ > 0, A > 0  ⇒  мінімум
Δ > 0, A < 0  ⇒  максимум
Δ < 0         ⇒  екстремуму нема
Δ = 0         ⇒  треба досліджувати далі
```

**Умовний екстремум (Лагранж):** L = f + λφ, розв'язати L'ₓ = 0, L'ᵧ = 0, φ = 0. **Найбільше і найменше в замкненій області:** стаціонарні точки всередині + точки на межі, потім порівняти значення.
