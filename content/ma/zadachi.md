## Множини та індукція

**Задача 1.** A = {x ∈ ℝ : x² - 5x + 4 < 0}, B = [2; 6]. Знайти A ∪ B, A ∩ B, A \ B, B \ A.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Розв'язуємо нерівність: x² - 5x + 4 = (x - 1)(x - 4) < 0 ⇔ 1 < x < 4. Отже A = (1; 4).

**Крок 2.** Малюємо обидві множини на прямій і читаємо відповідь:

```
A ∪ B = (1; 6]
A ∩ B = [2; 4)
A \ B = (1; 2)    2 ∈ B, викидаємо
B \ A = [4; 6]    4 ∉ A, лишається
```

**Крок 3.** Кінці перевіряємо окремо: 4 не належить A (нерівність строга), тому в A ∩ B кінець 4 круглий, а в B \ A - квадратний.

</details>

**Задача 2.** X = {(2n + 1)/(n + 1) : n ∈ ℕ}. Знайти sup X, inf X, max X, min X.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Випишемо елементи: 3/2; 5/3; 7/4; 9/5; ... Виділимо цілу частину: (2n + 1)/(n + 1) = 2 - 1/(n + 1). Чим більше n, тим менше віднімаємо - елементи зростають.

**Крок 2.** Найменший елемент при n = 1: 3/2. Отже inf X = min X = 3/2.

**Крок 3.** Кандидат на sup - число 2. Перевіряємо означення: 1) 2 - 1/(n + 1) < 2 для всіх n; 2) для ∀ε > 0 хочемо 2 - 1/(n + 1) > 2 - ε ⇔ n + 1 > 1/ε. Такий n є (принцип Архімеда). Отже sup X = 2.

**Крок 4.** 2 ∉ X (бо 1/(n + 1) ≠ 0), тому max X не існує.

Число: ε = 0,01 ⇒ n + 1 > 100, n = 100: 201/101 = 1,990099 > 1,99.

</details>

**Задача 3.** Довести індукцією: 1² + 2² + ... + n² = n(n + 1)(2n + 1)/6.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1 (база).** n = 1: ліва частина 1² = 1, права 1·2·3/6 = 1. Збіг.

**Крок 2 (припущення).** Нехай 1² + ... + k² = k(k + 1)(2k + 1)/6.

**Крок 3 (перехід).** Для n = k + 1 використовуємо припущення:

```
1² + ... + k² + (k + 1)²
= k(k+1)(2k+1)/6 + (k+1)²
= (k+1)·(k(2k+1) + 6(k+1))/6
= (k+1)(2k² + 7k + 6)/6
= (k+1)(k+2)(2k+3)/6
```

**Крок 4.** Це формула при n = k + 1 (бо 2(k + 1) + 1 = 2k + 3). За принципом індукції рівність правильна для всіх n.

Звідки (k + 2)(2k + 3): розкриваємо дужки: 2k² + 3k + 4k + 6 = 2k² + 7k + 6. Збіг.

</details>

**Задача 4.** Довести, що 4ⁿ + 15n - 1 ділиться на 9 для всіх n ∈ ℕ.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1 (база).** n = 1: 4 + 15 - 1 = 18 = 9·2.

**Крок 2 (припущення).** 4ᵏ + 15k - 1 ділиться на 9.

**Крок 3 (перехід).** Виділяємо вираз з припущення, домноживши на 4:

```
4ᵏ⁺¹ + 15(k+1) - 1
= 4·4ᵏ + 15k + 14
= 4(4ᵏ + 15k - 1) - 45k + 18
= 4(4ᵏ + 15k - 1) - 9(5k - 2)
```

**Крок 4.** Перший доданок ділиться на 9 за припущенням, другий має множник 9. Отже сума ділиться на 9.

Перевірка: 4·(15k - 1) = 60k - 4, а нам треба 15k + 14, різниця 15k + 14 - 60k + 4 = -45k + 18.

</details>

## Неперервність і розриви

**Задача 24.** Дослідити на неперервність y = (x² - 4)/(x² - 5x + 6).

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Знаменник (x - 2)(x - 3) = 0 при x = 2 і x = 3. Поза ними функція елементарна, тому неперервна.

**Крок 2.** x = 2: y = (x - 2)(x + 2)/((x - 2)(x - 3)) = (x + 2)/(x - 3) → 4/(-1) = -4 з обох боків. Границі скінченні і рівні, f(2) нема ⇒ **усувний розрив** (розрив I роду). Довизначивши f(2) = -4, усунемо його.

**Крок 3.** x = 3: (x + 2)/(x - 3): зліва 5/(мале від'ємне) → -∞, справа → +∞ ⇒ **розрив II роду**.

</details>

**Задача 25.** Дослідити y = 1/(1 + 2^(1/(x - 1))) у точці x = 1.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Зліва (x < 1): 1/(x - 1) → -∞, 2^(-∞) → 0, y → 1/(1 + 0) = 1.

**Крок 2.** Справа (x > 1): 1/(x - 1) → +∞, 2^(+∞) → +∞, y → 0.

**Крок 3.** Обидві скінченні, але різні ⇒ розрив I роду зі скінченним стрибком. Стрибок δ = f(1 + 0) - f(1 - 0) = 0 - 1 = -1.

</details>

**Задача 27.** Довести, що x³ - 3x + 1 = 0 має корінь на [0; 1], і знайти його з точністю 0,125.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** f(x) = x³ - 3x + 1 - многочлен, неперервна на [0; 1].

**Крок 2.** f(0) = 1 > 0, f(1) = 1 - 3 + 1 = -1 < 0. За першою теоремою Больцано-Коші ∃c ∈ (0; 1): f(c) = 0.

**Крок 3.** Ділимо навпіл:

```
f(0,5)   = -0,375   ⇒ [0; 0,5]
f(0,25)  =  0,266   ⇒ [0,25; 0,5]

```

**Задача 28.** Довести, що f(x) = x² рівномірно неперервна на [0; 2], але не на ℝ.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1 (на [0; 2]).** |x₁² - x₂²| = |x₁ - x₂|·|x₁ + x₂| ≤ 4|x₁ - x₂| (обидва ≤ 2). Беремо δ = ε/4 - не залежить від точки. (Це ж дає і теорема Кантора.)

**Крок 2 (на ℝ, заперечення).** Беремо ε = 1, x₁ = n + 1/n, x₂ = n.

**Крок 3.** |x₁ - x₂| = 1/n → 0: для будь-якого δ знайдеться n, що відстань < δ.

**Крок 4.** |x₁² - x₂²| = (n + 1/n)² - n² = 2 + 1/n² ≥ 1 = ε. Це заперечення рівномірної неперервності.

</details>

**Задача 29.** а) Чи існує lim xy/(x² + y²) при (x; y) → (0; 0)? б) z = x²·e^(xy): знайти z'ₓ, z'ᵧ і dz у точці (1; 0).

<details markdown="1"><summary>Розвʼязання</summary>

**а) Крок 1.** Ідемо по прямій y = kx: kx²/(x² + k²x²) = k/(1 + k²).

**а) Крок 2.** k = 0 дає 0, k = 1 дає 1/2. Різні шляхи - різні числа ⇒ границі нема.

**б) Крок 1.** По x (y стале), правило добутку: z'ₓ = 2x·e^(xy) + x²·y·e^(xy).

**б) Крок 2.** По y (x стале): z'ᵧ = x²·x·e^(xy) = x³·e^(xy).

**б) Крок 3.** У (1; 0): e⁰ = 1, z'ₓ = 2, z'ᵧ = 1. dz = 2dx + dy.

**Задача 32.** Дотична площина і нормаль до z = x² + y² у точці (1; 1; 2).

<details markdown="1"><summary>Розвʼязання</summary>

**Задача 36.** Методом Лагранжа знайти екстремуми f = x + 2y за умови x² + y² = 5.

<details markdown="1"><summary>Розвʼязання</summary>

**Задача 37.** Найбільше і найменше значення z = x² - 2x + y² у крузі x² + y² ≤ 4.
