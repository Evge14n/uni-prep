## Кінематика

### Задача 1. Розворот: шлях і переміщення

Тіло рухається вздовж осі X: x = 2 + 3t - 0,5t² (усе в СІ). Коли тіло зупиниться?
Знайти шлях і переміщення за перші 5 с і обидві середні швидкості.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Порівнюємо з x = x₀ + v₀t + at²/2: x₀ = 2 м, v₀ = 3 м/с, a/2 = -0,5, тобто a = -1 м/с².

**Крок 2.** v = v₀ + at = 3 - t. Зупинка v = 0 ⇒ t = 3 с.

**Крок 3.** Координати:
```
x(0) = 2 м
x(3) = 2 + 9 - 4,5 = 6,5 м
x(5) = 2 + 15 - 12,5 = 4,5 м
```

**Крок 4.** Тіло йшло вперед, потім назад, тому шлях = (6,5 - 2) + (6,5 - 4,5) = 6,5 м.
Переміщення = x(5) - x(0) = 2,5 м.

**Крок 5.** Шляхова середня 6,5/5 = 1,3 м/с; середня переміщення 2,5/5 = 0,5 м/с.

**Відповідь:** t = 3 с; s = 6,5 м; Δx = 2,5 м; середні 1,3 м/с і 0,5 м/с.

Типова помилка: шлях = |x(5) - x(0)|. Шлях рахують по ділянках до і після розвороту.

</details>

### Задача 2. Дві середні швидкості

Автомобіль першу половину **шляху** їхав зі швидкістю 60 км/год, другу - 40 км/год.
Яка середня швидкість? А якщо першу половину **часу** - 60, другу - 40?

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Середня шляхова швидкість = весь шлях / весь час.

**Крок 2.** Половини шляху (весь шлях 2s): t₁ = s/v₁, t₂ = s/v₂.
```
<v> = 2s/(s/v₁ + s/v₂)
    = 2·v₁·v₂/(v₁ + v₂)
    = 2·60·40/100 = 48 км/год
```

**Крок 3.** Половини часу: <v> = (v₁t + v₂t)/(2t) = (v₁ + v₂)/2 = 50 км/год.

**Відповідь:** 48 км/год (половини шляху); 50 км/год (половини часу).

Типова помилка: одразу (60 + 40)/2 = 50 для половин шляху. Повільну половину машина
їде довше, тож середня менша за 50.

</details>

### Задача 3. Тангенціальне і нормальне прискорення

r = 2t·i + t²·j (м). Для t = 1 с знайти |v|, a_τ, a_n і радіус кривизни R.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** v = dr/dt = 2·i + 2t·j, |v| = √(4 + 4t²). При t = 1: √8 = 2,83 м/с.

**Крок 2.** a = dv/dt = 2·j, |a| = 2 м/с² (стале).

**Крок 3.** a_τ = d|v|/dt = 4t/√(4 + 4t²); при t = 1: 4/2,83 = 1,41 м/с².

**Крок 4.** a_n = √(|a|² - a_τ²) = √(4 - 2) = 1,41 м/с².

**Крок 5.** a_n = v²/R ⇒ R = v²/a_n = 8/1,41 = 5,66 м.

**Відповідь:** |v| = 2,83 м/с; a_τ = 1,41 м/с²; a_n = 1,41 м/с²; R = 5,66 м.

Траєкторія y = x²/4 - парабола.

</details>

### Задача 4. Кидок під кутом з висоти

З балкона на висоті h = 20 м кинули камінь зі швидкістю v₀ = 15 м/с під кутом α = 30°
вгору до горизонту. Знайти час польоту, дальність, швидкість при падінні і кут удару.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Осі: x горизонтально, y вгору, початок на землі під балконом.
```
x = v₀·cos α·t
y = h + v₀·sin α·t - g·t²/2
v₀x = 12,99 м/с,  v₀y = 7,5 м/с
```

**Крок 2.** Падіння y = 0: 4,9t² - 7,5t - 20 = 0.
```
t = (v₀y + √(v₀y² + 2gh))/g
  = (7,5 + 21,17)/9,8 = 2,93 с
```
Другий корінь від'ємний.

**Крок 3.** L = v₀x·t = 12,99·2,926 = 38,0 м.

**Крок 4.** v_y = 7,5 - 9,8·2,926 = -21,17 м/с; v = √(12,99² + 21,17²) = 24,8 м/с.
Перевірка енергією: v = √(v₀² + 2gh) = √617 = 24,8 м/с - від кута не залежить.

**Крок 5.** tg β = 21,17/12,99 ⇒ β = 58,5° нижче горизонту.

**Відповідь:** t = 2,93 с; L = 38,0 м; v = 24,8 м/с; β = 58,5°.

Типова помилка: t = 2v₀·sin α/g - це лише для кидка «із землі на землю».

</details>

### Задача 5. Диск розкручується

Диск з місця рівноприскорено зробив N = 50 обертів за t = 10 с. Для точки на відстані
R = 0,2 м від осі в момент t = 10 с знайти ε, ω, v, a_τ, a_n.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Кут φ = 2π·N = 314,2 рад.

**Крок 2.** φ = ε·t²/2 (ω₀ = 0) ⇒ ε = 2φ/t² = 6,28 рад/с².

**Крок 3.** ω = ε·t = 62,8 рад/с; v = ω·R = 12,6 м/с.

**Крок 4.** a_τ = ε·R = 1,26 м/с²; a_n = ω²·R = 790 м/с².

**Відповідь:** ε = 6,28 рад/с²; ω = 62,8 рад/с; v = 12,6 м/с; a_τ = 1,26 м/с²; a_n = 790 м/с².

Повне прискорення майже дорівнює a_n.

</details>

### Задача 6. Катер і пліт (Іродов № 1.1)

Катер, пливучи за течією, обігнав пліт у пункті A. Через τ = 60 хв він повернув назад і
зустрів пліт на відстані l = 6,0 км нижче пункту A. Двигун працював однаково. Знайти
швидкість течії.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Беремо систему відліку «вода» - у ній пліт стоїть.

**Крок 2.** У воді катер відпливає від плота τ і з тією ж швидкістю повертається - теж τ.
Від обгону до зустрічі минуло 2τ = 2 год.

**Крок 3.** За цей час пліт (разом з водою) пройшов відносно берега l:
u = l/(2τ) = 6/2 = 3 км/год.

**Відповідь:** u = 3,0 км/год.

Типова помилка: писати рівняння в системі «берег» з невідомою швидкістю катера. Вона не
потрібна - тому її й не дали.

</details>

### Задача 7. Брусок на похилій площині

α = 30°, μ = 0,2, брусок з місця проїхав l = 2 м. Знайти прискорення, час і швидкість внизу.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Сили: mg, N, тертя вгору по площині (брусок їде вниз).

**Крок 2.** Вісь ⊥ площині: N = mg·cos α. Вісь вниз по площині: ma = mg·sin α - μ·mg·cos α.

**Крок 3.** a = g(sin α - μ·cos α) = 9,8·(0,5 - 0,173) = 3,20 м/с².

**Крок 4.** t = √(2l/a) = 1,12 с; v = √(2al) = 3,58 м/с.

**Відповідь:** a = 3,20 м/с²; t = 1,12 с; v = 3,58 м/с.

</details>

### Задача 8. Брусок штовхнули вгору по похилій з тертям

v₀ = 10 м/с, α = 30°, μ = 0,2. Знайти прискорення вгору, шлях до зупинки, час підйому,
прискорення вниз, швидкість повернення і час спуску.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Вгору тертя діє вниз разом з mg·sin α:
```
a↑ = g(sin α + μ·cos α)
   = 9,8·0,673 = 6,60 м/с²
```

**Крок 2.** s = v₀²/(2a↑) = 7,58 м; t↑ = v₀/a↑ = 1,52 с.

**Крок 3.** Чи поїде назад? tg α = 0,577 > μ = 0,2 - так.

**Крок 4.** Вниз тертя діє вгору: a↓ = g(sin α - μ·cos α) = 3,20 м/с².

**Крок 5.** v = √(2·a↓·s) = 6,97 м/с; t↓ = √(2s/a↓) = 2,18 с.

**Відповідь:** a↑ = 6,60 м/с²; s = 7,58 м; t↑ = 1,52 с; a↓ = 3,20 м/с²; v = 6,97 м/с; t↓ = 2,18 с.

Типова помилка: одне прискорення на весь рух. Тертя міняє напрям разом з рухом.

</details>

### Задача 9. Машина Атвуда

m₁ = 0,3 кг і m₂ = 0,2 кг на нитці через невагомий блок. Знайти прискорення і натяг.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** m₁ важчий - їде вниз. Однакові |a| і натяг T.
```
m₁a = m₁g - T
m₂a = T - m₂g
```

**Крок 2.** Додаємо: a = (m₁ - m₂)g/(m₁ + m₂) = 0,1·9,8/0,5 = 1,96 м/с².

**Крок 3.** T = m₂(g + a) = 0,2·11,76 = 2,35 Н (те саме дає 2m₁m₂g/(m₁ + m₂)).

**Відповідь:** a = 1,96 м/с²; T = 2,35 Н.

</details>

### Задача 10. Брусок на похилій і тягарець через блок

Брусок m₁ = 2 кг на похилій (α = 30°, μ = 0,1), нитка через блок на вершині, на ній
висить m₂ = 1,5 кг. Знайти прискорення і натяг.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Спершу напрям. m₂g = 14,7 Н, m₁g·sin α = 9,8 Н. Різниця 4,9 Н більша за
найбільше тертя μm₁g·cos α = 1,70 Н, тож m₂ іде вниз.

**Крок 2.**
```
m₂a = m₂g - T
m₁a = T - m₁g·sin α - μm₁g·cos α
```

**Крок 3.** Додаємо: a = (14,7 - 9,8 - 1,70)/3,5 = 0,915 м/с².

**Крок 4.** T = m₂(g - a) = 1,5·8,885 = 13,3 Н.

**Відповідь:** a = 0,915 м/с²; T = 13,3 Н.

Типова помилка: не перевірити напрям. При m₂ = 1,1 кг система стоїть, а формула дала б
від'ємне a.

</details>

### Задача 11. Автомобіль на опуклому мосту

m = 1000 кг, R = 40 м, v = 54 км/год. Знайти силу тиску на міст у верхній точці і
швидкість, за якої авто відірветься.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** 54 км/год = 15 м/с.

**Крок 2.** До центра (вниз): mg - N = mv²/R ⇒ N = m(g - v²/R) = 1000·(9,8 - 5,625) = 4175 Н.
За третім законом авто тисне на міст так само.

**Крок 3.** Відрив: N = 0 ⇒ v = √(gR) = √392 = 19,8 м/с.

**Відповідь:** N = 4175 Н; v = 19,8 м/с.

</details>

### Задача 12. Конічний маятник

Кулька m = 0,2 кг на нитці l = 1 м описує горизонтальне коло, нитка відхилена на
α = 30° від вертикалі. Знайти натяг, кутову швидкість і період.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Сили: mg і натяг F. Радіус кола r = l·sin α.

**Крок 2.** Вертикаль: F·cos α = mg ⇒ F = 1,96/0,866 = 2,26 Н.

**Крок 3.** Горизонталь: F·sin α = mω²·l·sin α ⇒ ω² = g/(l·cos α) = 11,32 ⇒ ω = 3,36 рад/с.

**Крок 4.** T = 2π/ω = 1,87 с.

**Відповідь:** F = 2,26 Н; ω = 3,36 рад/с; T = 1,87 с.

Доцентрову роль грає горизонтальна складова натягу, окремої «доцентрової сили» на
малюнку нема.

</details>

### Задача 13. Човен з вимкненим двигуном (опір ∝ v)

m = 200 кг, v₀ = 5 м/с, сила опору F = -k·v, k = 40 кг/с. За який час швидкість упаде
вдвічі? Який шлях до повної зупинки? Який шлях, поки швидкість падала вдвічі?

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** m·dv/dt = -k·v ⇒ dv/v = -(k/m)dt ⇒ v = v₀·e^(-kt/m).

**Крок 2.** v = v₀/2: t = (m/k)·ln 2 = 5·0,693 = 3,47 с.

**Крок 3.** s = ∫v dt = (m·v₀/k)·(1 - e^(-kt/m)). При t → ∞: s = 25 м. При t = 3,47 с: 12,5 м.

**Відповідь:** t = 3,47 с; s = 25 м; s½ = 12,5 м.

Типова помилка: рахувати як рівносповільнений рух. Сила падає разом зі швидкістю.

</details>

### Задача 14. Кулька на нитці у вагоні

</details>

### Задача 17. Людина в човні

Човен M = 120 кг, довжина L = 3 м, людина m = 60 кг переходить з корми на ніс. На скільки
зсунеться човен? Опору води нема.

<details markdown="1"><summary>Розвʼязання</summary>

### Задача 18. Ракета

**Відповідь:** v = 2773 м/с; m₀/m = 51,9.

</details>

### Задача 21. Балістичний маятник

Куля m = 9 г зі швидкістю 400 м/с застрягає в бруску M = 2 кг на нитці. Знайти швидкість
бруска після удару, висоту підйому і частку енергії кулі, що пішла в тепло.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Удар: лише імпульс. mv = (m + M)V ⇒ V = 3,6/2,009 = 1,79 м/с.

**Крок 2.** Після удару енергія: (m + M)V²/2 = (m + M)gh ⇒ h = V²/(2g) = 0,164 м.

**Крок 3.** Частка в тепло = M/(m + M) = 2/2,009 = 99,6 %.

**Відповідь:** V = 1,79 м/с; h = 16,4 см; 99,6 %.

Головна пастка: писати mv²/2 = (m + M)gh одразу. Удар і підйом - два етапи.

</details>

### Задача 22. Пружний лобовий удар

Куля m₁ = 1 кг (v₁ = 4 м/с) налітає на нерухому m₂ = 3 кг. Удар пружний, лобовий.

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Сл. (5.172)-(5.173) з v₂ = 0:
```
v₁' = (m₁ - m₂)v₁/(m₁ + m₂)
    = (1 - 3)·4/4 = -2 м/с
v₂' = 2m₁v₁/(m₁ + m₂) = 2 м/с
```

**Крок 2.** Перевірка: імпульс 4 = 1·(-2) + 3·2; енергія 8 Дж = 2 + 6.

**Відповідь:** v₁' = -2 м/с (легка відскочила); v₂' = 2 м/с.

</details>

### Задача 23. Тіло зісковзує з півсфери

Маленьке тіло без початкової швидкості зісковзує з вершини гладкої півсфери R = 1,2 м.
На якій висоті над центром воно відірветься, з якою швидкістю, під яким кутом від вертикалі?

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Енергія: mgR(1 - cos θ) = mv²/2.

**Крок 2.** До центра: mg·cos θ - N = mv²/R. Відрив: N = 0.

**Крок 3.** g·cos θ = 2g(1 - cos θ) ⇒ cos θ = 2/3 ⇒ θ = 48,2°.

**Крок 4.** h = R·cos θ = 0,8 м; v = √(2gR/3) = √7,84 = 2,8 м/с.

**Відповідь:** h = 0,8 м; v = 2,8 м/с; θ = 48,2°.

</details>

### Задача 24. Мертва петля

Тіло m = 0,1 кг ковзає без тертя по жолобу з петлею R = 0,5 м. З якої найменшої висоти H
його пустити? З якою силою тисне на жолоб унизу петлі? А якщо це суцільна кулька, що
котиться без ковзання?

<details markdown="1"><summary>Розвʼязання</summary>

**Крок 1.** Верх петлі: mg + N = mv²/R, на межі N = 0 ⇒ v² = gR.

**Крок 2.** mgH = mg·2R + mgR/2 ⇒ H = 2,5R = 1,25 м.

**Крок 3.** Унизу v² = 2gH = 5gR: N - mg = 5mg ⇒ N = 6mg = 5,88 Н.

**Крок 4.** Кулька: E_k = mv²/2 + (2/5)mr²(v/r)²/2 = (7/10)mv². H = 2R + 0,7R = 1,35 м.

**Відповідь:** H = 1,25 м; N = 5,88 Н; H_кульки = 1,35 м.

Типова помилка: умова «v = 0 угорі» замість «N = 0».

</details>
