## Передбач, потім запусти

1. Синус 90 - це 1?

```bash
python3 -c 'import math; print(math.sin(90), math.sin(math.radians(90)))'
```

<details markdown="1"><summary>Відповідь</summary>

```text
0.8939966636005579 1.0
```

`math.sin` чекає радіани. 90 радіан - це не 90°. Без `math.radians` doctest завдання 3 не пройде.
</details>

2. Косинус 90° - рівно нуль?

```bash
python3 -c 'import math; print(math.cos(math.radians(90)), f"{math.cos(math.radians(90)):.2f}")'
```

<details markdown="1"><summary>Відповідь</summary>

```text
6.123233995736766e-17 0.00
```

Дробові числа в компʼютері наближені: замість 0 вийшло 6·10⁻¹⁷. Формат `:.2f` показує `0.00`, тому doctest
з `0.00` проходить. Порівнювати такі числа через `==` не можна.
</details>

3. Що з цього вийде?

```bash
python3 -c 'print(f"{-0.001:.2f}", 2 ** 3 ** 2, -2 ** 2)'
```

<details markdown="1"><summary>Відповідь</summary>

```text
-0.00 512 -4
```

Мінус зберігається навіть після округлення (`-0.00` - не те саме, що `0.00` для doctest). `**` рахується справа
наліво: 3² = 9, потім 2⁹ = 512. А `-2 ** 2` - це `-(2 ** 2)`, бо `**` сильніший за унарний мінус.
</details>

4. Ланцюжок порівнянь і `and`/`or`:

```bash
python3 -c 'print(0 <= 5 <= 10, 5 > 3 and 2 > 4 or 1 > 0)'
```

<details markdown="1"><summary>Відповідь</summary>

```text
True True
```

`0 <= 5 <= 10` - це `0 <= 5 and 5 <= 10`. `and` виконується раніше за `or`: `(True and False) or True` = `True`.
Ставь дужки, коли змішуєш `and` і `or` - так читати легше і помилитися важче.
</details>

5. Останні цифри:

```bash
python3 -c 'print(111 % 100, 111 % 10, 1013 % 100)'
```

<details markdown="1"><summary>Відповідь</summary>

```text
11 1 13
```

У 111 остання цифра 1, але дві останні - 11, тому «111 років», а не «рік».
</details>

## Коли помиляється doctest викладача

**Завдання 1, точка (-5, 0).** Вона лежить **на межі** - там, де дуга кола зустрічається з лівим відрізком. Умова
каже «включно з межею», тобто мало б бути `True`. А doctest чекає:

```text
    >>> check_point_belonging(-5, 0)
    False
```

Якщо всі межі в тебе нестрогі (`<=`), пройдуть 15 прикладів з 16:

```text
Failed example:
    check_point_belonging(-5, 0)
Expected:
    False
Got:
    True
...
   1 of  16 in __main__.check_point_belonging
```

Що робити: це суперечність умови і doctest. Щоб doctest пройшли (а це критерій викладача), подумай, яку саме
частину межі біля (-5, 0) треба зробити строгою, - і обовʼязково напиши викладачу про цю точку. Інша межова

## Як роблять профі

- **Геометрію перевіряють малюнком.** Можна намалювати точки з doctest і свою область у matplotlib (Урок 08, ЛР3)
  і побачити, де помилка. Так роблять і з реальними даними: спершу графік, потім висновок.
- **Числа з крапкою порівнюють з допуском**, а не `==`: `math.isclose(a, b)`.
  https://docs.python.org/3/library/math.html
- **Таблиця перевірок замість драбини `if`.** У великих програмах сім повідомлень про помилки збирають з
  частин (список проблем → `", ".join(...)`), а не перебирають усі комбінації. У ЛР2 - роби так, як вимагають doctest.
- **`if __name__ == "__main__":`** - у ЛР2 `if` поза функцією завдання 1 не заборонений, але викладач дав
  заготовку без нього; якщо хочеш так - спитай. https://docs.python.org/3/library/__main__.html

## Самоперевірка

1. Чому в завданні 1 функція може одразу написати `return` з умовою, і що вона поверне?
2. Як подати в програму відʼємне число через `printf`?

4. Чому `math.sin(90)` не дорівнює 1 і як це виправити?
5. Що не так з doctest `check_point_belonging(-5, 0)` і що з цим робити?

<details markdown="1"><summary>Відповіді</summary>

1. Порівняння і `and`/`or`/`not` самі дають `True` або `False`, тож `return вираз` уже повертає `bool` - `if`
   не потрібен (с. 11 методички, приклад `return x >= 0 and y <= 5`).
2. `printf -- "-5\n"` (дві риски кажуть, що опції скінчились) або `printf '%s\n' -5`.
3. У doctest `age_chat` очікуваний текст без лапок - так виглядає друк. У `year_word` - у лапках (`'рік'`) -
   так виглядає повернений рядок.
4. `math.sin` приймає радіани; 90 радіан - це не 90°. Треба `math.sin(math.radians(90))`.
5. Точка лежить на межі області, а умова каже «включно з межею» - мало б бути `True`, doctest чекає `False`.
   Зробити так, щоб doctest пройшли (одна частина межі строга), і написати викладачу про суперечність.
