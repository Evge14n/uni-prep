## Коротко

**turtle** («черепашка») - модуль Python для малювання: уявна черепашка повзе по вікну і лишає слід. Вікно малює
бібліотека **Tk** (через модуль `tkinter`). На свіжій Mint 22.3 пакета `python3-tk` нема, його треба поставити один раз.
Скрипт `ustanovka-mint.sh` (урок 03) це вже робить.

| Що | Команда / рядок коду |
|---|---|
| поставити Tk для turtle (один раз) | `sudo apt install python3-tk` |
| перевірити, що Tk є | `python3 -c "import tkinter; print(tkinter.TkVersion)"` → `8.6` |
| запустити малюнок | `python3 lr4_1_1.py` - відкриється вікно |
| тримати вікно відкритим | останній рядок програми `turtle.done()` |
| закрити вікно кліком у ньому | замість `done()` - `screen.exitonclick()` |
| зупинити програму | закрити вікно хрестиком ✕; поки ще малює - `Ctrl+C` у терміналі (не завжди); останній засіб - `Ctrl+\` |
| перевірити математику без вікна | `python3 -m doctest -v lr4_1_1.py` (бо `testmod()` у тебе під `if __name__`, крок 3) |

Головне про вікно:

```text
python3 lr4_1_1.py
   │
   ├─ рядки малювання виконуються, вікно відкрите
   │
   ├─ turtle.done()  ← тут програма ЧЕКАЄ: вікно живе, термінал зайнятий
   │                    (turtle.done - це те саме, що turtle.mainloop)
   │
   └─ закрив вікно хрестиком → done() закінчився → програма йде далі → кінець
```

Якщо `turtle.done()` нема, вікно закривається відразу після останньої команди (так і написано в ЛР4, с. 1).
Поки вікно відкрите, термінал не приймає нових команд. Це нормально: закрий вікно хрестиком ✕. `Ctrl+C` у терміналі
тут **не допоможе**: у `turtle.done()` програмою керує Tk (цикл подій вікна), і Python не обробляє Ctrl+C, поки
Tk чекає. Якщо вікно зависло і не закривається - `Ctrl+\` у терміналі (крок 4).

Готових doctest-ів до ЛР4 викладач не дав: є лише PDF. Малюнок doctest-ом не перевіриш, а математику (кути, радіуси,
моделювання зіткнень) - можна. Для цього є **`turtle.TNavigator()`** - «черепашка без вікна»: уміє `forward`, `left`,
`goto` і рахує позицію, але нічого не малює. Тому doctest з нею працює будь-де, навіть без графіки.

## Передбач, потім запусти

**1.** Шестикутник «без вікна». Що надрукує останній рядок?

```python
import turtle

nav = turtle.TNavigator()
for _ in range(6):
    nav.forward(50)
    nav.left(60)
print(nav.position())
print(round(nav.xcor(), 6), round(nav.ycor(), 6))
```

<details markdown="1"><summary>Відповідь</summary>

```text
(-0.00,0.00)
-0.0 0.0
```

Черепашка повернулась у старт, але float має похибку: x вийшов `-3.9e-14`, крихітне відʼємне число. Після `round`
лишається **відʼємний нуль** `-0.0`. Для Python `-0.0 == 0.0` - це `True`, але doctest порівнює **текст**, і
`-0.0` ≠ `0.0`. Тому в doctest краще писати перевірку так: `nav.distance(0, 0) < 1e-9` → `True`.
</details>

**2.** Кольори по колу (з ЛР4, с. 4). Що надрукує?

```python
colors = ["gold", "crimson", "lime", "cyan"]
for step in range(6):
    print(step, colors[step % len(colors)])
```

<details markdown="1"><summary>Відповідь</summary>

```text
0 gold
1 crimson
2 lime
3 cyan
4 gold
5 crimson
```

`step % 4` дає 0, 1, 2, 3, 0, 1, ... - індекс «ходить по колу». `len(colors)` замість числа 4 - щоб код не зламався,
коли додаси пʼятий колір.
</details>

**3.** Ти назвав свій файл `turtle.py` (бо «це ж лаба з turtle») і запустив `python3 turtle.py`. У файлі:

```python
import turtle

turtle.forward(100)
turtle.done()
```

<details markdown="1"><summary>Відповідь</summary>

```text
AttributeError: partially initialized module 'turtle' has no attribute 'forward' (most likely due to a circular import)
```

`import turtle` шукає модуль спершу в теці скрипта і знаходить **твій** `turtle.py`, а не справжній. Твій файл імпортує
сам себе, і `forward` у ньому нема. Ліки: перейменуй файл (`lr4_1_1.py`). Те саме буде з `math.py`, `random.py` тощо.
</details>

**4.** Ти зайшов на ноутбук по ssh (урок 21) або в текстову консоль `Ctrl+Alt+F2` і запустив малюнок. Що буде?

<details markdown="1"><summary>Відповідь</summary>

Вікна відкрити нікуди, останній рядок помилки:

```text

```

`DISPLAY` - змінна, яка каже програмі, на який екран малювати. У графічному терміналі Cinnamon вона є, у ssh і в TTY -
нема. Turtle запускай у звичайному терміналі на робочому столі (`Ctrl+Alt+T`). Doctest з `TNavigator` працює і там, і там.
</details>

**Крок 3. Один файл на завдання.** Назви: `lr4_1_1.py`, `lr4_1_2.py`, ..., `lr4_2_clock.py`, `lr4_3_balls.py`
(ніколи не `turtle.py`). Відкрий редактор:

```bash
nano lr4_1_1.py
```

Структура файлу (заглушки `...` - місця для твого коду):

```text
# ЛР4, завдання 1.1
import doctest
import math
import turtle


def ...(...) -> ...:          ← функції з умови (назви й параметри - як у PDF)
    """Що робить, одним реченням.

    >>> приклад виклику           ← doctest лише для того, що ПОВЕРТАЄ число
    очікуваний результат
    """
    ...


if __name__ == "__main__":       ← усе, що малює, - тільки тут
    doctest.testmod()
    screen = turtle.Screen()
    screen.setup(600, 600)
    ... малювання ...
    turtle.done()                ← останній рядок
```

Чому малювання під `if __name__ == "__main__":`. Команда `python3 -m doctest файл.py` **імпортує** файл. Усе, що
стоїть на верхньому рівні, виконається: на ноутбуці вискочить вікно, а без екрана буде `TclError`. Під `if` малювання
запускається лише від `python3 lr4_1_1.py`, а тести - тихо, без вікна.

Тому в **твоїх** файлах ЛР4 команда `python3 -m doctest -v` чесна. На файлах викладача, де `doctest.testmod()` стоїть
просто внизу файлу (ЛР1, ЛР5), вона дає чужий провал `DebugRunner` - там перевіряй `python3 файл.py -v` або
`perevir` (урок 04, «Типові помилки» п. 10).

Збереження в nano: `Ctrl+O`, `Enter`; вихід: `Ctrl+X` (урок 03).

**Крок 4. Запуск і вікно.**

```bash
python3 lr4_1_1.py
```

- Зʼявилось вікно, малюнок готовий - роздивись і закрий хрестиком ✕. Термінал знову приймає команди.
- Хочеш закривати кліком по вікну - заміни `turtle.done()` на `screen.exitonclick()` (`screen = turtle.Screen()`).
- Малює дуже довго (наприклад, нескінченний цикл малювання) - закрий вікно ✕ або клацни в термінал і натисни
  `Ctrl+C`. Поки йде малювання, `Ctrl+C` **може** спрацювати (останній рядок буде `KeyboardInterrupt` - це не помилка
  в коді, це ти зупинив програму), а може й ні. Коли програма вже дійшла до `turtle.done()` - точно ні: там чекає
  Tk, і Ctrl+C він не бачить. Закривай вікно.
- Вікно зависло і не закривається - останній засіб: у терміналі `Ctrl+\` (сигнал SIGQUIT - «негайно вийди»).
  Програма вмирає одразу, без traceback, термінал пише (перевірено в тестовій Mint на звичайній програмі, що чекала):

```text
Quit (core dumped)
```

  На українській Mint - `Вихід (збережено знімок оперативної пам’яті)`. «Знімок памʼяті» - службовий файл для
  розбору падіння, тобі він не потрібен. Код виходу - 131 (`echo $?`).
- Закрив вікно хрестиком **посеред** малювання - буде помилка `turtle.Terminator` (вікна вже нема, а черепашка ще
  малює). Теж не баг: просто дочекайся кінця. Текст цієї помилки тут не відтворено (потрібен екран), опис - у
  «Курс/ДОВІДНИК-ФУНКЦІЙ.md», розділ turtle → `turtle.Terminator`.

**Крок 5. Математика - doctest без вікна.** Не пиши doctest, який створює `turtle.Turtle()` чи `turtle.Screen()`: він
відкриє вікно. Винось обчислення у функцію, що **повертає** число, а рух перевіряй через `TNavigator`.
Приклад на **іншій** задачі (не з ЛР4): скільки сторін має правильний многокутник, якщо на кожній вершині черепашка
повертає на `turn` градусів. Файл `bagatokutnyk.py`:

```python
def side_count(turn: float) -> int:
    """Скільки сторін має правильний многокутник із поворотом turn.

    >>> side_count(72)
    5
    >>> import turtle
    >>> nav = turtle.TNavigator()
    >>> for _ in range(side_count(72)):
    ...     nav.forward(100)
    ...     nav.left(72)
    >>> nav.distance(0, 0) < 1e-9
    True
    """
    return round(360 / turn)
```

```bash
python3 -m doctest -v bagatokutnyk.py | tail -n 3
```

```text
5 tests in 2 items.
5 passed and 0 failed.
Test passed.
```

`import turtle` стоїть усередині doctest, бо поза тестами модуль у цьому файлі не потрібен. Якби він був угорі
файлу, flake8 сказав би `F401 'turtle' imported but unused` (імпортовано, але не використано). У самій лабі `turtle`
малює, тож там імпорт угорі - на місці.

Ідея: «обійшов фігуру - повернувся в старт» перевіряється без жодного вікна. Так само можна перевірити кут своєї зірки
з 1.1 (після n відрізків черепашка має бути в старті) або координати точок троянди з 1.8.

**Крок 6. Підказки по завданнях** (без розвʼязків - розвʼязок твій).

- **1.1 зірка.** Кут - готова формула з умови. `math.gcd(n, k)` дає найбільший спільний дільник (ДОВІДНИК-ФУНКЦІЙ:
  `math.gcd()`). Попередження - звичайний `print`. Фарба: `begin_fill()` до циклу, `end_fill()` після.
- **1.2-1.10.** Майже скрізь одна схема: `for` на N повторів, у тілі - одна фігура і поворот. Колір по колу - як у
  «Передбач» №2. Зміна товщини чи кольору «першим 12 - одне, наступним 12 - інше» - це умова на номер ітерації
  (`if`/`elif` або цілочисельне ділення `//`). Потрібне: `circle(r)`, `circle(r, steps=6)`, `pensize`, `pencolor`,
  `setheading`, `goto`, `penup`/`pendown` (ДОВІДНИК, розділ turtle).
- **1.8 троянда.** Кут у градусах → радіани: `math.radians` (ДОВІДНИК: `math.radians()`); точки сполучай `goto`,
  перший перехід - з піднятим пером, щоб не було лінії з центру.
- **1.11 пейзаж.** Список точок `[(x, y), ...]` і цикл `for x, y in points` (ЛР4, с. 6). Порядок шарів: що
  намальоване пізніше, лежить зверху.
- **2 годинник.** Каркас з 8 кроків - ЛР4, с. 10; формули плавних стрілок - с. 7-8. На Linux права кнопка миші в Tk -
  `btn=3` (примітка «може бути btn=2» на с. 9 - про macOS; перевір на своєму ноутбуці кліком). День тижня:
  `datetime.now().strftime("%A")` дає англійською (`Monday`), бо Python за замовчуванням не бере мову системи;
  простіше мати свій список українських назв і брати з нього за номером `datetime.now().weekday()` (0 - понеділок).
- **3 зіткнення.** Розділи програму на «фізику» (функція, що повертає N і S, - її можна покрити doctest) і «показ»
  (анімація, графіки). Тоді фізику перевіриш за секунду без вікна. Вхідні дані без набору руками:
  `printf '1\n100\n10\n1\n' | python3 lr4_3_balls.py` (порядок - як питає твоя програма).
- **Графіки matplotlib** (Завдання 3). `plt.show()` відкриває вікно (воно теж на Tk). Надійніше зберегти у файл і

## Типові помилки

| Що бачиш | Чому | Що робити |
|---|---|---|
| `ModuleNotFoundError: No module named 'tkinter'` | нема пакета `python3-tk` (на свіжій Mint 22.3 його нема) | `sudo apt install python3-tk` |
| `_tkinter.TclError: no display name and no $DISPLAY environment variable` | запуск без графіки: ssh, TTY | запускай у терміналі на робочому столі |
| `AttributeError: partially initialized module 'turtle' has no attribute 'forward' (most likely due to a circular import)` | файл названо `turtle.py` | перейменуй файл |
| вікно блимнуло і зникло | нема `turtle.done()` наприкінці | додай останнім рядком |
| `KeyboardInterrupt` | ти натиснув `Ctrl+C`, поки програма малювала | нічого, це зупинка |

**Пастка в умові завдання 3 (с. 12).** Там написано: кінець, коли мала кулька ліворуч від великої (`x_m < x_M`),
летить вправо (`v_m > 0`) і не швидше за велику (`v_m ≤ v_M`). Якщо закодувати це дослівно, цикл **не зупиниться**:

- після останнього зіткнення кульок вони стоять **в одній точці**, `x_m == x_M` (у перевірочній програмі курсу для
  m = 1, M = 4, L = 10, v = 1 обидві координати однакові: `50.000000000000014`), тому `x_m < x_M` хибне;
- при m = M після зіткнення мала кулька зупиняється: `v_m = 0.0`, і `v_m > 0` теж хибне.

Подій більше нема, а умова кінця не спрацювала - програма висить або «зіштовхує» кульки знову в тій самій точці.
Подумай, яка умова кінця правильна саме для швидкостей (без координат), і перевір її на m = M. Про це варто сказати
викладачу.

## Як роблять профі

- **Модель окремо від показу.** Фізику (зіткнення) пишуть як чисту функцію «вхід → числа», покривають тестами, а
  анімацію роблять тонким шаром зверху. Так тестують і ігрові рушії, і наукові симуляції.
- **Подієве моделювання** (event-driven) - стандарт для задач з пружними зіткненнями: рахують час до наступної події,
  а не женуть малий крок dt. Так влаштовані симуляції газу з твердих кульок.
- **Графіки - у файли.** На серверах і в автоматичних перевірках (CI) екрана нема, тому `savefig` у PNG, а не `show()`.
- **Тести без екрана.** Для turtle це `TNavigator`; для справжніх програм з вікнами - «віртуальний екран» Xvfb.
- **Форматування - інструментом.** `black` і `ruff format` вирівнюють код самі, людина стиль не править руками.

Документація: turtle - https://docs.python.org/3/library/turtle.html ; matplotlib `savefig` -
https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.savefig.html

4. Що означає помилка `no display name and no $DISPLAY environment variable`?

<details markdown="1"><summary>Відповіді</summary>
