```python
def cube_root_bisect(value: float, eps: float) -> tuple[float, int]:
    """Кубічний корінь бісекцією і кількість кроків.

    >>> cube_root_bisect(27, 1e-6)
    (3.0, 25)
    >>> cube_root_bisect(2, 1e-6)
    (1.259921, 21)
    """
    low, high = 0.0, max(1.0, value)
    steps = 0
    while high - low > eps:
        middle = (low + high) / 2
        if middle**3 < value:
            low = middle
        else:
            high = middle
        steps += 1
    return round((low + high) / 2, 6), steps
```

## Що не так у файлі викладача

Викладач просив надсилати помилки в doctest. Перевірено запуском у тестовій Mint 22.3:

1. **`is_happy(55, 3)` і `is_happy(136, 3)` чекають `True`.** За означенням (с. 6: цикл має містити 1):
   55 → 250 → 133 → 55 і 136 → 244 → 136 - цикли без одиниці. Правильна функція дає `False`, і саме ці 2 з 36 тестів
   не пройдуть. Покажи викладачу ланцюжки.
2. **Коментар у тестах** «Для k = 1 будь-яке число зводиться до 1 лише якщо воно саме 1» - неправда: 10 → 1 + 0 = 1.
   Тестів на це нема, але не покладайся на коментар.
3. **Коментар** «alpha = 1 ... неможливо для n >= 1» суперечить тесту `is_abundant(1, 1)` → `True`: σ(1) = 1 = 1·1.
   Правий тест.
4. **Назва `is_abundant`.** «Abundant» англійською - «надлишкове» число (σ(n) > 2n), а функція перевіряє α-досконалість
   (σ(n) = α·n). Назву не міняй (так вимагає викладач), просто знай.
5. **flake8 на файлі викладача:** 5 рядків `E501` (коментарі в тестах довші за 78), 2 × `E302` (між функціями один
   порожній рядок замість двох), 2 × `E265` (`#Тут` без пробілу після `#`). E302 і E265 виправиш сам або `black -l 78`
   (порожні рядки і пробіл - не тести). E501 у рядках тестів не чіпай - скажи викладачу.

> - `python3 -m flake8` - шукає помилки стилю і зайвий код, нічого не змінює. Назва: pyflakes + pep8: обʼєднав дві старі програми перевірки коду. `--max-line-length` - найбільша дозволена довжина рядка; викладач хоче 78 (типово 79).
> - `python3 -m pycodestyle` - перевіряє лише оформлення коду за PEP 8. Назва: Python code style - «стиль коду Python» (раніше програма звалась pep8). `--max-line-length` - найбільша довжина рядка; викладач хоче 78 (типово 79).
> - `python3 -m ruff check` - швидко шукає помилки в коді, з --fix сам виправляє. Назва: ruff - назва не розшифровується; check - «перевірити».
> - `python3 -m mypy` - перевіряє типи (int, str ...) без запуску програми. Назва: назва не розшифровується (py - від Python).
> - `grep` - знаходить рядки з текстом у файлах. Назва: g/re/p з редактора ed: «знайти регулярний вираз у всьому файлі і надрукувати». `-n` - показати номер рядка перед кожним збігом (line number).
