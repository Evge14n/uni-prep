# Урок 13. Робочий стіл Cinnamon і гарячі клавіші

[← Усі уроки](#/u/mint/uroky)

**Навіщо:** щоб працювати в Mint швидко, як у знайомій системі: знайти будь-яку програму за дві секунди, розкласти
вікна лаби і браузера поруч, перемикати розкладку, налаштувати все під себе і знати, що робити, коли панель «завмерла».

## Коротко

**Cinnamon** - це робочий стіл Mint: панель, меню, вікна, налаштування. Версія в Mint 22.3 - 6.6.

Назви пунктів нижче взято з українського перекладу самої Mint (файли перекладу з пакетів `cinnamon-l10n`,
`mint-translations`, `captain` для Mint 22.3). Тому вони можуть звучати незвично («Сполучення клавішів»,
«Системні знятки») - зате саме так написано у тебе на екрані. Англійська назва - в дужках, якщо в тебе
система англійською.

**Що на панелі** (смуга внизу екрана). Типовий набір аплетів (аплет - маленька програма на панелі) у Cinnamon 6.6,
зліва направо:

```text
[Меню] | [вікна і закріплені програми]          [трей] [Сповіщення] [Принтери] [Змінні носії] [Клавіатура]
                                                 [Улюблені] [Мережа] [Звук] [Живлення] [Календар-годинник]
```

| Аплет | Що робить |
|---|---|
| «Меню» (Menu) | усі програми і пошук. Відкривається клавішею **Super** (клавіша з віконцем) |
| «Групований перелік вікон» (Grouped window list) | відкриті вікна; програму можна закріпити: права кнопка → «Приєднати до панелі» |
| «Змінні носії» (Removable drives) | флешки: відкрити або безпечно вийняти (урок 14) |
| «Клавіатура» (Keyboard) | поточна розкладка, клік - перемкнути |
| «Керування мережею» (Network Manager) | Wi-Fi, кабель, VPN (урок 21) |
| «Звук» (Sound) | гучність, вибір навушників чи динаміків, мікрофон |
| «Керування живленням» (Power Manager) | батарея і **«Режим живлення»**: «Заощадження енергії», «Збалансоване», «Продуктивність» |
| «Календар» (Calendar) | годинник і календар |

Ще там «Сповіщення» (Notifications), «Принтери» (Printers) і «Улюблені» (Favorites - файли, позначені зірочкою).

Права кнопка на порожньому місці панелі: «Аплети», «Налаштування панелі», «Режим редагування панелі» (перетягувати
аплети), «Вирішення проблем» → «Перезавантажити Cinnamon».

**Меню (Super).** Натисни Super, почни набирати назву (`term`, `тер`, `firefox`) і Enter - так запускають програми
профі, мишкою ніхто не шукає. Права кнопка на програмі в меню: «Додати до улюблених» (зʼявиться в лівій колонці
меню), «Додати до панелі», «Додати на робочий стіл», «Вилучити» (видалити програму).

**Гарячі клавіші Cinnamon 6.6** (типові, перевірено зі схем `cinnamon-desktop` у Mint 22.3):

| Клавіші | Дія |
|---|---|
| Super | меню |
| Ctrl+Alt+T | термінал |
| **Ctrl+Alt+L** | **заблокувати екран** |
| Super+L | **НЕ блокування!** Це «Збільшувальне скло» (Looking Glass) - налагоджувач Cinnamon |
| Super+D | показати робочий стіл (сховати всі вікна) |
| Super+E | домашня тека у файловому менеджері Nemo |
| Alt+Tab | перемикати вікна |
| Alt+F4 | закрити вікно |
| Alt+F10 | розгорнути / згорнути до звичайного розміру |
| Super+← / → / ↑ / ↓ | прилипання вікна: ліва чи права половина, верхня чи нижня; чверть - Super+↑, потім Super+→ (крок 2) |
| Super+Shift+стрілки | перенести вікно на інший монітор |
| Ctrl+Alt+← / → | інший робочий простір |
| Ctrl+Alt+↑ (або Alt+F1) | огляд робочих просторів |
| Ctrl+Alt+↓ | огляд усіх вікон |
| Ctrl+Shift+Alt+← / → | перенести вікно на сусідній робочий простір |
| Alt+F2 | виконати команду |
| Super+Space | наступна розкладка клавіатури |
| Super+P | монітори (дублювати, розширити - для проєктора на парі) |
| Print / Alt+Print / Shift+Print | знімок екрана / вікна / області; з Ctrl - одразу в буфер обміну |
| Ctrl+Alt+Esc | перезапустити Cinnamon (вікна і програми лишаються) |
| Ctrl+Alt+Delete | вийти з сеансу |
| Ctrl+Alt+End | вимкнути компʼютер |

У терміналі копіювати - **Ctrl+Shift+C**, вставити - **Ctrl+Shift+V** (детально - урок 03).

**Де міняти:** меню → «Системні налаштування» (System Settings) → «Клавіатура» (Keyboard) → вкладка
«Сполучення клавішів» (Shortcuts). Там же вкладка «Розкладки» (Layouts).

**Робочі простори** (workspaces) - кілька окремих «столів». Типово їх 4. Зручно: на першому - лаба (термінал + PDF),
на другому - браузер, на третьому - месенджер. Перемикання Ctrl+Alt+← / →.

**Інші корисні вікна налаштувань** (усі в «Системні налаштування»):

| Пункт | Що там |
|---|---|
| «Теми» (Themes) | вигляд вікон, піктограм, панелі; вкладка «Налаштування» → «Темний режим» |
| «Вікна» (Windows) | вкладка «Мозаїка» (Tiling): «Увімкнути мозаїчне розташування вікон» |
| «Робочі простори» (Workspaces) | скільки їх і як перемикати |
| «Гарячі кути» (Hot Corners) | дія, коли мишка в куті екрана |
| «Аплети», «Десклети», «Розширення» | додатки до Cinnamon («spices», нижче) |
| «Автозапуск програм» (Startup Applications) | що запускається при вході |
| «Керування живленням» (Power Management) | сон, яскравість, кришка ноутбука |
| «Екран» (Display) | монітори: роздільність, частота, поворот, головний монітор |
| «Дата та час» (Date & Time) | часовий пояс, «Мережевий час» - годинник сам звіряється з інтернетом (урок 26) |

**Екран і проєктор.** «Системні налаштування» → «Екран» (Display) показує всі монітори прямокутниками. Клацни на
потрібний - під ним «Роздільність» (Resolution), «Частота поновлення» (Refresh Rate), «Обертання» (Rotation) і
«Зробити основним» (Set as Primary - на ньому буде панель). Зміни діють після кнопки «Застосувати» (Apply). На парі з
проєктором швидше **Super+P** (таблиця клавіш вище). Назви - з перекладу
`cinnamon.mo` і `cinnamon-control-center.mo`; як саме виглядає вікно на твоєму ноутбуці - не перевірено (у тестовій
Mint нема графіки).

**Spices** («спеції») - аплети, десклети (віджети на столі), розширення і теми від спільноти. Ставляться з вкладки
«Завантаження» (Download) у вікні «Аплети» (там же вкладка «Налаштування» (Manage) - вже встановлені). Mint бере їх з
cinnamon-spices.linuxmint.com, а Диспетчер оновлень оновлює їх разом із системою (урок 02).

**Екран привітання** (Welcome Screen) відкривається при першому вході. Розділ «Перші кроки» (First Steps) - це список
справ після встановлення, у кожному кнопка «Запуск»: «Кольори стільниці», «Системні знятки» (Timeshift, урок 01),
«Керування драйверами» (урок 17), «Кодеки мультимедія», «Керування оновленнями» (у меню ця програма зветься
«Диспетчер оновлень», урок 02), «Системні налаштування», «Керування програмами» (урок 16), «Мережевий екран»
(брандмауер, урок 25). Знайти потім: меню → «Екран привітання». Галочка «Показувати це вікно під час запуску» -
чи показувати його при кожному вході.

**«Інформація про систему»** (System Information, у 22.3 так перейменували System Reports): сторінки USB, GPU, PCI,
BIOS (там видно режим завантаження і «Безпечне завантаження» - Secure Boot). Нова програма 22.3 «Керування системою»
(System Administration) має сторінку «Меню завантаження» (як довго показувати меню GRUB).

**X11 чи Wayland.** Це «рушій», що малює вікна. У Mint 22.x типово працює **X11 (Xorg)**. Сеанс Wayland можна вибрати
на екрані входу (значок біля імені), але в 22.x він **експериментальний** (linuxmint.com, «What's new» 21.3-22.3) -
для лаб і повсякденної роботи лишай типовий. Перевірити, що зараз: `echo $XDG_SESSION_TYPE` (`x11` або `wayland`).

> **Нове тут:**
>
> - `echo` - друкує на екран текст, який йому дали. Назва: echo - «луна»: повторює те, що йому дали.
> - `$ЗМІННА` (dollar) - бере значення змінної (назви, під якою bash тримає текст).
>
> **Як читати:**
>
> - Символи `~` `|` `>` набирай в англійській розкладці (`~` - Shift і клавіша ліворуч від 1; `|` - Shift і клавіша `\`).
>
> Усе про кожну команду - у довіднику «05_Програмування/КОМАНДИ - довідник.md» (на сайті - вкладка «Команди»).

**Доступність** (лупа, екранна клавіатура, великий текст, озвучення) - теж у «Системних налаштуваннях», пункт про
доступність (Accessibility; назва може трохи відрізнятись).

## Передбач, потім запусти

*Спершу відповідай подумки, нічого не запускаючи, і лише тоді розкрий «Відповідь». Файли з цих прикладів зʼявляться в розділі «Руками» нижче - запусти й перевір себе, коли його пройдеш.*

Відкрий термінал (Ctrl+Alt+T). `gsettings` читає налаштування робочого столу. Якщо ти нічого не міняв, буде
типове значення.

1. Яка комбінація блокує екран?

```bash
gsettings get org.cinnamon.desktop.keybindings.media-keys screensaver
```

> **Нове тут:**
>
> - `gsettings get` - друкує значення одного налаштування робочого столу. Назва: `gsettings` - G(Lib) settings - «налаштування» через бібліотеку GLib. `org.cinnamon.desktop.keybindings.media-keys` - схема гарячих клавіш Cinnamon для програм і «мультимедіа» (термінал, блокування); `screensaver` - ключ: комбінація, що блокує екран.

<details markdown="1"><summary>Відповідь</summary>

```text
['<Control><Alt>l', 'XF86ScreenSaver']
```

Ctrl+Alt+L (`<Control>` = Ctrl). `XF86ScreenSaver` - окрема клавіша «замок», якщо вона є на клавіатурі ноутбука.

</details>

2. А що тоді робить Super+L?

```bash
gsettings get org.cinnamon.desktop.keybindings looking-glass-keybinding
```

> **Нове тут:**
>
> - `gsettings get`: `looking-glass-keybinding` - ключ схеми org.cinnamon.desktop.keybindings: налагоджувач Looking Glass.

<details markdown="1"><summary>Відповідь</summary>

```text
['<Super>l']
```

Super+L відкриває «Збільшувальне скло» (Looking Glass) - налагоджувач для тих, хто пише аплети. Екран він не
блокує. Звичка з Windows (Win+L) тут підводить.

</details>

3. Скількома комбінаціями відкривається огляд робочих просторів?

```bash
gsettings get org.cinnamon.desktop.keybindings.wm switch-to-workspace-up
```

> **Нове тут:**
>
> - `gsettings get`: `switch-to-workspace-up` - ключ схеми ...keybindings.wm: перехід на інший робочий простір.

<details markdown="1"><summary>Відповідь</summary>

```text
['<Control><Alt>Up', '<Alt>F1']
```

Двома: Ctrl+Alt+↑ і Alt+F1. Одна дія може мати кілька комбінацій - тому значення записане списком у `[...]`.

</details>

4. Що зараз вибрано в «Теми» → «Налаштування» → «Темний режим»?

```bash
gsettings get org.x.apps.portal color-scheme
```

> **Нове тут:**
>
> - `gsettings get`: `org.x.apps.portal` - схема Mint для програм; ключ color-scheme - світла чи темна тема; `color-scheme` - ключ: 'default', 'prefer-dark' або 'prefer-light'.

<details markdown="1"><summary>Відповідь</summary>

```text
'default'
```

`'default'` - це пункт «На розсуд застосунків» (Let applications decide). `'prefer-dark'` = «Надати перевагу
темному режиму», `'prefer-light'` = «Надати перевагу світлому режиму».

</details>

## Руками

**Крок 1. Меню без мишки.** Super → набери `xed` → Enter (відкриється текстовий редактор). Закрий Alt+F4. Тепер
Super → `термінал` → права кнопка на «Термінал» → «Додати до улюблених». Знову Super: термінал тепер у лівій колонці.

**Крок 2. Вікна поруч.** Відкрий термінал (Ctrl+Alt+T) і Firefox. Активне вікно - Firefox: Super+→ (права половина).
Клацни на термінал: Super+← (ліва половина). Так зручно робити лабу: умова в браузері справа, термінал зліва. Спробуй
ще Super+↑ (верхня половина), потім Super+→ (вийде верхня права чверть). Якщо вікна не прилипають: «Системні
налаштування» → «Вікна» → «Мозаїка» → увімкни «Увімкнути мозаїчне розташування вікон».

**Крок 3. Робочі простори.** Ctrl+Alt+→ - ти на другому просторі, тут порожньо. Ctrl+Alt+← - назад. Тепер стань на
Firefox і натисни Ctrl+Shift+Alt+→ - вікно поїхало на другий простір. Ctrl+Alt+↑ - огляд усіх просторів (Esc - вийти).

**Крок 4. Гарячі клавіші в терміналі.** Усі комбінації для робочих просторів одним списком:

```bash
gsettings list-recursively org.cinnamon.desktop.keybindings.wm | grep "switch-to-workspace-[a-z]"
```

```text
org.cinnamon.desktop.keybindings.wm switch-to-workspace-down ['<Control><Alt>Down']
org.cinnamon.desktop.keybindings.wm switch-to-workspace-left ['<Control><Alt>Left']
org.cinnamon.desktop.keybindings.wm switch-to-workspace-right ['<Control><Alt>Right']
org.cinnamon.desktop.keybindings.wm switch-to-workspace-up ['<Control><Alt>Up', '<Alt>F1']
```

> **Нове тут:**
>
> - `gsettings list-recursively` - друкує всі налаштування схеми зі значеннями. Назва: list recursively - «перелічити все, з усіма вкладеними».
> - `|` (pipe) - вивід лівої команди йде на вхід правої.
> - `grep` - шукає рядки з текстом (у файлах або те, що прийшло через `|`). Назва: g/re/p з редактора ed: global regular expression print - «скрізь знайти шаблон, надрукувати».
> - `"..."` (double quotes) - усе між лапками - одне слово, навіть з пробілами.

Збережи всі свої комбінації у файл - знадобиться, якщо колись перевстановиш систему:

```bash
gsettings list-recursively org.cinnamon.desktop.keybindings.media-keys > ~/moi-klavishi.txt
grep terminal ~/moi-klavishi.txt
```

```text
org.cinnamon.desktop.keybindings.media-keys terminal ['<Primary><Alt>t']
```

> **Нове тут:**
>
> - `>` (redirect) - пише вивід у файл, старий вміст стирає.
> - `~` (tilde) - твоя домашня тека, /home/evgen.

`<Primary>` - те саме, що Ctrl.

**Крок 5. Змінити комбінацію і повернути як було.** «Системні налаштування» → «Клавіатура» → «Сполучення
клавішів». Зліва категорія «Панелі запуску» (Launchers), справа «Запустити термінал» (Launch terminal). Клацни на рядок з `Ctrl+Alt+T` унизу, натисни нову комбінацію, наприклад Super+T. Перевір у терміналі:

```bash
gsettings get org.cinnamon.desktop.keybindings.media-keys terminal
```

> **Нове тут:**
>
> - `gsettings get`: `terminal` - ключ: комбінація, що відкриває термінал.

Тепер там твоя нова комбінація. Повернути типову однією командою:

```bash
gsettings reset org.cinnamon.desktop.keybindings.media-keys terminal
gsettings get org.cinnamon.desktop.keybindings.media-keys terminal
```

```text
['<Primary><Alt>t']
```

> **Нове тут:**
>
> - `gsettings reset` - повертає налаштування до типового значення. `terminal` - ключ схеми ...media-keys: комбінація для терміналу (типово Ctrl+Alt+T).

Своя програма на клавішу: та сама вкладка, кнопка «Додати власне скорочення» (Add custom shortcut) - назва,
команда (наприклад `xed`) і комбінація.

**Крок 6. Українська розкладка.** «Системні налаштування» → «Клавіатура» → «Розкладки» → кнопка «+» → знайди
Ukrainian (у списку може бути українською, назва може трохи відрізнятись) → «Додати». Тепер **Super+Space** перемикає
EN ↔ UA, а аплет «Клавіатура» на панелі показує поточну. Набери в xed «привіт», перемкни, «hello».

## Далі - за бажанням

Кроки 7-11 - другим заходом, коли основне (кроки 1-6) вже звичне. Найважливіший з них - крок 9 (Ctrl+Alt+Esc).

**Крок 7. Тема і темний режим.** «Системні налаштування» → «Теми». Тут можна вибрати вигляд вікон («Програми»),
піктограм, панелі («Робочий стіл»). Вкладка «Налаштування» → «Темний режим» → «Надати перевагу темному режиму».
Перевір командою з «Передбач» 4 - тепер `'prefer-dark'`. Простіший шлях - «Екран привітання» → «Перші кроки» →
«Кольори стільниці»: колір і світла чи темна тема.

**Крок 8. Знімок екрана.** Print - увесь екран, Alt+Print - лише активне вікно, Shift+Print - виділи мишкою область.
З Ctrl (Ctrl+Print тощо) знімок іде одразу в буфер - вставляй у Telegram чи документ Ctrl+V. Без Ctrl - у файл
з назвою на зразок `Знімок екрана з ...png` (так у перекладі gnome-screenshot; якщо система англійською -
`Screenshot from ...png`) у теці зображень. Клавішу Print обробляє програма `gnome-screenshot`, а
вона, коли теку не задано, кладе знімки в теку зображень користувача (на ноутбуці не перевірено). Де ця тека у тебе
(українською вона може зватись інакше, ніж Pictures):

```bash
xdg-user-dir PICTURES
```

> **Нове тут:**
>
> - `xdg-user-dir` - друкує шлях до теки завантажень, зображень тощо. Назва: XDG user directory - «тека користувача» за правилами freedesktop.org. `PICTURES` - тека зображень (туди йдуть знімки екрана).

**Крок 9. Перезапуск Cinnamon.** Натисни **Ctrl+Alt+Esc**: панель зникне і зʼявиться за секунду, а вікна і
програми лишаться. Той самий пункт мишкою: права кнопка на панелі → «Вирішення проблем» → «Перезавантажити Cinnamon».
Запамʼятай - це перша допомога, коли панель чи меню «застигли».

**Крок 10. Яка в тебе система.**

```bash
grep PRETTY_NAME /etc/os-release
grep DESCRIPTION /etc/linuxmint/info
```

```text
PRETTY_NAME="Linux Mint 22.3"
DESCRIPTION="Linux Mint 22.3 Zena"
```

Те саме мишкою: меню → «Інформація про систему». Подивись сторінку BIOS: там написано, чи увімкнено «Безпечне
завантаження» (Secure Boot) - знадобиться в уроці 17.

**Крок 11. Аплет зі spices (за бажанням).** Права кнопка на панелі → «Аплети» → вкладка «Завантаження». Знайди,
наприклад, аплет погоди, встанови, перейди на вкладку «Налаштування», виділи його і натисни «+» (додати на панель).
Прибрати: там само «-».

## Типові помилки

- **Натиснув Super+L, щоб заблокувати, а відкрилось дивне вікно з вкладками** - це «Збільшувальне скло» (Looking
  Glass). Нічого не зламано: закрий його (Esc або хрестик у вікні, не перевірено на ноутбуці). Блокування -
  **Ctrl+Alt+L**.
- **Ctrl+Alt+Backspace - миттєво вбиває весь графічний сеанс**, усі незбережені файли пропадуть. У Mint це
  увімкнено навмисно (налаштування `terminate:ctrl_alt_bksp` у пакеті `mint-artwork`). Не плутай з Ctrl+Alt+Delete
  (там спершу питає).
- **Панель зникла або меню не відкривається** - Ctrl+Alt+Esc. Якщо не допомогло і все застигло - перейти в
  текстову консоль Ctrl+Alt+F2 (урок 26).
- **Темна тема сховала галочку** - на темній темі деякі програми малюють галочки і сірі кнопки майже невидимими.
  Так у Диспетчері оновлень не видно було, що пункт не вибраний, а кнопка «Застосувати» сіра (r/linuxmint, 12.01.2026,
  47 балів). Не розумієш, чому кнопка неактивна, - тимчасово «Надати перевагу світлому режиму» і подивись ще раз.
- **Super+Space нічого не робить** - у тебе лише одна розкладка. Додай українську (крок 6).
- **Ctrl+C у терміналі не копіює**, а зупиняє програму (урок 03). Копіювати - Ctrl+Shift+C.
- **Нова комбінація «не працює»** - перевір, чи вона не зайнята іншою дією в «Сполучення клавішів», і постав
  вільну. Зіпсував - `gsettings reset` (крок 5).
- **Поставив незнайомий аплет і Cinnamon почав гальмувати чи падати** - «Аплети» → вкладка «Налаштування» → вибери
  його → «-». Якщо через нього не стартує панель - права кнопка на панелі → «Вирішення проблем» →
  «Повернути типові значення налаштувань» (Restore all settings to default) - але це скине всі налаштування панелі.

## Як роблять профі

- **Клавіатура замість мишки:** Super + перші літери назви програми, Super+стрілки для вікон, Ctrl+Alt+стрілки для
  просторів. Курс MIT «Missing Semester» (2026) окремо вчить налаштовувати своє середовище, бо це заощаджує години.
- **Один простір - одна справа**: лаба окремо від месенджера, менше відволікань.
- **Налаштування - у файл**: `gsettings list-recursively ... > файл.txt` (крок 4) перед перевстановленням чи
  великим оновленням. Плюс знімок Timeshift (урок 01).
- **Spices ставлять обережно**: лише з офіційного сайту (вкладка «Завантаження»), дивляться оцінку і дату оновлення,
  непотрібне видаляють. Кожен аплет - чужий код, що працює всередині Cinnamon.
- **Не вставляй команди, яких не розумієш** - навіть «просто змінити тему». Спершу прочитай (explainshell.com).

## Самоперевірка

1. Якою комбінацією заблокувати екран, коли йдеш з ноутбуком від столу? Що зробить Super+L?
2. Як поставити термінал зліва, а браузер справа, кожен на половину екрана?
3. Панель «застигла», меню не відкривається. Що натиснути першим, і чи пропадуть відкриті вікна?
4. Де змінити гарячу клавішу і як повернути типову, якщо зіпсував?
5. Ти додав українську розкладку. Як перемикати мови і де видно, яка зараз?

<details markdown="1"><summary>Відповіді</summary>

1. Ctrl+Alt+L. Super+L відкриває «Збільшувальне скло» (Looking Glass), налагоджувач, - екран лишається
   незаблокованим.
2. Вибрати термінал і Super+←, вибрати браузер і Super+→. Якщо не прилипає - «Вікна» → «Мозаїка» → «Увімкнути
   мозаїчне розташування вікон».
3. Ctrl+Alt+Esc (або права кнопка на панелі → «Вирішення проблем» → «Перезавантажити Cinnamon»). Вікна і програми
   лишаються, перезапускається лише панель і робочий стіл.
4. «Системні налаштування» → «Клавіатура» → «Сполучення клавішів». Повернути: `gsettings reset` з назвою схеми і
   ключа, наприклад `gsettings reset org.cinnamon.desktop.keybindings.media-keys terminal`.
5. Super+Space (або клік на аплет «Клавіатура»). Поточну розкладку показує аплет «Клавіатура» на панелі.

</details>
