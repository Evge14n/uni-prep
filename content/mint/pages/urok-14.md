# Урок 14. Файли в Nemo і в терміналі, кошик

[← Усі уроки](#/u/mint/uroky)

**Навіщо:** знати, де в Linux що лежить, швидко працювати з файлами мишкою (Nemo) і в терміналі, вміти
повернути випадково видалене і не стерти зайвого. Головне: `rm` у терміналі **не кладе в кошик**.

## Коротко

**Дерево тек.** У Linux нема дисків C: і D:, усе - одне дерево з коренем `/`. Основне (детальніше про `cd`, `ls`,
шляхи - урок 03):

| Тека | Що там |
|---|---|
| `/` | корінь, звідси росте все |
| `/home/evgen` = `~` | **твоя домашня тека**: документи, лаби, налаштування. Твоє - лише тут |
| `/etc` | налаштування системи (текстові файли, змінює лише адміністратор) |
| `/usr/bin` | програми (`python3`, `nano`, `ls`) |
| `/var/log` | журнали системи (урок 20) |
| `/tmp` | тимчасове: Mint 22.3 спорожнює її при кожному завантаженні, а без перезавантаження прибирає файли, старші за 30 днів |
| `/media/evgen` | сюди Mint сама підключає **флешки**: `/media/evgen/НАЗВА_ФЛЕШКИ` |
| `/mnt` | порожня тека для ручного підключення дисків |
| `/boot` | ядро і завантажувач (не чіпати) |
| `/dev` | пристрої: `/dev/nvme0n1` - NVMe SSD, `/dev/sda`, `/dev/sdb` - SATA-диски і флешки (на ноутбуці з NVMe флешка часто `sda`), `/dev/sda1` - перший розділ. Хто є хто - лише за розміром і моделлю в `lsblk` (урок 18) |

**Приховані файли** - ті, чиє імʼя починається з крапки: `.bashrc`, `.config/`, `.local/`. Їх не видно, поки не
попросиш: у терміналі `ls -a`, у Nemo **Ctrl+H**. У них живуть налаштування програм - зайве не видаляй.

**Nemo** - файловий менеджер Mint (у меню «Файли», версія 6.6.3). Відкрити домашню теку - **Super+E**.
Назви пунктів - з українського перекладу Nemo в Mint 22.3:

| Клавіші | Дія |
|---|---|
| Ctrl+H | показати / сховати приховані файли |
| Ctrl+L | рядок адреси (можна вписати шлях, напр. `/etc`) |
| Ctrl+F | пошук у цій теці |
| Ctrl+T | нова вкладка |
| F3 | друга панель поруч (зручно копіювати між теками) |
| F6 | перейти в іншу панель |
| F9 | бічна панель |
| Ctrl+Shift+N | нова тека |
| F2 | перейменувати |
| Alt+↑ | на теку вище |
| Alt+Home | додому |
| Ctrl+1 / 2 / 3 | вигляд: піктограми / список / компактно |
| **Delete** | «Перемістити у смітник» (можна відновити) |
| **Shift+Delete** | «Видалити назавжди» (спитає «Ви впевнені, що бажаєте остаточно видалити...?») |

Права кнопка миші в теці: «Відкрити у терміналі» (у Nemo 6.6.3 для цього нема клавіші F4 - лише меню),
«Відкрити як адміністратор» (Open as Root - лише коли справді треба змінювати системні файли, урок 15).
На архіві: «Розпакувати сюди», на файлах: «Стиснути…» (ці два пункти дає розширення Nemo для архівів; назва може
трохи відрізнятись).

**Кошик** у Mint зветься **«Смітник»** (Trash): є в бічній панелі Nemo. Там: «Відновити» (повернути файл туди, звідки
його видалили) і «Спорожнити смітник» («Усі об’єкти зі смітника буде остаточно видалено.»). Фізично смітник лежить
у прихованій теці `~/.local/share/Trash/` (`files/` - самі файли, `info/` - звідки вони).

**Кошик і термінал:**

| Команда | Що робить |
|---|---|
| `rm файл` | видаляє **назавжди**, без смітника і без питань |
| `gio trash файл` | кладе у смітник, як Delete у Nemo |
| `gio trash --list` | що в смітнику і звідки воно (шлях) |
| `gio trash --restore trash:///файл` | повернути на старе місце |
| `gio trash --empty` | спорожнити смітник |

**Безпечні звички в терміналі** (докладно - нижче в «Руками»):
- `cp -i`, `mv -i`, `rm -i` - спитає перед перезаписом чи видаленням (`-i` = interactive).
- Перед `rm` з шаблоном (`*.py`) - та сама команда з `echo` попереду: покаже, які файли зачепить.
- Назви з пробілами - у лапки: `"Лаба 1"`. Краще взагалі без пробілів: `laba_1`, `lr1`.
- **Tab** дописує назви і сам ставить `\` перед пробілами.

**Архіви:**

| Команда | Що робить |
|---|---|
| `zip -r lr1.zip lr1` | запакувати теку в zip (`-r` - з усім вмістом) |
| `unzip lr1.zip -d rozpak` | розпакувати zip у теку `rozpak` |
| `tar -czf lr1.tar.gz lr1` | запакувати в `.tar.gz` (c - створити, z - стиснути gzip, f - імʼя файлу) |
| `tar -tzf lr1.tar.gz` | показати, що всередині (t - список) |
| `tar -xzf lr1.tar.gz -C rozpak2` | розпакувати (x) у теку `rozpak2` (вона має вже існувати) |

**Відкрити з терміналу у вікні:** `xdg-open .` (поточна тека в Nemo), `xdg-open файл.pdf` (у програмі для цього типу),
`nemo .`. Крапка = «ця тека».

## Передбач, потім запусти

Усе - у практичній теці з «Руками». Пункт 2 - це сам крок 3, пункт 1 - одразу після кроку 3 (у теці `lab1.py`,
`lab2.py`, `notes.txt` і `Лаба 1`), пункти 3-4 - після кроку 9.

1. Ти хотів написати `rm *.py`, але між `*` і `.py` випадково став пробіл. Що видалила б така команда? Перевіряємо
   безпечно - через `echo`:

```bash
echo rm * .py
```

<details markdown="1"><summary>Відповідь</summary>

```text
rm lab1.py lab2.py notes.txt Лаба 1 .py
```

`*` окремо - це **всі** файли в теці. Справжня команда стерла б `notes.txt` і всі файли, а `rm` ще й поскаржився б,
що файлу `.py` нема. Ось чому перед `rm` з шаблоном пишуть `echo`.

</details>

2. Скільки тек створить кожна команда?

```bash
mkdir "Лаба 1"
mkdir Лаба 2
```

<details markdown="1"><summary>Відповідь</summary>

Перша - одну, `Лаба 1`. Друга - **дві**: `Лаба` і `2`, бо пробіл розділяє аргументи. `ls` у терміналі покаже:

```text
 2   lab1.py   lab2.py   notes.txt   Лаба  'Лаба 1'
```

Назву з пробілом `ls` бере в лапки, щоб було видно, що це одна тека. Прибрати зайві: `rmdir Лаба 2`.

</details>

3. Файл видалили через `rm`. Чи буде він у смітнику?

```bash
echo "тест" > tymchasovyi.txt
rm tymchasovyi.txt
gio trash --list
```

<details markdown="1"><summary>Відповідь</summary>

Ні, `gio trash --list` нічого не покаже (якщо смітник був порожній). `rm` не знає про смітник - файл зник назавжди.
Відновлювати такі файли - окрема морока з невеликими шансами. Тому важливе - у git (урок 24) і в резервній копії.

</details>

4. `~/lr1` - символьне посилання на теку `~/univer/labs/lr1` (крок 9). Ти видалив посилання. Що сталось із самою
   текою і файлами в ній?

```bash
rm ~/lr1
ls ~/univer/labs/lr1
```

<details markdown="1"><summary>Відповідь</summary>

Нічого: `rm` без `-r` прибрав лише посилання («ярлик»), тека і файли на місці, `ls` їх показує. А от `rm -r` з
**рискою в кінці** (посилання, потім `/`) - небезпечно, див. «Типові помилки».

</details>

## Руками

**Крок 1. Подивись дерево.**

```bash
ls /
ls -d /etc /home /media /tmp /usr/bin /var/log
ls -a ~
```

У `ls -a ~` побачиш приховані `.bashrc`, `.config`, `.local`. Те саме в Nemo: Super+E, потім Ctrl+H (і ще раз Ctrl+H -
сховати). Спробуй Ctrl+L і впиши `/etc` - ти в системних налаштуваннях (дивитись можна, міняти - ні).

**Крок 2. Практична тека.**

```bash
mkdir -p ~/univer/praktyka/u14
cd ~/univer/praktyka/u14
touch lab1.py lab2.py notes.txt .chernetka.txt
ls
ls -a
```

```text
lab1.py  lab2.py  notes.txt
.  ..  .chernetka.txt  lab1.py  lab2.py  notes.txt
```

`.chernetka.txt` видно лише з `-a`. Відкрий цю теку в Nemo: `xdg-open .` - і натисни Ctrl+H.

**Крок 3. Пробіли в назвах.**

```bash
mkdir "Лаба 1"
mkdir Лаба 2
ls
rmdir Лаба 2
```

Зайти в теку з пробілом можна двома способами: `cd "Лаба 1"` або `cd Лаба\ 1` (так пише Tab: набери `cd Лаба\ `
і натисни Tab - він сам поставить `\` перед пробілом). Повернись: `cd ..`.

**Крок 4. Копіювати і переносити, не перезаписуючи.**

```bash
echo 'print(1)' > lab1.py
cp -i lab1.py lab2.py
```

Спитає (відповідай `n` і Enter - не перезаписувати):

```text
cp: overwrite 'lab2.py'?
```

Без `-i` вміст `lab2.py` мовчки замінився б на вміст `lab1.py`. Те саме з `mv`: `mv -i`. Теку копіюють з `-r`:
`cp -r lr1 lr1-kopiya`. (Якщо Mint у тебе українською, питання буде `cp: переписати 'lab2.py'?`, а в кроці 5 -
`rm: вилучити звичайний порожній файл 'notes.txt'?`.)

**Крок 5. Видаляти обережно.**

```bash
echo rm *.py
rm -i notes.txt
```

```text
rm lab1.py lab2.py
rm: remove regular empty file 'notes.txt'?
```

Перший рядок - це лише друк (`echo`): так ти бачиш, що `rm *.py` зачепив би рівно два файли. Друге питає - `y`, Enter.

**Крок 6. Смітник з терміналу.**

```bash
echo "чернетка" > chernetka.txt
gio trash chernetka.txt
gio trash --list
```

```text
trash:///chernetka.txt  /home/evgen/univer/praktyka/u14/chernetka.txt
```

Ліворуч - адреса у смітнику, праворуч - звідки файл. Подивись у Nemo: бічна панель → «Смітник» - він там. Поверни
його командою і переконайся:

```bash
gio trash --restore trash:///chernetka.txt
ls
```

Тепер видали інший файл і спорожни смітник:

```bash
echo "стара версія" > stara.txt
gio trash stara.txt
ls ~/.local/share/Trash/files
gio trash --empty
gio trash --list
```

`ls` покаже `stara.txt` у прихованій теці смітника, а після `--empty` список порожній (смітник чиститься за секунду-дві).

**Крок 7. Архіви.**

```bash
mkdir lr1
cp lab1.py lr1/
zip -r lr1.zip lr1
unzip lr1.zip -d rozpak
```

```text
  adding: lr1/ (stored 0%)
  adding: lr1/lab1.py (stored 0%)
Archive:  lr1.zip
   creating: rozpak/lr1/
 extracting: rozpak/lr1/lab1.py
```

`stored 0%` - файл крихітний, стискати нема чого. Тепер `.tar.gz`, як часто викладають програми для Linux:

```bash
tar -czf lr1.tar.gz lr1
tar -tzf lr1.tar.gz
mkdir rozpak2
tar -xzf lr1.tar.gz -C rozpak2
```

```text
lr1/
lr1/lab1.py
```

У Nemo те саме мишкою: права кнопка на `lr1.zip` → «Розпакувати сюди».

**Крок 8. Знайти файл.**

```bash
find . -name "*.py" | sort
```

```text
./lab1.py
./lab2.py
./lr1/lab1.py
./rozpak/lr1/lab1.py
./rozpak2/lr1/lab1.py
```

`find ТЕКА -name "шаблон"` шукає в теці і всіх підтеках; лапки навколо шаблону обовʼязкові. Корисні варіанти:
`find ~ -iname "*лаба*"` (`-iname` - без різниці великі чи малі літери), `find ~/Завантаження -name "*.pdf" -mmin -60`
(PDF, змінені за останні 60 хвилин; `Завантаження` - якщо система українською, інакше `Downloads`).

**Крок 9. Символьне посилання** (symbolic link, «ярлик»): короткий шлях до глибокої теки.

```bash
mkdir -p ~/univer/labs/lr1
ln -s ~/univer/labs/lr1 ~/lr1
readlink ~/lr1
ls ~/lr1/
```

```text
/home/evgen/univer/labs/lr1
```

Тепер `cd ~/lr1` веде прямо в лабу. `ls -l ~/lr1` покаже на початку рядка `l` і стрілку `~/lr1 -> /home/evgen/...`.

**Жорстке посилання** (hard link, `ln` без `-s`) - друге імʼя того самого файлу, а не ярлик. Повернись у практичну
теку і спробуй:

```bash
cd ~/univer/praktyka/u14
echo "дані лаби" > original.txt
ln original.txt kopiya-tverda.txt
ls -li original.txt kopiya-tverda.txt
rm original.txt
cat kopiya-tverda.txt
```

```text
121445 -rw-rw-r-- 2 evgen evgen 18 Nov 18 11:26 kopiya-tverda.txt
121445 -rw-rw-r-- 2 evgen evgen 18 Nov 18 11:26 original.txt
дані лаби
```

Перше число (`-i` - номер inode, «паспорт» файлу на диску; у тебе інше, як і дата) у обох однакове: це один файл з двома
іменами. Цифра `2` після прав - скільки в нього імен. Після `rm original.txt` дані лишились - файл зникає, лише
коли видалено **останнє** імʼя. Обмеження: жорстке посилання не можна зробити на теку і на інший диск (флешку) - там
лише `ln -s`. Timeshift (урок 01) так і береже місце: незмінені файли в знімках - жорсткі посилання.

**Крок 10. Флешка.** Встав флешку - Mint сама підключить її в `/media/evgen/НАЗВА`, а в Nemo вона зʼявиться зліва.
Подивитись у терміналі, яка вона:

```bash
lsblk -o NAME,SIZE,RM,TYPE,MOUNTPOINTS
```

Флешка - це рядок з `RM` = `1` (removable - знімна), тип `disk` (наприклад `sda` на ноутбуці з NVMe або `sdb`) і під
ним розділ `part` (`sda1` / `sdb1`) з `MOUNTPOINTS` = `/media/evgen/...`. Звір розмір і модель (урок 18) - букву не
вгадуй. Скопіюй на неї архів: `cp lr1.zip /media/evgen/` і Tab - допише назву флешки.

**Вийняти правильно:** у Nemo - кнопка ⏏ біля флешки або права кнопка → «Вийняти» (Eject), або аплет «Змінні
носії» на панелі. Чекай, поки зникне з бічної панелі, - тоді витягуй. У терміналі (назви `sdb1` і `sdb` - **свої**, з
`lsblk`):

```text
sync                                  дописати все з памʼяті на диски
udisksctl unmount -b /dev/sdb1        відключити розділ
udisksctl power-off -b /dev/sdb       вимкнути флешку, тепер можна витягати
```

**Крок 11. Прибрати за собою.**

```bash
cd ~
gio trash ~/univer/praktyka/u14
```

Практична тека пішла у смітник - звідти її ще можна повернути. Посилання `~/lr1` ти прибрав у передбач 4 (якщо ні -
`rm ~/lr1`).

## Типові помилки

Якщо Mint у тебе українською, ті самі помилки будуть українською - нижче обидва варіанти (український - з файлів
перекладу `language-pack-uk-base` і `language-pack-gnome-uk-base` для Mint 22.3, перевірено запуском). Англійський текст зручно шукати в інтернеті: запусти ту саму
команду як `LC_ALL=C команда` - вона відповість англійською.

- **`rm -r` по посиланню з рискою в кінці** (`rm -r ~/lr1/`) - стирає **вміст справжньої теки**, а потім пише
  `rm: cannot remove 'lr1/': Not a directory` (українською `rm: не вдалося вилучити 'lr1/': Не є каталогом`).
  Перевірено в Mint 22.3: файли лаби зникли. Посилання видаляють без `-r` і без риски: `rm ~/lr1` (передбач 4).
- **`bash: cd: too many arguments`** (`bash: cd: забагато аргументів`) - назва з пробілом без лапок (`cd Лаба 1`).
  Пиши `cd "Лаба 1"` або тисни Tab.
- **`cp: -r not specified; omitting directory 'lr1'`** (`cp: -r не вказано; пропускаємо каталог 'lr1'`) - копіюєш
  теку без `-r`. Треба `cp -r lr1 lr1-kopiya`.
- **`rmdir: failed to remove 'lr1': Directory not empty`** (`rmdir: не вдалося вилучити 'lr1': Каталог непорожній`) -
  `rmdir` видаляє лише порожні теки, і це добре: файли не загубиш. Теку з вмістом - у смітник: `gio trash lr1`.
- **`gio: file:///.../nema.txt: Error trashing file ...: No such file or directory`** (українською -
  `Помилка під час спроби надіслати файл ... до смітника: Немає такого файла або каталогу`) - такого файлу нема (не
  та тека або назва). `ls`, Tab.
- **Кирилиця і `gio trash --restore`.** Для файлу `звіт.txt` список показує
  `trash:///%D0%B7%D0%B2%D1%96%D1%82.txt` і шлях з `\xd0\xb7...`, а `--restore` повертає файл з **поламаною назвою**
  `\xd0\xb7\xd0\xb2\xd1\x96\xd1\x82.txt` (перевірено в Mint 22.3, GLib 2.80). Файли з кириличними назвами відновлюй
  у Nemo: «Смітник» → права кнопка → «Відновити». А назви для лаб давай латиницею.
- **Файл точно у смітнику (`ls ~/.local/share/Trash/files` його показує), а `gio trash --list` і «Спорожнити
  смітник» його не бачать.** У тестовій Mint 22.3 так було з файлом, який відновили і одразу знову видалили з тим
  самим імʼям: служба смітника (gvfs) «загубила» його до кінця сеансу. Вийди з сеансу і зайди знову (на ноутбуці не
  перевірено).
- **Видалив файли з флешки в Nemo, а місця не побільшало** - вони в смітнику **на самій флешці** (прихована тека
  `.Trash-1000` на ній). Спорожни смітник до того, як виймати флешку.
- **Витягнув флешку без «Вийняти»** - останні скопійовані файли можуть бути битими (дописуються з памʼяті пізніше).
  Завжди «Вийняти» і чекати.
- **`unzip` питає `replace rozpak/lr1/lab1.py? [y]es, [n]o, [A]ll, [N]one, [r]ename:`** - у цій теці вже є такий
  файл (unzip питає англійською за будь-якої мови системи). `n` - не чіпати, `A` - перезаписати все. Безпечніше розпаковувати в нову порожню теку (`-d нова_тека`).
- **`gio trash` у теці, де нема прав** (наприклад, у `/etc`), не допоможе - системні файли взагалі не видаляють
  (урок 15).

## Як роблять профі

- **Видаляють через смітник**, а `rm` - лише для того, що точно не потрібне (тимчасові файли, `__pycache__`). Дехто
  робить собі `alias del='gio trash'` у `~/.bashrc` (урок 22).
- **Спершу дивляться, потім видаляють:** `ls шаблон` або `echo rm шаблон`, лише потім `rm`. Новачки на r/linux4noobs
  (2026) найчастіше втрачають файли саме через неперевірений шаблон чи чужу команду.
- **Назви без пробілів і латиницею** (`lr1`, `zvit_lr1.pdf`): менше лапок, Tab працює, `gio` і архіви не ламаються.
- **Дві панелі в Nemo (F3)** для копіювання між теками і флешкою - швидше за перетягування між вікнами.
- **Резервна копія важливого - правило 3-2-1**: 3 копії, на 2 різних носіях, 1 - поза домом (практики r/linuxmint,
  12.09.2026). Смітник і Timeshift (урок 01) - не резервна копія лаб.

## Самоперевірка

1. Чим відрізняється Delete від Shift+Delete у Nemo? А `rm` у терміналі - як що з них?
2. Як у терміналі покласти файл у смітник, подивитись смітник і повернути файл?
3. Де Mint підключає флешку і як її правильно вийняти?
4. Що покаже `echo rm *.txt` і навіщо його запускати?
5. Як запакувати теку `lr2` у `.tar.gz` і подивитись, що в архіві, не розпаковуючи?

<details markdown="1"><summary>Відповіді</summary>

1. Delete - «Перемістити у смітник» (можна відновити), Shift+Delete - «Видалити назавжди». `rm` - як Shift+Delete, але
   ще й без питання.
2. `gio trash файл`, `gio trash --list`, `gio trash --restore trash:///файл` (файли з кириличними назвами - через Nemo,
   «Відновити»).
3. У `/media/evgen/НАЗВА`. Вийняти: у Nemo кнопка ⏏ або «Вийняти», або аплет «Змінні носії»; у терміналі `sync`,
   `udisksctl unmount -b /dev/sdX1`, `udisksctl power-off -b /dev/sdX` (замість X - своя буква з `lsblk`).
4. Рядок `rm` зі списком файлів, на які розгорнеться шаблон, - нічого не видаляючи. Так видно, чи не зачепить зайве.
5. `tar -czf lr2.tar.gz lr2`, потім `tar -tzf lr2.tar.gz`.

</details>
