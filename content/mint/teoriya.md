# Linux Mint - повністю

## Почни тут

Курс для твого ноутбука зі **справжньою Linux Mint** (робочий стіл Cinnamon). Усе, що тут написано, набирається в
терміналі Mint (Ctrl+Alt+T) або робиться мишкою в Mint.

Старий курс «Linux за 10 днів» (тека `05_Програмування/Linux/`) був для ПК. Для ноутбука бери цей. Курс Python
(тека `05_Програмування/Курс/` на ПК: уроки Python і довідник функцій) лишається як був - тут лише як запускати все
те саме в Mint. Коли урок пише «курс Python, урок 07» - це урок тієї теки, а не «Урок 07» цього курсу.

Файли з ПК (цей курс, `Курс/`, лаби викладача) на ноутбук переносиш флешкою, через GitHub (урок 24) або пересилаєш
собі в Telegram - і потім копіюєш у `~/univer` командою `cp` (урок 03, 04).

### Крок 0. Яка в тебе Mint (1 хвилина)

```bash
cat /etc/os-release
python3 --version
```

Має бути `PRETTY_NAME="Linux Mint 22.3"` (або 22, 22.1, 22.2) і `UBUNTU_CODENAME=noble`, Python 3.12.3. Тоді курс
підходить дослівно. Mint 22.x підтримується до квітня 2029. Наступна велика версія Mint (на базі Ubuntu 26.04)
запланована на Різдво 2026 і ще не вийшла (blog.linuxmint.com, березень 2026); коли вийде - урок 02 каже, як
переходити.

Якщо бачиш `21.x` - курс теж майже весь підходить, але Python там 3.10, і спершу варто оновитись (урок 02).

### Мова повідомлень (1 хвилина)

```bash
echo $LANG
```

Якщо бачиш `uk_UA.UTF-8` - Mint українською, і багато повідомлень **системи** (bash, `cp`, `mkdir`, apt, nano,
Timeshift) будуть українською, а не так, як у курсі. Наприклад, замість `bash: python: command not found` буде
`bash: python: команду не знайдено`. У «Типових помилках» уроків для таких повідомлень дано обидва варіанти.
Повідомлення самого **Python** (`Traceback`, `NameError`, doctest `Expected`/`Got`) завжди англійською.

Шукати помилку в інтернеті легше англійською. Отримати англійський текст: допиши `LC_ALL=C` перед командою -
тоді лише ця одна команда говорить англійською:

```bash
LC_ALL=C ls nema-takoyi-teky
```

```text
ls: cannot access 'nema-takoyi-teky': No such file or directory
```

### Як вчити, щоб запамʼяталось надовго

- **Передбач, потім запусти.** У кожному уроці є розділ, де спершу треба сказати, що виведе команда, і лише потім
  натиснути Enter. Помилка в передбаченні запамʼятовується краще, ніж правильна відповідь, прочитана готовою.
- **Самоперевірка без підглядання.** 5 питань у кінці уроку - відповідай вголос або на папері, тоді відкривай
  «Відповіді».
- **Повтори через день і через тиждень.** Картки «Linux Mint» у боті (тема «Навчання»): увімкнути -
  напиши боту `увімкни колоду мінт`, вимкнути - `вимкни колоду мінт`. Колода типово вимкнена, щоб не заважати
  колоквіумам.
- **Руками, не очима.** Кожну команду з блоків коду набирай сам (Tab допомагає), не копіюй пачкою.

### Швидке налаштування (якщо хочеш одразу, без уроку 03)

Скрипт ставить python3-venv, pip, tkinter (для turtle), git, створює `~/univer/labs` і `~/univer/.venv` з pytest,
flake8, black, mypy, ruff, matplotlib, numpy і додає дві команди: `univer` (перейти в `~/univer` і увімкнути venv)
та `perevir файл.py` (doctest + black + flake8, pycodestyle, ruff до 78 символів + mypy, як вимагає викладач).
Систему він не оновлює.

```bash
cd ~
wget -O ustanovka-mint.sh https://evge14n.github.io/uni-prep/files/ustanovka-mint.sh
less ustanovka-mint.sh
bash ustanovka-mint.sh
```

Якщо `wget` пише помилку `404` (файл на сайті ще не опублікований) або інтернету нема - скопіюй
`ustanovka-mint.sh` з теки цього курсу (лежить поруч з «00 - Почни тут.md») у домашню теку `~`.

`less` - щоб **спершу прочитати** скрипт (гортати пробілом, вийти `q`): чужі скрипти без читання не запускають
(урок 03). Пароль sudo в Mint показується зірочками - це нормально. Після скрипта відкрий нове вікно термінала.

### Пастки, яких нема в підручниках

- **Відʼєднав диск з `/etc/fstab` - система в аварійному режимі.** Опція `nofail` (урок 18, 26).
- **Диск заповнився журналами до 900 ГБ** - через TTY: `sudo journalctl --vacuum-time=2d` і шукати, хто пише (урок 18).
- **Годинник у Windows «зʼїжджає» на 2-3 години** після Linux - Windows рахує час апаратного годинника місцевим,
  Linux - UTC (урок 26).
- **BitLocker:** спершу зберегти ключ відновлення; Secure Boot не вимикати - після змін завантаження Windows може
  попросити ключ відновлення (Microsoft, «BitLocker recovery overview»; на ноутбуці не перевірено, урок 26).
- **Записав образ Mint не на ту флешку** - перед будь-яким записом `lsblk -o NAME,SIZE,MODEL,MOUNTPOINT` (урок 18).
- **Темна тема сховала галочку** - кнопка «Застосувати» в Диспетчері оновлень сіра, бо невидимий пункт не вибрано (урок 13).
- **GUI-програми з `sudo`** лишають файли root у твоїй домашній теці, потім щось «не зберігається» (урок 15).
- **Mint-обгортка `apt`** сама додає `sudo`; `apt deb` = `dpkg -i` без залежностей (урок 16).
- **У Mint пароль sudo видно зірочками**, а в TTY і `passwd` - не видно нічого. Обидва варіанти нормальні.
- **gh з репозиторію Mint (2.45) зламаний** - ставити з репозиторію GitHub (урок 24).
- **У cron нема твого PATH і venv** - лише абсолютні шляхи (урок 23).
- **`awk 'length > 78'` у Mint рахує байти** (mawk), і українські рядки здаються «задовгими» - бери `grep '.\{79,\}'` (урок 22).
- **doctest викладача теж помиляється** - ЛР1 завд. 3, ЛР2 точка на межі, ЛР5 пі, ЛР6 `is_happy(55, 3)`: як це помітити
  (уроки 04, 07, 10, 11). Не підганяй код під хибний тест - покажи викладачу розрахунок.
