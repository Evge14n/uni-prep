# Молекулярна фізика - шпаргалка (1 екран)

## Колоквіум 1 - ідеальний газ

```
PV = νRT   P = n₀kT   ν = m/μ
<ε_пост> = (3/2)kT   U = ν(i/2)RT
i: 3 (He)  5 (N₂, O₂, повітря)  6 (H₂O)
Q = ΔU + A   A = ∫P dV
ізотерма: ΔU = 0, Q = A = νRT·ln(V₂/V₁)
C_V = (i/2)R  C_P = C_V + R  γ = C_P/C_V
адіабата: PV^γ, TV^(γ-1) = const
політропа: C = C_V - R/(n - 1)
η = A/Q₁   Карно 1 - T₂/T₁
холодильник η* = T₂/(T₁ - T₂)
ΔS = νC_V·ln(T₂/T₁) + νR·ln(V₂/V₁)
S = k·ln W
v_ім, <v>, v_кв = √(2, 8/π, 3 ·RT/μ)
P = P₀e^(-μgh/RT)   <x²> = 2Dτ
λ = kT/(√2πd²P)  D = <v>λ/3  η = ρD
```

## Колоквіум 2 - реальний газ, рідини, тверді

```
(P + a/V²)(V - b) = RT
V_к = 3b  P_к = a/27b²  T_к = 8a/27Rb
U = C_V T - a/V   T_інв = 2a/(Rb)
ΔP: крапля 2σ/r, бульбашка 4σ/r
h = 2σcos θ/(ρgr)   Стокс 6πηrv
Рауль ΔP/P₀ = ν₂/(ν₁ + ν₂)  π = cRT
Дюлонг-Пті C = 3R ≈ 25 Дж/(моль·К)
dP/dT = i/(T(v₂ - v₁)) - усе ПИТОМЕ
перехід ΔS = mλ/T; нагрів cm·ln(T₂/T₁)
```

## Пастки

1. T - лише в кельвінах. Відношення T₂/T₁ у °C - груба помилка.
2. μ у кг/моль (азот 0,028, не 28). 1 л = 10⁻³ м³. Г → кг.
3. Поступальний рух - завжди 3 ступені; i = 5 - це вже з обертанням.
4. Ізотерма: нуль - ΔU, а не Q.
5. Не плутай C_V і C_P: ізохора - C_V, ізобара - C_P.
6. ККД циклу: у знаменнику все тепло від нагрівника (лише додатні Q).
7. Карно - верхня межа, а не ККД реального циклу.
8. ΔS - функція стану: шлях вибирай зручний.
9. Необоротний процес: ΔS рахуй оборотним шляхом; ізольована система - ΔS > 0.
10. η і χ газу не залежать від тиску; D ∝ T^(3/2)/P.
11. ВдВ: a, b у СІ разом з V у м³.
12. Реальний газ в ізотермі: ΔU ≠ 0.
13. Злиття крапель: зберігається об'єм, R = r·∛n.
14. Жюрен - з радіусом; мильна бульбашка 4σ/r.
15. Стокс: не забудь Архімеда.
16. Клапейрон-Клаузіус: питома теплота з питомими об'ємами.
17. Різниця температур: 1 °C = 1 К, «+273» і «+32» не додають.
