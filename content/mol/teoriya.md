
## Тема 1. Молекули, моль, ідеальний газ, рівняння стану (К1)

**Моль** - стільки частинок, скільки атомів у 0,012 кг вуглецю-12, тобто N_A штук.
ν = m/μ = N/N_A. Маса однієї молекули m₀ = μ/N_A (Підр. с. 16-17).

**Ідеальний газ** - молекули як точки, взаємодіють лише при пружних зіткненнях
(Підр. с. 27). Добре працює, коли газ розріджений.

**Основне рівняння МКТ** (Підр. с. 91): молекули б'ються об стінку і передають їй імпульс.
Словами: тиск = 2/3 середньої кінетичної енергії поступального руху молекул в одиниці об'єму.

```
P = (2/3)·n₀·<m₀v²/2>
P = n₀·k·T
PV = (m/μ)·R·T = ν·R·T = N·k·T
```

Газові закони - це рівняння стану, де один параметр сталий (Підр. с. 95-102):

```
T = const: PV = const   Бойль-Маріотт
P = const: V/T = const  Гей-Люссак
V = const: P/T = const  Шарль
P₁V₁/T₁ = P₂V₂/T₂
Дальтон: P = P₁ + P₂ + ...
<μ> суміші = m/ν
```

Пастки: T лише в кельвінах; літри в м³ (1 л = 10⁻³ м³); грами в кг; для кисню μ = 0,032
(молекула O₂), а не 0,016.

## Тема 2. Температура і шкали (К1)

**Температура** - параметр, однаковий у тіл у тепловій рівновазі. Через МКТ - міра середньої
кінетичної енергії молекул: <ε_пост> = (3/2)kT (Підр. с. 142-143).

**Термометричне тіло** - тіло, властивість якого міняється з температурою (ртуть, газ);
**термометрична величина** - сама ця властивість (довжина стовпчика, тиск).

```
t = 100·(l_t - l₀)/(l₁₀₀ - l₀)
n °C = 0,8n °R = (32 + 1,8n) °F
T = t + 273,15
```

Ідеально-газова шкала: для всіх ідеальних газів α = β = 1/273,15, тому шкала не залежить
від сорту газу. Сучасна шкала будується за однією точкою - потрійною точкою води, 273,16 К
(Підр. с. 148-151).

Для **різниці** температур 1 °C = 1 К = 1,8 °F, «+32» не додають.

## Тема 3. Ступені вільності, внутрішня енергія, перше начало (К1)

**Ступені вільності** i - кількість незалежних координат, що задають положення молекули:
одноатомна 3, двоатомна жорстка 5, нелінійна жорстка 6 (Підр. с. 189-191).

**Рівнорозподіл** (Підр. с. 192-195): на кожен ступінь вільності в середньому kT/2, на
коливальний - kT (ще й потенціальна енергія).

```
<ε> = (i/2)·k·T
U = ν·(i/2)·R·T    лише від T!
A = ∫P dV          площа під P(V)
Q = ΔU + A         перше начало
```

Перше начало (Підр. с. 206): теплота, надана газу, йде на зміну внутрішньої енергії і на
роботу газу. Вічний двигун першого роду неможливий.

```
ізохора   A = 0,  Q = ΔU
ізобара   A = PΔV = νRΔT
ізотерма  ΔU = 0, Q = A = νRT·ln(V₂/V₁)
```

U - функція стану (по циклу ΔU = 0). A і Q залежать від шляху. Знаки: A > 0 - газ
розширюється; Q > 0 - газ отримує тепло.

## Тема 4. Теплоємність, рівняння Майєра (К1)

```
C_V = (i/2)·R
C_P = C_V + R      Майєр
γ = C_P/C_V = (i + 2)/i
c = C/μ            питома
```

γ: 1,67 (He), 1,40 (N₂, O₂), 1,33 (H₂O). C_P > C_V, бо при P = const частина тепла йде на
роботу розширення. R - робота 1 моль газу при нагріванні на 1 К при P = const (Підр. с. 207-211).

**Водень** (Підр. с. 211-219): C_V = (3/2)R біля 50 К, (5/2)R при кімнатній, (7/2)R біля
6000 К. Класика цього не пояснює: обертання і коливання квантовані і «заморожені», поки kT
мале.

У суміші газів складають не γ, а теплоємності з вагою ν.

## Тема 5. Політропа і адіабата (К1)

**Політропний процес** - процес при сталій теплоємності C (Підр. с. 219-226):

```
PVⁿ = const
n = (C - C_P)/(C - C_V)
C = C_V - R/(n - 1)
A = (P₁V₁ - P₂V₂)/(n - 1)
```

Ізобара n = 0, ізотерма n = 1, ізохора n = ±∞, адіабата n = γ.

**Адіабатний процес** - без теплообміну, δQ = 0, C = 0:

```
PV^γ = const       Пуассон
TV^(γ-1) = const
A = νC_V(T₁ - T₂)  за рахунок U
```

Адіабата крутіша за ізотерму: тиск падає і через ріст V, і через падіння T. При
адіабатному стисненні T росте (дизель). При 1 < n < γ теплоємність від'ємна - газ отримує
тепло, а холоне. З одного стану на той самий об'єм: A_ад < A_T < A_P.

## Тема 6. Друге начало, теплові машини, цикл Карно (К1)

**Томсон (Кельвін)**: неможливий циклічний процес, єдиний результат якого - робота за
рахунок теплоти одного джерела (вічний двигун другого роду неможливий).
**Клаузіус**: неможливий циклічний процес, у результаті якого теплота сама переходить від
холоднішого тіла до гарячішого. Ці формулювання еквівалентні (Підр. с. 230-232).

```
A = Q₁ - Q₂
η = A/Q₁ = (Q₁ - Q₂)/Q₁
холодильник: η* = Q₂/A
Карно: η = 1 - T₂/T₁
```

Цикл Карно: дві ізотерми і дві адіабати. Теореми Карно: ККД оборотної машини Карно не
залежить від робочого тіла; необоротна машина має менший ККД (Підр. с. 236-243).
У знаменнику ККД довільного циклу - уся теплота, отримана від нагрівника.

## Тема 7. Ентропія, Больцман, третє начало (К1)

Для оборотного циклу ∮δQ/T = 0, тому δQ/T - диференціал функції стану, **ентропії**
(Підр. с. 249-257):

```
dS = δQ/T
ΔS = νC_V·ln(T₂/T₁) + νR·ln(V₂/V₁)
T = const: ΔS = νR·ln(V₂/V₁)
V = const: ΔS = νC_V·ln(T₂/T₁)
P = const: ΔS = νC_P·ln(T₂/T₁)
адіабата:  ΔS = 0
```

**Нерівність Клаузіуса**: для необоротного циклу ∮δQ/T < 0, dS ≥ δQ/T. В ізольованій
системі ентропія не спадає (Підр. с. 259-263).

**Формула Больцмана** S = k·ln W, W - кількість мікростанів макростану. Ентропія - міра
безладу; друге начало статистичне: зворотний процес не заборонений, але неймовірний
(Підр. с. 267-277).

**Третє начало**: Нернст - при T → 0 процеси йдуть без зміни ентропії; Планк - S → 0.
Наслідки: C → 0, абсолютний нуль недосяжний (Підр. с. 283-287).

Необоротний процес (розширення в пустоту, змішування) рахують уявним оборотним шляхом між
тими самими станами.

## Тема 8. Розподіл Максвелла (К1 або лише іспит)

f(v)dv - частка молекул зі швидкостями від v до v + dv; площа під кривою 1 (Підр. с. 70-82).

```
v_ім = √(2RT/μ)
<v>  = √(8RT/(πμ))
v_кв = √(3RT/μ)
1 : 1,13 : 1,22
удари на 1 м² за 1 с: n₀<v>/4
```

З ростом T максимум зсувається вправо і нижчає. Перевірка - дослід Штерна (атоми срібла
на циліндрі, що обертається). За енергіями: E_ім = kT/2, <E> = (3/2)kT.

## Тема 9. Розподіл Больцмана, броунівський рух (К1 або лише іспит)

```
n = n₀·e^(-E_п/kT)
P = P₀·e^(-μgh/(RT))
<x²> = kTτ/(3πηa) = 2Dτ
```

Барометрична формула - для ізотермічної атмосфери; кожен газ має свою «висоту згасання»
RT/(μg). Перрен рахував частинки гумігуту на різних висотах і їх зміщення - так знайшов k
(Підр. с. 103-132). Зміщення броунівської частинки росте як √τ.

## Тема 10. Вільний пробіг, явища перенесення (К1 або лише іспит)

```
<λ> = 1/(√2·π·d²·n₀) = kT/(√2πd²P)
D = (1/3)<v><λ>     дифузія (маса)
η = ρD              в'язкість (імпульс)
χ = ηc_v            теплопровідність
```

λ ∝ 1/P. D ∝ T^(3/2)/P. η і χ газу від тиску не залежать (ρ ∝ P, λ ∝ 1/P) і ростуть як √T
(Підр. с. 160-163, 305-320). Працює, поки λ менша за розмір посудини.

## Тема 11. Реальні гази, Ван-дер-Ваальс (К2)

Молекули мають власний об'єм (поправка b) і притягуються (внутрішній тиск a/V²)
(Підр. с. 342-359):

```
(P + ν²a/V²)(V - νb) = νRT
V_к = 3b
P_к = a/(27b²)
T_к = 8a/(27Rb)
RT_к/(P_кV_к) = 8/3
U = νC_V·T - ν²a/V
```

Критична точка - точка перегину ізотерми (∂P/∂V = 0 і ∂²P/∂V² = 0). Нижче T_к на ізотермі
є горизонтальна ділянка (рідина + насичена пара). Біля критичної точки - критична
опалесценція (речовина мутніє через флуктуації густини).

Розширення в пустоту: U = const, але газ ВдВ охолоджується. **Ефект Джоуля-Томсона** -
повільне протискання газу через пористу перегородку, H = U + PV = const; у підручнику
«додатний» ефект = охолодження. Температура інверсії T_i = 2a/(Rb): для водню ≈ 220 К,
тому його перед дроселюванням охолоджують (Підр. с. 365-385).

Сталі a, b - у СІ (Па·м⁶/моль², м³/моль), тож V - у м³.

## Тема 12. Рідини і розчини (К2)

Рідина має ближній порядок (як кристал на 2-3 сусідів), дальнього нема. Молекули
коливаються і час від часу перестрибують - тому в'язкість рідини з ростом T **падає**
(η = A·e^(U/kT)), а в газу росте (Підр. с. 408-421).

**Поверхневий натяг** σ = F/l = W/S. Рідина прагне зменшити поверхню. Змочування - θ < 90°.

```
крапля:     ΔP = 2σ/r
бульбашка:  ΔP = 4σ/r (дві поверхні)
Лаплас:     ΔP = σ(1/r₁ + 1/r₂)
Жюрен:      h = 2σcos θ/(ρgr)
Стокс:      F = 6πηrv
```

**Розчини** (Підр. с. 551-567): Рауль - відносне зниження тиску пари розчинника дорівнює
молярній частці розчиненої речовини; Генрі - концентрація розчиненого газу ∝ тиску газу;
Вант-Гофф - осмотичний тиск π·V = νRT (як газ у тому самому об'ємі). Ідеальний розчин
утворюється без виділення і вбирання теплоти.

## Тема 13. Тверді тіла і фазові переходи (К2)

Кристал має дальній порядок, гратку, елементи симетрії; 7 систем, 14 граток Браве. Дефекти:
точкові (вакансії, домішки), лінійні - дислокації, поверхневі - межі зерен (Підр. с. 462-485).

**Дюлонг і Пті**: C = 3R ≈ 25 Дж/(моль·К) - атом має 3 коливальні ступені по kT. При низьких
T теплоємність падає до нуля - пояснюють Ейнштейн і Дебай (C ∝ T³) (Підр. с. 499-509).

**Фазові переходи**: I роду - стрибок питомого об'єму і ентропії, є теплота переходу
(плавлення, кипіння); II роду - теплоти нема, стрибає теплоємність (надпровідність,
λ-точка гелію) (Підр. с. 517-525).

```
Клапейрон-Клаузіус:
dP/dT = i/(T(v₂ - v₁))
i - ПИТОМА теплота, v - ПИТОМІ об'єми
```

Пара ≈ ідеальний газ: ln(P₂/P₁) = -(iμ/R)(1/T₂ - 1/T₁). Лід легший за воду, тому під тиском
тане при нижчій T. На фазовій діаграмі криві плавлення, кипіння (кінчається в критичній
точці) і сублімації сходяться в потрійній точці.
