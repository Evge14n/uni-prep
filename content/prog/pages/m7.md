# Модуль 7. ЛР7: решето, точки, матриці - заготовки й doctest сам

ЛР7: решето на списку, точки як кортежі і сортування, матриці. Готових тестів нема: сам розбиваєш задачу на функції, пишеш заготовки і щонайменше 5 doctest до кожної.

Кроки по порядку - кожен наступний спирається на попередній. Разом ≈ 5 год 24 хв роботи, це ≈ 8 днів по 30-40 хв (орієнтовно). [Графік](#/grafik) і бот розкладають це по днях у межах 30-40 хв: першими лаби і Linux Mint, частина уроків Git - після ЛР7, уроків Python і безпеки в графіку нема. Встигаєш більше - іди по модулю.

## Крок 5. Налагодження (pdb)

- Зламана програма: [bug_6.py - дві серії вимірювань](#/u/prog/mint-zadachi/bug-6py-дві-серії-вимірювань) - Bug_6.py - друга серія «памʼятає» першу: список як значення за замовчуванням. Знайди помилку способом з уроків 05-06 (traceback, print, assert, pdb), потім звір з розбором під програмою.

Нагадування pdb: `python3 -m pdb файл.py`, далі `n` (рядок), `s` (усередину функції), `p змінна`, `c` (далі), `q`; після падіння - `python3 -m pdb -c continue файл.py` (post-mortem). Детально - [урок 06](#/u/prog/mint-06).
