## 1. Ідея

**Програма - це список наказів компʼютеру, які він виконує згори вниз, по одному, рівно по разу.**
Такі програми, без розгалужень і циклів, називають **лінійними**. З них починається Лекція 1 і вся ЛР1.

Уяви рецепт млинців: «1) розбий 2 яйця; 2) додай 300 мл молока; 3) перемішай». Ти не робиш крок 3
раніше за крок 1, і кожен крок робиш один раз. Компʼютер так само: читає рядок 1, виконує, потім
рядок 2, і так до кінця файлу. Він не «здогадується», що ти мав на увазі. Робить рівно написане.

### Перша програма

```python
print("Hello, World!")
```

```text
Hello, World!
```

`print` - вбудована функція: що їй дали в дужках, те й виводить на екран. Лапки не друкуються: вони
лише кажуть Python «це текст, а не імʼя змінної».

### Вираз і інструкція - різниця, яка знадобиться весь курс

**Вираз** - те, що має значення: `2 + 3`, `x + 3`, `"Hello"`. **Інструкція** - дія: `x = 23`
(«запамʼятай»), `print(x)` («покажи»). В інтерактивному режимі (REPL, Лекція 1, с. 7) Python сам
показує значення кожного виразу, а присвоєння нічого не показує:

```python
>>> 2 + 3
5
>>> total = 2 + 3
>>> total
5
```

Рядок `>>> total = 2 + 3` нічого не вивів: це інструкція, вона лише дала імʼя `total` числу 5.
А от **у файлі програми** рядок `2 + 3` сам по собі не виведе нічого: Python порахує 5 і викине.
Щоб побачити результат у файлі, потрібен `print`. REPL - це «Read-Eval-Print Loop»: прочитай,
обчисли, **покажи**. Файл показує лише те, що ти попросив через `print`.

### Типи літералів

Кожне значення має тип. Тип визначає, що з ним можна робити (Лекція 1, с. 9):

```python
>>> type(256)
<class 'int'>
>>> type(0.1)
<class 'float'>
>>> type("256")
<class 'str'>
```

`256` - ціле число (`int`), `0.1` - дійсне (`float`), `"256"` у лапках - **рядок** (`str`), тобто
текст із трьох символів `2`, `5`, `6`. З числом можна рахувати, з текстом - ні (детальніше в уроці 2).
Функцію `type` детально розберемо в уроці 3 (Лекція 3, с. 3), тут вона лише щоб «підглянути» тип.

### Змінна - це імʼя, а не коробка

```python
x = 23
y = x + 3
print(x, y)
```

```text
23 26
```

Рядок `y = x + 3` виконується так: **спершу** права частина (`x + 3` = `23 + 3` = `26`), **потім**
імʼя `y` прикріплюється до числа 26. Знак `=` - не «дорівнює» з математики, а «обчисли праве і дай
йому імʼя зліва». Тому в Python нормально писати `x = x + 1`: праве `x + 1` рахується зі старим `x`.

Лекція (с. 10): після `a = 3` і `s = a` маємо не дві змінні, а **одне** число 3 з двома іменами.
Числа незмінювані: «змінити» `a` можна лише прикріпивши імʼя `a` до **іншого** числа. Тоді `s` і далі
вказує на 3. Це перевіримо в розділі 3.

### Ключові слова

```python
>>> import keyword
>>> len(keyword.kwlist)
35
>>> keyword.iskeyword("class")
True
>>> keyword.iskeyword("total")
False
```

`keyword.kwlist` - з лекції (с. 11); `len` і `keyword.iskeyword` - у лекціях нема, стандартний Python.
Редактор підсвічує ключові слова іншим кольором: побачив кольорове слово - не бери його за імʼя.

### Коментарі: пояснюй «чому»

```python
seconds = 7200
# Ділимо на 3600, бо в годині 60 хв по 60 с.
hours = seconds / 3600
print(hours)  # друкує 2.0
```

```text
2.0
```

Усе після `#` Python пропускає. Коментар «друкує 2.0» тут для навчання; у справжньому коді він зайвий,
бо це видно й так. А от «бо в годині 60 хв по 60 с» - корисний: пояснює, звідки 3600 (Лекція 1, с. 12:
«коментар повинен пояснювати чому, а не що»). Зверни увагу: `7200 / 3600` дало `2.0`, а не `2`.
Ділення `/` завжди дає `float` (це з Лекції 3 і ЛР1, с. 2-3, але знати треба вже зараз).

## 2. Розібраний приклад

**Умова.** Світло летить зі швидкістю приблизно 300 000 км/с. Відстань від Сонця до Землі -
приблизно 150 000 000 км. За скільки секунд і за скільки хвилин сонячне світло долітає до нас?

```python
# Скільки летить світло від Сонця до Землі.
SPEED_OF_LIGHT = 300000           # км/с, іменована константа
distance = 150000000              # км, відстань Сонце - Земля
time_seconds = distance / SPEED_OF_LIGHT
time_minutes = time_seconds / 60  # у хвилині 60 секунд
print("Світло летить", time_seconds, "секунд")
print("Це", time_minutes, "хвилин")
```

```text
Світло летить 500.0 секунд
Це 8.333333333333334 хвилин
```

**Кожен рядок:**

| Рядок | Що робить |
|---|---|
| `# Скільки летить ...` | Коментар. Python його пропускає. Пише людині, що робить програма. |
| `SPEED_OF_LIGHT = 300000` | Іменована константа. Великі літери = «не змінюй мене» (домовленість, Лекція 1, с. 9). `300000` - літерал типу `int`. |
| `distance = 150000000` | Змінна `distance` посилається на ціле число 150 000 000. |
| `time_seconds = distance / SPEED_OF_LIGHT` | Спершу права частина: 150000000 / 300000 = 500. Ділення `/` завжди дає `float`, тому 500.0. Потім імʼя `time_seconds` прикріплюється до 500.0. |
| `time_minutes = time_seconds / 60` | 500.0 / 60 = 8.333... Коментар пояснює, звідки 60. |
| `print("Світло летить", time_seconds, "секунд")` | Друкує три значення через пробіл: текст, число, текст. |
| `print("Це", time_minutes, "хвилин")` | Те саме для хвилин. Останні цифри `...334` - не помилка програми, а похибка дійсних чисел (Лекція 3, с. 4-5). |

**Трасувальна таблиця** (що лежить у змінних після кожного кроку; `-` = змінної ще нема):

| Крок | SPEED_OF_LIGHT | distance | time_seconds | time_minutes | На екрані |
|---|---|---|---|---|---|
| 1 | 300000 | - | - | - | |
| 2 | 300000 | 150000000 | - | - | |
| 3 | 300000 | 150000000 | 500.0 | - | |
| 4 | 300000 | 150000000 | 500.0 | 8.333333333333334 | |
| 5 | так само | | | | `Світло летить 500.0 секунд` |
| 6 | так само | | | | `Це 8.333333333333334 хвилин` |

Чому порядок рядків важливий: якщо переставити крок 3 вище кроку 2, Python дійде до `distance`, якої
ще не існує, і впаде з `NameError` (це буде в розділі 4).

**Закрий приклад і напиши його сам з памʼяті.** Зміни сюжет: Місяць від Землі приблизно за
384 000 км. Порахуй, за скільки секунд і хвилин світло долетить від Місяця. Якщо все правильно,
побачиш `Світло летить 1.28 секунд` і `Це 0.021333333333333333 хвилин`.

## 3. Передбач вивід

Що виведе? Спершу напиши відповідь на папері, потім відкрий.

**Фрагмент 1.** Дві інструкції в одному рядку.

```python
print("Пара о"); print("8:30")
print("2 + 3")
print(2 + 3)
```

<details markdown="1"><summary>Відповідь</summary>

```text
Пара о
8:30
2 + 3
5
```

Крапка з комою розділяє дві **окремі** інструкції (Лекція 1, с. 7), тому кожен `print` друкує свій
рядок. `"2 + 3"` у лапках - текст, його друкують як є. `2 + 3` без лапок - вираз, його спершу
обчислюють, а потім друкують результат 5.
</details>

**Фрагмент 2.** Змінили `x` - чи зміниться `y`?

```python
x = 23
y = x + 3
x = 100
print(x, y)
```

<details markdown="1"><summary>Відповідь</summary>

```text
100 26
```

`y = x + 3` виконався **один раз**, коли `x` був 23. У `y` записалось готове число 26, а не формула.
Пізніше `x = 100` прикріплює імʼя `x` до іншого числа, а `y` про це не знає. Це головна пастка
лінійних програм: присвоєння - це «знімок» значення в цю мить.
</details>

**Фрагмент 3.** Два імені на одне число (Лекція 1, с. 10).

```python
price = 3
old_price = price
price = price + 2
print(price, old_price)
```

<details markdown="1"><summary>Відповідь</summary>

```text
5 3
```

Після `old_price = price` обидва імені вказують на одне число 3. Рядок `price = price + 2` не
змінює саме число 3 (числа незмінювані), а створює нове число 5 і прикріплює до нього імʼя `price`.
Імʼя `old_price` і далі вказує на 3.
</details>

**Фрагмент 4 (каверзний).** Довгий вираз у двох рядках. Перший варіант - з дужками, другий - без.

```python
x = 2
y = (x ** 2 +
     x + 1)
z = x ** 2
+ x + 1
print(y, z)
```

<details markdown="1"><summary>Відповідь</summary>

```text
7 4
```

`y`: дужки кажуть Python «інструкція ще не закінчилась» (Лекція 1, с. 7-8), тому `y = 4 + 2 + 1 = 7`.
`z`: без дужок кінець рядка = кінець інструкції, тож `z = x ** 2 = 4`. Наступний рядок `+ x + 1` -
окремий вираз: Python рахує `+2 + 1 = 3` і викидає (у файлі вираз нічого не показує). Помилки нема,
але результат неправильний. Такі тихі помилки - найнебезпечніші.
</details>

**Фрагмент 5.** Що з цього коментар?

```python
'''Ця програма рахує площу.
Автор: я'''
side = 4  # сторона квадрата, см
# print("це не виконається")
print(side * side)  # print("і це теж")
```

<details markdown="1"><summary>Відповідь</summary>

```text
16
```

Рядок у потрійних лапках, який ніде не використано, Python обчислює і викидає, тому він працює як
багаторядковий коментар (Лекція 1, с. 11). Усе після `#` - коментар, навіть якщо там написано
`print(...)`. Тому виконується лише `print(side * side)`, тобто 4 · 4 = 16.
</details>

## 4. Знайди помилку

Кожен фрагмент падає. Знайди причину, а потім відкрий відповідь.

**Помилка 1.** Хотіли запамʼятати, хто на другому місці.

```python
# БАГ
2nd_place = "Олена"
print(2nd_place)
```

<details markdown="1"><summary>Що не так</summary>

Python пише `SyntaxError: invalid decimal literal`. Ідентифікатор не може починатися з цифри
(Лекція 1, с. 8): побачивши `2`, Python думає, що це число, а далі йдуть літери, яких у числі не буває.
Виправлення - імʼя з літери, змістовне й англійське:

```python
# ВИПРАВЛЕНО
second_place = "Олена"
print(second_place)
```

```text
Олена
```
</details>

**Помилка 2.** Порахували вартість до того, як задали ціну.

```python
# БАГ
quantity = 3
total = price_per_item * quantity
price_per_item = 25
print(total)
```

<details markdown="1"><summary>Що не так</summary>

`NameError: name 'price_per_item' is not defined`. Програма лінійна: на рядку 3 Python ще не бачив
рядка 4 і не знає імені `price_per_item`. Він не «заглядає вперед». Виправлення - поставити рядки в
порядку, у якому потрібні значення:

```python
# ВИПРАВЛЕНО
quantity = 3
price_per_item = 25
total = price_per_item * quantity
print(total)
```

```text
75
```
</details>

**Помилка 3.** Зайвий пробіл на початку рядка.

```python
# БАГ
group_name = "ФзІ-11"
 print(group_name)
```

<details markdown="1"><summary>Що не так</summary>

`IndentationError: unexpected indent`. У Python відступ - частина синтаксису (Лекція 1, с. 8):
відступ означає «це вкладений блок» і можливий лише після рядка з двокрапкою. Тут двокрапки нема,
тому навіть один пробіл - помилка. В інших мовах це було б «неохайно», у Python програма не
запуститься взагалі.

```python
# ВИПРАВЛЕНО
group_name = "ФзІ-11"
print(group_name)
```

```text
ФзІ-11
```
</details>

## 5. Склади з рядків

Скільки разів серце вдарить за добу, якщо пульс - 70 ударів за хвилину? Розстав рядки в правильному
порядку. **Один рядок зайвий (пастка)** - знайди його і поясни, чому він зламає програму.

```parsons
print("За добу серце вдарить", beats_per_day, "разів")
heart_rate = 70  # ударів за хвилину
beats_per_day = heart_rate * minutes_in_day
MINUTES_IN_DAY = 24 * 60
beats_per_day = heart_rate * MINUTES_IN_DAY
```

<details markdown="1"><summary>Розвʼязок</summary>

```python
MINUTES_IN_DAY = 24 * 60
heart_rate = 70  # ударів за хвилину
beats_per_day = heart_rate * MINUTES_IN_DAY
print("За добу серце вдарить", beats_per_day, "разів")
```

```text
За добу серце вдарить 100800 разів
```

Зайвий рядок - `beats_per_day = heart_rate * minutes_in_day`. Великі й малі літери в іменах різні
(Лекція 1, с. 8): `minutes_in_day` і `MINUTES_IN_DAY` - два різні імена, і першого ніхто не створив,
тому було б `NameError`. Порядок: константа і пульс можуть стояти в будь-якому порядку між собою,
але обидва - до обчислення, а `print` - останнім. 70 · 1440 = 100800.
</details>

Як у ЛР1: функцію вже оголошено, doctest уже написано, ти лише замінюєш `pass` одним рядком
`return <вираз>`. Що таке `def` і `return` докладно - в уроці 2. Зараз досить знати: `return вираз`
обчислює вираз і віддає його як результат функції, а doctest перевіряє цей результат.

Обмеження як у ЛР1: без `if`, без циклів, без списків.

Запуск з теки `Курс`:

```text
python3 -m doctest zadachi/urok01.py -v
```

Спершу всі приклади червоні (`Failed`), бо `pass` нічого не повертає. Дописуєш - стають зелені.
Наприкінці має бути `Test passed`.

**Задача 1. `kinetic_energy(mass, speed)`.** Кінетична енергія E = m · v² / 2. Приклади з doctest:
маса 2 кг і швидкість 3 м/с дають 9.0 Дж; швидкість -4 м/с дає ту саму енергію, що й 4 м/с.

<details markdown="1"><summary>Підказка-план</summary>

1. Запиши формулу через `*`, `/` і `**` (`**` - піднесення до степеня, Лекція 1, с. 8: `x**5`).
2. Подумай, чи потрібні дужки: `**` виконується раніше за `*` і `/`.
3. Перевір у голові граничний випадок: маса 0 - енергія 0.0 (не 0: ділення `/` дає `float`).
4. Перевір від'ємну швидкість: (-4)² = 16, а не -16. Якщо `speed` - змінна, мінус уже всередині
   числа, і `speed ** 2` дає 16.0.
</details>

**Задача 2. `trip_seconds(hours, minutes, seconds)`.** Перевести «2 год 30 хв 15 с» в секунди
(9015). У файлі вже є константи `SECONDS_IN_HOUR` і `SECONDS_IN_MINUTE` - використай їх.

<details markdown="1"><summary>Підказка-план</summary>

1. Години → секунди: множимо на `SECONDS_IN_HOUR`.
2. Хвилини → секунди: множимо на `SECONDS_IN_MINUTE`.
3. Додаємо все й секунди.
4. Якщо рядок задовгий (більше 79 знаків), візьми весь вираз у дужки і перенеси (Лекція 1, с. 7-8).
5. Це обернена задача до ЛР1, завд. 2 (там секунди розкладають на дні, години, хвилини).
</details>

```python
"""Урок 1. Розвʼязки задач з doctest.

Відкривай лише після 2 спроб написати самому.
Перевірка: python3 -m doctest _rozvyazky/urok01.py -v

import doctest

# Іменовані константи: великі літери кажуть «це значення не змінюємо».
# Python цього не забороняє (Лекція 1, с. 9), це домовленість PEP 8.
SECONDS_IN_MINUTE = 60
SECONDS_IN_HOUR = 3600


def kinetic_energy(mass: float, speed: float) -> float:
    """Повертає кінетичну енергію тіла E = m * v ** 2 / 2 (у джоулях).

    :param mass: маса тіла, кг
    :param speed: швидкість тіла, м/с (знак не важить: її підносять
        до квадрата)
    :return: енергія, Дж

    >>> kinetic_energy(2.0, 3.0)
    9.0
    >>> kinetic_energy(1500.0, 20.0)
    300000.0
    >>> kinetic_energy(0.0, 10.0)
    0.0
    >>> kinetic_energy(1.0, 0.0)
    0.0
    >>> kinetic_energy(0.5, -4.0)
    4.0
    """
    # ** виконується раніше за * і /, тому дужки не потрібні:
    # спершу speed ** 2, потім множення на масу, потім ділення на 2.
    # Для speed = -4.0 квадрат дає 16.0, тому енергія додатна.
    # Ділення / завжди дає float, тому навіть 9 виходить як 9.0.
    return mass * speed ** 2 / 2


def trip_seconds(hours: int, minutes: int, seconds: int) -> int:
    """Переводить тривалість поїздки «години, хвилини, секунди» в секунди.

    Використай константи SECONDS_IN_HOUR і SECONDS_IN_MINUTE,
    а не числа 3600 і 60 прямо у формулі.

    :param hours: повні години (0 або більше)
    :param minutes: хвилини (від 0 до 59)

    61

    return (hours * SECONDS_IN_HOUR
            + minutes * SECONDS_IN_MINUTE
            + seconds)
```

## 7. Поясни чому

**1. Чому після `x = 23`, `y = x + 3`, `x = 100` у `y` лишається 26?**

<details markdown="1"><summary>Еталон</summary>

Присвоєння виконується один раз: спершу рахується права частина з тими значеннями, що є **зараз**
(23 + 3 = 26), і готове число 26 отримує імʼя `y`. Формула не запамʼятовується. Наступне `x = 100`
лише прикріплює імʼя `x` до нового числа, а `y` і далі вказує на 26.
</details>

**2. Чому `PI = 3.14159` - «константа» лише на словах, і навіщо тоді великі літери?**

<details markdown="1"><summary>Еталон</summary>

У Python нема окремої конструкції для констант (Лекція 1, с. 9): `PI = 3.14159` - звичайне
присвоєння, і нижче можна написати `PI = 3`, Python не заперечить. Великі літери - домовленість між
людьми (PEP 8): хто читає код, бачить «це значення ніхто не мусить змінювати». Так помилку видно
одразу: якщо десь `PI = ...` удруге - щось не так.
</details>

**3. Чому рядок `2 + 3` в інтерактивному режимі показує 5, а у файлі програми - нічого?**

<details markdown="1"><summary>Еталон</summary>

Інтерактивний режим - це REPL: Read-Eval-**Print** Loop. Він сам друкує значення кожного виразу, щоб
було зручно експериментувати. Файл програми так не робить: вираз `2 + 3` обчислюється і результат
викидається, бо ніхто не сказав, що з ним робити. Щоб побачити - `print(2 + 3)`, щоб використати
далі - `total = 2 + 3`.
</details>

## 8. Що запамʼятати

- Лінійна програма виконується згори вниз, кожна інструкція рівно один раз. Порядок рядків - частина
  алгоритму.
- `=` - «обчисли праву частину і дай їй імʼя зліва», а не «дорівнює». Значення береться в цю мить.
- Змінна - імʼя, що посилається на значення. `int`, `float`, `complex` - незмінювані.
- Кінець рядка = кінець інструкції; довгий вираз - у дужках; відступ - частина синтаксису (4 пробіли).
- Ідентифікатор: латинські літери, цифри, `_`, не з цифри, регістр важить, не одне з 35 ключових слів.
- Літерал - значення в коді (`256`, `0.1`, `"текст"`); іменована константа - великими літерами.
- Вираз має значення, інструкція виконує дію. REPL показує значення виразів, файл - лише через `print`.
- Коментар `#` пояснює «чому», а не «що».

**Де в лабах:**

- ЛР1, с. 1: лінійний алгоритм `a = 15`, `b = 4`, `c = a + b`, `print(c)` - те саме, що розділ 2.
- ЛР1, с. 1: типи `int`, `float`, `str`, `bool` і `type()`.
- ЛР1, с. 8: імена змінних `snake_case` (`remaining_amount`, а не `q`) і константи `SECONDS_IN_MINUTE = 60`,
  `SECONDS_IN_DAY = 86400`. Константи знадобляться в ЛР1, завд. 2 (секунди → дні, години, хвилини).
- ЛР1, завд. 1-3: заборонено `if`, `elif`, `else`, `for`, `while` (ЛР1, с. 12) - тобто кожна функція
  там лінійна, як усе в цьому уроці.
- ЛР1, завд. 3: довгий список параметрів `calculate_payment(...)` записано в дужках на кількох рядках -
  це правило переносу з Лекції 1, с. 7-8.
