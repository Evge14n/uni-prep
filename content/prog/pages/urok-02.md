## 1. Ідея

Урок 1 дав «цеглинки»: змінні й `print`. Тепер з них складаємо справжню програму, яка
**питає** дані (`input`), **рахує** і **показує** результат гарно відформатованим (`%`, f-рядки).
А щоб ту саму обчислювальну частину можна було перевірити й використати ще раз, її ховають у
**функцію**, яка **повертає** результат (`return`). Плюс правила оформлення PEP 8, бо викладач
перевіряє не лише «чи працює», а й «чи правильно написано».

Головна думка уроку: **друкувати і повертати - різні речі.** `print` показує текст людині і віддає
`None`. `return` віддає значення програмі, щоб з ним працювати далі. doctest у лабах перевіряє саме
те, що функція **повертає**.

### `pass` і присвоєння

```python
def future_feature():
    pass


print(future_feature())
```

```text
None
```

`pass` - «тут поки нічого». Функцію без `return` можна викликати, і вона поверне `None` («нічого»).
Саме тому в заготовках задач стоїть `pass`: doctest чекає число чи рядок, отримує `None` і червоніє.

Присвоєння (с. 1): у `x = e` спершу рахується `e`, потім старе значення `x` стає недосяжним.
`x = 12` і `y = (x**5 + x**4 + x**3 + x**2 + x + 1)` дає `y = 271453` (так і в коді з пари, с. 1).

### Ввід: `input` завжди повертає рядок

```python
# ввід: Андрій
name = input("Як тебе звати? ")
print("Привіт,", name)
```

```text
Як тебе звати? Андрій
Привіт, Андрій
```

Програма друкує підказку, зупиняється, чекає, поки людина набере текст і натисне Enter, і **повертає
набраний текст як рядок** (`str`). Навіть якщо набрали `25`, це рядок з двох символів `"25"`. Для
чисел потрібне перетворення: `int(input(...))` для цілих, `float(input(...))` для дійсних
(Лекція 3, с. 3; ЛР1, с. 2).

### Вивід: `print`, `sep` і `end`

```python
print(1, 2, 3)
print(1, 2, 3, sep="_")
print(1); print(2)
print(1, end="!"); print(2, end="!")
print()
print(1, 2, 3, sep="\n", end="!")
```

```text
1 2 3
1_2_3
1
2
1!2!
1
2
3!
```

`sep` - що ставити **між** значеннями (типово пробіл), `end` - що ставити **в кінці** (типово
`"\n"`, тобто перехід на новий рядок). У рядку 4 `end="!"` прибрав перехід, тому `1!2!` в одному
рядку. Порожній `print()` друкує лише `end`, тобто закінчує цей рядок. `"\n"` - один символ «новий
рядок», тому `sep="\n"` ставить кожне число на свій рядок (код з пари, с. 1).

### Форматування оператором `%`

```python
print("First = %d, second = %d" % (1, 2))
print("%s було %d років, коли він пішов у %d клас" % ("Миколі", 7, 1))
print("Високосний рік має %d днів" % 366)
print("Знижка %d%%" % 15)
print("%.2f і %e" % (3.14159, 0.000123))
```

```text
First = 1, second = 2
Миколі було 7 років, коли він пішов у 1 клас
Високосний рік має 366 днів
Знижка 15%
3.14 і 1.230000e-04
```

Зліва - шаблон, справа після `%` - значення в дужках. Кожен `%d` (ціле), `%s` (рядок), `%f` (дійсне),
`%e` (експоненційна форма) забирає **одне** значення по черзі. `%%` - сам знак відсотка. Одне значення
можна без дужок (с. 3). Правило: скільки `%...` у шаблоні, стільки значень справа, інакше `TypeError`.
Цей стиль старий, але в чужому коді (і в Лекції 3) трапляється часто.

### f-рядки - сучасний спосіб

```python
pi = 3.14159265
val = 0.0012345
print(f"2 знаки після коми: {pi:.2f}")
print(f"3 значущі цифри:    {val:.3g}")
print(f"Роздільник тисяч:   {1000000:_}")
name = "Марко"
score = 95
print(f"{name:<10} | {score:>5}")
print(f"[{name:^9}]")
print(f"{7:02d}:{5:02d}")
```

```text
2 знаки після коми: 3.14
3 значущі цифри:    0.00123
Роздільник тисяч:   1_000_000
Марко      |    95
[  Марко  ]
07:05
```

Буква `f` перед лапками вмикає підстановку: у `{}` можна писати змінну або будь-який вираз. Після
двокрапки - **як** показати:

| Запис | Що означає | Приклад → результат |
|---|---|---|
| `:.2f` | 2 знаки після коми | `3.14159` → `3.14` |
| `:.3g` | 3 значущі цифри | `0.0012345` → `0.00123` |
| `:_` | підкреслення між тисячами | `1000000` → `1_000_000` |
| `:<10`, `:>5`, `:^9` | ширина поля, вирівнювання вліво, вправо, по центру | `"Марко"` → `Марко     ` |
| `:02d` | ціле, ширина 2, доповнити нулями (ЛР1, с. 4) | `7` → `07` |

Форматування міняє лише **показ**, саме число лишається тим самим (ЛР1, с. 3-4). Ширина - це
**мінімум**: довший текст не обрізається.

Ті самі вирівнювання - методами рядків (с. 4):

```python
text = "Python"
print(text.ljust(10, "-"))
print(text.rjust(10, "*"))
print(text.center(10, "."))
print("7".zfill(3))
print("{} + {} = {}".format(2, 3, 5))
```

```text
Python----
****Python
..Python..
007
2 + 3 = 5
```

### Лінійна програма (с. 5)

Програма лише з вводу, виводу, присвоєння і `pass`. Без розгалужень і циклів, кожна інструкція - один
раз, згори вниз. Саме такі програми просять у ЛР1.

### PEP 8 і перевірка стилю

PEP 8 - офіційні рекомендації, як оформлювати код Python (Лекція 2, с. 6-12). Код з порушеннями
все одно запуститься, але викладач перевіряє стиль, і читати такий код у 10 разів частіше, ніж писати
(с. 6). Найважливіше:

| Правило | Як правильно | Як не треба |
|---|---|---|
| Відступ | 4 пробіли, без табуляції (змішування дає `TabError`) | 2 пробіли або Tab |
| Довжина рядка | до 79 знаків (докстрінг і коментар до 72) | рядок на весь екран |
| Перенос | усередині дужок: `total = (first + second +` | зворотна риска `\` у кінці |
| Порожні рядки | 2 між функціями, 1 між методами класу | 0 |
| Пробіли | `x = 1`, `y = x + 3`, `f(a, b)`, `data[1]` | `x=1`, `f (a,b)`, `( a + b )` |
| Змінні, функції | `snake_case`: `student_name`, `calculate_area()` | `studentName`, `a`, `d1` |
| Константи | `UPPER_SNAKE_CASE`: `MAX_SPEED`, `EARTH_RADIUS_KM = 6371` | `maxspeed` |
| Класи | `PascalCase`: `BankAccount` | `bank_account` |
| Не брати | `l`, `O`, `I` (схожі на 1 і 0); імена `sum`, `list`, `str`, `type`, `id` | |
| Імпорти | кожен на окремому рядку, на початку файлу: стандартні, сторонні, свої | `import math, os` |
| Коментарі | повне речення; не дублювати код; функції - докстрінг `"""..."""` | |
| Порівняння | `if value is None:`, `if is_valid:` (про `if` - урок 3) | `== None`, `== True` |

> **Нове тут:**
>
> - `\` (backslash) - робить наступний символ звичайним; у кінці рядка - перенос.
> - `type` - каже, що це за команда і де вона. Назва: type - «тип».
> - `id` - показує твій номер у системі (uid) і групи. Назва: identity - «особа» (ID - ідентифікатор, номер).

Інструменти (с. 12-14): **лінтери** знаходять проблеми, не запускаючи код (`pycodestyle` - лише PEP 8;
`flake8` - PEP 8 + невикористані імена; `pylint` - глибше, ставить оцінку з 10; `mypy` - перевіряє
типи). **Форматери** самі переписують код (`black` - «безкомпромісний», ширина 88; `autopep8`;
`isort` - сортує імпорти). Запуск: `pip install flake8 black`, потім `flake8 my_program.py`.
У Linux Mint `pip install` працює лише всередині venv (`source ~/univer/.venv/bin/activate`), інакше
помилка `externally-managed-environment` - курс Linux-Mint, уроки 02-03.

> **Нове тут:**
>
> - `pip install` - ставить бібліотеку Python (лише у venv). Назва: `pip` - pip installs packages - «pip ставить пакети» (назва, що посилається сама на себе); pip installs packages - «pip ставить пакети»; install - «встановити».
> - `source` - виконує команди з файлу просто в цьому вікні термінала. Назва: source - «джерело». `~/univer/.venv/bin/activate` - увімкнути venv (окремий Python для лаб); вимкнути - deactivate.
> - `~` (tilde) - твоя домашня тека, /home/evgen.

Приклад з лекції (с. 14-15), сума цифр двозначного числа. Спершу «до PEP 8» (працює, але читати важко):

```python
# не запускати: приклад поганого стилю, flake8 знайде 7 зауважень
x=int(input("Введіть двозначне число "))
f=x//10
s=x%10
sum=f+s
print("Сума цифр числа %d = %d"%(x,sum))
```

`pycodestyle` на парі (код з пари, с. 17) видав для такого коду, зокрема:
`E225 missing whitespace around operator` (нема пробілів навколо `=`), `E228` (навколо `%`), `E231`
(після коми). І ще гірше: `sum` - імʼя вбудованої функції `sum()`, після `sum=f+s` вона «затінена» і
далі в програмі не працює. Після PEP 8:

```python
# ввід: 25
x = int(input("Введіть двозначне число "))
first_digit = x // 10   # перша (десяткова) цифра числа
second_digit = x % 10   # друга (одинична) цифра числа
digit_sum = first_digit + second_digit
print("Сума цифр числа %d = %d" % (x, digit_sum))
```

```text
Введіть двозначне число 25
Сума цифр числа 25 = 7
```

`//` - ціла частина від ділення (25 // 10 = 2), `%` для чисел - остача (25 % 10 = 5). Детально ці
операції - в уроці 3 (Лекція 3, с. 1-3).

### Анотації типів: підказка, а не заборона

```python
x: int = 10
x = "hello"
print(x, type(x))
```

```text
hello <class 'str'>
```

`x: int` каже людині й інструменту `mypy` «тут має бути ціле». Сам Python це **ігнорує** (с. 13),
тому рядок `x = "hello"` спрацював. На парі `mypy` для такого коду написав (код з пари, с. 17):
`error: Incompatible types in assignment (expression has type "str", variable has type "int")`.

### Функції (с. 15-17)

```python
def calculate_area(width: float, height: float) -> float:
    """Обчислює площу прямокутника."""
    return width * height


# Виклик функції та збереження результату
rect_area = calculate_area(5.0, 3.0)
print(f"Площа: {rect_area}")
```

```text
Площа: 15.0
```

| Частина | Що це |
|---|---|
| `def` | «оголошую функцію» (define). Тіло ще **не виконується**, лише запамʼятовується. |
| `calculate_area` | імʼя, `snake_case`. |
| `(width: float, height: float)` | **параметри** - імена для даних, які передадуть при виклику; `: float` - анотація. |
| `-> float` | анотація: функція повертає `float`. |
| `:` і відступ 4 пробіли | межі тіла функції. |
| `"""..."""` | докстрінг: що робить функція. У лабах тут живуть doctest. |
| `return width * height` | обчислити і **віддати** результат у місце виклику; функція на цьому закінчується. |
| `calculate_area(5.0, 3.0)` | **виклик**: `width = 5.0`, `height = 3.0` (це **аргументи**, ЛР1, с. 4), виконується тіло, вираз виклику набуває значення 15.0. |

Без `return` (або з порожнім `return`) функція повертає `None` (с. 16).

Python не перевіряє анотації, тому функція працює з будь-якими значеннями, для яких є `+` (код з пари,
с. 18):

```python
def add(number1: int, number2: int):
    result = number1 + number2
    return result


print(add(7, 8))
print(add(-7, 5))
print(add("I like", " Python"))
```

```text
15
-2
I like Python
```

Для рядків `+` склеює (конкатенація). Зате `"23" + 17` (рядок + число) - `TypeError: can only
concatenate str (not "int") to str` (код з пари, с. 1).

**Змінні всередині функції - локальні** (с. 17): їх видно лише всередині.

```python
def process():
    inner_value = 10  # локальна змінна
    return inner_value * 2


print(process())
print(inner_value)
```

```text
20
Traceback (most recent call last):
  ...
NameError: name 'inner_value' is not defined
```

Навіщо функції (с. 15-17): **DRY** - не повторювати код; **декомпозиція** - велику задачу ділять на
малі функції (`load_data`, `process_data`, `save_reports`); **ізоляція** - локальні змінні не
плутаються з іншими; **одна точка входу і виходу** - виклик заходить у перший рядок, `return` віддає
результат назад. Це структурне програмування: послідовність, розгалуження, повторення.

На парі ще показали (код з пари, с. 16): `import math`, `help(math)` - довідка про модуль, і
`math.cos(math.pi/3)` дає `0.5000000000000001`, а не 0.5 (похибка дійсних чисел, урок 3).

## 2. Розібраний приклад

**Умова.** Користувач вводить відстань у км і час у годинах. Функція повертає рядок із середньою
швидкістю, округленою до 1 знака. Структура - як у ЛР1, с. 11: функція з doctest, ввід, виклик,
вивід, перевірка.

```python
# ввід: 120 | 1.5
import doctest


def average_speed(distance_km: float, hours: float) -> str:
    """Повертає рядок із середньою швидкістю, км/год.

    >>> average_speed(120.0, 1.5)
    'Середня швидкість: 80.0 км/год'
    >>> average_speed(0.0, 2.0)
    'Середня швидкість: 0.0 км/год'
    """
    speed = distance_km / hours
    return f"Середня швидкість: {speed:.1f} км/год"


distance = float(input("Відстань, км: "))
time_hours = float(input("Час, год: "))
message = average_speed(distance, time_hours)
print(message)
doctest.testmod()
```

```text
Відстань, км: 120
Час, год: 1.5
Середня швидкість: 80.0 км/год
```

**Кожен рядок:**

| Рядок | Що робить |
|---|---|
| `import doctest` | Підключає модуль для перевірки прикладів з докстрінгів. Імпорти - на початку (PEP 8). |
| `def average_speed(distance_km: float, hours: float) -> str:` | Оголошує функцію з двома параметрами; обіцяє повернути рядок. Тіло поки не виконується. |
| `"""Повертає рядок ... >>> ..."""` | Докстрінг з двома doctest: виклик після `>>> ` і очікуваний результат. Рядок у лапках, бо функція повертає `str`. |
| `speed = distance_km / hours` | Локальна змінна: 120.0 / 1.5 = 80.0. |
| `return f"Середня швидкість: {speed:.1f} км/год"` | Збирає рядок, `:.1f` - 1 знак після коми, і віддає його в місце виклику. |
| (2 порожні рядки) | PEP 8: дві порожні лінії після функції. |
| `distance = float(input("Відстань, км: "))` | Друкує підказку, чекає, отримує рядок `"120"`, `float` робить з нього 120.0. |
| `time_hours = float(input("Час, год: "))` | Так само: `"1.5"` → 1.5. |
| `message = average_speed(distance, time_hours)` | Виклик: параметри отримують 120.0 і 1.5, виконується тіло, `return` повертає рядок, він отримує імʼя `message`. |
| `print(message)` | Лише тут щось зʼявляється на екрані. Функція сама нічого не друкувала. |
| `doctest.testmod()` | Проганяє обидва приклади з докстрінгу. Якщо все добре - мовчить. |

**Трасувальна таблиця** (виконання від першого рядка, що щось робить):

| Крок | Де | distance | time_hours | distance_km | hours | speed | message |
|---|---|---|---|---|---|---|---|
| 1 | `distance = ...` (ввели `120`) | 120.0 | - | - | - | - | - |
| 2 | `time_hours = ...` (ввели `1.5`) | 120.0 | 1.5 | - | - | - | - |
| 3 | вхід у функцію | 120.0 | 1.5 | 120.0 | 1.5 | - | - |
| 4 | `speed = ...` | 120.0 | 1.5 | 120.0 | 1.5 | 80.0 | - |
| 5 | `return` → вихід із функції | 120.0 | 1.5 | (зникли) | (зникли) | (зникла) | - |
| 6 | `message = ...` | 120.0 | 1.5 | | | | `'Середня швидкість: 80.0 км/год'` |
| 7 | `print(message)` | | | | | | на екрані без лапок |

Після кроку 5 локальні `distance_km`, `hours`, `speed` зникають: вони жили лише всередині функції.

**Закрий приклад і напиши його сам з памʼяті.** Інший сюжет: функція `fuel_per_100km(liters,
distance_km)` повертає `f"Витрата: ... л/100 км"` (формула: літри / км · 100). Для 13 л на 200 км має
вийти `Витрата: 6.5 л/100 км`. Не забудь doctest на граничний випадок: 0 л - `Витрата: 0.0 л/100 км`.

## 3. Передбач вивід

Що виведе? Спершу напиши відповідь на папері, потім відкрий.

**Фрагмент 1.** `sep` і `end`.

```python
print("a", "b", sep="")
print("x", "y", sep=", ", end=" | ")
print("кінець")
```

<details markdown="1"><summary>Відповідь</summary>

```text
ab
x, y | кінець
```

`sep=""` - між значеннями нічого. У другому `print` між `x` і `y` стоїть `", "`, а в кінці `" | "`
замість переходу на новий рядок. Тому третій `print` дописує `кінець` у той самий рядок.
</details>

**Фрагмент 2.** `%d` і дробове число.

```python
print("%s має %d балів" % ("Оля", 95.7))
print("%.1f%%" % 95.75)
```

<details markdown="1"><summary>Відповідь</summary>

```text
Оля має 95 балів
95.8%
```

`%d` - **ціле**, тому від 95.7 лишається 95: дробову частину відкинуто, а не округлено. `%.1f` -
дійсне з 1 знаком (95.75 → 95.8), `%%` - сам знак `%`.
</details>

**Фрагмент 3.** Формати у f-рядку.

```python
print(f"{2 / 3:.3f}|{5:03d}|{'ok':>4}|{1234567:_}|")
```

<details markdown="1"><summary>Відповідь</summary>

```text
0.667|005|  ok|1_234_567|
```

`2 / 3` = 0.666..., `:.3f` округлює до 0.667. `5:03d` - ширина 3 з нулями: `005`. `'ok':>4` - ширина
4, вправо: два пробіли і `ok`. `:_` ставить `_` між тисячами. Усередині `{}` можна писати вирази
(`2 / 3`) і літерали (`'ok'` в одинарних лапках, бо зовнішні - подвійні).
</details>

**Фрагмент 4 (головна пастка).** `print` замість `return`.

```python
def double(number):
    print(number * 2)


result = double(5)
print(result)
print(double(1) == 2)
```

<details markdown="1"><summary>Відповідь</summary>

```text
10
None
2
False
```

`double(5)` **друкує** 10, але нічого не повертає, тобто повертає `None`. Тому `result` = `None`.
В останньому рядку `double(1)` друкує `2` і повертає `None`; `None == 2` - хибно, `False`. На екрані
«2» видно, а в програмі його нема. Це і є різниця «друкує» і «повертає».
</details>

**Фрагмент 5.** `input` і `+`.

```python
# ввід: 12 | 18
first = input("Перше число: ")
second = input("Друге число: ")
print(first + second)
print(int(first) + int(second))
```

<details markdown="1"><summary>Відповідь</summary>

```text
Перше число: 12
Друге число: 18
1218
30
```

`input` повертає рядки `"12"` і `"18"`. Для рядків `+` - склеювання: `"1218"`. Лише після `int`
вони стають числами, і `+` додає: 30. Як у коді з пари: `"23" + "17"` дає `'2317'`, а `23 + 17` - 40.
</details>

## 4. Знайди помилку

**Помилка 1.** Функція має повертати привітання.

```python
# БАГ
def greet(name: str) -> str:
    """Повертає привітання.

    >>> greet("Оля")
    'Привіт, Оля!'
    """
    print(f"Привіт, {name}!")
```

<details markdown="1"><summary>Що не так</summary>

doctest падає: чекав `'Привіт, Оля!'` (у лапках, бо це **значення-рядок**), а отримав `Привіт, Оля!`
без лапок - це **надрукований текст**. Функція друкує, а повертає `None`.

Пастка: з числами doctest таку помилку **не ловить**. Якщо `double` друкує 4, то doctest
`>>> double(2)` / `4` бачить на екрані `4` і задоволений. Помилка вилізе пізніше, коли результат
спробують використати (`double(2) + 1` - `TypeError`). Тому в лабах (ЛР1, с. 5, с. 12) - завжди
`return`, а друк - поза функцією.

```python
# ВИПРАВЛЕНО
def greet(name: str) -> str:
    """Повертає привітання.

    >>> greet("Оля")
    'Привіт, Оля!'
    """
    return f"Привіт, {name}!"
```
</details>

**Помилка 2.** Рахуємо вік.

```python
# БАГ
# ввід: 2007
birth_year = input("Рік народження: ")
age = 2026 - birth_year
print("Вам", age, "років")
```

<details markdown="1"><summary>Що не так</summary>

`TypeError: unsupported operand type(s) for -: 'int' and 'str'`. `input` повернув рядок `"2007"`,
а від числа рядок не відняти. Те саме на парі знайшов `mypy` (порівняння `str` з `int`). Виправлення:

```python
# ВИПРАВЛЕНО
# ввід: 2007
birth_year = int(input("Рік народження: "))
age = 2026 - birth_year
print("Вам", age, "років")
```

```text
Рік народження: 2007
Вам 19 років
```
</details>

**Помилка 3.** Шаблон на три значення.

```python
# БАГ
hours = 3
minutes = 7
seconds = 5
print("Час: %d год %d хв %d с" % (hours, minutes))
```

<details markdown="1"><summary>Що не так</summary>

`TypeError: not enough arguments for format string`. У шаблоні три `%d`, а значень два. Правило з
Лекції 2, с. 3: кількість спеціальних символів зліва = кількості значень справа.

```python
# ВИПРАВЛЕНО
hours = 3
minutes = 7
seconds = 5
print("Час: %d год %d хв %d с" % (hours, minutes, seconds))
print(f"Час: {hours:02d}:{minutes:02d}:{seconds:02d}")
```

```text
Час: 3 год 7 хв 5 с
Час: 03:07:05
```

Другий рядок - той самий результат f-рядком у форматі ЛР1, с. 4.
</details>

<details markdown="1"><summary>Розвʼязок (відкривай лише після 2 своїх спроб)</summary>

```python
"""Урок 2. Розвʼязки задач з doctest.

Відкривай лише після 2 спроб написати самому.
Перевірка: python3 -m doctest _rozvyazky/urok02.py -v
"""
import doctest


def temperature_report(celsius: float) -> str:
    """Повертає рядок «C °C = F °F», а для морозу дописує « (мороз)».

    Формула: F = C * 9 / 5 + 32. Обидва числа - з одним знаком
    після коми. Мороз - коли температура нижче нуля (0.0 - ще ні).
    Без if: використай прийом «рядок * умова».

    :param celsius: температура в градусах Цельсія
    :return: рядок-звіт

    >>> temperature_report(0.0)
    '0.0 °C = 32.0 °F'
    >>> temperature_report(36.6)
    '36.6 °C = 97.9 °F'
    >>> temperature_report(100.0)
    '100.0 °C = 212.0 °F'
    >>> temperature_report(-40.0)
    '-40.0 °C = -40.0 °F (мороз)'
    >>> temperature_report(-0.5)
    '-0.5 °C = 31.1 °F (мороз)'
    """
    fahrenheit = celsius * 9 / 5 + 32
    # celsius < 0 - це логічний вираз: True або False.
    # У множенні True поводиться як 1, False як 0, тому
    # " (мороз)" * True = " (мороз)", а " (мороз)" * False = "".
    # Строго «< 0», а не «<= 0»: 0.0 °C ще не мороз (див. doctest).
    frost_note = " (мороз)" * (celsius < 0)
    # :.1f - один знак після коми. 97.88 показується як 97.9,
    # але саме число fahrenheit не змінюється (це лише показ).
    return f"{celsius:.1f} °C = {fahrenheit:.1f} °F{frost_note}"


def receipt(item: str, price: float, quantity: int) -> str:
    """Повертає чек з двох рядків, склеєних через символ нового рядка.

    Перший рядок: назва товару (займає щонайменше 8 знаків,
    вирівняна вліво), риска, кількість і ціна за штуку.
    Другий рядок: загальна сума. Ціни - з двома знаками після коми.
    Один return з одним f-рядком.

    :param item: назва товару
    :param price: ціна за штуку, грн
    :param quantity: кількість штук (0 або більше)
    :return: текст чека

    >>> receipt("Milk", 28.5, 2)
    'Milk    | 2 x 28.50\\nTotal: 57.00 UAH'
    >>> receipt("Tea", 45.0, 0)
    'Tea     | 0 x 45.00\\nTotal: 0.00 UAH'
    >>> receipt("Chocolate", 52.25, 3)
    'Chocolate| 3 x 52.25\\nTotal: 156.75 UAH'
    >>> print(receipt("Bread", 19.9, 1))
    Bread   | 1 x 19.90
    Total: 19.90 UAH
    """
    total = price * quantity
    # {item:<8} - ширина щонайменше 8, вирівнювання вліво. Ширина -
    # це МІНІМУМ: "Chocolate" має 9 літер, його не обрізає, тому
    # риска стоїть одразу після назви (див. третій doctest).
    # \n всередині рядка - це один символ «перейти на новий рядок».
    # doctest без print показує його як \n, а print - як перенос.
    return (f"{item:<8}| {quantity} x {price:.2f}\n"
            f"Total: {total:.2f} UAH")


if __name__ == "__main__":
    doctest.testmod(verbose=True)
```

</details>

## 7. Поясни чому

**1. Чому у лабах функція має повертати результат через `return`, а не друкувати його?**

<details markdown="1"><summary>Еталон</summary>

`print` показує текст людині, а функція при цьому повертає `None`: з результатом далі нічого не
зробиш (не додаси, не передаси в іншу функцію, не перевіриш). doctest порівнює саме повернене
значення. Крім того, ЛР1, с. 11-12 вимагає розділяти обчислення (функція) і ввід-вивід (поза
функцією): так функцію можна тестувати й використовувати з будь-яким джерелом даних.
</details>

**2. Чому `input()` + `input()` склеює числа, а не додає?**

<details markdown="1"><summary>Еталон</summary>

`input` завжди повертає **рядок** (`str`), навіть якщо набрали цифри. Що робить `+`, залежить від
типу: для чисел - додавання, для рядків - склеювання. `"12" + "18"` = `"1218"`. Тому одразу пишуть
`int(input(...))` або `float(input(...))`.
</details>

**3. Чому код, що порушує PEP 8, працює, а викладач однаково вимагає `flake8`?**

<details markdown="1"><summary>Еталон</summary>

PEP 8 - не синтаксис, а домовленість (Лекція 2, с. 7): інтерпретатору байдуже, чи є пробіли навколо
`=`. Але код читають у 10 разів частіше, ніж пишуть, і в команді всі мають писати однаково. Частина
правил ловить справжні проблеми: імʼя `sum` ламає вбудовану функцію, `flake8` бачить невикористані
змінні, `mypy` - рядок там, де чекали число. І ще: проходження `flake8` не означає правильний
алгоритм, а зелений doctest не означає гарний стиль (ЛР1, с. 9) - перевіряють обидва.
</details>

## 8. Що запамʼятати

- `input()` повертає рядок завжди; числа - `int(input())` / `float(input())`.
- `print(..., sep=" ", end="\n")`: `sep` між значеннями, `end` у кінці; `print` повертає `None`.
- `%`: кількість `%d`/`%s`/`%f` = кількість значень; `%%` - знак відсотка; `%d` відкидає дріб.
- f-рядок: `{x:.2f}` знаки після коми, `{n:02d}` нулі зліва, `{s:<10}` / `{s:>10}` / `{s:^10}`
  ширина і вирівнювання (ширина - мінімум). Форматування змінює показ, не число.
- `def імʼя(параметр: тип) -> тип:`, докстрінг, `return`. Без `return` - `None`. Змінні в функції
  локальні.
- **Друкує ≠ повертає.** У лабах функція повертає, друк - поза нею.
- Анотації типів Python не перевіряє, це робить `mypy`.
- PEP 8: 4 пробіли, ≤ 79 знаків, 2 порожні рядки між функціями, `snake_case`, `UPPER_SNAKE_CASE`,
  не `sum`/`list`/`str`. Перевірка: `flake8`, `pycodestyle`, `ruff`; виправлення: `black`.

**Де в лабах:**

- ЛР1, завд. 1: частку виводять з трьома знаками (`12.700`, `44.000`) - це `:.3f` (ЛР1, с. 4, с. 14).
- ЛР1, завд. 2: формат `HH:MM:SS` - `{hours:02d}:{minutes:02d}:{seconds:02d}` (ЛР1, с. 4, с. 16).
- ЛР1, завд. 1-3: функція повертає `str` одним `return`, частини через `\n` (ЛР1, с. 6); введення -
  `int(input(...))` поза функцією; структура програми - ЛР1, с. 11.
- ЛР1, с. 9-10 і ЛР2, с. 9-10: `pycodestyle`, `flake8`, `ruff`, `black`, `mypy`; у ЛР2 (завд. 1-3)
  прямо написано прогнати всі.
- ЛР2, завд. 2: виняток із правила! `age_chat(age: int) -> None` за doctest **друкує** (у прикладах
  нема лапок), а `year_word` - **повертає** рядок (ЛР2, с. 14, с. 17). Читай doctest першим.
- ЛР2, завд. 3: `body_moving(...) -> str` повертає рядок з числами, округленими до 2 знаків, - це
  `:.2f`.
