## 1. Ідея

**Рекурентне співвідношення** ти вже знаєш: новий член рахуємо з попереднього
(aₙ = 3·aₙ₋₁). **Система** рекурентних співвідношень - це коли на кожному кроці
ми рахуємо **кілька** величин одразу, і вони залежать одна від одної. Лекція каже:
«послідовності є векторними - на кожному кроці ми одночасно обчислюємо кілька
взаємопов'язаних величин» (Лекція 7, с. 1).

Аналогія. Ти ведеш облік на складі: щодня рахуєш, скільки товару (aₙ) і скільки грошей
у касі (Sₙ). Гроші завтра залежать від того, скільки товару продали сьогодні. Одна
величина «тягне» іншу. Рахувати їх треба разом, у тому самому циклі.

### 1.1. Сума ряду xⁿ/n! - перша система (Лекція 7, с. 1-2)

Треба Sₙ = 1 + x/1! + x²/2! + ... + xⁿ/n!. Можна щоразу рахувати xⁿ і n! заново - але
це купа зайвих множень, а для великих n ще й переповнення (саме про це ЛР5). Хитрість:
позначимо доданок aₙ = xⁿ/n!. Тоді наступний доданок - це попередній, помножений на x/n:

```
        xⁿ        xⁿ⁻¹       x
aₙ = ──────  =  ─────── · ───  = aₙ₋₁ · x / n
        n!       (n-1)!     n

a₀ = 1,  S₀ = 1
aₙ = aₙ₋₁ · x / n          (спершу новий доданок)
Sₙ = Sₙ₋₁ + aₙ             (потім додаємо його до суми)
```

Дві послідовності, aₙ і Sₙ, рахуємо в одному циклі. У лекції змінні звуться `a` і `S`
(як у математиці), а в лабах викладач хоче змістовні імена - тому в мене `term` (доданок)
і `total` (сума):

```python
x = 2
count = 4
term = 1       # a₀ = 1
total = 1      # S₀ = 1
for number in range(1, count + 1):
    term = x / number * term     # aₙ = aₙ₋₁ · x / n
    total = total + term         # Sₙ = Sₙ₋₁ + aₙ
    print(number, term, total)
```

```text
1 2.0 3.0
2 2.0 5.0
3 1.3333333333333333 6.333333333333333
4 0.6666666666666666 7.0
```

Трасувальна таблиця (те саме, але повільно, на папері):

| n | як рахуємо aₙ | aₙ | як рахуємо Sₙ | Sₙ |
|---|---|---|---|---|
| 0 | старт | 1 | старт | 1 |
| 1 | 1 · 2 / 1 | 2 | 1 + 2 | 3 |
| 2 | 2 · 2 / 2 | 2 | 3 + 2 | 5 |
| 3 | 2 · 2 / 3 | 1.333 | 5 + 1.333 | 6.333 |
| 4 | 1.333 · 2 / 4 | 0.667 | 6.333 + 0.667 | 7.0 |

Порядок рядків у тілі важливий: спершу новий доданок, **потім** сума. Якщо переставити,
до суми додасться старий доданок.

### 1.2. Одне значення кільком змінним: `S = x = 1` (Лекція 7, с. 2)

Сума Sₙ = Σ aᵏ·bⁿ⁻ᵏ (k від 0 до n). Розкривши суму, лекція отримує систему:
xₙ = a·xₙ₋₁ (це aⁿ), Sₙ = b·Sₙ₋₁ + xₙ, обидві з початком 1. Код лекції починається з
`S = x = 1` - це **одночасне присвоєння одного значення кільком змінним**. Обидві
змінні отримують 1. Перевіримо на a = 2, b = 3, N = 2 (вручну: 3² + 2·3 + 2² = 9 + 6 + 4 = 19):

```python
base_a = 2
base_b = 3
total = power = 1
for number in range(1, 3):
    power = base_a * power           # xₙ = a · xₙ₋₁
    total = base_b * total + power   # Sₙ = b · Sₙ₋₁ + xₙ
    print(number, power, total)
```

```text
1 2 5
2 4 19
```

### 1.3. Третій порядок і «зсув» змінних (Лекція 7, с. 2-3)

Послідовність a₁ = a₂ = a₃ = 1, aₖ = aₖ₋₁ + aₖ₋₃ (k ≥ 4) - третього порядку: новий член
залежить від трьох попередніх. Тримаємо три змінні: `a1` (останній), `a2` (передостанній),
`a3` (ще раніший). Після обчислення нового `a` всі «зсуваються на одну позицію»:

```
до кроку:    a3   a2   a1         нове a = a1 + a3
               \    \    \
після:        a3 = a2,  a2 = a1,  a1 = a
```

Порядок зсуву - **від найстарішого**: спершу `a3 = a2`, потім `a2 = a1`, потім `a1 = a`.
Якщо почати з `a1 = a`, старе значення `a1` пропаде раніше, ніж ми перекладемо його в `a2`.

Ще одна думка з того прикладу: перші три члени особливі (вони задані, а не пораховані),
тому лекція пише **два цикли підряд**: перший обробляє «межові» (початкові) випадки,
другий - загальний рекурентний випадок. Межа першого - `range(1, min(4, N + 1))`, щоб
не зайти далі, ніж просили, коли N < 3.

Найскладніший приклад лекції (с. 4-5) - добуток Pₙ = Π aₖ/3ᵏ, де aₖ теж третього порядку.
Там аж три допоміжні послідовності: `a` (третього порядку), `z` = 3ᵏ (z = z · 3) і
`t` = 2ᵏ⁻¹ (t = t · 2). Ідея та сама: кожну з них рахуємо в тому самому циклі її власною
маленькою формулою. Лекція називає це «декомпозицією задачі на систему простіших
рекурентних співвідношень».

### 1.4. Перехресні співвідношення - головна пастка (Лекція 7, с. 3-4)

a₀ = b₀ = 1; aₖ = aₖ₋₁ · bₖ₋₁; bₖ = aₖ₋₁ + bₖ₋₁. Нове a залежить від **старого** b, нове b - від
**старого** a. Якщо написати `a = a * b`, а потім `b = a + b`, то в другому рядку `a` - вже
нове. Лекція наголошує: потрібні допоміжні змінні `a_k`, `b_k`, і це «загальний принцип
для будь-яких перехресних співвідношень». Розберемо це на прикладі в розділі 2.

### 1.5. Знайти перший член, що задовольняє умову: `while` (Лекція 7, с. 5-7)

Досі цикл `for` рахував член за номером. Але буває інше питання: «знайди **перший** член,
для якого виконується умова». Скільки кроків - невідомо, тому `for` замінюємо на `while`.

Правило лекції: **умова `while` - це заперечення умови зупинки.** Треба найменше 3ᵏ ≥ N.
Зупинитись треба, коли aₖ ≥ N. Заперечення: aₖ < N. Отже, `while power < limit:`.

```python
limit = 100
power = 1
while power < limit:      # поки ще НЕ досягли умови 3ᵏ >= 100
    power = power * 3
print(power)
```

```text
243
```

Перевірка: 1, 3, 9, 27, 81 - усі менші за 100, цикл крутиться далі; 243 ≥ 100 - стоп.

Варіант «найбільший член, що **не перевищує** a» (с. 6-7): xₙ = xₙ₋₁ + 2xₙ₋₂ + xₙ₋₃,
члени 1, 0, 1, 2, 4, 9, 19, 41, 88. Цикл іде, поки член ≤ a, і зупиняється на **першому, що
вже більший**. Тому відповідь - **попередній** член, а не поточний. Ось код лекції без змін
(запустимо з a = 30, як у лекції):

```python
# ввід: 30
a = int(input("a = "))
x3 = 1
x2 = 0
x1 = 1
n = 2    # Номер поточного члену послідовності
while x1 <= a:    # Поки поточний член послідовності
    n += 1
    x = x1 + 2 * x2 + x3
    x3 = x2
    x2 = x1
    x1 = x
print("x(%d) = %d <= %d = a" % (n - 1, x2, a))
```

```text
a = 30
x(6) = 19 <= 30 = a
```

Після виходу з циклу `x1 = 41` (перший, що більший за 30), а `x2 = 19` - той, що перед ним.
Лекція: «доводиться зберігати не лише поточний, а й попередній стан». (Тут імена `a`, `x1`
лишились лекційні; у лабі краще `limit`, `current`, `previous`.)

### 1.6. Границя з точністю ε (Лекція 7, с. 7-9)

Послідовність yₙ прямує до границі y. Комп'ютер не дійде до нескінченності, тому лекція
домовляється: «наближене з точністю ε значення» - це перший член y_N, для якого
|y_N - y_N-1| < ε. Отже, рахуємо, **поки** |yₙ - yₙ₋₁| ≥ ε (знову заперечення умови
зупинки). Потрібні дві змінні: `current` (поточний член) і `previous` (попередній).

Золотий переріз Φ ≈ 1.618: Φₙ = 1 + 1/Φₙ₋₁, Φ₁ = 1. Код лекції (с. 8):

```python
eps = 0.0000000001    # точність
prev = 0        # попередній член послідовності
current = 1     # поточний член послідовності
while abs(current - prev) >= eps:
    prev = current
    current = 1 + 1 / current
print("Ф =", current)    # Виводимо значення золотого перетину
# Перевірка результату згідно з властивостями
print("Ф - 1 =", current - 1)
print("1 / Ф =", 1 / current)
```

```text
Ф = 1.618033988738303
Ф - 1 = 0.6180339887383031
1 / Ф = 0.6180339887543225
```

Вивід збігся з лекцією до останньої цифри. Перевірка Φ - 1 = 1/Φ виконується до 10 знаків
після коми - саме з такою точністю ε ми рахували.

Для eˣ (с. 9) Sₙ - Sₙ₋₁ = aₙ, тому умова «поки |aₙ| ≥ ε». Тут лекція звертає увагу: у `while`
**нема вбудованого лічильника**, як у `for`. А номер n потрібен у формулі aₙ = aₙ₋₁·x/n.
Тому лічильник заводимо самі: `n = 0` до циклу і `n += 1` першим рядком тіла.

### 1.7. Бісекція і хорди (Лекція 7, с. 10-11)

Рівняння f(x) = 0, на кінцях відрізка [a, b] f має різні знаки (тоді корінь усередині -
теорема Больцано-Коші). **Бісекція**: ділимо відрізок навпіл, лишаємо ту половину, де знаки на
кінцях різні; повторюємо, поки довжина ≥ ε. Відповідь - середина останнього відрізка.
Перевага - збігається завжди; недолік - повільно (кожен крок лише вдвічі зменшує відрізок).

Код лекції для tan x = 2x на [0.5, 1.5] (с. 11), лише `l`, `r` перейменовано на `left`,
`right` (буква `l` схожа на одиницю, PEP 8 її не радить):

```python
import math
eps = 0.0000000000001
left = 0.5    # tan(left) - 2 * left < 0
right = 1.5   # tan(right) - 2 * right > 0
while right - left >= eps:
    middle = (left + right) / 2.0
    value = math.tan(middle) - 2.0 * middle
    if value == 0.0:
        break             # влучили точно в корінь - далі нема куди
    elif value < 0.0:
        left = middle     # [left, right] = [middle, right]
    else:
        right = middle    # [left, right] = [left, middle]
root = (left + right) / 2.0
print(root)
```

```text
1.165561185207224
```

**Метод хорд** - через дві точки графіка проводимо пряму (хорду) і беремо точку її
перетину з віссю x як наступне наближення. Кінець b нерухомий, і виходить знову
рекурентне співвідношення:

```
u₀ = a
                          b - uₙ₋₁
uₙ = uₙ₋₁ - f(uₙ₋₁) · ─────────────────
                      f(b) - f(uₙ₋₁)
рахуємо, поки |uₙ - uₙ₋₁| ≥ ε
```

У лекції коду для хорд нема, лише формула. Ось приклад на x² - 2 = 0, [1, 2] (мій код,
ЛР6 завд. 3 просить те саме, але для полінома і з історією наближень):

```python
def func(x):
    return x * x - 2

right_end = 2.0       # нерухомий кінець b
previous = 1.0        # u₀ = a
current = previous - func(previous) * (right_end - previous) / (
    func(right_end) - func(previous))
steps = 1
while abs(current - previous) >= 1e-9:
    previous = current
    current = previous - func(previous) * (right_end - previous) / (
        func(right_end) - func(previous))
    steps += 1
print(round(current, 9), steps)
```

```text
1.414213562 13
```

Бісекції для такої точності треба було б близько 30 кроків, хордам вистачило 13: вони
враховують не лише знак f, а й саме значення.

## 2. Розібраний приклад

**Задача.** Дві кімнати: гаряча (hot) і холодна (cold). Кожну годину гаряча віддає холодній
чверть різниці температур: hotₖ = hotₖ₋₁ - (hotₖ₋₁ - coldₖ₋₁)/4, coldₖ = coldₖ₋₁ + (hotₖ₋₁ - coldₖ₋₁)/4.
Ввести дві температури, друкувати стан після кожного кроку, і знайти, після якого кроку
різниця стане меншою за 1 градус. Для перевірки друкуємо ще й hot + cold: тепло нікуди
не зникає, тож сума мусить бути сталою.

Це **перехресна** система (як у лекції, с. 3-4): обидві нові температури рахуються зі
**старих** обох. І це пошук **першого** кроку з умовою, тому `while`.

```python
# ввід: 80 | 20
hot = float(input("Гаряча кімната, °C: "))
cold = float(input("Холодна кімната, °C: "))
step = 0
while hot - cold >= 1:
    step += 1
    new_hot = hot - (hot - cold) / 4
    new_cold = cold + (hot - cold) / 4
    hot = new_hot
    cold = new_cold
    print(step, hot, cold, hot + cold)
print("Різниця менша за 1 градус після кроку", step)
```

```text
Гаряча кімната, °C: 80
Холодна кімната, °C: 20
1 65.0 35.0 100.0
2 57.5 42.5 100.0
3 53.75 46.25 100.0
4 51.875 48.125 100.0
5 50.9375 49.0625 100.0
6 50.46875 49.53125 100.0
Різниця менша за 1 градус після кроку 6
```

| рядок | що робить |
|---|---|
| `hot = float(input(...))` | читає рядок з клавіатури і робить з нього дійсне число (`input` завжди дає рядок) |
| `step = 0` | лічильник кроків: у `while` свого лічильника нема (лекція, с. 9) |
| `while hot - cold >= 1:` | умова = заперечення умови зупинки. Зупинка: «різниця < 1», тому крутимось, поки різниця ≥ 1 |
| `step += 1` | номер кроку, який зараз рахуємо |
| `new_hot = ...` | нова гаряча **зі старих** hot і cold |
| `new_cold = ...` | нова холодна - теж **зі старих**: `hot` ще не змінений, бо нове лежить у `new_hot` |
| `hot = new_hot`, `cold = new_cold` | лише тепер, коли обидва нові пораховані, записуємо їх |
| `print(step, hot, cold, hot + cold)` | стан після кроку; сума 100.0 - перевірка, що формула правильна |
| останній `print` | після циклу `step` - номер першого кроку, де умова зупинки виконалась |

Трасувальна таблиця:

| step | hot до | cold до | (hot - cold) / 4 | new_hot | new_cold | hot - cold після | цикл далі? |
|---|---|---|---|---|---|---|---|
| 1 | 80 | 20 | 15 | 65 | 35 | 30 | так |
| 2 | 65 | 35 | 7.5 | 57.5 | 42.5 | 15 | так |
| 3 | 57.5 | 42.5 | 3.75 | 53.75 | 46.25 | 7.5 | так |
| 4 | 53.75 | 46.25 | 1.875 | 51.875 | 48.125 | 3.75 | так |
| 5 | 51.875 | 48.125 | 0.9375 | 50.9375 | 49.0625 | 1.875 | так |
| 6 | 50.9375 | 49.0625 | 0.46875 | 50.46875 | 49.53125 | 0.9375 | ні, 0.9375 < 1 |

А що було б без `new_hot`? Крок 1: `hot = 80 - 60/4 = 65`, а далі `cold = 20 + (65 - 20)/4 = 31.25`.
Сума 65 + 31.25 = 96.25 - «зникло» 3.75 градуса тепла. Фізика підказує, що код неправильний.
Ще один спосіб без двох нових змінних: спершу порахувати потік `flow = (hot - cold) / 4`
(зі старих значень!), а потім `hot = hot - flow`, `cold = cold + flow`. Це теж правильно.

**Закрий приклад і напиши його сам з пам'яті.** Перевір на 80 і 20: має вийти 6 кроків і
сума 100.0 у кожному рядку.

**Фрагмент 3** (перехресна система з лекції, с. 3, але записана без допоміжних змінних)

```python
a = 1
b = 1
for step in range(3):
    a = a * b
```

## 4. Знайди помилку

**Помилка 1.** Функція має повернути температури після `steps` кроків обміну.

```python
# БАГ
def exchange(hot: float, cold: float, steps: int) -> str:
    """Температури двох кімнат після steps кроків обміну теплом.

    >>> exchange(80.0, 20.0, 1)
    '65.0 35.0'
    >>> exchange(80.0, 20.0, 2)
    '57.5 42.5'
    """
    for _ in range(steps):
        hot = hot - (hot - cold) / 4
        cold = cold + (hot - cold) / 4
    return f"{hot} {cold}"
```

<details markdown="1"><summary>Що не так</summary>

Перехресна система без допоміжних змінних. У другому рядку тіла `hot` уже **новий** (65),
тому `cold = 20 + (65 - 20)/4 = 31.25`, а не 35. doctest отримує `'65.0 31.25'`.
Чому так: Python виконує рядки по черзі, і після першого присвоєння старого `hot` вже ніде
нема. Лікування - як у лекції (с. 4): спершу порахувати обидва нові значення, потім записати.

```python
# ВИПРАВЛЕНО
def exchange(hot: float, cold: float, steps: int) -> str:
    """Температури двох кімнат після steps кроків обміну теплом.

    >>> exchange(80.0, 20.0, 1)
    '65.0 35.0'
    >>> exchange(80.0, 20.0, 2)
    '57.5 42.5'
    """
    for _ in range(steps):
        new_hot = hot - (hot - cold) / 4
        new_cold = cold + (hot - cold) / 4
        hot = new_hot
        cold = new_cold
    return f"{hot} {cold}"
```

</details>

**Помилка 2.** Знайти найменший степінь двійки, **більший** за `limit`.

```python
# БАГ
```

<details markdown="1"><summary>Що не так</summary>

</details>

**Помилка 3.** eˣ через ряд Тейлора з точністю eps (як у лекції, с. 9).

```python
# БАГ
def exp_series(x: float, eps: float) -> float:
    """e у степені x через ряд Тейлора з точністю eps.

    >>> round(exp_series(1.0, 1e-10), 6)
    2.718282
    """
    term = 1
    total = 1
    number = 0
    while abs(term) >= eps:
        term = x / number * term
        total = total + term
        number += 1
    return total
```

<details markdown="1"><summary>Що не так</summary>

Лічильник `number` збільшують **після** формули. На першому кроці `number = 0`, і
`x / number` дає `ZeroDivisionError: division by zero`. У лекції `n += 1` стоїть **першим**
рядком тіла: спершу «перейшли до наступного номера», потім рахуємо член з цим номером.

```python
# ВИПРАВЛЕНО
def exp_series(x: float, eps: float) -> float:
    """e у степені x через ряд Тейлора з точністю eps.

    >>> round(exp_series(1.0, 1e-10), 6)
    2.718282
    """
    term = 1
    total = 1
    number = 0
    while abs(term) >= eps:
        number += 1
        term = x / number * term
        total = total + term
    return total
```

## 7. Поясни чому

**Питання 1.** Чому в перехресній системі (aₖ залежить від bₖ₋₁, bₖ від aₖ₋₁) не можна
просто написати `a = a * b`, а потім `b = a + b`?

<details markdown="1"><summary>Еталон</summary>

Бо Python виконує рядки по черзі, а присвоєння **затирає** старе значення. Після `a = a * b`
у змінній `a` лежить вже aₖ, а формула для bₖ хоче aₖ₋₁. Старого значення більше ніде нема.
Тому спершу треба порахувати **всі** нові значення в допоміжні змінні (`a_k`, `b_k`) зі
старих, і лише потім присвоїти. В уроці 09 буде коротший запис `a, b = a * b, a + b` - там
права частина рахується повністю до присвоєння.

</details>

**Питання 2.** Чому умова в `while` - це **заперечення** умови зупинки, а не сама умова?

<details markdown="1"><summary>Еталон</summary>

Бо `while` означає «**поки** умова істинна - роби ще крок». Ми ж формулюємо задачу як
«рахуй, **доки не** стане aₖ ≥ N». «Доки не стане A» = «поки не-A». Заперечення
aₖ ≥ N - це aₖ < N; заперечення |yₙ - yₙ₋₁| < ε - це |yₙ - yₙ₋₁| ≥ ε. Якщо в `while`
написати саму умову зупинки, цикл або не почнеться, або зупиниться не там.

</details>

**Питання 3.** У прикладі «найбільший член, що не перевищує a» програма друкує `x2`, а
не `x1`. Чому?

<details markdown="1"><summary>Еталон</summary>

Цикл `while x1 <= a` зупиняється лише тоді, коли `x1` **вже** більший за `a` (41 > 30).
Тобто після циклу в `x1` - перший «поганий» член. Шуканий - той, що перед ним, а він
якраз лежить у `x2` після зсуву. Ми не можемо «знати наперед», що наступний член
перевищить межу, - дізнаємось, лише коли порахуємо його. Тому й тримаємо попередній.

</details>

**Питання 4.** Чому член ряду aₙ = xⁿ/n! рахують як `term = x / number * term`, а не
`x ** n / factorial(n)`?

<details markdown="1"><summary>Еталон</summary>

Дві причини. Швидкість: з попереднього члена - одне множення і одне ділення, а
заново - n множень для xⁿ і ще n для n!. Діапазон: xⁿ і n! окремо дуже швидко стають
величезними (171! вже більше за найбільший float, ЛР5, с. 2), хоча їхнє відношення
помірне. Множник x/n тримає член «нормального» розміру на кожному кроці. Саме це ЛР5
завд. 1 просить порівняти з «наївною» реалізацією.

</details>

## 8. Що запам'ятати

- Система рекурентних = кілька величин, які рахуються **разом в одному циклі**, кожна своєю
  маленькою формулою (доданок, сума, степінь...).
- Член ряду рахуй з попереднього: aₙ = aₙ₋₁ · (множник). Спершу новий член, потім сума.
- Перехресні співвідношення: спершу всі нові значення з **старих** (допоміжні змінні), потім
  присвоєння. Інакше другий рядок бере вже нове.
- Третій порядок - три змінні і зсув **від найстарішої**: `a3 = a2`, `a2 = a1`, `a1 = new`.
- «Знайти перший член з умовою» - `while`, і в ньому **заперечення** умови зупинки.
- «Останній, що ще задовольняє умову» - зберігай попередній член.
- Точність ε: рахуй, поки |поточний - попередній| ≥ ε. У `while` лічильник - сам (`n += 1`).
- Бісекція: середина, лишаємо половину з різними знаками, поки довжина ≥ ε.
  Хорди: uₙ = uₙ₋₁ - f(uₙ₋₁)·(b - uₙ₋₁)/(f(b) - f(uₙ₋₁)).

**Де в лабах:**
- ЛР5 завд. 1 (пункти a-c) - член ряду і суму/добуток з попереднього, без степенів і
  факторіалів; пункт d) - дві звʼязані послідовності aₖ, bₖ (перехресна система).
- ЛР5 завд. 2 - ряд для sin з точністю ε (`while`, член з попереднього); завд. 3 - π з
  точністю (Грегорі, Валліс).
- ЛР6 завд. 2 - визначник Dₙ рекурентно (другий порядок: Dₙ з Dₙ₋₁ і Dₙ₋₂) і перший n,
  де |Dₙ| < a або |Dₙ| > a (`while` з запереченням); завд. 3 - бісекція і хорди.
