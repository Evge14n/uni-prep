## Задачі в терміналі (Linux)

```bash
mkdir -p ~/prog/zadachi && cd ~/prog         # заготовки скачати з сайту (посилання в кожному уроці)
python3 -m doctest zadachi/urok04.py -v     # спершу все червоне
python3 -m flake8 zadachi/urok04.py         # стиль, як вимагає викладач
```

> **Нове тут:**
>
> - `mkdir` - створює нову теку. Назва: make directory - «зробити теку». `-p` - створює і всі проміжні теки шляху; якщо тека вже є - мовчить, без помилки.
> - `cd` - переходить в іншу теку. Назва: change directory - «змінити теку».
> - `python3` - запускає Python: файл, рядок коду або модуль. Назва: Python - на честь комедійного шоу «Monty Python», 3 - третя версія мови. `-m` - запусти модуль як програму: python3 -m pytest, python3 -m venv, python3 -m pdb.
> - `python3 -m doctest` - перевіряє приклади >>> з опису функцій. Назва: doc test - «тест у документації»: приклади >>> в описі функції. `-v` - докладно: кожен приклад (Trying, Expecting, ok) і підсумок «N passed and M failed».
> - `python3 -m flake8` - шукає помилки стилю і зайвий код, нічого не змінює. Назва: pyflakes + pep8: обʼєднав дві старі програми перевірки коду.
> - `&&` - друга команда - лише якщо перша вдалась. Назва: «і»: друга команда - лише якщо перша вдалась.
> - `~` - домашня тека /home/evgen. Назва: tilde («тильда») - домашня тека.
> - `#` - коментар: далі до кінця рядка bash не читає. Назва: hash («решітка») - коментар.
>
> Усе про кожну команду - у довіднику «05_Програмування/КОМАНДИ - довідник.md» (на сайті - вкладка «Команди»).

Розвʼязок (на сайті під спойлером у розділі 6 уроку, на ПК - `_rozvyazky/`) - лише після двох своїх спроб. Підглянув - через день розвʼяжи ще раз сам.

## Як читати чужий (і свій) код - трасувальна таблиця

Не «дивлюсь і ніби зрозуміло», а таблиця на папері: рядок за рядком, що лежить у кожній змінній.

```
total = 0
for number in range(1, 4):
    total += number * number
```

| крок | number | total після рядка |
|---|---|---|
| до циклу | - | 0 |
| 1 | 1 | 1 |
| 2 | 2 | 5 |
| 3 | 3 | 14 |

Якщо в таблиці і в Python вийшло різне - ти знайшов місце, якого не розумієш. Саме його і питай.

## Як питати викладача (або мене)

Не «не працює», а 4 речі: що хотів (який doctest), що написав (код), що отримав (точний текст помилки або
doctest, скопійований), що вже пробував. Викладач перевіряє розуміння і може попросити пояснити будь-який
рядок - тому кожен рядок своєї лаби вмій пояснити словами (розділ 7 уроків тренує саме це).
