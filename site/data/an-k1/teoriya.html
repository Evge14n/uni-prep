Колоквіум 1: теорія коротко

Що точно відомо (силабус, с. 4): колоквіум - «тест по лекціях», 10 балів, бали пропорційно до кількості правильних відповідей. Окремо лектор дала список питань «до колоквіуму і контрольної»: «Закінчити речення» (1 бал), «Сформулювати означення» (2 бали), «Довести» і «Зразок практичних завдань».

Припущення (не оголошено): що тест складуть саме з цього списку, і його обсяг. Беремо теми 1-8 (вже були на лекціях; З1-57, О1-83 зі списку питань), тема 9 (криві другого порядку, З58-68, О84-97) - якщо встигнуть на лекціях. Дата, кількість питань і час невідомі - спитай у групі.

Позначення - як у методичці лектора і в лекціях. Вектори пишу звичайними буквами (a, b, AB), у зошиті став стрілку зверху. Координати - через крапку з комою: A(2; -1; 3).

Тема 1. Матриці, обернена матриця, ранг

Матриця розміру m×n - прямокутна таблиця з чисел: m рядків, n стовпців. Елемент a_ij стоїть в i-му рядку і j-му стовпці.

Види матриць (саме їх питають у «Закінчити речення» З1-З11):

квадратна       рядків = стовпців (m = n)
діагональна     квадратна,
                a_ij = 0 при i ≠ j
одинична E      діагональна, a_ii = 1
нульова         усі елементи 0
транспонована   Aᵀ: рядки замінили
                стовпцями
симетрична      a_ij = a_ji
антисиметрична  a_ij = -a_ji, на діагоналі 0
(інша назва: кососиметрична)
верхня трикутна a_ij = 0 при i > j
                (нулі ПІД діагоналлю)
нижня трикутна  a_ij = 0 при i < j
                (нулі НАД діагоналлю)

Дії з матрицями.

A + B   додаємо відповідні елементи
        (розміри однакові)
λ·A     кожен елемент множимо на λ
A·B     «рядок на стовпець»:
        c_ij = a_i1·b_1j + ... + a_in·b_nj
        можна, якщо стовпців у A
        стільки ж, скільки рядків у B
A·B ≠ B·A  (у загальному випадку)

Елементарні перетворення матриці: 1) переставити два рядки (стовпці); 2) помножити рядок на число ≠ 0; 3) додати до рядка інший рядок, помножений на число. Матриці, які отримані одна з одної такими перетвореннями, - еквівалентні.

Східчаста матриця: кожен наступний рядок починається з більшої кількості нулів, ніж попередній; нульові рядки - внизу.

Обернена матриця A⁻¹: A·A⁻¹ = A⁻¹·A = E. Існує тільки для невиродженої матриці (det A ≠ 0). Вироджена - det A = 0, оберненої не має.

         1    ⎛A₁₁ A₂₁ A₃₁⎞
A⁻¹ = ───── · ⎜A₁₂ A₂₂ A₃₂⎟
      det A   ⎝A₁₃ A₂₃ A₃₃⎠

A_ij - алгебраїчні доповнення, і їх ставлять транспоновано (доповнення рядка 1 йдуть у стовпець 1). Для 2×2 коротко:

    ⎛a  b⎞           1   ⎛ d  -b⎞
A = ⎝c  d⎠   A⁻¹ = ───── ⎝-c   a⎠
                   ad-bc

Матричні рівняння: A·X = B ⇒ X = A⁻¹·B; X·A = B ⇒ X = B·A⁻¹; A·X·C = B ⇒ X = A⁻¹·B·C⁻¹. Порядок множення важливий: A⁻¹ ставимо з того боку, де стояла A.

Ранг - найвищий порядок ненульового мінора. На практиці: зводимо до східчастого вигляду, ранг = кількість ненульових рядків. Елементарні перетворення ранг не змінюють.

Тема 2. Визначники

│a₁₁ a₁₂│
│a₂₁ a₂₂│ = a₁₁·a₂₂ - a₁₂·a₂₁

3-го порядку - правило трикутників (схема Саррюса - інший малюнок, та сама формула):

Δ = a₁₁a₂₂a₃₃ + a₁₂a₂₃a₃₁ + a₁₃a₂₁a₃₂
  - a₁₃a₂₂a₃₁ - a₁₁a₂₃a₃₂ - a₁₂a₂₁a₃₃

Мінор M_ij елемента a_ij - визначник, що лишився після викреслення i-го рядка і j-го стовпця. Алгебраїчне доповнення A_ij = (-1)^(i+j)·M_ij. Знаки (-1)^(i+j) йдуть шаховою дошкою:

+ - +
- + -
+ - +

Розклад за рядком: Δ = a_i1·A_i1 + a_i2·A_i2 + ... + a_in·A_in. Розкладай за рядком або стовпцем, де найбільше нулів.

Мінор k-го порядку - визначник з елементів на перетині будь-яких k рядків і k стовпців.

Головні властивості (повний список з 13 - на іспит, Д1): - транспонування не змінює визначник; - переставили два рядки - знак змінився; - два однакові або пропорційні рядки, або нульовий рядок ⇒ Δ = 0; - спільний множник рядка можна винести за знак визначника; - додали до рядка інший рядок, помножений на число, - Δ не змінився (цим роблять нулі); - визначник трикутної матриці = добуток елементів діагоналі; - det(A·B) = det A · det B.

Тема 3. Системи лінійних рівнянь

квадратна     рівнянь = невідомих
однорідна     усі вільні члени = 0
сумісна       є хоча б один розв'язок
несумісна     немає жодного розв'язку
визначена     рівно один розв'язок
невизначена   безліч розв'язків
рівносильні   множини розв'язків
(еквівалентні) збігаються

Розв'язок - набір чисел, який перетворює кожне рівняння на правильну рівність (тотожність).

Кронекер-Капеллі: система сумісна ⇔ rang A = rang (A│b) (ранг основної = рангу розширеної). Якщо ранг = кількості невідомих - розв'язок один; якщо менший - безліч, вільних невідомих n - rang.

Крамер (квадратна система, Δ ≠ 0): xᵢ = Δᵢ / Δ, де Δᵢ - у Δ замінили i-й стовпець стовпцем вільних членів. Якщо Δ = 0, Крамер не працює - тоді Гаус і ранги.

Гаус: розширену матрицю зводимо елементарними перетвореннями рядків до східчастого вигляду, потім знаходимо невідомі знизу вгору. Однорідна система завжди сумісна (є нульовий розв'язок).

Тема 4. Вектори

Вектор - напрямлений відрізок. Координати = кінець мінус початок:

A(x₁; y₁; z₁), B(x₂; y₂; z₂)
AB = (x₂-x₁; y₂-y₁; z₂-z₁)
|a| = √(aₓ² + a_y² + a_z²)

нуль-вектор   початок = кінець
одиничний     довжина 1 (орт: a⁰ = a/|a|)
колінеарні    на одній або паралельних
              прямих; координати
              пропорційні
рівні         колінеарні, однаково
              напрямлені, однакова
              довжина
компланарні   в одній або паралельних
              площинах

Сума a + b - правило трикутника: початок b ставимо в кінець a, сума йде з початку a в кінець b. Різниця a - b - вектор, який треба додати до b, щоб дістати a. λ·a - довжина |λ|·|a|, напрям той самий при λ > 0 і протилежний при λ < 0. Лінійна комбінація - λ₁a₁ + λ₂a₂ + ... + λₙaₙ.

Декартова система координат - точка O (початок) + база. Прямокутна - вектори бази одиничні й взаємно перпендикулярні (i, j, k).

Проекція на вісь: пр_l a = |a|·cos φ (зі знаком «+», якщо напрям проекції збігається з віссю). Напрямні косинуси: cos α = aₓ/|a|, cos β = a_y/|a|, cos γ = a_z/|a|, cos²α + cos²β + cos²γ = 1.

Тема 5. Скалярний, векторний, мішаний добутки

СКАЛЯРНИЙ - це ЧИСЛО
(a, b) = |a|·|b|·cos φ
       = aₓbₓ + a_y b_y + a_z b_z
cos φ = (a, b) / (|a|·|b|)
(a, b) = 0  ⇔  a ⟂ b
(a, a) = |a|²

ВЕКТОРНИЙ - це ВЕКТОР  [a, b] = a × b
|[a, b]| = |a|·|b|·sin φ
⟂ до a і до b, трійка a, b, [a,b] права
         │ i   j   k  │
[a, b] = │ aₓ  a_y a_z│
         │ bₓ  b_y b_z│
= i·(a_y b_z - a_z b_y)
- j·(aₓb_z - a_z bₓ)
+ k·(aₓb_y - a_y bₓ)
[a, b] = 0 ⇔ a ∥ b
S паралелограма = |[a, b]|
S трикутника = ½·|[a, b]|

МІШАНИЙ - це ЧИСЛО
(a, b, c) = ([a, b], c)
            │aₓ a_y a_z│
          = │bₓ b_y b_z│
            │cₓ c_y c_z│
V паралелепіпеда = |(a, b, c)|
V піраміди = ⅙·|(a, b, c)|
(a, b, c) = 0 ⇔ компланарні

Тема 6. Пряма на площині

s = (l; m) - напрямний вектор (вздовж прямої), n = (A; B) - нормальний (перпендикулярний). Нормаль прямої - перпендикуляр, опущений з початку координат на пряму (його довжина p).

загальне       Ax + By + C = 0
               n = (A; B), s = (-B; A)
канонічне      (x-x₀)/l = (y-y₀)/m
параметричне   x = x₀ + l·t
               y = y₀ + m·t
через 2 точки  (x-x₁)/(x₂-x₁)
                 = (y-y₁)/(y₂-y₁)
через точку ⟂ n:
       A(x-x₀) + B(y-y₀) = 0
з кутовим коеф.  y = kx + b, k = tg α
у відрізках    x/a + y/b = 1
нормальне      x·cos α + y·sin α - p = 0

Загальне → нормальне: ділимо на ±√(A² + B²), знак протилежний до знака C.

відстань від M₀(x₀; y₀):
     │A·x₀ + B·y₀ + C│
d = ─────────────────
       √(A² + B²)

Кут між прямими - кут між нормалями (або напрямними), для k: tg φ = (k₂ - k₁)/(1 + k₁k₂). Паралельні: A₁/A₂ = B₁/B₂, l₁/l₂ = m₁/m₂, k₁ = k₂. Перпендикулярні: A₁A₂ + B₁B₂ = 0, l₁l₂ + m₁m₂ = 0, k₁·k₂ = -1.

Тема 7. Площина

загальне    Ax + By + Cz + D = 0
            n = (A; B; C) - нормальний
через M₀ ⟂ n:
  A(x-x₀) + B(y-y₀) + C(z-z₀) = 0
через 3 точки:
  │x-x₁   y-y₁   z-z₁ │
  │x₂-x₁  y₂-y₁  z₂-z₁│ = 0
  │x₃-x₁  y₃-y₁  z₃-z₁│
у відрізках  x/a + y/b + z/c = 1

Окремі випадки (З48-З57): нема змінної - паралельна до цієї осі; нема змінної і нема D - проходить через цю вісь; D = 0 - через початок координат.

D = 0          через O
A = 0          ∥ Ox
B = 0          ∥ Oy
C = 0          ∥ Oz
A = B = 0      ∥ xOy   (Cz + D = 0)
A = C = 0      ∥ xOz   (By + D = 0)
B = C = 0      ∥ yOz   (Ax + D = 0)
A = D = 0      через Ox
B = D = 0      через Oy
C = D = 0      через Oz

Кут між площинами - кут між нормалями: cos φ = (n₁, n₂)/(|n₁|·|n₂|). Паралельні: A₁/A₂ = B₁/B₂ = C₁/C₂. Перпендикулярні: A₁A₂ + B₁B₂ + C₁C₂ = 0.

відстань від M₀(x₀; y₀; z₀):
     │Ax₀ + By₀ + Cz₀ + D│
d = ─────────────────────
       √(A² + B² + C²)

Тема 8. Пряма в просторі, пряма і площина

Напрямний вектор у методичці - a = (a₁; a₂; a₃).

канонічне   (x-x₀)/a₁ = (y-y₀)/a₂
                      = (z-z₀)/a₃
параметр.   x = x₀ + a₁t, y = y₀ + a₂t,
            z = z₀ + a₃t
через 2 точки:
  (x-x₁)/(x₂-x₁) = (y-y₁)/(y₂-y₁)
                 = (z-z₁)/(z₂-z₁)
загальне    система двох площин
  A₁x + B₁y + C₁z + D₁ = 0
  A₂x + B₂y + C₂z + D₂ = 0
  напрямний a = [n₁, n₂]

Нуль у знаменнику канонічного рівняння означає, що й чисельник 0 (напр. z = z₀ для всіх точок).

Кут між прямими - через напрямні (cos). Кут між прямою і площиною - через синус:

         │A·a₁ + B·a₂ + C·a₃│
sin φ = ─────────────────────
         |n| · |a|
пряма ∥ площині:  A·a₁ + B·a₂ + C·a₃ = 0
пряма ⟂ площині:  A/a₁ = B/a₂ = C/a₃

Тема 9. Криві другого порядку (можливо, якщо встигнуть на лекціях)

Криві другого порядку - лінії, рівняння яких у прямокутній декартовій системі є рівнянням другого степеня відносно x і y.

КОЛО      однакова відстань R від центра
          (x-x₀)² + (y-y₀)² = R²
ЕЛІПС     r₁ + r₂ = 2a
          x²/a² + y²/b² = 1, b² = a² - c²
          ε = c/a < 1, директриси x = ±a/ε
ГІПЕРБОЛА │r₁ - r₂│ = 2a
          x²/a² - y²/b² = 1, b² = c² - a²
          ε = c/a > 1, асимптоти y = ±(b/a)x
ПАРАБОЛА  відстань до фокуса =
          відстані до директриси
          y² = 2px, F(p/2; 0), x = -p/2

Діаметр кола - відрізок, що сполучає дві точки кола і проходить через центр. Ексцентриситет - відношення відстані між фокусами (2c) до довжини великої (дійсної) осі (2a): ε = c/a.
