Тема 1-3. Що додатково треба на іспиті

Визначник n-го порядку (О15) - сума n! доданків. Кожен доданок - добуток n елементів, по одному з кожного рядка і стовпця, зі знаком «+» для парної перестановки номерів стовпців і «-» для непарної. Інверсія - коли більше число стоїть перед меншим. Приклад з методички: у перестановці (2, 4, 1, 3) інверсії 2>1, 4>1, 4>3 - їх 3, перестановка непарна.

Обернена матриця 3×3 покроково:

1) det A; якщо 0 - оберненої нема
2) усі 9 доповнень A_ij = (-1)^(i+j)M_ij
3) ставимо їх ТРАНСПОНОВАНО
   (доповнення 1-го рядка -
    у 1-й стовпець)
4) ділимо на det A
5) перевірка: A·A⁻¹ = E

Метод Гауса і загальний розвʼязок. Розширену матрицю (A│b) зводимо до східчастого вигляду. Якщо зʼявився рядок (0 ... 0 │ число ≠ 0) - система несумісна. Інакше: невідомі при перших ненульових елементах рядків - базисні, решта - вільні (їх n - r, де r - ранг). Базисні виражаємо через вільні знизу вгору.

Фундаментальна система розвʼязків (ФСР) однорідної системи - n - r лінійно незалежних розвʼязків, через які виражається будь-який розвʼязок. Беремо по черзі одну вільну невідому = 1 (або зручне число), інші вільні = 0. Загальний розвʼязок: X = c₁e₁ + ... + cₖeₖ.

Загальний розвʼязок неоднорідної = частинний розвʼязок + загальний розвʼязок однорідної (лекції, теорема 1.8.3).

Тема 4-8. Що додатково треба на іспиті

Поділ відрізка M₁M₂ у відношенні λ (M₁M : MM₂ = λ): x = (x₁ + λx₂)/(1 + λ), так само y, z.

База і розклад. У просторі база - будь-які 3 некомпланарні вектори; будь-які 4 вектори лінійно залежні. Щоб розкласти d за базою a, b, c, розвʼязуємо систему d = αa + βb + γc.

Властивості добутків:

(a, b) = (b, a)        [a, b] = -[b, a]
(λa, b) = λ(a, b)      [a, a] = 0
(a, a) = |a|²
(a, b, c) = (b, c, a) = (c, a, b)
переставили два - знак змінився

Симетрична точка (П22, П23):

відносно площини:
1) пряма через M ⟂ площині
   (напрямний = n), параметрично
2) у рівняння площини ⇒ t ⇒ H
3) M' = 2H - M
відносно прямої:
1) площина через M ⟂ прямій
   (нормаль = напрямний a)
2) перетин з прямою ⇒ H
3) M' = 2H - M

Відстань між паралельними прямими/площинами: беремо будь-яку точку однієї і рахуємо відстань до іншої. Формула │C₁ - C₂│/√(A² + B²) - тільки коли A, B в обох рівняннях однакові.

Тема 9. Криві другого порядку (повніше)

ЕЛІПС  x²/a² + y²/b² = 1, a > b
  c² = a² - b², фокуси (±c; 0)
  ε = c/a < 1
  директриси x = ±a/ε
  фокальні радіуси
  r₁ = a + εx, r₂ = a - εx
ГІПЕРБОЛА  x²/a² - y²/b² = 1
  c² = a² + b², фокуси (±c; 0)
  ε = c/a > 1
  директриси x = ±a/ε
  асимптоти y = ±(b/a)·x
  права гілка: r₁ = εx + a,
               r₂ = εx - a
ПАРАБОЛА  y² = 2px
  фокус (p/2; 0)
  директриса x = -p/2, ε = 1
  x² = 2py - вісь Oy
КОЛО (x-x₀)² + (y-y₀)² = R²

Якщо у еліпса b > a, фокуси на осі Oy: c² = b² - a², ε = c/b. Гіпербола x²/a² - y²/b² = -1 - дійсна вісь Oy.

Директоріальна властивість (Д8): для будь-якої точки кривої відношення відстані до фокуса r до відстані до відповідної директриси d стале і дорівнює ексцентриситету: r/d = ε.

Полярне рівняння (О97, Д9): полюс у фокусі, полярна вісь - вісь Ox.

          p
r = ─────────────
     1 - ε·cos φ
ε < 1 еліпс, ε = 1 парабола,
ε > 1 гіпербола
для еліпса і гіперболи p = b²/a

p - полярний параметр: половина хорди, що проходить через фокус перпендикулярно до полярної осі.

Як звести загальне рівняння до канонічного: виділяємо повні квадрати (x² - 4x = (x - 2)² - 4) і переносимо центр. Наприклад x² + y² - 4x + 6y - 3 = 0 ⇒ (x - 2)² + (y + 3)² = 16 - коло з центром (2; -3), R = 4.
