Криві (П24, П25)

П24. Канонічне рівняння еліпса: мала піввісь 3, ε = √2/2.

Розвʼязання

b = 3, ε = c/a = √2/2 ⇒ c² = a²/2. З c² = a² - b²: a²/2 = a² - 9 ⇒ a² = 18. x²/18 + y²/9 = 1.

П25. Канонічне рівняння гіперболи: дійсна вісь 2a = 1, M(1; 3) на гіперболі.

Розвʼязання

a = 1/2, a² = 1/4. Підставляємо M: 1/(1/4) - 9/b² = 1 ⇒ 4 - 9/b² = 1 ⇒ b² = 3. x²/(1/4) - y²/3 = 1, тобто 4x² - y²/3 = 1. Перевірка M: 4 - 3 = 1 ✓.

Задача 7. Що за поверхні: а) x² - y² = 4z; б) x² + y² = z²; в) y² = 4x; г) x² + y² - z² = -1?

Розвʼязання

б) x² + y² - z² = 0, праворуч 0 - конус.

в) немає z, парабола - параболічний циліндр.

г) праворуч -1 з одним мінусом - двопорожнинний гіперболоїд.

Задача 10. a = 2p - 3q, b = p + 2q, |p| = 2, |q| = 3, (p, q) = π/3. Площа паралелограма на a, b.

Розвʼязання

[a, b] = 2[p,p] + 4[p,q] - 3[q,p] - 6[q,q] = 4[p,q] + 3[p,q] = 7[p,q]. │[p,q]│ = 2·3·sin 60° = 3√3 ⇒ S = 21√3 ≈ 36,37. Пастка: -3[q,p] = +3[p,q].

Задача 11. Піраміда A(1; 2; 0), B(3; 0; -3), C(5; 2; 6), D(8; 4; -9). Обʼєм і висота з D.

Розвʼязання

Крок 1. AB = (2; -2; -3), AC = (4; 0; 6), AD = (7; 2; -9), мішаний добуток -204 ⇒ V = 204/6 = 34.

Крок 2. [AB, AC] = (-12; -24; 8), модуль 28 ⇒ S(ABC) = 14.

Крок 3. V = ⅓·S·h ⇒ h = 3·34/14 = 51/7 ≈ 7,29.

Задача 12. Відстань між площинами 2x - 3y + z - 1 = 0 і 4x - 6y + 2z + 5 = 0.

Розвʼязання

Паралельні: 2/4 = -3/-6 = 1/2. Точка першої: x = y = 0 ⇒ z = 1. Відстань до другої: │0 - 0 + 2 + 5│/√(16 + 36 + 4) = 7/√56 = √14/4 ≈ 0,94.
