Шпаргалка: колоквіум 2

Похідна = lim ΔyΔx при Δx → 0, скінченна. f'(x₀) = tg α (дотична). S'(t) = v, S''(t) = a.

дотична: y = f'(x₀)(x - x₀) + y₀
нормаль: y = -(x - x₀)/f'(x₀) + y₀
  • Похідна є ⇔ f'₊ = f'₋. |x| у нулі: 1 ≠ -1, похідної нема.
  • Диференційовна ⇔ скінченна похідна. Диференційовна ⇒ неперервна (не навпаки!).
  • (uv)' = u'v + uv'; (u/v)' = (u'v - uv')/v²; (f(φ))' = f'(φ)·φ'.
  • Обернена: x'ᵧ = 1/y'ₓ (f' ≠ 0, строго монотонна).
  • (cos x)' = -sin x; (arccos)', (arcctg)', (ctg)' теж з мінусом.
  • u^v: ln y = v ln u ⇒ y' = u^v(v' ln u + v u'/u).
  • Параметрична: y'ₓ = y'ₜ/x'ₜ; y''ₓₓ = (y'ₓ)'ₜ / x'ₜ.
  • Неявна: диференціюй по x, (y²)' = 2yy'.

Диференціал dy = f'(x)dx; f(x₀ + Δx) ≈ f(x₀) + f'(x₀)Δx (градуси → радіани!). d²y = f''dx² лише для незалежної x; інакше + f'·d²x.

Лейбніц: (uv)⁽ⁿ⁾ = Σ Cₙᵏ u⁽ⁿ⁻ᵏ⁾ v⁽ᵏ⁾
(sin x)⁽ⁿ⁾ = sin(x + nπ/2)
(eᵃˣ)⁽ⁿ⁾ = aⁿeᵃˣ

Ферма: max/min у внутрішній точці + f' існує ⇒ f' = 0. Ролль: неперервна [a; b], f' на (a; b), f(a) = f(b) ⇒ f'(c) = 0. Лагранж: те саме без f(a) = f(b) ⇒ f(b) - f(a) = f'(c)(b - a). Коші: + g' ≠ 0 ⇒ f(b) - f(a)g(b) - g(a) = f'(c)g'(c).

Лопіталь: лише 0/0, ∞/∞; f'/g' окремо; g' ≠ 0; lim f'/g' існує (може бути ∞). 0·∞ → дріб; ∞ - ∞ → спільний знаменник; 1^∞, 0⁰, ∞⁰ → e^(v ln u).

eˣ = 1 + x + x²/2! + x³/3! + ...
sin x = x - x³/3! + x⁵/5! - ...
cos x = 1 - x²/2! + x⁴/4! - ...
ln(1+x) = x - x²/2 + x³/3 - ...
(1+x)^α = 1 + αx + α(α-1)x²/2! + ...
rₙ = f⁽ⁿ⁺¹⁾(c)(x-x₀)ⁿ⁺¹/(n+1)!

Екстремум: f' = 0 або f' нема - лише кандидат (x³: f'(0) = 0, а екстремуму нема). f' з + на - ⇒ max; f'(x₀) = 0, f'' > 0 ⇒ min. Перша ненульова похідна парного порядку ⇒ екстремум, непарного ⇒ нема. На [a; b]: критичні точки і кінці.

Опуклість: f'' > 0 ∪ (донизу), f'' < 0 ∩ (доверху). Перегин: f'' міняє знак (x⁴ - ні). Асимптоти: x = a, якщо однобічна границя ∞; k = lim f/x, b = lim (f - kx), окремо ±∞.
