Типові задачі (колоквіум 2 і КР 2)

Задачі у стилі файлу «Розвʼязування типових завдань розділу Диференціальне числення функцій» і зразка КР 2. Числа здебільшого свої, щоб було на чому тренуватись. Кожну відповідь перевірено в sympy. Спершу розвʼяжи сам, потім відкривай розвʼязання.

1. Похідна за означенням

Задача 1. Знайдіть похідну f(x) = 1/x у точці x₀ = 2 за означенням.

Розвʼязання

Крок 1. Приріст функції:

       1        1     2 - (2 + Δx)
Δy = ────── - ─── = ────────────
     2 + Δx    2    2(2 + Δx)
          -Δx
     = ──────────
       2(2 + Δx)

Крок 2. Ділимо на Δx: ΔyΔx = -12(2 + Δx) (Δx скоротилось - так буде завжди).

Крок 3. Границя при Δx → 0: -12·2 = -1/4.

Відповідь: f'(2) = -1/4. Перевірка за таблицею: (1/x)' = -1/x², при x = 2 це -1/4.

2. Правила диференціювання

Задача 2. y = 2x + 1x² + 1. Знайдіть y'.

Розвʼязання

Крок 1. Частка: u = 2x + 1, u' = 2; v = x² + 1, v' = 2x.

Крок 2. За правилом (u/v)' = (u'v - uv')/v²:

     2(x² + 1) - (2x + 1)·2x
y' = ───────────────────────
           (x² + 1)²

Крок 3. Розкриваємо чисельник: 2x² + 2 - 4x² - 2x = -2x² - 2x + 2.

Відповідь: y' = 2(1 - x - x²)(x² + 1)².

3. Складена функція

Задача 3. a) y = √(9 - x²); b) y = lnx - 1x + 1. Знайдіть y'.

Розвʼязання

a) Крок 1. Пишемо як степінь: y = (9 - x²)^(1/2). Зовнішня - степінь 1/2, внутрішня 9 - x².

Крок 2. y' = (1/2)(9 - x²)^(-1/2)·(9 - x²)' = 12√(9 - x²)·(-2x) = -x√(9 - x²).

b) Крок 3. Спершу спрощуємо логарифм (так легше): y = ln(x - 1) - ln(x + 1).

Крок 4. y' = 1x - 1 - 1x + 1 = (x + 1) - (x - 1)(x - 1)(x + 1) = 2x² - 1.

У методичці цю саму функцію рахують «в лоб» через похідну частки - відповідь та сама, але довше.

Відповідь: a) -x/√(9 - x²); b) 2/(x² - 1).

Задача 4. y = arcsin 3x + arctg x². Знайдіть y'.

Розвʼязання

Крок 1. (arcsin u)' = u'√(1 - u²), u = 3x, u' = 3: 3√(1 - 9x²).

Крок 2. (arctg u)' = u'1 + u², u = x², u' = 2x, u² = x⁴: 2x1 + x⁴.

Відповідь: y' = 3√(1 - 9x²) + 2x1 + x⁴.

Пастка: (3x)² = 9x², а не 3x².

4. Логарифмічна похідна

Задача 5. y = (x² + 1)^(sin x). Знайдіть y'.

Розвʼязання

Крок 1. Змінна і в основі, і в показнику - логарифмуємо: ln y = sin x · ln(x² + 1).

Крок 2. Диференціюємо обидві частини. Зліва (ln y)' = y'/y (y - функція від x). Справа - похідна добутку:

y'
── = cos x·ln(x² + 1)
y          2x·sin x
        + ─────────
           x² + 1

Крок 3. Множимо на y:

y' = (x² + 1)^(sin x) ·
     ⎛                   2x·sin x⎞
   · ⎜cos x·ln(x² + 1) + ────────⎟
     ⎝                    x² + 1 ⎠

5. Параметрична і неявна функція

Задача 6. x = t² + 1, y = t³ - t. Знайдіть y'ₓ і y''ₓₓ, обчисліть їх при t = 1.

Розвʼязання

Крок 1. x'ₜ = 2t, y'ₜ = 3t² - 1.

Крок 2. y'ₓ = y'ₜx'ₜ = 3t² - 12t.

Крок 3. Для другої похідної спершу (y'ₓ)'ₜ - похідна по t від того, що вийшло:

          6t·2t - (3t² - 1)·2
(y'ₓ)'ₜ = ───────────────────
                 4t²
          6t² + 2   3t² + 1
        = ─────── = ───────
            4t²       2t²

Крок 4. Ділимо на x'ₜ = 2t: y''ₓₓ = 3t² + 12t²·2t = 3t² + 14t³.

Крок 5. t = 1: y'ₓ = (3 - 1)/2 = 1; y''ₓₓ = (3 + 1)/4 = 1.

Пастка: y''ₓₓ ≠ y''ₜ/x''ₜ = 6t/2 = 3t (при t = 1 дало б 3 - неправильно).

Задача 7. Функція задана неявно: e^y + xy = e. Знайдіть y' і його значення в точці (0; 1).

Розвʼязання

Крок 1. Перевіряємо точку: e¹ + 0·1 = e. Лежить на кривій.

Крок 2. Диференціюємо по x, памʼятаючи, що y = y(x): (e^y)' = e^y·y', (xy)' = 1·y + x·y', (e)' = 0.

e^y·y' + y + x·y' = 0

Крок 3. Виносимо y': y'(e^y + x) = -y ⇒ y' = -ye^y + x.

Крок 4. У точці (0; 1): y' = -1e + 0 = -1/e ≈ -0,368.

6. Дотична і нормаль

Задача 8. Запишіть рівняння дотичної і нормалі до y = x³ - 2x у точці x₀ = 1.

Розвʼязання

Крок 1. y₀ = 1 - 2 = -1. Точка (1; -1).

Крок 2. y' = 3x² - 2, y'(1) = 1.

Крок 3. Дотична: y = y'(x₀)(x - x₀) + y₀ = 1·(x - 1) - 1 = x - 2.

Крок 4. Нормаль: кутовий коефіцієнт -1/y'(x₀) = -1. y = -(x - 1) - 1 = -x.

Відповідь: дотична y = x - 2, нормаль y = -x.

Задача 9. Під яким кутом до осі OX нахилена дотична до y = x³/3 у точці x = 1?

Розвʼязання

Крок 1. y' = x², y'(1) = 1.

Крок 2. tg α = 1, α = 45° (π/4).

Розвʼязання

a) dy = y'dx = 2x1 + x⁴dx.

b) Крок 1. dy = 3x²·Δx = 3·4·0,01 = 0,12.

Крок 2. Δy = 2,01³ - 2³ = 8,120601 - 8 = 0,120601.

Крок 3. Різниця Δy - dy = 0,000601 - вона набагато менша за Δx = 0,01, як і каже теорія (нескінченно мала вищого порядку). Точно: 6Δx² + Δx³ = 0,0006 + 0,000001.

Задача 11. Обчисліть наближено: a) arcsin 0,51; b) sin 31°.

Розвʼязання

Формула: f(x₀ + Δx) ≈ f(x₀) + f'(x₀)·Δx.

a) Крок 1. f = arcsin x, x₀ = 0,5 (бо arcsin 0,5 = π/6 точно), Δx = 0,01.

Крок 2. f'(x) = 1√(1 - x²), f'(0,5) = 1√0,75 ≈ 1,1547.

Крок 3. arcsin 0,51 ≈ π/6 + 1,1547·0,01 = 0,52360 + 0,01155 = 0,53515.

Точне значення 0,53518 - збіг до 4 знаків.

У методичці цей самий приклад закінчується числом «0,513» - це арифметична описка: π/6 ≈ 0,5236, і 0,5236 + 0,0115 = 0,5351.

b) Крок 4. Градуси переводимо в радіани! x₀ = 30° = π/6, Δx = 1° = π/180 ≈ 0,017453.

Крок 5. (sin x)' = cos x, cos 30° = √3/2 ≈ 0,86603.

Крок 6. sin 31° ≈ 0,5 + 0,86603·0,017453 = 0,5 + 0,01511 = 0,51511 (точно 0,51504).

Пастка: підставити Δx = 1 (градус), а не π/180 - вийде 1,366, більше за 1, чого для синуса не буває.

Задача 12. Знайдіть y⁽ⁿ⁾ для y = 12x + 3.

Розвʼязання

Крок 1. y = (2x + 3)⁻¹.

Крок 2. Рахуємо кілька похідних і стежимо за закономірністю (кожного разу вилазить множник 2):

y'   = (-1)·2·(2x + 3)⁻²
y''  = (-1)(-2)·2²·(2x + 3)⁻³
y''' = (-1)(-2)(-3)·2³·(2x + 3)⁻⁴

Крок 3. Добуток (-1)(-2)...(-n) = (-1)ⁿ·n!. Тому

        (-1)ⁿ·n!·2ⁿ
y⁽ⁿ⁾ = ────────────
       (2x + 3)ⁿ⁺¹

Перевірка при n = 1: -2/(2x + 3)². Збіг.

Крок 2. C₅⁰ = 1, C₅¹ = 5, C₅² = 5·4/2 = 10.

Крок 3.

y⁽⁵⁾ = u⁽⁵⁾v + 5u⁽⁴⁾v' + 10u'''v''
 = 243e³ˣ·x² + 5·81e³ˣ·2x
   + 10·27e³ˣ·2

Відповідь: y⁽⁵⁾ = e^(3x)(243x² + 810x + 540).

Задача 14. Знайдіть d²y для y = x·ln x: a) x - незалежна змінна; b) x - функція іншої змінної.

Розвʼязання

Крок 1. y' = ln x + x·(1/x) = ln x + 1, y'' = 1/x.

Крок 2. a) d²y = y''dx² = dx²x.

Крок 3. b) d²y = y''dx² + y'd²x = dx²x + (ln x + 1)d²x. Зайвий доданок і є «неінваріантність» другого диференціала.

11. Формула Тейлора і Маклорена

Задача 19. Розкладіть f(x) = x³ - 2x² + 3x + 5 за степенями (x - 2).

Розвʼязання

Крок 1. Значення і похідні в x₀ = 2:

f(2)   = 8 - 8 + 6 + 5 = 11
f'     = 3x² - 4x + 3,  f'(2) = 7
f''    = 6x - 4,        f''(2) = 8
f'''   = 6,             f''''  = 0

Крок 2. Ділимо на факторіали: 11, 7/1! = 7, 8/2! = 4, 6/3! = 1.

Відповідь: f(x) = 11 + 7(x - 2) + 4(x - 2)² + (x - 2)³. Залишку нема: многочлен 3-го степеня. Перевірка: розкрий дужки - вийде початковий многочлен.

13. Опуклість, перегин, асимптоти

Задача 23. Проміжки опуклості і точки перегину y = x·e⁻ˣ.

Розвʼязання

Крок 1. y' = e⁻ˣ - x·e⁻ˣ = (1 - x)e⁻ˣ.

Крок 2. y'' = -e⁻ˣ - (1 - x)e⁻ˣ = (x - 2)e⁻ˣ.

Крок 3. e⁻ˣ > 0 завжди, тому знак y'' = знак (x - 2). y'' = 0 при x = 2.

Крок 4. x < 2: y'' < 0, опуклий доверху ∩; x > 2: y'' > 0, опуклий донизу ∪.

Крок 5. Знак змінився - перегин. y(2) = 2e⁻² ≈ 0,271.

Відповідь: ∩ на (-∞; 2), ∪ на (2; +∞), точка перегину (2; 2/e²).

Задача 24. Асимптоти графіка y = x² - 3x + 2.

Розвʼязання

Крок 1. Вертикальна: знаменник 0 при x = -2, чисельник там 4 - 3 = 1 ≠ 0. x → -2 + 0: 1/(+мале) → +∞; x → -2 - 0: → -∞. Отже, x = -2 - вертикальна асимптота.

Крок 2. k = lim f(x)x = lim x² - 3x² + 2x = 1.

Крок 3. b = lim (f(x) - x) = lim x² - 3 - x² - 2xx + 2 = lim -2x - 3x + 2 = -2.

Крок 4. Для x → -∞ ті самі k = 1, b = -2.

Відповідь: x = -2 і y = x - 2.

14. Повне дослідження функції (завдання 6 зі зразка КР 2, 3 бали)

Задача 25. Дослідіть функцію y = x²x - 1 і побудуйте графік.

Розвʼязання

Крок 1. Область. x ≠ 1: D = (-∞; 1) ∪ (1; +∞).

Крок 2. Перетин з осями. x = 0 ⇒ y = 0. Точка (0; 0) - єдина.

Крок 3. Парність. Область не симетрична відносно 0 - ні парна, ні непарна. Не періодична.

Крок 4. Розрив. У x = 1: x → 1 + 0: 1/(+0) → +∞; x → 1 - 0: → -∞. Розрив другого роду, x = 1 - вертикальна асимптота.

Крок 5. Похила. k = lim x²x(x - 1) = 1; b = lim (x²x - 1 - x) = lim xx - 1 = 1. Асимптота y = x + 1 (при x → ±∞).

Крок 6. Монотонність.

     2x(x - 1) - x²    x(x - 2)
y' = ────────────── = ────────
        (x - 1)²       (x - 1)²

y' = 0 при x = 0 і x = 2; не існує при x = 1 (не в області).

x (-∞; 0) 0 (0; 1) (1; 2) 2 (2; +∞)
y' + 0 - - 0 +
y ↗ max 0 ↘ ↘ min 4 ↗

y(2) = 4/1 = 4.

Крок 7. Опуклість. y'' = 2(x - 1)³. Нуля нема. x < 1: y'' < 0, ∩; x > 1: y'' > 0, ∪. Опуклість міняється лише в x = 1, але там функція не визначена - точок перегину нема.

Крок 8. Графік. Ліва гілка: йде з -∞ під асимптотою y = x + 1, вершина (0; 0), падає до -∞ біля x = 1. Права гілка: з +∞ біля x = 1, дно (2; 4), далі вгору над асимптотою y = x + 1.

Задача 26. Дослідіть функцію y = xx² + 1.

Розвʼязання

Крок 1. Область - уся пряма (x² + 1 > 0). Розривів і вертикальних асимптот нема.

Крок 2. (0; 0) - перетин з осями. y(-x) = -y(x) - функція непарна, графік симетричний відносно початку координат.

Крок 3. Горизонтальна асимптота: lim xx² + 1 = 0 при x → ±∞, тобто y = 0 (k = 0).
