Множини та індукція

Задача 1. A = {x ∈ ℝ : x² - 5x + 4 < 0}, B = [2; 6]. Знайти A ∪ B, A ∩ B, A \ B, B \ A.

Розвʼязання

Крок 1. Розв'язуємо нерівність: x² - 5x + 4 = (x - 1)(x - 4) < 0 ⇔ 1 < x < 4. Отже A = (1; 4).

Крок 2. Малюємо обидві множини на прямій і читаємо відповідь:

A ∪ B = (1; 6]
A ∩ B = [2; 4)
A \ B = (1; 2)    2 ∈ B, викидаємо
B \ A = [4; 6]    4 ∉ A, лишається

Крок 3. Кінці перевіряємо окремо: 4 не належить A (нерівність строга), тому в A ∩ B кінець 4 круглий, а в B \ A - квадратний.

Задача 2. X = {(2n + 1)/(n + 1) : n ∈ ℕ}. Знайти sup X, inf X, max X, min X.

Розвʼязання

Крок 1. Випишемо елементи: 3/2; 5/3; 7/4; 9/5; ... Виділимо цілу частину: (2n + 1)/(n + 1) = 2 - 1/(n + 1). Чим більше n, тим менше віднімаємо - елементи зростають.

Крок 2. Найменший елемент при n = 1: 3/2. Отже inf X = min X = 3/2.

Крок 3. Кандидат на sup - число 2. Перевіряємо означення: 1) 2 - 1/(n + 1) < 2 для всіх n; 2) для ∀ε > 0 хочемо 2 - 1/(n + 1) > 2 - ε ⇔ n + 1 > 1/ε. Такий n є (принцип Архімеда). Отже sup X = 2.

Крок 4. 2 ∉ X (бо 1/(n + 1) ≠ 0), тому max X не існує.

Число: ε = 0,01 ⇒ n + 1 > 100, n = 100: 201/101 = 1,990099 > 1,99.

Задача 3. Довести індукцією: 1² + 2² + ... + n² = n(n + 1)(2n + 1)/6.

Розвʼязання

Крок 1 (база). n = 1: ліва частина 1² = 1, права 1·2·3/6 = 1. Збіг.

Крок 2 (припущення). Нехай 1² + ... + k² = k(k + 1)(2k + 1)/6.

Крок 3 (перехід). Для n = k + 1 використовуємо припущення:

1² + ... + k² + (k + 1)²
= k(k+1)(2k+1)/6 + (k+1)²
= (k+1)·(k(2k+1) + 6(k+1))/6
= (k+1)(2k² + 7k + 6)/6
= (k+1)(k+2)(2k+3)/6

Крок 4. Це формула при n = k + 1 (бо 2(k + 1) + 1 = 2k + 3). За принципом індукції рівність правильна для всіх n.

Звідки (k + 2)(2k + 3): розкриваємо дужки: 2k² + 3k + 4k + 6 = 2k² + 7k + 6. Збіг.

Задача 4. Довести, що 4ⁿ + 15n - 1 ділиться на 9 для всіх n ∈ ℕ.

Розвʼязання

Крок 1 (база). n = 1: 4 + 15 - 1 = 18 = 9·2.

Крок 2 (припущення). 4ᵏ + 15k - 1 ділиться на 9.

Крок 3 (перехід). Виділяємо вираз з припущення, домноживши на 4:

4ᵏ⁺¹ + 15(k+1) - 1
= 4·4ᵏ + 15k + 14
= 4(4ᵏ + 15k - 1) - 45k + 18
= 4(4ᵏ + 15k - 1) - 9(5k - 2)

Крок 4. Перший доданок ділиться на 9 за припущенням, другий має множник 9. Отже сума ділиться на 9.

Перевірка: 4·(15k - 1) = 60k - 4, а нам треба 15k + 14, різниця 15k + 14 - 60k + 4 = -45k + 18.

Комплексні числа

Задача 5. z = (1 + 2i)/(3 - 4i). Знайти Re z, Im z, |z|.

Розвʼязання

Крок 1. Домножуємо чисельник і знаменник на спряжене до знаменника 3 + 4i.

Крок 2. Знаменник: (3 - 4i)(3 + 4i) = 9 - 16i² = 9 + 16 = 25.

Крок 3. Чисельник: (1 + 2i)(3 + 4i) = 3 + 4i + 6i + 8i² = 3 + 10i - 8 = -5 + 10i.

Крок 4. z = (-5 + 10i)/25 = -1/5 + (2/5)i. Re z = -1/5, Im z = 2/5 (без i!).

Крок 5. |z| = √(1/25 + 4/25) = √5/5 ≈ 0,447. Перевірка: |1 + 2i|/|3 - 4i| = √5/5. Збіг.

Задача 6. Обчислити (√3 + i)⁶.

Розвʼязання

Крок 1. ρ = √(3 + 1) = 2. x = √3 > 0, тому φ = arctg(1/√3) = π/6.

Крок 2. За формулою Муавра: (√3 + i)⁶ = 2⁶·(cos(6·π/6) + i·sin(6·π/6)) = 64·(cos π + i·sin π).

Крок 3. cos π = -1, sin π = 0. Відповідь: -64.

Задача 7. Знайти всі значення ∛(8i).

Розвʼязання

Крок 1. 8i = 0 + 8i: ρ = 8, точка на додатній осі Oy, φ = π/2. ∛8 = 2.

Крок 2. ψₖ = (π/2 + 2πk)/3, k = 0, 1, 2:

k=0: π/6    2(√3/2 + i/2) =  √3 + i
k=1: 5π/6   2(-√3/2 + i/2) = -√3 + i
k=2: 3π/2   2(0 - i)       = -2i

Крок 3. Контроль: (-2i)³ = -8i³ = -8·(-i) = 8i. Правильно.

Задача 8. За означенням довести, що lim (3n - 1)/(n + 2) = 3. Знайти n_ε при ε = 0,01.

Розвʼязання

Крок 1. |xₙ - 3| = |3n - 1 - 3(n + 2)|/(n + 2) = |-7|/(n + 2) = 7/(n + 2).

Крок 2. 7/(n + 2) < ε ⇔ n + 2 > 7/ε ⇔ n > 7/ε - 2.

Крок 3. n_ε = [7/ε - 2] (ціла частина). Для будь-якого ε > 0 такий номер є, отже lim = 3.

Крок 4. ε = 0,01: 700 - 2 = 698, n_ε = 698. Перевірка: n = 699: 7/701 = 0,00999 < 0,01; n = 698: 7/700 = 0,01 - не менше.

Задача 9. Знайдемо lim (√(4n² + 1) - n)/(3n + 2).

Розвʼязання

Крок 1. Маємо невизначеність ∞/∞. Старший степінь n - перший (√(4n²) = 2n).

Крок 2. Ділимо чисельник і знаменник на n (під коренем - на n²):

(√(4 + 1/n²) - 1)/(3 + 2/n)
→ (√4 - 1)/3 = 1/3

Задача 10. Знайдемо lim (√(n² + 4n) - n).

Розвʼязання

Крок 1. Невизначеність ∞ - ∞. Домножуємо і ділимо на спряжений вираз √(n² + 4n) + n.

Крок 2. Угорі (a - b)(a + b) = a² - b²: n² + 4n - n² = 4n.

Крок 3. 4n/(√(n² + 4n) + n), ділимо на n: 4/(√(1 + 4/n) + 1) → 4/2 = 2.

Задача 11. Знайдемо lim ((2n + 3)/(2n - 1))ⁿ.

Розвʼязання

Крок 1. Основа → 1, показник → ∞: невизначеність 1^∞, ведемо до числа e.

Крок 2. Виділяємо «1 + мале»: (2n + 3)/(2n - 1) = 1 + 4/(2n - 1).

Крок 3. Перетворюємо показник:

(1 + 4/(2n-1))ⁿ = [Aₙ]^(4n/(2n-1)),
Aₙ = (1 + 4/(2n-1))^((2n-1)/4)

Крок 4. Aₙ → e (друга важлива, мале 4/(2n - 1) і степінь обернені), показник 4n/(2n - 1) → 2. Відповідь e².

Задача 12. x₁ = √6, xₙ₊₁ = √(6 + xₙ). Довести збіжність і знайти границю.

Розвʼязання

Крок 1 (обмеженість, індукція). x₁ = √6 < 3. Якщо xₙ < 3, то xₙ₊₁ = √(6 + xₙ) < √9 = 3.

Крок 2 (зростання). xₙ₊₁ > xₙ ⇔ 6 + xₙ > xₙ² ⇔ (3 - xₙ)(2 + xₙ) > 0 - правда, бо 0 < xₙ < 3.

Крок 3. Зростає і обмежена зверху ⇒ за теоремою Вейєрштрасса збіжна, lim xₙ = a.

Крок 4. Переходимо до границі в рівності: a = √(6 + a) ⇒ a² - a - 6 = 0 ⇒ a = 3 або a = -2. -2 відкидаємо (усі члени додатні). Відповідь 3.

Задача 13. xₙ = (-1)ⁿ·(2n + 1)/(n + 3). Знайти часткові границі, верхню і нижню границі. Чи збіжна?

Розвʼязання

Крок 1. (2n + 1)/(n + 3) → 2 (старші коефіцієнти 2/1).

Крок 2. Парні n: xₙ → 2. Непарні n: xₙ → -2. L = {-2; 2}.

Крок 3. Верхня границя 2, нижня -2. Вони різні ⇒ послідовність розбіжна.

Крок 4. Послідовність обмежена (|xₙ| < 2), тому за Больцано-Вейєрштрассом збіжні підпослідовності мусять бути - вони і знайдені.

Задача 14. Довести за критерієм Коші, що xₙ = sin 1/2 + sin 2/2² + ... + sin n/2ⁿ збіжна.

Розвʼязання

Крок 1. Оцінюємо |xₙ₊ₚ - xₙ| (p - будь-яке натуральне):

|sin(n+1)/2ⁿ⁺¹ + ... + sin(n+p)/2ⁿ⁺ᵖ|
≤ 1/2ⁿ⁺¹ + ... + 1/2ⁿ⁺ᵖ
= 1/2ⁿ - 1/2ⁿ⁺ᵖ < 1/2ⁿ

(|sin k| ≤ 1, сума геометричної прогресії.)

Крок 2. 1/2ⁿ < ε ⇔ n > log₂(1/ε). Беремо n_ε = [log₂(1/ε)]: для n > n_ε і будь-якого p маємо |xₙ₊ₚ - xₙ| < ε.

Крок 3. Послідовність фундаментальна ⇒ за критерієм Коші збіжна. Саму границю ми не знайшли - і не треба.

Число: ε = 0,001: log₂ 1000 = 9,97, n_ε = 9.

Задача 15. За Коші довести, що lim x² = 9 при x → 3.

Розвʼязання

Крок 1. |x² - 9| = |x - 3|·|x + 3|. Множник |x + 3| треба оцінити зверху.

Крок 2. Обмежимось |x - 3| < 1, тобто 2 < x < 4. Тоді |x + 3| < 7.

Крок 3. |x² - 9| < 7|x - 3| < ε, якщо |x - 3| < ε/7.

Крок 4. Беремо δ = min(1; ε/7). Тоді при 0 < |x - 3| < δ виконуються обидві умови і |x² - 9| < ε.

Число: ε = 0,7 ⇒ δ = 0,1. x = 3,09: 9,5481 - 9 = 0,5481 < 0,7.

Задача 16. Знайдемо lim (x³ - 8)/(x² - 3x + 2) при x → 2.

Розвʼязання

Крок 1. x = 2: 8 - 8 = 0 і 4 - 6 + 2 = 0. Невизначеність 0/0.

Крок 2. Розкладаємо: x³ - 8 = (x - 2)(x² + 2x + 4), x² - 3x + 2 = (x - 2)(x - 1).

Крок 3. Скорочуємо на x - 2 (x ≠ 2): (x² + 2x + 4)/(x - 1) → (4 + 4 + 4)/1 = 12.

Задача 17. Знайдемо lim (√(2x + 1) - 3)/(√(x - 2) - √2) при x → 4.

Розвʼязання

Крок 1. x = 4: √9 - 3 = 0, √2 - √2 = 0. Невизначеність 0/0.

Крок 2. Домножуємо на обидва спряжені: (√(2x + 1) + 3) і (√(x - 2) + √2).

Крок 3. Угорі 2x + 1 - 9 = 2(x - 4), унизу x - 2 - 2 = x - 4:

2(x - 4)·(√(x-2) + √2)
──────────────────────
(x - 4)·(√(2x+1) + 3)

Крок 4. Скорочуємо x - 4, підставляємо 4: 2·(√2 + √2)/(3 + 3) = 4√2/6 = 2√2/3 ≈ 0,943.

Задача 18. Знайдемо lim (1 - cos 6x)/(x·sin 3x) при x → 0.

Розвʼязання

Крок 1. Невизначеність 0/0. Формула 1 - cos 2α = 2sin²α: 1 - cos 6x = 2sin² 3x.

Крок 2. 2sin² 3x/(x·sin 3x) = 2·sin 3x / x.

Крок 3. Перша важлива: sin 3x / x = 3·(sin 3x / 3x) → 3. Відповідь 2·3 = 6.

Задача 19. Знайдемо lim sin 3x/(x - π) при x → π.

Розвʼязання

Крок 1. 0/0, але x → π, а не до 0. Заміна t = x - π, t → 0, x = t + π.

Крок 2. sin 3x = sin(3t + 3π) = -sin 3t (бо sin(α + π) = -sin α, а 3π = 2π + π).

Крок 3. -sin 3t / t = -3·(sin 3t / 3t) → -3.

Задача 20. Знайдемо lim ((x - 1)/(x + 2))^(3x + 1) при x → ∞.

Розвʼязання

Крок 1. Основа → 1, показник → ∞: 1^∞.

Крок 2. (x - 1)/(x + 2) = 1 - 3/(x + 2).

Крок 3. Правило 1^∞: границя = e^(lim (u - 1)·v), де u - основа, v - показник:

(u - 1)·v = -3(3x + 1)/(x + 2) → -9

Крок 4. Відповідь e⁻⁹. (Строго: (1 - 3/(x + 2))^(-(x + 2)/3) → e, а показник -3(3x + 1)/(x + 2) → -9.)

Задача 21. Знайдемо lim (cos x)^(1/x²) при x → 0.

Розвʼязання

Крок 1. cos x → 1, 1/x² → ∞: 1^∞.

Крок 2. cos x = 1 + (cos x - 1), мале α = cos x - 1 → 0.

Крок 3. (1 + α)^(1/x²) = [(1 + α)^(1/α)]^(α/x²). Квадратні дужки → e.

Крок 4. α/x² = (cos x - 1)/x² → -1/2 (бо 1 - cos x = 2sin²(x/2), а 2sin²(x/2)/x² → 2·(1/2)² = 1/2). Відповідь e^(-1/2) = 1/√e ≈ 0,607.

Задача 22. а) lim arcsin 5x · tg 2x / ln(1 + 4x²) при x → 0. б) lim (3ˣ - 2ˣ)/x при x → 0.

Розвʼязання

а) Крок 1. Усе - множники, міняємо кожен на еквівалентний: arcsin 5x ~ 5x, tg 2x ~ 2x, ln(1 + 4x²) ~ 4x² (u = 4x² → 0).

а) Крок 2. 5x·2x/(4x²) = 10/4 = 5/2.

б) Крок 1. Тут різниця, тому додаємо і віднімаємо 1: (3ˣ - 1)/x - (2ˣ - 1)/x.

б) Крок 2. Наслідок другої важливої (aˣ - 1)/x → ln a: ln 3 - ln 2 = ln(3/2) ≈ 0,405.

Задача 23. Порівняти α = tg x - sin x і β = x при x → 0. Знайти порядок α і еквівалентну.

Розвʼязання

Крок 1. Пастка: «tg x ~ x, sin x ~ x, тому α ~ x - x = 0». Доданки міняти не можна!

Крок 2. Виносимо множник: tg x - sin x = tg x·(1 - cos x).

Крок 3. Тепер множники: tg x ~ x, 1 - cos x ~ x²/2. Отже α ~ x³/2.

Крок 4. α/x → 0, тому α = o(x), вищого порядку. Порядок 3: α/x³ → 1/2 ≠ 0.

Число: x = 0,1: (tg 0,1 - sin 0,1)/0,001 = 0,501.

Неперервність і розриви

Задача 24. Дослідити на неперервність y = (x² - 4)/(x² - 5x + 6).

Розвʼязання

Крок 1. Знаменник (x - 2)(x - 3) = 0 при x = 2 і x = 3. Поза ними функція елементарна, тому неперервна.

Крок 2. x = 2: y = (x - 2)(x + 2)/((x - 2)(x - 3)) = (x + 2)/(x - 3) → 4/(-1) = -4 з обох боків. Границі скінченні і рівні, f(2) нема ⇒ усувний розрив (розрив I роду). Довизначивши f(2) = -4, усунемо його.

Крок 3. x = 3: (x + 2)/(x - 3): зліва 5/(мале від'ємне) → -∞, справа → +∞ ⇒ розрив II роду.

Задача 25. Дослідити y = 1/(1 + 2^(1/(x - 1))) у точці x = 1.

Розвʼязання

Крок 1. Зліва (x < 1): 1/(x - 1) → -∞, 2^(-∞) → 0, y → 1/(1 + 0) = 1.

Крок 2. Справа (x > 1): 1/(x - 1) → +∞, 2^(+∞) → +∞, y → 0.

Крок 3. Обидві скінченні, але різні ⇒ розрив I роду зі скінченним стрибком. Стрибок δ = f(1 + 0) - f(1 - 0) = 0 - 1 = -1.

Задача 26. При яких a і b функція неперервна?

     ⎧ a·x + 1,   x < 1
y =  ⎨ x² + 2,    1 ≤ x ≤ 2
     ⎩ b·x - 2,   x > 2
Розвʼязання

Крок 1. Кожна формула - многочлен, неперервна. Ламатися може лише на стиках x = 1 і x = 2.

Крок 2. x = 1: ліва границя a + 1, права і f(1) = 1 + 2 = 3. Умова a + 1 = 3 ⇒ a = 2.

Крок 3. x = 2: ліва і f(2) = 4 + 2 = 6, права 2b - 2. Умова 2b - 2 = 6 ⇒ b = 4.

Відповідь: a = 2, b = 4.

Задача 27. Довести, що x³ - 3x + 1 = 0 має корінь на [0; 1], і знайти його з точністю 0,125.

Розвʼязання

Крок 1. f(x) = x³ - 3x + 1 - многочлен, неперервна на [0; 1].

Крок 2. f(0) = 1 > 0, f(1) = 1 - 3 + 1 = -1 < 0. За першою теоремою Больцано-Коші ∃c ∈ (0; 1): f(c) = 0.

Крок 3. Ділимо навпіл:

f(0,5)   = -0,375   ⇒ [0; 0,5]
f(0,25)  =  0,266   ⇒ [0,25; 0,5]
f(0,375) = -0,072   ⇒ [0,25; 0,375]

Крок 4. Довжина 0,125. Точний корінь (кодом) 0,3473 - справді в [0,25; 0,375].

Задача 28. Довести, що f(x) = x² рівномірно неперервна на [0; 2], але не на ℝ.

Розвʼязання

Крок 1 (на [0; 2]). |x₁² - x₂²| = |x₁ - x₂|·|x₁ + x₂| ≤ 4|x₁ - x₂| (обидва ≤ 2). Беремо δ = ε/4 - не залежить від точки. (Це ж дає і теорема Кантора.)

Крок 2 (на ℝ, заперечення). Беремо ε = 1, x₁ = n + 1/n, x₂ = n.

Крок 3. |x₁ - x₂| = 1/n → 0: для будь-якого δ знайдеться n, що відстань < δ.

Крок 4. |x₁² - x₂²| = (n + 1/n)² - n² = 2 + 1/n² ≥ 1 = ε. Це заперечення рівномірної неперервності.

Задача 29. а) Чи існує lim xy/(x² + y²) при (x; y) → (0; 0)? б) z = x²·e^(xy): знайти z'ₓ, z'ᵧ і dz у точці (1; 0).

Розвʼязання

а) Крок 1. Ідемо по прямій y = kx: kx²/(x² + k²x²) = k/(1 + k²).

а) Крок 2. k = 0 дає 0, k = 1 дає 1/2. Різні шляхи - різні числа ⇒ границі нема.

б) Крок 1. По x (y стале), правило добутку: z'ₓ = 2x·e^(xy) + x²·y·e^(xy).

б) Крок 2. По y (x стале): z'ᵧ = x²·x·e^(xy) = x³·e^(xy).

Задача 30. x² + 2y² + 3z² = 6 задає z(x, y). Знайти z'ₓ і z'ᵧ у точці (1; 1; 1).

Розвʼязання

Задача 31. u = x²y + yz². Знайти grad u у M(1; 1; 2), похідну за напрямком l = (2; -1; 2) і найбільшу швидкість зростання.

Задача 32. Дотична площина і нормаль до z = x² + y² у точці (1; 1; 2).

Розвʼязання

Крок 1. z'ₓ = 2x = 2, z'ᵧ = 2y = 2 у точці (1; 1).

Крок 2. Площина: z - 2 = 2(x - 1) + 2(y - 1) ⇒ 2x + 2y - z - 2 = 0.

Крок 3. Нормаль (вектор (2; 2; -1)): (x - 1)/2 = (y - 1)/2 = (z - 2)/(-1).

Крок 4. Перевірка: (1; 1; 2) у площині: 2 + 2 - 2 - 2 = 0.

Задача 33. z = sin(xy²). Перевірити z''ₓᵧ = z''ᵧₓ.

Крок 3. z''ᵧₓ = (2xy·cos(xy²))'ₓ = 2y·cos(xy²) - 2xy·sin(xy²)·y² = те саме. Похідні неперервні, тому рівність і мала бути.

Задача 34. Екстремум z = x² + xy + y² - 3x - 6y.

Розвʼязання

Крок 1. z'ₓ = 2x + y - 3 = 0, z'ᵧ = x + 2y - 6 = 0. З першого y = 3 - 2x, у друге: x + 6 - 4x = 6 ⇒ x = 0, y = 3.

Крок 2. A = z''ₓₓ = 2, B = z''ₓᵧ = 1, C = z''ᵧᵧ = 2. Δ = AC - B² = 4 - 1 = 3 > 0, A > 0 ⇒ мінімум.

Крок 3. z(0; 3) = 0 + 0 + 9 - 0 - 18 = -9.

Задача 36. Методом Лагранжа знайти екстремуми f = x + 2y за умови x² + y² = 5.

Розвʼязання

Крок 1. L = x + 2y + λ(x² + y² - 5).

Крок 2. L'ₓ = 1 + 2λx = 0 ⇒ x = -1/(2λ); L'ᵧ = 2 + 2λy = 0 ⇒ y = -1/λ.

Крок 3. Підставляємо в умову: 1/(4λ²) + 1/λ² = 5/(4λ²) = 5 ⇒ λ² = 1/4, λ = ±1/2.

Крок 4. λ = -1/2: (1; 2), f = 5 - максимум. λ = 1/2: (-1; -2), f = -5 - мінімум. (На колі - замкненій обмеженій множині - max і min точно є, тому більша з двох - max.)

Задача 37. Найбільше і найменше значення z = x² - 2x + y² у крузі x² + y² ≤ 4.

Розвʼязання

Крок 1 (всередині). z'ₓ = 2x - 2 = 0, z'ᵧ = 2y = 0 ⇒ (1; 0), z = -1. Точка всередині круга (1 < 4).

Крок 2 (межа). y² = 4 - x², тоді z = x² - 2x + 4 - x² = 4 - 2x, x ∈ [-2; 2]. Лінійна: найбільше при x = -2: 8; найменше при x = 2: 0.

Крок 3. Порівнюємо -1, 8, 0: найбільше 8 у (-2; 0), найменше -1 у (1; 0).
