Механіка - теорія до іспиту

Звідки: лекція 1 і практична 1 (кінематика) - є конспект. Теми 2-10 - конспектів лекцій нема, усе з підручника: Слободянюк О.В. «Механіка», 2016 (далі Сл., номер формули і сторінка). Біля таких тем стоїть позначка «[нема конспекту - звір з лекцією]». Силабусу нема, тож список тем - припущення. g = 9,8 м/с², як на практичних.

Позначення як у підручнику, з двома відмінностями: швидкість пишу v (у Сл. грецька υ), коефіцієнт тертя пишу μ (у Сл. він k, як і жорсткість пружини). Кінетична енергія тут E_k (у Сл. T, не плутай з періодом).

Тема 1. Кінематика точки, рух по колу

Кінематика описує рух, не питаючи, чому тіло рухається. Система відліку = тіло відліку + система координат + годинник. Матеріальна точка - тіло, розміри якого в цій задачі не важать.

Рух можна описати трьома способами: координатами x(t), y(t), z(t); радіус-вектором r(t) = x·i + y·j + z·k; або довжиною дуги s(t) вздовж відомої траєкторії.

<v> = Δr / Δt        середня
v = dr/dt = ṙ        миттєва
a = dv/dt = r̈

Крапка над буквою = похідна по часу. Швидкість завжди напрямлена по дотичній до траєкторії. Прискорення ділять на дві частини:

a_τ = d|v|/dt    міняє МОДУЛЬ v
a_n = v²/R       міняє НАПРЯМ v
|a| = √(a_τ² + a_n²)

R - радіус кривизни траєкторії. Звідси R = v²/a_n.

Усі шкільні формули - це інтеграли від означень (лектор вивів їх на лекції 1):

a = const:
v = v₀ + a·t
x = x₀ + v₀·t + a·t²/2
v² = v₀² + 2·a·s

Дві середні швидкості (практична 1): шляхова = весь шлях / весь час; середня швидкість переміщення = |Δr| / весь час. Якщо тіло розверталось, вони різні. Половини шляху з v₁ і v₂ дають 2·v₁·v₂v₁ + v₂, половини часу - v₁ + v₂2.

Рух по колу (лекція 1):

ω = dφ/dt     ε = dω/dt
v = ω·R       a_τ = ε·R
a_n = v²/R = ω²·R
ω = ω₀ + ε·t
φ = φ₀ + ω₀·t + ε·t²/2
1 оберт = 2π рад
n об/хв → ω = 2π·n/60

Додавання швидкостей (Галілей, Сл. с. 77-78): швидкість відносно берега = швидкість відносно води + швидкість води. Ідея з практичної (катер і пліт): вибери систему відліку, в якій задача найпростіша.

Колесо, що котиться без ковзання: нижня точка в цю мить стоїть, верхня має 2v (Сл. (2.55), с. 46).

Тема 2. Динаміка точки: закони Ньютона, сили

[нема конспекту - звір з лекцією] Сл. розд. 3, с. 53-103.

Перший закон: існують системи відліку (інерціальні), в яких тіло без дії сил рухається рівномірно і прямолінійно або стоїть. Другий: m·a = F (векторна сума всіх сил), або dp/dt = F (Сл. (3.4), (5.3)). Третій: F₁₂ = -F₂₁ - сили рівні, протилежні і прикладені до різних тіл.

Сили, які треба знати (Сл. с. 63-70):

тяжіння        F = m·g
всесвітнє      F = G·m₁·m₂/r²
пружності      F = -k·x
тертя ковз.    F = μ·N
тертя спокою   F ≤ μ·N
опір (повільно) F = -k·v

Як розв'язувати будь-яку задачу на динаміку:

1. Кожне тіло окремо, усі сили на нього
2. m·a = ΣF (векторно) для кожного
3. Вісь уздовж прискорення, проекції
4. Зв'язки: нитка нерозтяжна - однакові a;
   блок невагомий - однаковий натяг
5. Розв'язати систему, потім числа

Похила площина з тертям (Сл. (3.29)): a = g·(sin α - μ·cos α), коли тіло їде вниз. Тертя завжди проти руху, тому вгору і вниз прискорення різні.

Рух по колу: сума проекцій сил на напрям до центра = m·v²/R. «Доцентрова сила» - не окрема сила, а ця сума (наприклад, складова натягу в конічному маятнику).

Сила опору, що росте зі швидкістю (F = -k·v), дає не рівноприскорений рух, а експоненту: v = v₀·e^(-k·t/m).

Тема 3. Неінерціальні системи відліку, вага

[нема конспекту - звір з лекцією] Сл. розд. 4, с. 104-143.

У системі, що рухається з прискоренням a₀, закон Ньютона пишуть так само, але додають сили інерції (Сл. (4.16)-(4.17)):

m·a' = F + F_ін
F_ін = -m·a₀        поступальна
F_відц = m·ω²·r     відцентрова
F_К = -2m·[ω × v']  Коріоліса

Сила інерції - не взаємодія з якимось тілом, у неї нема «пари» за третім законом. Її додають лише для зручності, коли рахують у прискореній системі.

Вага - сила, з якою тіло тисне на опору або тягне підвіс (Сл. (4.47)): P = m·(g - a) векторно. Ліфт прискорюється вгору - вага більша, m(g + a). Вільне падіння - вага нуль (невагомість), хоча сила тяжіння є.

Коріоліс у північній півкулі відхиляє тіло праворуч від руху. Горизонтальна складова для руху по поверхні: F = 2m·Ω·v·sin φ (φ - широта).

Тема 4. Імпульс, центр мас, реактивний рух

[нема конспекту - звір з лекцією] Сл. розд. 5.1, 5.3, с. 146-189.

p = m·v
dp/dt = F,  Δp = F·Δt (стала F)
P = p₁ + p₂ + ...
dP/dt = F_зовн

Закон збереження імпульсу (Сл. (5.71)): у замкненій системі (зовнішніх сил нема або їх сума нуль) P = const. Внутрішні сили імпульс системи не міняють. Якщо зовнішні сили є, але їхня проекція на вісь нуль, зберігається проекція імпульсу на цю вісь (гармата під кутом на рейках).

Центр мас (Сл. (5.74)): R_C = (m₁r₁ + m₂r₂ + ...)/(m₁ + m₂ + ...). Імпульс системи P = M·V_C, а M·dV_C/dt = F_зовн - центр мас рухається так, ніби вся маса в ньому і всі зовнішні сили прикладені до нього. Нема зовнішніх сил - центр мас стоїть (людина в човні).

Ракета (Ціолковський, Сл. (5.92)): v = u·ln(m₀/m), u - швидкість газів відносно ракети. Щоб розігнатись до 7,9 км/с при u = 2 км/с, паливо має бути ~98 % маси.

Тема 5. Робота, енергія, закони збереження, зіткнення

[нема конспекту - звір з лекцією] Сл. розд. 5.2, 5.5, 5.6, с. 151-228.

δA = F·dr·cos α
A = F·s·cos α   (стала сила)
N = F·v         потужність
E_k = m·v²/2
E_k2 - E_k1 = A (усіх сил)

Сила ⊥ переміщенню роботи не робить (cos 90° = 0): сила тяжіння на горизонтальній дорозі, реакція опори, натяг нитки маятника.

Консервативна сила - її робота не залежить від шляху, лише від початку і кінця. Для неї є потенціальна енергія U, A₁₂ = U₁ - U₂, F = -dU/dx:

U = m·g·h      біля Землі
U = k·x²/2     пружина
U = -G·m·M/r   тяжіння (далеко)

Закон збереження енергії (Сл. (5.56)): нема тертя й інших сторонніх сил - E_k + U = const. Є тертя - E₂ - E₁ = A_тертя (від'ємна).

Зіткнення (Сл. 5.6.4): - абсолютно непружне - тіла злипаються; зберігається лише імпульс, частина енергії йде в тепло: v' = (m₁v₁ + m₂v₂)/(m₁ + m₂); - абсолютно пружне - зберігаються і імпульс, і енергія. Однакові маси при лобовому ударі обмінюються швидкостями.

Головне правило: удар і подальший рух - два етапи. На ударі - імпульс, після - енергія (балістичний маятник, пластилін на пружині).

Рідина (Сл. 5.6.3, с. 212): рівняння Бернуллі для стаціонарної течії ідеальної рідини P + ρ·g·h + ρ·v²/2 = const. Струмінь з отвору на глибині H під поверхнею широкого бака: v = √(2·g·H) (Торрічеллі).

Тема 6. Момент імпульсу, обертання твердого тіла

[нема конспекту - звір з лекцією] Сл. розд. 5.4, 6, с. 190-279.

L = [r × p]     M = [r × F]
dL/dt = M_зовн
L_z = I·ω       I·ε = M_z
E_k = I·ω²/2

Закон збереження моменту імпульсу (Сл. (5.100)): момент зовнішніх сил нуль - L = const. Сила, що проходить через вісь, моменту відносно цієї осі не дає. Тому коли тіло закріплене на осі, при ударі зберігається L, а імпульс - ні (вісь штовхає тіло).

Момент інерції I = Σ mᵢ·rᵢ² - «маса» для обертання. Таблиця (Сл. с. 247-260):

стрижень, вісь ⊥ через центр  m·l²/12
стрижень, вісь через кінець   m·l²/3
диск, суцільний циліндр       m·R²/2
обруч, тонкостінний циліндр   m·R²
куля (зі шпаргалки модуля)    2m·R²/5
Штейнер:  I = I_C + m·d²

Відповідності: x ↔ φ, v ↔ ω, a ↔ ε, m ↔ I, F ↔ M, p ↔ L, m·v²/2 ↔ I·ω²/2.

Кочення без ковзання: v = ω·R, E_k = m·v²/2 + I·ω²/2. Скочування з похилої (Сл. (6.69)): a = g·sin α / (1 + I/(m·R²)). Що більший I, то повільніше котиться.

Масивний блок: натяги нитки з двох боків різні, (T₁ - T₂)·R = I·ε.

Тема 7. Коливання

[нема конспекту - звір з лекцією] Сл. розд. 3.6, 8.1-8.2, с. 93-99, 310-350.

Гармонічні коливання (Сл. (3.39)-(3.40)): ẍ + ω₀²·x = 0, розв'язок x = A·cos(ω₀·t + φ).

пружинний       ω₀ = √(k/m)
математичний    ω₀ = √(g/l)  (малі кути)
фізичний        T = 2π·√(I/(m·g·d))
T = 2π/ω₀       ν = 1/T
v_max = A·ω₀    a_max = A·ω₀²
E = k·A²/2

У фізичному маятнику d - відстань від осі до центру мас, I - відносно осі (Штейнер).

Згасання (Сл. (8.9)-(8.20)): ẍ + 2β·ẋ + ω₀²·x = 0, x = a₀·e^(-β·t)·cos(ω_β·t + φ), ω_β = √(ω₀² - β²). Час релаксації τ = 1/β - за нього амплітуда падає в e разів. Логарифмічний декремент λ = β·T_β.

Вимушені коливання, резонанс (Сл. (8.42)): ω_рез = √(ω₀² - 2β²) - трохи менше за ω₀. Амплітуда в резонансі скінченна завдяки згасанню.

Тема 8. Всесвітнє тяжіння

[нема конспекту - звір з лекцією] Сл. розд. 7, с. 280-309.

F = G·m₁·m₂/r²
g = G·M/R²   ⇒  G·M = g·R²
v₁ = √(G·M/R) ≈ 7,9 км/с
v₂ = √2·v₁ ≈ 11,2 км/с
T²/a³ = 4π²/(G·M)   (Кеплер 3)

На коловій орбіті сила тяжіння і є доцентровою: G·M·m/r² = m·v²/r. Невагомість на орбіті - не відсутність тяжіння (на висоті МКС g ≈ 8,7 м/с²), а те, що станція і космонавт разом падають з однаковим прискоренням. mgh годиться лише біля поверхні; на висотах порядку R_З треба U = -G·M·m/r.

Тема 9. Пружні хвилі

[нема конспекту - звір з лекцією] Сл. розд. 8.3, с. 351-406.

λ = v·T = v/ν
ζ = a·cos(ω·t - k·z + α)
k = 2π/λ,  v = ω/k
стрижень (поздовжня): v = √(E/ρ)
Допплер:
ν = ν₀·(v + v_п)/(v - v_д)

У формулі Допплера v_п - швидкість приймача до джерела, v_д - джерела до приймача. Наближаються - частота вища, віддаляються - нижча.

Тема 10. Основи СТВ

[нема конспекту - звір з лекцією] Сл. розд. 9, с. 409-464.

β = v/c,  γ = 1/√(1 - β²)
l = l₀·√(1 - β²)   скорочення
τ = τ₀/√(1 - β²)   сповільнення
v = (v₁ + v₂)/(1 + v₁·v₂/c²)
E = γ·m·c²,  E₀ = m·c²
E_k = (γ - 1)·m·c²
p = γ·m·v
E² = (p·c)² + (m·c²)²

l₀ і τ₀ - власні: виміряні в системі, де тіло стоїть. Рухомий стрижень коротший, рухомий годинник іде повільніше. Релятивістське додавання ніколи не дає більше за c.
