Молекулярна фізика - типові задачі з розв'язаннями

Задачі з файлів підготовки (UNI2 і задачі до колоквіумів 1-2), числа перераховані генератором сайту tools/gen_mol.py (рахує з умови і звіряє з рядком «Відповідь»). Усі задачі «типові для теми», не з червоного збірника задач кафедри (його в теці нема). Сталі: R = 8,31 Дж/(моль·К), k = 1,38·10⁻²³ Дж/К, g = 9,8 м/с². Довідкові числа (σ, η, c, теплоти переходу) дано в умові - якщо викладач дасть інші, перерахуй.

На іспиті задача «середнього рівня, як на практичних». Оформлення: Дано (у СІ: К, м³, кг, кг/моль) → формула з підручника → розв'язок у буквах → числа → перевірка одиниць.

Задача 1. Маса газу в балоні

Балон 20 л містить азот при 27 °C і тиску 2 МПа. Яка маса азоту?

Розвʼязання

Крок 1. У СІ: V = 0,02 м³, T = 300 К, P = 2·10⁶ Па, μ = 0,028 кг/моль.

Крок 2. PV = (m/μ)RT ⇒ m = PVμ/(RT) = 2·10⁶·0,02·0,028/(8,31·300) = 1120/2493.

Відповідь: m = 0,449 кг.

Типова помилка: T = 27 (вийде 4,99 кг) або V = 20 (вийде 449 кг).

Задача 2. Суміш газів

У посудині 10 л є 14 г азоту і 16 г кисню при 300 К. Знайти тиск суміші і середню молярну масу.

Розвʼязання

Крок 1. ν(N₂) = 14/28 = 0,5 моль, ν(O₂) = 16/32 = 0,5 моль, разом 1 моль.

Крок 2. Дальтон: P = (ν₁ + ν₂)RT/V = 1·8,31·300/0,01.

Крок 3. <μ> = m/ν = 0,030/1.

Відповідь: P = 2,49·10⁵ Па; <μ> = 0,030 кг/моль.

Задача 3. Скільки повітря виходить з кімнати

Кімната 5 × 4 × 3 м, P = 100 кПа, повітря μ = 0,029 кг/моль. Скільки повітря при 20 °C? Скільки вийде через щілини, коли кімнату нагріють до 25 °C (тиск той самий)?

Розвʼязання

Крок 1. V = 60 м³, T₁ = 293,15 К, T₂ = 298,15 К.

Крок 2. m₁ = PVμ/(RT₁) = 10⁵·60·0,029/(8,31·293,15) = 71,4 кг.

Крок 3. Δm = m₁(1 - T₁/T₂) = 71,4·0,0168 = 1,20 кг.

Відповідь: m₁ = 71,4 кг; Δm = 1,20 кг.

Типова помилка: відношення температур у °C (20/25) - вийшло б 14 кг. Цікаво: U повітря в кімнаті не змінилась, бо U = (5/2)PV, а P і V ті самі.

Задача 4. Ізотермічне розширення

Розвʼязання

Крок 2. T = const, U залежить лише від T ⇒ ΔU = 0.

Крок 3. Q = ΔU + A = A.

Відповідь: A = 2739 Дж; ΔU = 0; Q = 2739 Дж.

Задача 5. Ізобарне нагрівання

0,5 моль азоту ізобарно нагріли на 100 К. Знайти A, ΔU, Q.

Розвʼязання 
A  = νRΔT = 0,5·8,31·100

Q  = ΔU + A
перевірка: Q = νC_PΔT, C_P = (7/2)R

Задача 6. Процес P ∝ V

1 моль одноатомного газу розширюється так, що P = αV, від 10 л до 20 л, T₁ = 300 К. Знайти T₂, роботу, ΔU, теплоту і молярну теплоємність у процесі.

Розвʼязання

Крок 1. PV = RT і P = αV ⇒ T ∝ V². T₂ = 300·4 = 1200 К.

Крок 2. Робота - площа трапеції під P = αV: A = (P₂V₂ - P₁V₁)/2 = R(T₂ - T₁)/2 = 8,31·900/2 = 3,74 кДж.

Крок 3. ΔU = (3/2)RΔT = 11,2 кДж. Q = ΔU + A = 15,0 кДж.

Крок 4. C = Q/ΔT = 16,6 Дж/(моль·К) = 2R. Перевірка: це політропа n = -1, C = C_V - R/(n - 1) = 1,5R + 0,5R.

Відповідь: T₂ = 1200 К; A = 3,74 кДж; ΔU = 11,2 кДж; Q = 15,0 кДж; C = 16,6 Дж/(моль·К).

Типова помилка: T₂ = 600 К «як в ізобарі». Тут і тиск зріс удвічі.

Задача 7. Що це за газ?

Для газу c_v = 650 Дж/(кг·К), c_p = 910 Дж/(кг·К). Знайти μ і число ступенів вільності.

Розвʼязання

Крок 1. Майєр для питомих: c_p - c_v = R/μ ⇒ μ = 8,31/260 = 0,032 кг/моль.

Крок 2. γ = 910/650 = 1,4; γ = (i + 2)/i ⇒ i = 2/(γ - 1) = 5.

Відповідь: μ = 0,032 кг/моль; i = 5 (кисень).

Задача 8. Теплоємність суміші

Суміш 1 моль гелію і 1 моль азоту. Знайти C_V, C_P і γ суміші (на моль).

Розвʼязання

Крок 1. Теплота на нагрівання суміші = сума теплот: C_V = (1,5R + 2,5R)/2 = 2R.

Крок 2. C_P = C_V + R = 3R; γ = 3R/2R = 1,5.

Відповідь: C_V = 16,6 Дж/(моль·К); C_P = 24,9 Дж/(моль·К); γ = 1,5.

Типова помилка: (1,67 + 1,40)/2 = 1,53 - γ не усереднюють.

Задача 9. Адіабатне стиснення

Повітря (γ = 1,4) при 300 К адіабатно стиснули в 10 разів. Кінцева температура і у скільки разів зріс тиск?

Розвʼязання

Крок 1. TV^(γ-1) = const ⇒ T₂ = 300·10^0,4 = 300·2,512.

Крок 2. PV^γ = const ⇒ P₂/P₁ = 10^1,4.

Відповідь: T₂ = 754 К; P₂/P₁ = 25,1.

Так запалюється суміш у дизелі. Типова помилка: γ замість γ - 1 у показнику для T.

Задача 10. Політропа

Азот перейшов з P₁ = 10⁵ Па, V₁ = 4 л у P₂ = 8·10⁵ Па, V₂ = 1 л політропно. Знайти n, C, A.

Крок 2. C = C_V - R/(n - 1) = 20,8 - 16,6 = 4,16 Дж/(моль·К).

Крок 3. A = (P₁V₁ - P₂V₂)/(n - 1) = (400 - 800)/0,5.

Мінус: газ стискали, роботу робили над ним.

Задача 14. Цикл-прямокутник

1 моль одноатомного газу: дві ізохори V₁ = 10 л, V₂ = 20 л і дві ізобари P₁ = 10⁵ Па, P₂ = 2·10⁵ Па (за годинниковою стрілкою). Знайти ККД і порівняти з Карно між крайніми T.

Задача 18. ΔS між довільними станами

Задача 19. Змішали гарячу і холодну воду

0,2 кг води при 80 °C і 0,3 кг при 20 °C, c = 4190 Дж/(кг·К). Кінцева температура і ΔS?

Розвʼязання

ΔS₁ = 4190·0,2·ln(317,15/353,15) = -90,1
ΔS₂ = 4190·0,3·ln(317,15/293,15) = +98,9

Відповідь: T = 317 К; ΔS = 8,81 Дж/К.

ΔS > 0 - необоротний процес в ізольованій системі.

Задача 23. Склад повітря на висоті 10 км

Ізотермічна атмосфера T = 280 К. У скільки разів концентрація азоту на 10 км менша, ніж біля землі? Як зміниться відношення концентрацій кисню і азоту?

Задача 31. Ізотермічне розширення газу ВдВ

1 моль CO₂ при 300 К ізотермічно з 1 л до 10 л. Знайти ΔU, роботу, роботу ідеального газу, теплоту.

Розвʼязання

Крок 1. U = C_V T - a/V ⇒ ΔU = a(1/V₁ - 1/V₂) = 0,361·900.

Крок 2. A = ∫P dV = RT·ln((V₂ - b)/(V₁ - b)) - a(1/V₁ - 1/V₂) = 5839 - 325.

Крок 3. A_ід = RT·ln 10; Q = ΔU + A.

Відповідь: ΔU = 325 Дж; A = 5,51 кДж; A_ід = 5,74 кДж; Q = 5,84 кДж.

Типова помилка: ΔU = 0 «бо ізотерма». Це лише для ідеального газу.

Задача 39. Тиск насиченої пари (Клапейрон-Клаузіус)

Вода кипить при 100 °C під 101,3 кПа. Пара - ідеальний газ, r = 2,26·10⁶ Дж/кг стала. Тиск насиченої пари при 90 °C? При якій T вода кипить під 50 кПа?

Розвʼязання

Крок 1. dP/dT = r/(T·v_п), v_п = RT/(μP) ⇒ dP/P = (rμ/R)dT/T².

Крок 2. ln(P₂/P₁) = -(rμ/R)(1/T₂ - 1/T₁), rμ/R = 4895 К.

Крок 3. T₂ = 363,15 К: ln(P₂/P₁) = -0,3613 ⇒ P₂ = 101,3·0,6968.

Крок 4. P = 50 кПа: 1/T = 1/373,15 + 0,7061/4895.

Відповідь: тиск пари 70,6 кПа; температура кипіння 354 К.

Типова помилка: молярна теплота з питомими об'ємами (або навпаки).
