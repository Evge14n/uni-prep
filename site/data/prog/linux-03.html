Тема 3. День 3: Переглянути і редагувати: nano і VS Code

Навіщо: швидко глянути файл, поправити рядок у терміналі, а лаби писати в нормальному редакторі.

Коротко (5 хв)

Подивитись файл:

Команда Що робить
cat файл вивести весь файл (для коротких)
less файл гортати довгий: стрілки, пробіл, /слово - пошук, q - вийти
head -n 20 файл перші 20 рядків
tail -n 20 файл останні 20 рядків
wc -l файл скільки рядків

Нове тут:

  • cat - показує вміст файлу. Назва: concatenate - «зчепити» (уміє склеїти кілька файлів в один вивід).
  • less - гортає довгий файл по сторінках, вихід q. Назва: less - «менше»: жарт, бо less is more - кращий за старий переглядач more.
  • head - показує перші рядки файлу (або того, що прийшло через |). Назва: head - «голова». -n (--lines) - скільки перших рядків показати: -n 3, коротко -3 (lines - «рядки»).
  • tail - показує останні рядки (файлу чи того, що прийшло через |). Назва: tail - «хвіст». -n (--lines) - скільки останніх рядків показати: -n 3, коротко -3.
  • wc - рахує рядки, слова, символи. Назва: word count - «підрахунок слів»; рахує ще рядки й байти. -l (--lines) - лише кількість рядків.

Як читати:

  • Слово з мінусом (як -n тут) - прапорець: уточнює, що саме зробити команді.
  • Якщо поруч у дужках стоїть довга назва з двома мінусами - це той самий прапорець, пиши будь-яку одну.
  • Символи ~ # набирай в англійській розкладці (~ - Shift і клавіша ліворуч від 1; # - Shift і 3 (в українській розкладці там №)).

Усе про кожну команду - у вкладці «Команди», а тут торкнись команди в коді - вискочить підказка.

nano - простий редактор у терміналі. nano файл.py відкриває (або створює) файл. Підказки внизу: ^ - це Ctrl.

Нове тут:

  • nano - простий редактор файлів у терміналі. Назва: nano - жарт з одиницями: наступник редактора pico (піко < нано).
Клавіші Що
Ctrl+O, Enter зберегти (Write Out); Ctrl+S теж зберігає
Ctrl+X вийти (якщо не зберіг - спитає: Y/N)
Ctrl+W пошук
Ctrl+K / Ctrl+U вирізати рядок / вставити
Alt+U скасувати
Ctrl+_ перейти до рядка за номером (зручно, коли flake8 каже «рядок 19»)

VS Code - для лаб. У теці лаби:

cd ~/univer/labs/ЛР4
code .

Нове тут:

  • cd - переходить в іншу теку. Назва: change directory - «змінити теку».
  • ~ (tilde) - твоя домашня тека, /home/evgen.
  • code - відкриває файл або теку у VS Code. Назва: code - від Visual Studio Code («код»). . - крапка = поточна тека: відкрити її всю як проєкт.

Відкриється VS Code у режимі WSL (унизу ліворуч зелене «WSL: Ubuntu»). Терміналом усередині VS Code (Ctrl+- клавіша ліворуч від 1, або меню Terminal → New Terminal) є Ubuntu. Python-розширення бачить venv: Ctrl+Shift+P → «Python: Select Interpreter» →~/univer/.venv/bin/python`.

Кінці рядків. Windows закінчує рядок двома символами (CRLF, \r\n), Linux - одним (LF, \n). Python усе одно, а bash-скрипт з CRLF ламається: bash: $'\r': command not found. Перевірити: file скрипт.sh (буде «with CRLF line terminators»). У VS Code внизу праворуч напис CRLF - клікни і вибери LF.

Нове тут:

  • file - каже, що за файл за його вмістом. Назва: file - «файл».

Руками (10 хв)

cd ~/univer/praktyka
nano hello.py

Надрукуй:

name = input("Як тебе звати? ")
print(f"Привіт, {name}!")

Ctrl+O, Enter, Ctrl+X. Далі:

cat hello.py
python3 hello.py
wc -l hello.py          # 2 hello.py
head -n 1 hello.py
less ~/.bashrc          # погортай, знайди /univer, вийди q
tail -n 25 ~/.bashrc    # тут команди univer і perevir
code .                  # відкрий hello.py у VS Code, допиши рядок, Ctrl+S
cat hello.py            # бачиш зміну з VS Code
file hello.py

Нове тут:

  • python3 - запускає Python: твій файл .py, один рядок коду або вбудований інструмент. Назва: Python - на честь комедійного шоу «Monty Python», 3 - третя версія мови.
  • # (hash) - коментар: далі до кінця рядка bash не читає.

Типові помилки

  • Натиснув Ctrl+Z у nano (як «скасувати» у Windows) - нічого не скасувалось, а внизу напис [ To suspend, type ^T^Z ]. Скасувати в nano - Alt+U. (У звичайному терміналі Ctrl+Z призупиняє програму - день 6.)
  • Ctrl+S поза nano (просто в терміналі) може «заморозити» вікно - нічого не друкується. Розморозити - Ctrl+Q.
  • cat на величезний файл засипає екран - для довгих бери less.
  • Відкрив code . у /mnt/c/... - VS Code працює, але повільніше. Лаби - у ~/univer/labs.
  • Редагував файл у Блокноті Windows через \\wsl.localhost\... і він став CRLF. Краще VS Code.

Самоперевірка

  1. Як зберегти файл і вийти з nano?
  2. Як подивитись останні 5 рядків файлу log.txt?
  3. Що означає помилка $'\r': command not found і як виправити?
  4. Як відкрити поточну теку у VS Code з Ubuntu?
  5. Чим less кращий за cat для довгого файлу?
Відповіді
  1. Ctrl+O, Enter (зберегти), Ctrl+X (вийти).
  2. tail -n 5 log.txt.
  3. Файл має кінці рядків Windows (CRLF), bash бачить зайвий символ \r. Виправити: у VS Code переключити CRLF на LF і зберегти, або sed -i 's/\r$//' файл.
  4. code . (крапка - поточна тека).
  5. less показує по екрану, можна гортати назад і шукати /слово; cat вивалює все одразу.

Нове тут:

  • sed - друкує потрібні рядки або замінює текст. Назва: stream editor - «потоковий редактор». -i (--in-place) - змінити САМ файл (без -i sed лише показує); -i.bak - ще й копія (in-place - «на місці»).
  • '...' (single quotes) - текст буквально: $, * і пробіли всередині - звичайні символи.
