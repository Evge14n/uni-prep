Тема 5. День 5: Пакети: apt

Навіщо: у Linux програми не качають з сайтів, а ставлять однією командою з перевіреного сховища.

Коротко (5 хв)

apt - менеджер пакетів Ubuntu. Пакет = програма або бібліотека.

Команда Що робить
sudo apt update оновити список пакетів (нічого не ставить)
sudo apt upgrade поставити оновлення всього встановленого
sudo apt install tree встановити пакет
sudo apt remove tree видалити пакет
apt search turtle знайти пакет за словом
apt show python3-tk опис пакета
apt list --installed | grep python3 що з python3 встановлено

Нове тут:

  • sudo - виконує одну команду як адміністратор; спитає твій пароль (видно зірочки). Назва: superuser do - «зроби як суперкористувач» (адміністратор).
  • apt update - завантажує свіжий список програм і версій, нічого не ставить. Назва: apt - Advanced Package Tool - «розширений інструмент для пакетів (програм)».
  • apt upgrade - ставить новіші версії всіх встановлених програм. Назва: upgrade - «перейти на новішу версію».
  • apt install - ставить програму з інтернету; на «Бажаєте продовжити? [Y/n]» - Enter.
  • apt remove - видаляє програму, налаштування в /etc лишаються.
  • apt search - шукає програми за словом у назві: i - стоїть, p - ні.
  • apt show - показує опис програми (пакета): версію, розмір, від чого залежить.
  • apt list - показує список програм (пакетів): встановлених або з оновленнями. --installed - лише пакети, що вже стоять у системі (installed - «встановлені»).
  • | (pipe) - вивід лівої команди йде на вхід правої.
  • grep - шукає рядки з текстом (у файлах або те, що прийшло через |). Назва: g/re/p з редактора ed: global regular expression print - «скрізь знайти шаблон, надрукувати».

Як читати:

  • Слово з мінусом (як -l тут) - прапорець: уточнює, що саме зробити команді.
  • Якщо поруч у дужках стоїть довга назва з двома мінусами - це той самий прапорець, пиши будь-яку одну.
  • Символи | > & # набирай в англійській розкладці (| - Shift і клавіша \; # - Shift і 3 (в українській розкладці там №)).

Усе про кожну команду - у вкладці «Команди», а тут торкнись команди в коді - вискочить підказка.

Порядок завжди: спершу update, потім install або upgrade. Раз на тиждень - sudo apt update && sudo apt upgrade. && - «другу команду лише якщо перша пройшла без помилки».

Нове тут:

  • && (AND) - друга команда - лише якщо перша вдалась.

Де шукати, чи програма є: which python3 → /usr/bin/python3. python3 --version - версія.

Нове тут:

  • which - показує, який саме файл запуститься. Назва: which - «котрий».
  • python3 - запускає Python: твій файл .py, один рядок коду або вбудований інструмент. Назва: Python - на честь комедійного шоу «Monty Python», 3 - третя версія мови. --version - надрукувати версію Python, напр. Python 3.12.3.

apt чи pip? - apt - для системи: python3, git, nano, python3-tk. - pip - для Python-бібліотек у venv твого проєкту: matplotlib, numpy, pytest (день 8). - pip install поза venv в Ubuntu 24.04 дає помилку externally-managed-environment. Це захист, щоб не зламати системний Python. Не обходь її прапорцем --break-system-packages - просто увімкни venv.

Нове тут:

  • pip install - ставить бібліотеку Python (лише у venv). Назва: pip - pip installs packages - «pip ставить пакети» (назва, що посилається сама на себе); pip installs packages - «pip ставить пакети»; install - «встановити».

Руками (10 хв)

sudo apt update
apt list --upgradable           # що можна оновити
which tree
apt show tree | head -5
sudo apt install cowsay         # кумедна програма для тренування
/usr/games/cowsay "Привіт, Linux"
sudo apt remove cowsay
/usr/games/cowsay "ще є?"       # No such file or directory - видалено
dpkg -l python3-tk | tail -1    # ii = встановлено (його поставив ustanovka.sh)
deactivate 2>/dev/null         # вимкнути venv, якщо був увімкнений (рядок без (.venv))
pip install requests            # error: externally-managed-environment - так і треба (буває, думає кілька секунд)
python3 -m venv --help | head -3

Нове тут:

  • apt list: --upgradable - лише пакети, для яких є новіша версія; список свіжий після sudo apt update (upgradable - «можна оновити»).
  • apt remove: cowsay - пакет-іграшка (корова в терміналі): на ньому зручно вчитись ставити і прибирати програми.
  • # (hash) - коментар: далі до кінця рядка bash не читає.
  • head - показує перші рядки файлу (або того, що прийшло через |). Назва: head - «голова». -5 - лише 5 перші рядки (те саме, що -n 5); -3 - лише 3 перші рядки (те саме, що -n 3).
  • "..." (double quotes) - усе між лапками - одне слово, навіть з пробілами.
  • dpkg - ставить один файл .deb і веде список встановлених програм. Назва: Debian package - «пакет Debian». -l (--list) - рядок стану пакета: ii - встановлено, rc - видалено, лишились налаштування (list - «список»).
  • tail - показує останні рядки (файлу чи того, що прийшло через |). Назва: tail - «хвіст». -1 - лише 1 останний рядок (те саме, що -n 1).
  • deactivate - вимикає venv (окремий Python проєкту): python знову системний. Назва: deactivate - «вимкнути» (venv). 2 - у deactivate 2>/dev/null це не слово для deactivate: 2> ховає помилку, якщо venv і так вимкнений.
  • 2> (redirect stderr) - пише лише помилки у файл.
  • python3 -m venv - створює venv - окрему теку з Python і бібліотеками для лаб. Назва: virtual environment - «віртуальне середовище». --help - довідка: усі прапорці venv.
  • python3: -m - запусти модуль Python (вбудований чи поставлений через pip) як програму, напр. python3 -m venv (module - «модуль»).
  • ./скрипт - запускає програму за шляхом до її файлу, напр. ./файл.sh. Назва: ./ - «звідси».

Типові помилки

  • apt install без sudo → «Permission denied» / «are you root?».
  • install без update після довгої перерви → «Unable to locate package» або 404. Спершу sudo apt update.
  • Could not get lock /var/lib/dpkg/lock-frontend - інший apt уже працює (часто автооновлення у фоні). Зачекай кілька хвилин. Не видаляй lock-файли.
  • Закрив вікно Ubuntu посеред upgrade → наступного разу «dpkg was interrupted». Виправлення: sudo dpkg --configure -a. (Так сталося і в мене під час налаштування твого ПК 17.11.)
  • sudo pip install або --break-system-packages - ламає системний Python. Бібліотеки - у venv.

Нове тут:

  • dpkg: --configure - доналаштовує розпаковані пакети; з -a - усі, які перервались (configure - «налаштувати»); -a (--pending) - з --configure: усі пакети, що чекають налаштування (pending - «ті, що чекають»).

Самоперевірка

  1. Чим apt update відрізняється від apt upgrade?
  2. Як встановити програму htop?
  3. Що означає && у sudo apt update && sudo apt upgrade?
  4. Чому pip install numpy поза venv дає externally-managed-environment?
  5. Що робити, якщо бачиш «dpkg was interrupted»?
Відповіді
  1. update лише оновлює список доступних версій, upgrade реально ставить новіші версії встановлених пакетів.
  2. sudo apt update, потім sudo apt install htop.
  3. Друга команда виконається лише якщо перша завершилась успішно.
  4. Ubuntu захищає системний Python від сторонніх пакетів (правило PEP 668). Ставити треба у venv.
  5. sudo dpkg --configure -a - доналаштує обірвані пакети; потім повторити свою команду.
