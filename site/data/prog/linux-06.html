Тема 6. День 6: Процеси

Навіщо: програма з нескінченним циклом (у лабах буває) - її треба вміти зупинити, а не закривати вікно.

Коротко (5 хв)

Процес = запущена програма. У кожного є номер PID.

Команда / клавіші Що робить
Ctrl+C зупинити програму, що працює зараз у терміналі
Ctrl+D «кінець вводу»: вийти з python3 без аргументів, закрити input()
Ctrl+Z призупинити (не зупинити!) і повернути термінал
jobs що призупинено або працює у фоні в цьому терміналі
fg повернути призупинене на передній план
bg продовжити призупинене у фоні
команда & одразу запустити у фоні
ps процеси цього терміналу
pgrep -af python усі процеси python: PID і команда
ps aux | grep python те саме по-старому (останній рядок - сам grep, його не чіпай)
top (вийти q) або htop живий список: хто їсть процесор і память
kill PID попросити процес завершитись
kill -9 PID вбити без питань (якщо kill не допоміг)
pkill назва вбити за назвою програми. Обережно: pkill python вбʼє ВСІ python, і ті, що працюють для VS Code
free -h, df -h скільки памʼяті, скільки місця на диску

Нове тут:

  • python3 - запускає Python: твій файл .py, один рядок коду або вбудований інструмент. Назва: Python - на честь комедійного шоу «Monty Python», 3 - третя версія мови.
  • jobs - показує програми, запущені у фоні чи призупинені в цьому вікні. Назва: jobs - «задачі».
  • fg - повертає задачу з фону у вікно. Назва: foreground - «передній план».
  • bg - продовжує призупинену (Ctrl+Z) програму у фоні. Назва: background - «задній план, фон».
  • ps - показує запущені програми (процеси) та їхні номери (PID). Назва: process status - «стан процесів». aux - без дефіса (старий стиль BSD): a - усіх користувачів, u - з власником і %CPU/%MEM, x - і без термінала.
  • pgrep - знаходить номери (PID) запущених програм за назвою. Назва: process grep - «grep по процесах». -a (--list-full) - друкувати поруч з PID повну команду (list full - «повний список»); -f (--full) - шукати слово в усьому командному рядку, а не лише в назві програми (full - «повний»).
  • | (pipe) - вивід лівої команди йде на вхід правої.
  • grep - шукає рядки з текстом (у файлах або те, що прийшло через |). Назва: g/re/p з редактора ed: global regular expression print - «скрізь знайти шаблон, надрукувати».
  • top - живий список програм, що працюють зараз (вийти - q). Назва: top - «верх».
  • htop - живий кольоровий список запущених програм; вийти - F10. Назва: h + top: h - Hisham, імʼя автора; top - старший список процесів.
  • kill - надсилає програмі сигнал (команду) «зупинись» за її номером PID. Назва: kill - «вбити». PID - номер процесу (запущеної програми) з pgrep -af назва або ps aux (другий стовпець); -9 - сигнал номер 9, SIGKILL: система вбиває програму одразу, вона не встигне зберегти файли - лише якщо звичайний kill не допоміг.
  • pkill - завершує запущені програми за назвою (усі, що підійшли). Назва: process kill - «вбити процес» (за назвою, а не за номером).
  • free - показує памʼять: скільки зайнято і доступно. Назва: free - «вільна» (скільки вільної памʼяті). -h (--human) - зручні одиниці Ki, Mi, Gi замість кілобайтів (human - «для людини»).
  • df - показує вільне місце на дисках. Назва: disk free - «вільне на диску». -h (--human-readable) - розміри в K, M, G замість кілобайтних блоків (human-readable).

Як читати:

  • Слово з мінусом (як -h тут) - прапорець: уточнює, що саме зробити команді.
  • Якщо поруч у дужках стоїть довга назва з двома мінусами - це той самий прапорець, пиши будь-яку одну.
  • Короткі можна склеювати: -af = -a і -f.
  • Символи ~ | > & # набирай в англійській розкладці (~ - Shift і клавіша ліворуч від 1; | - Shift і клавіша \; # - Shift і 3 (в українській розкладці там №)).

Усе про кожну команду - у вкладці «Команди», а тут торкнись команди в коді - вискочить підказка.

Повністю вимкнути Ubuntu (все зависло): у PowerShell Windows wsl --shutdown. Ubuntu також сама вимикається за кілька секунд, коли закриті всі її вікна - тоді все, що в ній працювало, теж зупиняється.

Руками (10 хв)

cd ~/univer/praktyka
printf 'import time\nn = 0\nwhile True:\n    n += 1\n    time.sleep(1)\n    print(n)\n' > forever.py
cat forever.py
python3 forever.py       # рахує 1, 2, 3... Натисни Ctrl+C
                         # KeyboardInterrupt - це нормально, програму зупинено
python3 forever.py       # знову, а тепер Ctrl+Z
jobs                     # [1]+ Stopped
fg                       # знову рахує; Ctrl+C
python3 forever.py > /dev/null &     # у фоні, вивід викидаємо
jobs
pgrep -af forever        # PID і команда
kill %1                  # %1 - номер у jobs (або kill PID з pgrep)
jobs                     # Terminated
top                      # подивись, q - вийти
free -h
df -h ~

Нове тут:

  • cd - переходить в іншу теку. Назва: change directory - «змінити теку».
  • ~ (tilde) - твоя домашня тека, /home/evgen.
  • printf - друкує текст; \n у ньому - Enter (новий рядок). Назва: print formatted - «надрукувати за шаблоном».
  • '...' (single quotes) - текст буквально: $, * і пробіли всередині - звичайні символи.
  • > (redirect) - пише вивід у файл, старий вміст стирає.
  • cat - показує вміст файлу. Назва: concatenate - «зчепити» (уміє склеїти кілька файлів в один вивід).
  • # (hash) - коментар: далі до кінця рядка bash не читає.
  • & (ampersand) - запускає команду у фоні, термінал лишається вільним.
  • kill: %1 - задача номер 1 з jobs у ЦЬОМУ вікні термінала (з іншого вікна - лише PID).
  • df: ~ - розділ, де лежить твоя домашня тека.

Типові помилки

  • Ctrl+Z замість Ctrl+C - програма «зникла», але висить у памʼяті. jobs покаже. Потім fg і Ctrl+C.
  • Закривати вікно хрестиком, щоб зупинити програму. Працює, але втрачаєш усе в терміналі.
  • kill -9 одразу. Спершу звичайний kill: програма встигне закрити файли.
  • Програма чекає input(), а тобі здається, що вона зависла. Курсор блимає на порожньому рядку - вона чекає вводу. Введи значення або Ctrl+D.
  • Ctrl+C у вікні терміналу без виділеного тексту - не «копіювати», а «зупинити». Як копіювати - день 1.

  5. Коли потрібен wsl --shutdown?
Відповіді
  1. Ctrl+C зупиняє програму (Python кидає KeyboardInterrupt). Ctrl+Z лише призупиняє: програма жива, її можна повернути fg.
  2. Ctrl+C. Якщо не реагує - в іншому вікні pgrep -af python і kill PID (у крайньому разі kill -9 PID).
  3. pgrep -af python (перше число в рядку - PID). Або ps aux | grep python (друга колонка; рядок з самим grep пропусти).
  4. Запускає команду у фоні, термінал одразу вільний.
  5. Коли зависла вся Ubuntu (не відповідає жодне вікно) або після зміни налаштувань WSL. Виконується в PowerShell Windows.
