Крок 5. Налагодження (pdb)

  • Зламана програма: bug_4.py - кроки часу по 0.1 с - Bug_4.py - цикл з кроком 0.1 с не закінчується: чому float не дорівнює рівно 1.0. Знайди помилку способом з уроків 05-06 (traceback, print, assert, pdb), потім звір з розбором під програмою.

Нагадування pdb: python3 -m pdb файл.py, далі n (рядок), s (усередину функції), p змінна, c (далі), q; після падіння - python3 -m pdb -c continue файл.py (post-mortem). Детально - урок 06.
