Модуль 4. ЛР4: turtle, анімація і події

ЛР4: малюнки turtle, годинник з мишею і клавішами, анімація зіткнень кульок. Нове в терміналі - вікно програми: як відкрити, закрити, що робити, коли не зʼявляється.

Кроки по порядку - кожен наступний спирається на попередній. Разом ≈ 4 год 35 хв роботи, це ≈ 7 днів по 30-40 хв (орієнтовно). Графік і бот розкладають це по днях у межах 30-40 хв: першими лаби і Linux Mint, частина уроків Git - після ЛР7, уроків Python і безпеки в графіку нема. Встигаєш більше - іди по модулю.

Крок 4. Лаба в терміналі (розбір з підказками)

  • Урок 09. ЛР4 у терміналі (turtle) - у ЛР4 програма малює у вікні. Треба знати, як це вікно відкрити з термінала, як його закрити, що робити, коли воно не зʼявляється, і як перевіряти математику doctest-ом без вікна взагалі.
  • ЛР4 - розбір по завданнях: підказки трьома рівнями
  • Сама лаба: ЛР4: зробити самому в терміналі і перевірити перед здачею - напиши ЛР4 з нуля в nano: кожне завдання, doctest після кожної функції; перевір: розділ «Перевір перед здачею» уроку: doctest зелені, flake8 без зауважень, назви з умови

Окремо є розбір ЛР4 по завданнях: підказки трьома рівнями, без готового коду.

Крок 5. Налагодження (pdb)

  • Зламана програма: bug_1.py - середнє g - Bug_1.py - середнє менше за кожне вимірювання: де цикл губить елемент. Знайди помилку способом з уроків 05-06 (traceback, print, assert, pdb), потім звір з розбором під програмою.

Нагадування pdb: python3 -m pdb файл.py, далі n (рядок), s (усередину функції), p змінна, c (далі), q; після падіння - python3 -m pdb -c continue файл.py (post-mortem). Детально - урок 06.
