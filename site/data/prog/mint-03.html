Урок 03. Термінал для лаб - теки, файли, nano, запуск, venv

← Усі уроки

Навіщо: це мінімум, щоб уже сьогодні сісти за ЛР1 без VS Code: зробити теку, написати файл у nano, запустити, подати ввід, зупинити програму і поставити venv з pytest, flake8, mypy.

Коротко

Термінал відкривається клавішами Ctrl+Alt+T. Копіювати в ньому - Ctrl+Shift+C, вставити - Ctrl+Shift+V. Звичайний Ctrl+C у терміналі не копіює, а зупиняє програму, що зараз працює.

Рядок-запрошення (prompt) - термінал чекає команду:

evgen@назва-ноутбука:~/univer/labs/lr1$
  │        │           │                └ $ - чекаю команду (# - якщо ти root)
  │        │           └─────────────────── де ти зараз (~ = /home/evgen, домашня тека)
  │        └─────────────────────────────── імʼя компʼютера
  └──────────────────────────────────────── твій логін

Файли в Linux - одне дерево з коренем /. Твоє робоче місце для лаб:

/home/evgen/              = ~  (домашня тека)
└── univer/
    ├── .venv/            віртуальне середовище Python (крапка = прихована тека)
    └── labs/
        ├── lr1/          hello.py, lab1.py ...
        └── lr2/
Команда Що робить
pwd де я зараз
ls, ls -la що тут; -l детально, -a з прихованими (імʼя з крапки)
cd тека, cd .., cd, cd - зайти; на рівень вище; додому; туди, де був перед цим
mkdir -p ~/univer/labs/lr1 зробити теку разом з усіма проміжними (-p)
touch файл.py створити порожній файл
cat файл.py показати вміст файлу
clear або Ctrl+L очистити екран
Tab дописати назву файлу чи теки (два Tab - показати варіанти)
↑, history, Ctrl+R попередня команда; уся історія; пошук в історії

nano - простий редактор у терміналі (версія 7.2). nano hello.py відкриває файл або створює новий. Внизу підказки, ^ = Ctrl, M- = Alt. Усе в таблиці перевірено в nano 7.2 на Mint 22.3:

Клавіші Що
Ctrl+S зберегти
Ctrl+O, потім Enter зберегти (Write Out) - так написано в підказці
Ctrl+X вийти (якщо не зберіг, спитає Save modified buffer? - Y або N)
Alt+U скасувати (undo). Ctrl+Z тут НЕ скасовує
Ctrl+W пошук (Where Is)
Ctrl+K / Ctrl+U вирізати рядок / вставити
Ctrl+_ перейти до рядка за номером (у підказці ^/ Go To Line)
Alt+N показати / сховати номери рядків ([ Line numbering enabled ], укр. [ Нумерація рядків дозволено ])
Ctrl+G довідка

На українській Mint підказки внизу nano теж українською: ^O Виписати, ^X Вихід, ^W Пошук (переклад nano з пакета мови; клавіші ті самі).

Відкрити файл одразу на рядку 19 (коли flake8 каже «рядок 19»): nano +19 lab1.py.

Інші редактори коротко: - micro - як звичайний блокнот: Ctrl+S зберегти, Ctrl+Q вийти, Ctrl+Z скасувати. Ставиться sudo apt install micro. - vim - якщо випадково потрапив у нього: натисни Esc, набери :q! і Enter (вийти без збереження) або :wq і Enter (зберегти і вийти). - xed - звичайний віконний редактор Mint: xed hello.py & (& - щоб термінал лишився вільним).

Запуск Python:

Команда Що робить
python3 hello.py запустити програму
printf "5\n" \| python3 файл.py подати ввід для input() без клавіатури (\n = Enter)
Ctrl+C зупинити програму (зависла, нескінченний цикл)
python3 -i файл.py запустити, а потім лишитись у Python з усіма функціями файлу (>>>, вихід Ctrl+D)
source ~/univer/.venv/bin/activate увімкнути venv, на початку рядка зʼявиться (.venv)
deactivate вимкнути venv

venv (віртуальне середовище) - окрема тека з Python і бібліотеками саме для лаб. Бібліотеки ставиш у неї, а не в систему (урок 02 пояснює чому).

Передбач, потім запусти

  1. Ти в домашній теці. Що покаже останній рядок?
cd
mkdir -p univer/labs/lr1
cd univer/labs
cd ..
pwd

Нове тут:

  • cd - переходить в іншу теку. Назва: change directory - «змінити теку». .. - тека на рівень вище (з lr1 у labs); ../.. - на два рівні вище.
  • mkdir - створює нову теку. Назва: make directory - «зробити теку». -p - створює і всі проміжні теки шляху; якщо тека вже є - мовчить, без помилки.
  • pwd - показує, в якій теці ти зараз. Назва: print working directory - «надрукувати робочу (поточну) теку».

Усе про кожну команду - у вкладці «Команди», а тут торкнись команди в коді - вискочить підказка.

Відповідь 
/home/evgen/univer

cd univer/labs завів у /home/evgen/univer/labs, cd .. - на одну теку вище.

  1. Програма kolo.py з «Руками» (крок 3). Що побачиш?
printf "2\n" | python3 kolo.py

Нове тут:

  • printf - друкує текст за шаблоном; \n - Enter. Назва: print formatted - «надрукувати за шаблоном».
  • python3 - запускає Python: файл, рядок коду або модуль. Назва: Python - на честь комедійного шоу «Monty Python», 3 - третя версія мови.
  • "..." - текст з пробілами одним словом, $ підставляється. Назва: подвійні лапки - «усе це одне слово, але $ працює».
  • | - передає вивід однієї команди на ввід іншій. Назва: pipe - «труба» (пайп), вертикальна риска.
Відповідь 
Радіус: Площа: 12.57

Усе в одному рядку: input("Радіус: ") друкує підказку, а «Enter» з printf на екран не потрапляє - він пішов одразу в програму.

  1. А тепер з комою, як ми пишемо в зошиті:
printf "2,5\n" | python3 kolo.py
Відповідь

Помилка, останній рядок:

ValueError: could not convert string to float: '2,5'

Python розуміє лише крапку: 2.5. Це не баг програми, це ввід.

  1. У nano ти набрав рядок і натиснув Ctrl+Z, щоб скасувати. Що буде?
Відповідь

Нічого не скасується, а внизу зʼявиться [ To suspend, type ^T^Z ] (на українській Mint [ Для призупинення введіть ^T^Z ]). У nano скасування - Alt+U.

Руками

Крок 0. Доставити пакети для лаб (на свіжій Mint 22.3 їх нема: venv, pip, tkinter для turtle, git). Попросить пароль - замість символів зʼявляються зірочки **** (так налаштовано в Mint), це нормально.

sudo apt update
sudo apt install python3-venv python3-pip python3-tk git

Нове тут:

  • sudo - виконує одну команду від імені адміністратора (root). Назва: su do - «виконати як інший користувач», зазвичай root.
  • apt update - оновлює список пакетів, нічого не ставить. Назва: update - «оновити» (тут оновлюється лише список пакетів).
  • apt install - ставить програму (пакет) зі сховища. Назва: install - «встановити».

Крок 1. Тека для ЛР1.

mkdir -p ~/univer/labs/lr1
cd ~/univer/labs/lr1
pwd
touch hello.py
ls -la

/home/evgen/univer/labs/lr1
total 8
drwxrwxr-x 2 evgen evgen 4096 Nov 18 08:53 .
drwxrwxr-x 3 evgen evgen 4096 Nov 18 08:53 ..
-rw-rw-r-- 1 evgen evgen    0 Nov 18 08:53 hello.py

Нове тут:

  • touch - створює порожній файл або оновлює його час. Назва: touch - «торкнутися» файлу: оновити час зміни, а як нема - створити.
  • ls - показує, що лежить у теці. Назва: list - «список» (вмісту теки). -l - докладний список: права, власник, розмір у байтах, дата зміни (long); -a - показати й приховані (назва з крапки), разом з . і .. (all).
  • ~ - домашня тека /home/evgen. Назва: tilde («тильда») - домашня тека.

0 - розмір файлу в байтах (поки порожній). . - ця тека, .. - тека вище. Дата у тебе своя (можливо, українською).

Спробуй Tab: набери cd ~/uni і натисни Tab - допишеться univer/.

Крок 2. Налаштуй nano під Python, потім перша програма.

У Mint nano типово ставить на Tab справжній символ табуляції, а Python і flake8 хочуть 4 пробіли (інакше TabError або flake8 W191 indentation contains tabs). Потрібні опції в /etc/nanorc є, але закоментовані (# set tabstospaces). Увімкни їх для себе один раз - допиши у свій файл налаштувань ~/.nanorc:

printf 'set tabstospaces\nset tabsize 4\nset linenumbers\nset autoindent\n' >> ~/.nanorc
cat ~/.nanorc

set tabstospaces
set tabsize 4
set linenumbers
set autoindent

Нове тут:

  • cat - показує вміст файлу. Назва: concatenate - «зчепити»: склеює кілька файлів в один вивід. ~/.nanorc - твої налаштування nano (урок 03).
  • '...' - текст буквально, нічого не підставляється. Назва: одинарні лапки - «буквально, як написано».
  • >> - дописує вивід у кінець файлу. Назва: append - «дописати» в кінець файлу.

Тепер Tab = 4 пробіли, зліва номери рядків, а Enter зберігає відступ попереднього рядка. Команду виконай один раз (>> дописує в кінець файлу; вдруге рядки просто повторяться - це не шкодить).

nano hello.py

Нове тут:

  • nano - простий редактор файлів у терміналі. Назва: nano - жарт з одиницями: наступник редактора pico (піко < нано).

Набери:

name = input("Як тебе звати? ")
print(f"Привіт, {name}!")

Ctrl+S (зберегти), Ctrl+X (вийти). Далі:

cat hello.py
python3 hello.py

Програма спитає імʼя і чекатиме - набери його і натисни Enter. Без клавіатури:

printf "Прізвище\n" | python3 hello.py

Як тебе звати? Привіт, Прізвище!

import time

n = 0

    n += 1

python3 vichno.py

Через кілька секунд натисни Ctrl+C:

крок 1
крок 2

  File "/home/evgen/univer/labs/lr1/vichno.py", line 7, in <module>

^C - так термінал показує натиснуте Ctrl+C, і Python пише свій текст одразу після нього. KeyboardInterrupt - це не помилка в коді, а «тебе перервали з клавіатури».

Крок 5. Запустити і погратись з функцією. nano kub.py:

def kub(x: float) -> float:
    """Куб числа.

    >>> kub(2)
    8
    >>> kub(-3)
    -27
    """
    return x * x * x


print(kub(2))

python3 -i kub.py

Нове тут:

  • python3: -i - спершу виконати файл, а потім лишитись у Python з >>> і всіма його функціями.

Спершу файл виконається (надрукує 8), потім зʼявиться >>>. Набери kub(3), Enter, потім kub(1.5):

8
>>> kub(3)
27
>>> kub(1.5)
3.375
>>>

Вийти - Ctrl+D (або exit()).

Крок 6. venv з інструментами для перевірки лаб.

python3 -m venv ~/univer/.venv
source ~/univer/.venv/bin/activate
which python
python3 -m pip install pytest flake8 black mypy ruff pycodestyle

Нове тут:

  • python3: -m - запусти модуль як програму: python3 -m pytest, python3 -m venv, python3 -m pdb.
  • python3 -m venv - створює окреме середовище Python (venv) для бібліотек лаб. Назва: virtual environment - «віртуальне середовище». ~/univer/.venv - наш venv на всі лаби; крапка на початку - тека прихована (ls -a її покаже).
  • source - виконує файл у поточному bash (venv, ~/.bashrc). Назва: source - «джерело»: виконати команди з файлу-джерела. ~/univer/.venv/bin/activate - увімкнути venv для лаб; вимкнути - deactivate.
  • which - показує шлях до програми з PATH. Назва: which - «котрий»: котрий файл запуститься. python - у venv покаже ~/univer/.venv/bin/python; поза venv - тиша.
  • python3 -m pip install - ставить бібліотеки Python (лише у venv!). Назва: pip installs packages - «pip ставить пакети»; install - «встановити».

which python у venv покаже /home/evgen/univer/.venv/bin/python. Кінець справжнього виводу pip (версії у тебе можуть бути новіші):

Successfully installed ast-serialize-0.13.1 black-26.10.1 click-8.5.1 flake8-7.5.0 iniconfig-2.3.1 librt-0.16.0 mccabe-0.7.0 mypy-2.4.1 mypy-extensions-1.2.0 packaging-26.3 pathspec-1.1.1 platformdirs-4.14.7 pluggy-1.7.0 pycodestyle-2.15.0 pyflakes-4.1.0 pygments-2.21.0 pytest-9.2.0 pytokens-0.4.1 ruff-0.17.5 typing_extensions-4.16.0

Перевір (venv увімкнено):

python3 -m pytest --doctest-modules -q kub.py
python3 -m flake8 --max-line-length=78 kub.py
python3 -m mypy kub.py

Нове тут:

  • python3 -m pytest - проганяє doctest і дає чесний код виходу 0/1. Назва: py + test - «тести для Python». --doctest-modules - шукати doctest (приклади >>>) у файлах .py; без нього pytest шукає лише функції test_; -q - коротко: крапка за кожен тест і рядок підсумку «1 passed in 0.01s».
  • python3 -m flake8 - шукає помилки стилю і зайвий код, нічого не змінює. Назва: pyflakes + pep8: обʼєднав дві старі програми перевірки коду. --max-line-length - найбільша дозволена довжина рядка; викладач хоче 78 (типово 79).
  • python3 -m mypy - перевіряє типи (int, str ...) без запуску програми. Назва: назва не розшифровується (py - від Python).

pytest напише 1 passed, flake8 - нічого (тиша = зауважень нема), mypy - Success: no issues found in 1 source file. Вимкнути venv - deactivate (зникне (.venv)). Кожне нове вікно термінала стартує без venv - вмикай знову.

Крок 7. Інші редактори (за бажанням).

sudo apt install micro
micro hello.py
xed hello.py &

Нове тут:

  • micro - простий редактор у терміналі з Ctrl+S і Ctrl+Q. Назва: micro - «мікро»: маленький простий редактор. hello.py - файл, який відкрити; якщо його нема - створиться при збереженні.
  • xed - віконний редактор Mint, як Блокнот. Назва: x (набір програм X-Apps від Mint) + ed від editor - «редактор».
  • & - запускає команду у фоні, термінал лишається вільним. Назва: ampersand («амперсанд») - «запустити у фоні».

У micro: допиши щось, Ctrl+S, Ctrl+Q. xed відкриється вікном - знайомий вигляд, як Блокнот.

Крок 8. Скорочення - скрипт ustanovka-mint.sh. Він робить кроки 0 і 6 сам (ще ставить matplotlib, numpy, htop, tree) і додає дві команди: univer (перейти в ~/univer і увімкнути venv) і perevir файл.py (doctest через pytest, black, flake8, pycodestyle і ruff до 78 символів, mypy). ~/.nanorc (крок 2) він не чіпає.

cd ~
wget -O ustanovka-mint.sh https://evge14n.github.io/uni-prep/files/ustanovka-mint.sh
less ustanovka-mint.sh
bash ustanovka-mint.sh

Нове тут:

  • cd: ~ - домашня тека /home/evgen; ~/univer/labs - шлях від домашньої теки.
  • wget - завантажує файл з інтернету за адресою. Назва: World Wide Web + get - «дістати з вебу». -O - під яким імʼям зберегти; -O - (мінус) означає «на екран», щоб передати далі в трубу |.
  • less - гортає довгий файл по сторінках, вихід q. Назва: less - «менше»: жарт, бо less is more - кращий за старий переглядач more. ustanovka-mint.sh - прочитати чужий скрипт перед запуском (урок 03).
  • bash - оболонка, що виконує команди; bash файл.sh запускає скрипт. Назва: Bourne-Again SHell - «знову оболонка Борна» (гра слів: born again - «народжений знову»).

Якщо wget пише помилку 404 (файл на сайті ще не опублікований) або інтернету нема - скопіюй ustanovka-mint.sh з теки курсу (лежить поруч з уроками) у домашню теку, а далі так само: less, потім bash.

less - щоб спершу прочитати, що скрипт робить (гортати пробілом, вийти q). Чужі скрипти без читання не запускають. Потім відкрий нове вікно термінала і:

univer
cd labs/lr1

Нове тут:

  • univer - переходить у ~/univer і вмикає venv. Назва: наша назва: «універ» - тека ~/univer для навчання.

Для hello.py (він питає input()) perevir скаже:

doctest: файл питає input() при запуску. Дай відповіді після назви: perevir hello.py 5

Відповіді на input() пишуть після назви файлу через пробіл, кожна - окремий рядок вводу: perevir lr1_1.py 127 (урок 04). Doctest-ів у hello.py нема, тож perevir корисний насамперед для лаб, де doctest є.

Типові помилки

Повідомлення bash, mkdir і nano на українській Mint українською (у дужках), повідомлення Python - завжди англійською (див. «00 - Почни тут», «Мова повідомлень»).

  • bash: cd: Univer: No such file or directory (укр. bash: cd: Univer: Немає такого файла або каталогу) - великі й малі літери різні, тека univer. Тисни Tab, не вгадуй.
  • python3: can't open file '/home/evgen/univer/labs/lr1/Hello.py': [Errno 2] No such file or directory - не та назва або ти не в тій теці. pwd і ls.
  • bash: python: command not found (укр. bash: python: команду не знайдено) - поза venv у Mint є лише python3. У venv працюють обидва.
  • /usr/bin/python3: No module named ruff (або pytest, flake8) - venv вимкнено. Подивись, чи є (.venv) на початку рядка, і source ~/univer/.venv/bin/activate.
  • The virtual environment was not created successfully because ensurepip is not available. - не поставлено python3-venv (крок 0). Після установки видали недороблену теку ~/univer/.venv і створи venv знову.
  • mkdir: cannot create directory ‘...’: No such file or directory - забув -p, а проміжної теки ще нема. Укр.: mkdir: Не вдалося створити каталог «...»: Немає такого файла або каталогу.
  • flake8 W191 indentation contains tabs або Python TabError - nano вставив табуляцію: не налаштовано ~/.nanorc (крок 2). Налаштуй, а в зламаних рядках видали відступ і набери заново.
  • Програма «зависла» і нічого не пише - найчастіше вона чекає input(). Набери значення і Enter. Справді зависла - Ctrl+C.
  • Ctrl+S поза nano (просто в терміналі) «заморожує» вікно - нічого не друкується. Це старе керування потоком терміналу (ixon). Розморозити - Ctrl+Q.
  • python3 -m doctest файл.py на файлах викладача з doctest.testmod() у кінці показує чужу помилку 1 of 21 in __main__.DebugRunner, хоча твій код правильний. Перевіряй python3 файл.py -v або python3 -m pytest --doctest-modules файл.py (детально - урок 04). І памʼятай: python3 файл.py завершується «успішно» (код 0), навіть коли doctest впав - читай вивід.

Як роблять профі

  • Один проєкт - один venv, venv ніколи не кладуть у git і не копіюють між компʼютерами, а перестворюють зі списку requirements.txt (урок 02). Ми тримаємо один venv на всі лаби - для першого курсу цього досить.
  • Термінал - перше, чого вчать програмістів: курс MIT «Missing Semester» (січень 2026) починається саме з лекції про shell. Tab, ↑ і Ctrl+R замість набору вручну економлять години.
  • ruff - «надзвичайно швидкий лінтер і форматер», який, за словами авторів, може замінити flake8 і black. Але викладач просить flake8, pycodestyle, mypy, ruff або black - тому ставимо всі.
  • Не вставляй у термінал команду, якої не розумієш - спершу прочитай (less для скриптів, explainshell.com для рядків). Популярний пост r/linux4noobs (18.08.2026, 283 бали) - саме про це.

Самоперевірка

  1. Ти в ~/univer/labs/lr1. Куди потрапиш після cd ../..?
  2. Як зберегти файл у nano і вийти? Як скасувати останню дію?
  3. Програма питає два числа через input(). Як подати 3 і 4 без клавіатури?
  4. Як зрозуміти, що venv увімкнено, і як його увімкнути?
  5. python3 -m flake8 lab1.py пише /usr/bin/python3: No module named flake8. Що не так?
Відповіді
  1. /home/evgen/univer (lr1 → labs → univer).
  2. Ctrl+S (або Ctrl+O і Enter), потім Ctrl+X. Скасувати - Alt+U.
  3. printf "3\n4\n" | python3 файл.py - кожне \n це Enter для чергового input().
  4. На початку рядка (.venv), which python показує шлях з .venv. Увімкнути: source ~/univer/.venv/bin/activate (або univer, якщо запускав ustanovka-mint.sh).
  5. venv вимкнено, тому запустився системний Python, де flake8 нема. Увімкнути venv і повторити.
