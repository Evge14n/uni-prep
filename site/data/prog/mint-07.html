Завдання 2. «Простий» чат-бот (с. 12-18, клітинки 7-8). Вводять вік. Менше 0 → Ви ще не народилися, більше 140 → Стільки не живуть..., інакше Я думав, що Вам N рік/роки/років, де N = вік + 1. Дві функції: year_word(n) повертає «рік», «роки» або «років» і нічого не друкує; age_chat(age) друкує відповідь і для слова викликає year_word(age + 1). Тут if дозволений.

Завдання 3. Тіло, кинуте під кутом (с. 18-21, клітинки 9-10). Вводять висоту H, швидкість v0, кут alpha у градусах і момент t; g = 10 м/с². Файли з Telegram Desktop зазвичай лягають у ~/Завантаження/Telegram Desktop/ (не перевірено на ноутбуці; урок 04, крок 2). У назві теки пробіл - тому лапки:

Нове тут:

  • mkdir - створює нову теку. Назва: make directory - «зробити теку». -p - створює і всі проміжні теки шляху; якщо тека вже є - мовчить, без помилки.
  • cd - переходить в іншу теку. Назва: change directory - «змінити теку».
  • ls - показує, що лежить у теці. Назва: list - «список» (вмісту теки).
  • cp - копіює файл або теку. Назва: copy - «копіювати». . - «сюди», у поточну теку: cp ~/Завантаження/lab1.py .
  • ~ - домашня тека /home/evgen. Назва: tilde («тильда») - домашня тека.
  • "..." - текст з пробілами одним словом, $ підставляється. Назва: подвійні лапки - «усе це одне слово, але $ працює».

Усе про кожну команду - у вкладці «Команди», а тут торкнись команди в коді - вискочить підказка.

Нове тут:

Підказки до завдань (без розвʼязку)

Функції й оператори - Курс/ДОВІДНИК-ФУНКЦІЙ.md (тека курсу Python на ПК): «порівняння: < <= > >= == !=», «Що вважається False», math.cos(), math.sqrt(), math.pi, % (остача від ділення), f-рядок. Логіка і розгалуження - курс Python (тека Курс/), урок 03.

Завдання 1.

  • Намалюй рисунок на папері, познач усі 16 точок з doctest і для кожної скажи «в області чи ні» до коду.
  • Розбий область на прості шматки (під прямою, над прямою, всередині кола, у якій чверті) і з'єднай and / or. Кожен шматок - одна нерівність.
  • Пряма через дві точки. Приклад на інших точках (1, 1) і (3, 5): нахил (5 - 1) / (3 - 1) = 2, пряма y = 2·x - 1. «Над прямою» - y >= 2 * x - 1. Яка сторона потрібна, перевір точкою, про яку точно знаєш відповідь.
  • Щоб не мати дробів у нахилі, домнож нерівність на знаменник. Приклад на іншій прямій: y >= 4 / 9 * x те саме, що 9 * y >= 4 * x.
  • Коло з центром (2, 3) і радіусом 4 (інше, ніж на рисунку): точка всередині або на колі, якщо (x - 2) ** 2 + (y - 3) ** 2 <= 16.
  • <= чи < - це питання межі. Умова каже «включно з межею», але один doctest з цим не згоден (див. розділ «Коли помиляється doctest викладача»).
def in_band(x: float, y: float) -> bool:
    return 0 <= x <= 3 and not y > 2

Це інша фігура (смуга), але сам вигляд - «одразу return логічний вираз, без if» - якраз те, що треба.

Завдання 2.

  • Правило слів - с. 2 методички: закінчення на 1, крім 11; на 2, 3, 4, крім 12, 13, 14; решта. Остання цифра - n % 10, дві останні - n % 100 (див. «Передбач», пункт 5).
  • Порядок перевірок важливий: якщо спершу перевірити «закінчується на 1», то 11 і 111 стануть «рік» (див. «Типові помилки», п. 4).
  • age_chat друкує (print), а слово бере з year_word(age + 1). doctest age_chat без лапок - це друк.

Завдання 3.

  • Кут - у радіани: math.radians(alpha) (с. 8). math.sin(90) - це синус 90 радіан («Передбач», пункт 1).
  • Розклади швидкість на v0·cos α і v0·sin α, далі формули x(t), y(t), v(t) і максимальної висоти - с. 6-8.
  • Дальність: спершу час падіння T з умови y(T) = 0 - це квадратне рівняння відносно T; з двох коренів фізичний смисл має додатний. Потім дальність = горизонтальна швидкість × T.
  • Перевірки: подивись у doctest, які значення погані. t = 0.0 у першому doctest - нормальне значення. Повідомлень сім (поодинці, парами, усі три) - вибирай порядок перевірок так, щоб при двох поганих значеннях виходило повідомлення про пару, а не про одне.
  • Усі числа - формат :.2f.

Інший приклад з math (не з лаби): довжина гіпотенузи і кут у градусах.

import math

leg_a = 3.0
leg_b = 4.0
hypotenuse = math.sqrt(leg_a**2 + leg_b**2)
angle = math.degrees(math.atan2(leg_b, leg_a))
print(f"{hypotenuse:.2f} {angle:.2f}")  # 5.00 53.13

Передбач, потім запусти

  1. Синус 90 - це 1?
python3 -c 'import math; print(math.sin(90), math.sin(math.radians(90)))'

Нове тут:

  • python3: -c - виконати рядок коду з командного рядка, без файлу: python3 -c 'print(2 ** 10)'.
Відповідь 
0.8939966636005579 1.0

math.sin чекає радіани. 90 радіан - це не 90°. Без math.radians doctest завдання 3 не пройде.

  1. Косинус 90° - рівно нуль?
python3 -c 'import math; print(math.cos(math.radians(90)), f"{math.cos(math.radians(90)):.2f}")'
Відповідь 
6.123233995736766e-17 0.00

Дробові числа в компʼютері наближені: замість 0 вийшло 6·10⁻¹⁷. Формат :.2f показує 0.00, тому doctest з 0.00 проходить. Порівнювати такі числа через == не можна.

  1. Що з цього вийде?
python3 -c 'print(f"{-0.001:.2f}", 2 ** 3 ** 2, -2 ** 2)'
Відповідь 
-0.00 512 -4

Мінус зберігається навіть після округлення (-0.00 - не те саме, що 0.00 для doctest). ** рахується справа наліво: 3² = 9, потім 2⁹ = 512. А -2 ** 2 - це -(2 ** 2), бо ** сильніший за унарний мінус.

  1. Ланцюжок порівнянь і and/or:
python3 -c 'print(0 <= 5 <= 10, 5 > 3 and 2 > 4 or 1 > 0)'
Відповідь 
True True

0 <= 5 <= 10 - це 0 <= 5 and 5 <= 10. and виконується раніше за or: (True and False) or True = True. Ставь дужки, коли змішуєш and і or - так читати легше і помилитися важче.

  1. Останні цифри:
python3 -c 'print(111 % 100, 111 % 10, 1013 % 100)'
Відповідь 
11 1 13

У 111 остання цифра 1, але дві останні - 11, тому «111 років», а не «рік».

Типові помилки

Тексти - справжній вивід Python 3.12 у Mint 22.3.

1. Відʼємне число в printf. Справжній вивід у терміналі (printf "-5\n"):

bash: printf: -5: invalid option
printf: usage: printf [-v var] format [arguments]

На українській Mint: bash: printf: -5: неправильний параметр і printf: використовуйте: printf [-v змінна] шаблон-форматування [аргументи]. Пиши printf -- "-5\n" або printf '%s\n' -5 (Крок 3).

1а. Файлу нема там, звідки копіюєш (Крок 1):

cp: cannot stat '/home/evgen/Завантаження/Telegram Desktop/Лабораторна_робота_2Пайтон_2026_2027.ipynb': No such file or directory

укр.: cp: не вдалося виконати stat для '...': Немає такого файла або каталогу. Файл в іншій теці - find (Крок 1). Без лапок навколо Telegram Desktop - дві такі помилки (окремо для Telegram і для Desktop/...).

2. Запустив заготовку до введення. NameError: name 'x' is not defined (завдання 1) або NameError: name 'H' is not defined (завдання 3). mypy каже те саме: error: Name "x" is not defined [name-defined].

3. age_chat повертає замість друкувати. Приклад на іншій функції weather_chat:

Failed example:
    weather_chat(-3)
Expected:
    Холодно
Got:
    'Холодно'

Навпаки, ніж у ЛР1: тут Expected без лапок - функція має друкувати. Лапки в Got означають return.

4. Неправильний порядок перевірок у year_word. Якщо «закінчується на 1» перевіряється раніше за 11-14:

Failed example:
    year_word(11)
Expected:
    'років'
Got:

Коли помиляється doctest викладача

Завдання 1, точка (-5, 0). Вона лежить на межі - там, де дуга кола зустрічається з лівим відрізком. Умова каже «включно з межею», тобто мало б бути True. А doctest чекає:

    >>> check_point_belonging(-5, 0)
    False

Якщо всі межі в тебе нестрогі (<=), пройдуть 15 прикладів з 16:

Failed example:
    check_point_belonging(-5, 0)
Expected:
    False
Got:
    True
...
   1 of  16 in __main__.check_point_belonging

Що робити: це суперечність умови і doctest. Щоб doctest пройшли (а це критерій викладача), подумай, яку саме частину межі біля (-5, 0) треба зробити строгою, - і обовʼязково напиши викладачу про цю точку. Інша межова точка, (0, 5), у doctest True - тобто «межа рахується» для неї працює.

tasks_for_2_lab.py: заготовка завдання 2 - копія завдання 1, body_moving двічі (Крок 1).

Завдання 3, слова в повідомленнях: Time moment t must be positive number, але t = 0.0 у першому doctest дає нормальну відповідь - тобто t має бути невідʼємним, а не додатним. Що робити з H = 0 і v0 = 0, doctest не кажуть: обери за словом «positive» (тоді 0 - помилка) і будь готовий пояснити.

Довгий рядок doctest у завданні 3 (192 символи) - flake8 E501, як у ЛР1: не твоя помилка.

Нове тут:

  • python3: -m - запусти модуль як програму: python3 -m pytest, python3 -m venv, python3 -m pdb.
  • tail - показує останні рядки; -f стежить наживо. Назва: tail - «хвіст»: кінець файлу. -n - скільки останніх рядків показати: -n 3 (lines).
  • python3 -m pytest - проганяє doctest і дає чесний код виходу 0/1. Назва: py + test - «тести для Python». --doctest-modules - шукати doctest (приклади >>>) у файлах .py; без нього pytest шукає лише функції test_; -q - коротко: крапка за кожен тест і рядок підсумку «1 passed in 0.01s»; -s - не перехоплювати ввід і вивід: потрібен, коли файл питає input().
  • python3 -m black - сам гарно оформлює код Python (пробіли, переноси). Назва: black - «чорний»: як у Форда, «будь-який колір, якщо він чорний». -l - найбільша довжина рядка; викладач хоче 78 (black сам ставить 88).
  • python3 -m flake8 - шукає помилки стилю і зайвий код, нічого не змінює. Назва: pyflakes + pep8: обʼєднав дві старі програми перевірки коду. --max-line-length - найбільша дозволена довжина рядка; викладач хоче 78 (типово 79).
  • python3 -m pycodestyle - перевіряє лише оформлення коду за PEP 8. Назва: Python code style - «стиль коду Python» (раніше програма звалась pep8). --max-line-length - найбільша довжина рядка; викладач хоче 78 (типово 79).
  • python3 -m ruff check - швидко шукає помилки в коді, з --fix сам виправляє. Назва: ruff - назва не розшифровується; check - «перевірити».
  • python3 -m mypy - перевіряє типи (int, str ...) без запуску програми. Назва: назва не розшифровується (py - від Python).
  • grep - знаходить рядки з текстом у файлах. Назва: g/re/p з редактора ed: «знайти регулярний вираз у всьому файлі і надрукувати». -n - показати номер рядка перед кожним збігом (line number); -E - розширені регулярні вирази: |, +, {79,} без зворотних рисок.

Як роблять профі

  • Геометрію перевіряють малюнком. Можна намалювати точки з doctest і свою область у matplotlib (Урок 08, ЛР3) і побачити, де помилка. Так роблять і з реальними даними: спершу графік, потім висновок.
  • Числа з крапкою порівнюють з допуском, а не ==: math.isclose(a, b). https://docs.python.org/3/library/math.html
  • Таблиця перевірок замість драбини if. У великих програмах сім повідомлень про помилки збирають з частин (список проблем → ", ".join(...)), а не перебирають усі комбінації. У ЛР2 - роби так, як вимагають doctest.
  • if __name__ == "__main__": - у ЛР2 if поза функцією завдання 1 не заборонений, але викладач дав заготовку без нього; якщо хочеш так - спитай. https://docs.python.org/3/library/main.html

Самоперевірка

  1. Чому в завданні 1 функція може одразу написати return з умовою, і що вона поверне?
  2. Як подати в програму відʼємне число через printf?
  3. Як за doctest зрозуміти, що age_chat має друкувати, а year_word - повертати?
  4. Чому math.sin(90) не дорівнює 1 і як це виправити?
  5. Що не так з doctest check_point_belonging(-5, 0) і що з цим робити?
Відповіді
  1. Порівняння і and/or/not самі дають True або False, тож return вираз уже повертає bool - if не потрібен (с. 11 методички, приклад return x >= 0 and y <= 5).
  2. printf -- "-5\n" (дві риски кажуть, що опції скінчились) або printf '%s\n' -5.
  3. У doctest age_chat очікуваний текст без лапок - так виглядає друк. У year_word - у лапках ('рік') - так виглядає повернений рядок.
  4. math.sin приймає радіани; 90 радіан - це не 90°. Треба math.sin(math.radians(90)).
  5. Точка лежить на межі області, а умова каже «включно з межею» - мало б бути True, doctest чекає False. Зробити так, щоб doctest пройшли (одна частина межі строга), і написати викладачу про суперечність.
