"""Корені квадратного рівняння a·x² + b·x + c = 0 (дискримінант > 0)."""
import math


def roots(coef_a, coef_b, coef_c):
    disc = coef_b ** 2 - 4 * coef_a * coef_c
    root_1 = (-coef_b + math.sqrt(disc)) / 2 * coef_a
    root_2 = (-coef_b - math.sqrt(disc)) / 2 * coef_a
    return root_1, root_2


equations = [(1, -3, 2), (2, -6, 4), (1, -5, 6)]
for coef_a, coef_b, coef_c in equations:
    root_1, root_2 = roots(coef_a, coef_b, coef_c)
    residual = coef_a * root_1 ** 2 + coef_b * root_1 + coef_c
    assert abs(residual) < 1e-9, f"x1 = {root_1} не корінь"
    print(f"{coef_a, coef_b, coef_c}: x1 = {root_1}, x2 = {root_2}")

bug_1.py - середнє g

Симптом. П'ять вимірювань близько 9.8, а середнє чомусь менше за кожне з них:

python3 bug_1.py

g = 7.852 м/с²

Метод: print-налагодження f"{x=}" (урок 05) або logging.debug (урок 06, крок 10): надрукуй, які значення потрапляють у суму.

Підказки
  • Середнє менше за найменше вимірювання - значить, у суму потрапило не все. Додай у цикл print(f"{k=} {values[k]=}") і порахуй рядки: їх має бути 5.
  • Або з logging: на початку import logging і logging.basicConfig(level=logging.DEBUG), у циклі logging.debug(f"{k=} {total=}").
  • Або pdb: python3 -m pdb bug_1.py, b 8, c, p k, values[k] - з якого k починається?

Нове тут:

  • python3: -m - запусти модуль Python (вбудований чи поставлений через pip) як програму, напр. python3 -m venv (module - «модуль»).
  • python3 -m pdb - запускає програму покроково: рядок за рядком, з паузами. Назва: Python debugger - «налагоджувач Python» (debug - «виловити жуків», помилки).
Виправлення

range(1, len(values)) починається з 1, тому values[0] = 9.79 не потрапляє в суму (а ділимо все одно на 5). Типова помилка «на одиницю» (off-by-one). Правильно range(len(values)):

    for k in range(len(values)):

Після виправлення:

Ще простіше без циклу: sum(values) / len(values).

    """Середня швидкість на всьому шляху, м/с: увесь шлях / увесь час.

    Порожній список ділянок - швидкість 0.0.

    >>> mean_speed([100, 200], [10, 30])
    7.5
    >>> mean_speed([], [])
    0.0
    """
    if not times:
        return 0.0
    return sum(distances) / sum(times)

Правило 3-2-1: ще флешка (rsync -rtv --modify-window=1 --exclude=.venv --exclude=__pycache__ ~/univer/ /media/evgen/НАЗВА/univer/ - на FAT/exFAT -a не працює, урок 01) і приватний GitHub. І це дзеркало, а не історія: зіпсований файл завтра перезапише хорошу копію - історію версій дає git (урок 24).

Нове тут:

Назва: remote sync - «віддалена синхронізація». -r (--recursive) - копіювати теки з підтеками; -a включає -r (recursive - «рекурсивно»); -t (--times) - зберегти час зміни файлів (times), щоб наступного разу не копіювати те саме; -v (--verbose) - писати, що копіюється; --modify-window - вважати час однаковим з допуском у секундах: =1 для флешок (modify window - «вікно зміни»); --exclude - пропустити такі файли чи теки: --exclude=.venv (exclude - «виключити»); /media/evgen/НАЗВА/univer/ - тека на флешці (так Mint підключає флешки).

Б7. Чому «Permission denied» на власному файлі?

Три різні повідомлення в різні дні. Що означає кожне і що робиш?

1) git@github.com: Permission denied (publickey).
2) ! [rejected]        main -> main (fetch first)
3) remote: Support for password authentication was removed
Відповідь
  1. GitHub не знає твій ключ або ssh бере інший. По черзі: ls -l ~/.ssh (ключ є, права 600), ssh -T git@github.com (має привітати), .pub доданий на GitHub (Settings → SSH and GPG keys), ssh -v git@github.com (рядки Offering public key).
  2. На GitHub є коміти, яких нема в тебе (пушив з іншого компʼютера): git pull, потім git push.
  3. Адреса origin - https://..., а пароль GitHub не приймає: git remote -v, потім git remote set-url origin git@github.com:Evge14n/labs.git.

В20. Поясни: «у VS Code усе зелене»

Ти поставив VS Code, і редактор не підсвічує помилок. Чому перед здачею все одно треба перевірити лабу в терміналі (якими командами)? Навіщо знати pdb, якщо у VS Code є налагоджувач debugpy? Яке налаштування VS Code обовʼязково вимкнути для лаб і чому?

Відповідь
  • «Зелене» в редакторі - це підсвітка, не doctest. Викладач перевіряє doctest, flake8 до 78, mypy - саме ними: python3 -m pytest --doctest-modules, python3 -m flake8 --max-line-length=78, mypy (або perevir файл.py), з venv ~/univer/.venv. До того ж VS Code міг узяти не той інтерпретатор (ModuleNotFoundError у ньому, а в терміналі працює).
  • debugpy - той самий принцип, що pdb (F10 = n, F11 = s, F5 = c), але pdb працює в будь-якому терміналі: по ssh, у TTY, на парі чи іспиті без VS Code.
  • ШІ-функції (chat.disableAIFeatures): код, який дописав ШІ, ти не поясниш викладачу, а пояснення кожного рядка - частина здачі.
