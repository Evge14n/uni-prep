Програмування (Python) - поняття

Означення - своїми словами за лекціями 1, 2, 7-9 і файлом UNI2. Позначка «[нема конспекту - звір з лекцією]» - теми, яких у лекціях 1-9 нема.

Тема 1. Програма, змінні, типи

  • Алгоритм - точна послідовність кроків, яка з вхідних даних дає результат.
  • Інтерпретатор - програма, яка читає код Python і виконує його рядок за рядком.
  • Змінна - імʼя, яке показує на обʼєкт у памʼяті. Присвоєння x = 12 не копіює число в «коробку», а привʼязує імʼя до обʼєкта.
  • Літерал - значення, записане прямо в коді: 12, 3.14, "hello", True, 2 + 3j.
  • Тип - що це за дані і які операції з ними можна робити: int, float, str, bool, complex. Дізнатися: type(x).
  • Анотація типу - підказка x: int = 8 або def f(n: int) -> str. Python її не перевіряє, перевіряє mypy.
  • Приведення типу - int("12"), float("2.5"), str(7). Потрібне після input(), бо input() завжди повертає рядок.
  • Конкатенація - склеювання рядків: "23" + "17" дає "2317".
  • Цілочисельне ділення // - ціла частина частки, округлення вниз: -7 // 2 = -4.
  • Остача % - те, що лишається: 17 % 5 = 2. Знак як у дільника.
  • Збирач сміття (garbage collector) - видаляє з памʼяті обʼєкти, на які не показує жодне імʼя.

Тема 2. Функції, doctest, PEP 8

  • Функція - іменований блок коду, який отримує параметри і повертає результат.
  • Параметр - імʼя в def f(param); аргумент - значення, яке передали при виклику f(5).
  • return - повертає значення з функції. Без return функція повертає None.
  • Процедура - стара назва функції без return.
  • None - спеціальне значення «нічого».
  • docstring - рядок у потрійних лапках одразу під def, опис функції.
  • doctest - тест усередині docstring: рядок >>> виклик і під ним точний очікуваний результат. Модуль doctest виконує виклик і порівнює вивід як текст.
  • Test Driven Development - спершу тести, потім код, який їх проходить.
  • Edge case (граничний випадок) - нуль, відʼємне число, порожній список, одне число.
  • DRY (Don't Repeat Yourself) - не повторювати той самий код, а винести його у функцію.
  • Декомпозиція - розбиття задачі на прості блоки (функції).
  • Локальна змінна - створена всередині функції і видна лише там.
  • Структурне програмування - програма з трьох конструкцій: послідовність, галуження, повторення; без goto.
  • Самодокументований код - назви функцій і змінних самі пояснюють, що відбувається.
  • f-рядок - f"... {вираз:формат} ...", вставляє значення в текст. .2f - 2 знаки після коми, .3g - 3 значущі цифри, <10 / >10 - ширина 10 вліво / вправо.
  • PEP 8 - офіційний стандарт оформлення коду Python (PEP = Python Enhancement Proposal).
  • snake_case - слова малими літерами через _: last_digit. Для змінних і функцій.
  • UPPER_CASE - для констант: MAX_SIZE.
  • Лінтер - програма, що шукає стильові й логічні помилки, не запускаючи код: pycodestyle, flake8, ruff, mypy (типи); black - форматувальник.
  • Модуль - файл з функціями (math); бібліотека - набір модулів; пакет - те, що ставлять через pip install.

Тема 3. Розгалуження [конспекту лекції нема]

  • Логічний вираз - вираз, що дає True або False: x > 0, a == b.
  • Логічні оператори - not, and, or (у такому порядку пріоритету).
  • Тернарний вираз - a if умова else b; це вираз, а не оператор if.
  • Множення на умову - "текст" * (умова): True = 1, False = 0.

Тема 4. Цикли [конспекту лекції нема]

  • Цикл - повторення блоку коду.
  • for - цикл по елементах (range, список, рядок).
  • range(start, stop, step) - числа від start до stop не включно з кроком step.
  • while - цикл, поки умова істинна.
  • Ітерація - один прохід тіла циклу.
  • break - негайний вихід з циклу; else після циклу виконується, якщо break не було.
  • Нескінченний цикл - умова while ніколи не стає хибною.

Тема 5. Цілочисельні алгоритми [конспекту лекції нема]

  • НСД - найбільший спільний дільник; алгоритм Евкліда: a, b = b, a % b, поки b != 0.
  • НСК - найменше спільне кратне: a * b // НСД(a, b).
  • Просте число - більше за 1 і ділиться лише на 1 і на себе.
  • Перебір до √n - дільники шукають, поки d * d <= n, бо кожен дільник більший за √n має пару, меншу за √n.

Тема 6-7. Рекурентні співвідношення, точність, корені

  • Рекурентне співвідношення - формула, де новий член рахується з попередніх.
  • Порядок співвідношення - зі скількох попередніх членів рахується новий.
  • Одночасне присвоєння - a, b = b, a + b: спершу рахується вся права частина, потім присвоєння.
  • Часткова сума ряду - S(n) = a(0) + ... + a(n), рахують S = S + a.
  • Точність ε - зупиняємось, коли два сусідні наближення відрізняються менше ніж на ε.
  • Бісекція - пошук кореня діленням відрізка навпіл.
  • Метод хорд - корінь як перетин хорди з віссю x, один кінець відрізка нерухомий.
  • Схема Горнера - значення многочлена b = b * x + a[i], без степенів.

Тема 8-9. Списки, кортежі

  • Список - змінювана впорядкована послідовність [1, 2, 3].
  • Індекс - номер елемента з нуля; -1 - останній.
  • Зріз - частина списку values[start:stop:step], stop не входить.
  • Метод - функція обʼєкта, через крапку: values.append(5).
  • Псевдонім (alias) - друге імʼя того самого обʼєкта: b = a.
  • Копія - новий список з тими самими елементами: a.copy(), a[:].
  • Спискоутворення (list comprehension) - [вираз for x in ... if умова].
  • Кортеж - незмінна послідовність (1, 2); з одного елемента (5,).
  • Розпакування - x, y = (3, 4).
  • Генератор-вираз - (вираз for x in ...), дає значення по одному, не тримає список.
  • lambda - коротка безіменна функція: lambda r: r[1].
  • Стек - список, де додають і забирають з кінця: append, pop.
  • Двійковий пошук - пошук у відсортованому списку діленням навпіл.

Тема 11. Рядки, словники, винятки, файли [нема конспекту - звір з лекцією]

  • Рядок (str) - незмінна послідовність символів; методи upper, split, join, strip.
  • Словник (dict) - пари ключ: значення {"Ann": 18}; ключі не повторюються.
  • Множина (set) - набір без повторів {1, 2}.
  • Виняток - помилка під час виконання (ZeroDivisionError, ValueError, TypeError, IndexError, KeyError, NameError).
  • try / except - спробувати виконати блок і перехопити виняток.
  • with open(...) - відкрити файл так, що він сам закриється після блоку.
