Тема 1. Змінні, типи, арифметика

Присвоєння x = 12 не «кладе число в коробку», а показує змінній обʼєкт у памʼяті. У Python усе - обʼєкти. 12 - це літерал. Тип змінної - це тип того, що їй присвоїли:

12        int     ціле
3.14      float   дійсне
"hello"   str     рядок
True      bool    логічне
2 + 3j    complex комплексне

Анотація типу x: int = 8 - лише домовленість. Python не заборонить потім написати x = "hello". Перевіряє домовленість окремий інструмент mypy.

Арифметика:

7 / 2   = 3.5    звичайне ділення, завжди float
7 // 2  = 3      ціла частина (вниз!)
-7 // 2 = -4     вниз, а не до нуля
7 % 2   = 1      остача
-7 % 2  = 1      знак як у дільника
2 ** 10 = 1024   степінь

Цифри числа без рядків: n % 10 - остання, n // 10 % 10 - передостання, n // 100 - перша цифра тризначного. Для відʼємного числа спершу abs(n).

input() завжди повертає рядок. Якщо ввести 12 і 18 і додати без int, вийде "1218": для рядків + - це склеювання (конкатенація). Тип визначає зміст операції. Тому number = int(input("Число: ")).

True поводиться як 1, False як 0. Звідси прийом без if, який приймали в ЛР1: "парне" * (n % 2 == 0) дає "парне" або порожній рядок.

Пастка з лекції 2: вираз у два рядки без дужок. Другий рядок + x**3 стає окремою командою, яка нічого не змінює. Синтаксичної помилки нема, логічна є. Лікується дужками.

Тема 2. Функції, return, f-рядки, doctest, PEP 8

def add(first: int, second: int) -> int:
    """Додає два числа.

    >>> add(3, 5)
    8
    """
    return first + second
  • def - оголошення, далі імʼя, параметри з анотаціями, -> int - тип результату.
  • docstring - рядок у потрійних лапках одразу під def. У ньому живуть doctest.
  • Без return функція повертає None. Найчастіша помилка в ЛР1: усе пораховано, а результату нема, бо функція друкує через print, а не повертає.
  • Вимога викладача: один return з одним рядком, частини склеєні через \n.

Навіщо функції. DRY (Don't Repeat Yourself - не повторюйся), декомпозиція (розбити задачу на блоки, як компʼютер на плату, памʼять, диск), локальні змінні, одна точка входу і виходу. Це структурне програмування: послідовність, галуження, повторення.

print: sep - що між значеннями (типово пробіл), end - що в кінці (типово \n). print(1, 2, 3, sep=", ") дає 1, 2, 3.

f-рядки: f"{x:.2f}" - 2 знаки після коми, f"{x:.3g}" - 3 значущі цифри, f"{s:<10}" - ширина 10 вліво, f"{n:>5}" - вправо, f"{1234567:,}" - 1,234,567. Старий спосіб "%d" % 5 ще трапляється в чужому коді.

doctest бере рядок після >>>, виконує його і порівнює з наступним рядком точно як текст. Рядок у відповіді - в лапках, зайвий пробіл = тест не пройшов. Запуск: python -m doctest -v file.py або doctest.testmod() у кінці файлу. У лабах тести вже написані до коду - це Test Driven Development: читай doctest першими, це і є умова. Помилку в doctest викладача не підганяй: порахуй вручну і покажи.

PEP 8 (стандарт оформлення):

відступ 4 пробіли, без табуляції
рядок до 79 символів (docstring 72)
2 порожні рядки між функціями
пробіли навколо = + - і після коми
snake_case: last_digit, total_seconds
UPPER_CASE: MAX_SIZE (константи)
не називати змінні list, sum, str, type, id
імпорти зверху: стандартні, сторонні, свої

Назви - англійські і змістовні: last_digit, а не a, b, d. Коментар - повне речення, очевидне не коментувати. Лінтери шукають помилки, не виконуючи код: pycodestyle (PEP 8), flake8 (PEP 8 + невикористані змінні), ruff (те саме швидше), mypy (типи), black (сам переформатовує).

Тема 3. Розгалуження [конспекту лекції нема]

if умова:
    ...
elif інша_умова:
    ...
else:
    ...

and, or, not. Пріоритет: спершу not, потім and, потім or. Порівняння можна ланцюжком: 0 < x < 10. Тернарний вираз a if умова else b - це вираз, не оператор, тому його приймали в лабах, де if заборонено.

Високосний рік одним виразом: year % 4 == 0 and year % 100 != 0 or year % 400 == 0.

Пастки: = замість ==; if x > 0 and < 10 (так не можна); порядок перевірок (спершу некоректні дані, потім звичайні випадки); float через == (0.1 + 0.2 не дорівнює 0.3).

Тема 4. Цикли [конспекту лекції нема]

for i in range(5):         0 1 2 3 4
for i in range(1, 10, 2):  1 3 5 7 9
while умова:               поки умова True
break                      вийти з циклу
for ... else               else - якщо не було break

range(start, stop, step): stop не входить. У while змінна з умови мусить мінятися всередині, інакше цикл нескінченний. Змінити лічильник for всередині тіла - марно, на наступному кроці він візьме нове значення з range.

Тема 5. Цілочисельні алгоритми [конспекту лекції нема]

цифри:    while n > 0: digit = n % 10; n //= 10
дільники: перебір d, поки d * d <= n
          знайшли d - є і пара n // d
НСД:      while b != 0: a, b = b, a % b
НСК:      a * b // НСД(a, b)
просте:   нема дільників від 2 до √n

Чому до √n: якщо d - дільник і d > √n, то його пара n // d < √n уже знайдена. Для n = 10⁶ це 1000 кроків замість мільйона.

Тема 6. Рекурентні співвідношення [конспекту лекції нема]

Рекурентне співвідношення - кожен новий член рахується з попередніх.

1-й порядок:  a = f(a)                    одна змінна
2-й порядок:  prev, cur = cur, f(prev, cur)   дві змінні
3-й порядок:  x3, x2, x1 = x2, x1, нове
сума ряду:    S = S + a,  a(n) з a(n-1)

Фібоначчі: previous, current = current, previous + current. Права частина рахується повністю до присвоєння. Якщо написати в два рядки (previous = current, потім current = previous + current), друга змінна візьме вже нове значення - помилка.

Член ряду eˣ рахують з попереднього: a(n) = a(n-1) · x / n, а не степенем і факторіалом заново.

Тема 7. Системи рекурентних, точність ε, корені рівнянь

Система рекурентних (лекція 7): a(k) = a(k-1)·b(k-1), b(k) = a(k-1) + b(k-1). Нові значення треба рахувати зі старих: або допоміжні змінні a_new, b_new, або одночасне присвоєння.

Точність ε: рахуємо, поки |y(n) - y(n-1)| ≥ ε. Умова while - це заперечення умови зупинки.

Бісекція (ділення навпіл): на [a, b] f(a) і f(b) різних знаків. c = (a + b) / 2; якщо f(a)·f(c) < 0, корінь у [a, c], інакше у [c, b]. Повторюємо, поки b - a ≥ ε. Кожен крок ділить відрізок навпіл, тому кроків приблизно log₂((b - a) / ε).

Хорди: один кінець b нерухомий, u(n) = u(n-1) - f(u(n-1))·(b - u(n-1)) / (f(b) - f(u(n-1))), поки |u(n) - u(n-1)| ≥ ε. Нерухомий той кінець, де знак f збігається зі знаком f''.

Горнер (ЛР6): значення многочлена a₀xⁿ + ... + aₙ: b = a[0], далі b = b * x + a[i]. Це теж рекурентне співвідношення першого порядку.

Тема 8. Списки

values = [10, 20, 30, 40]
values[0]    перший     values[-1]   останній
values[1:3]  [20, 30]   кінець не входить
values[::-1] навпаки    len(values)  довжина
values.append(50)       додає в кінець, повертає None!
[x * 2 for x in values if x > 15]   спискоутворення

b = a - не копія, а друге імʼя того самого списку: зміниш b - зміниться a. Копія: a.copy() або a[:].

Матриця - список списків: [[0] * m for _ in range(n)]. Не [[0] * m] * n - там усі рядки - той самий обʼєкт, зміниш один - зміняться всі.

Тема 9. Кортежі, генератор-вирази, сортування

Кортеж (1, 2, 3) змінити не можна. Кортеж з одного елемента - з комою: (5,), бо (5) - просто число в дужках. Функція може повернути кілька значень: return root, steps, history, а потім root, steps, history = method(...) (розпакування). Обмін: a, b = b, a.

Генератор-вираз sum(1 for x in values if x % 2 == 0) - підрахунок за один прохід без проміжного списку.

sorted(records, key=lambda r: (-r[1], r[0])) - спершу за балом за спаданням (мінус), при рівних - за імʼям. sorted повертає новий список, list.sort() міняє сам список і повертає None.

Тема 11. Рядки, словники, винятки, файли [нема конспекту - звір з лекцією]

У лекціях 1-9 цього нема. Файл UNI2 ставить ці теми «далі за логікою курсу, не підтверджено». Тут - мінімум зі стандартного Python.

"abc".upper()  'ABC'     " a b ".split()  ['a', 'b']
"-".join(["1", "2"])  '1-2'    "abc"[::-1]  'cba'

Словник - пари ключ: значення. ages = {"Ann": 18}, ages["Ann"] дає 18, ages["Bob"] - помилка KeyError, ages.get("Bob", 0) дає 0. Цикл for key, value in ages.items().

Множина {1, 2, 2} - без повторів, тобто {1, 2}.

Винятки:

try:
    result = 10 / number
except ZeroDivisionError:
    result = 0

Типові: ZeroDivisionError (ділення на 0), ValueError (int("abc")), TypeError ("2" + 3), IndexError (індекс за межами списку), KeyError (нема ключа), NameError (змінна не існує).

Файли: with open("data.txt", encoding="utf-8") as file: - файл сам закриється після блоку. file.read() - увесь текст, for line in file: - по рядках.
