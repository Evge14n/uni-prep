1. Ідея

Досі програма йшла згори вниз і завжди робила одне й те саме. Але справжні задачі вимагають рішень: «якщо дискримінант додатний - два корені, якщо нуль - один, інакше - нема». Для цього потрібні дві речі:

  1. Числа і точна арифметика: ціле ділення //, остача %, степінь **, функції з math. Тут найбільше пасток: -7 // 2 дає -4, а 0.1 + 0.2 - не 0.3.
  2. Логічні вирази (True/False) і розгалуження (if/elif/else, тернарний вираз). Умова - це теж вираз, просто його значення не число, а True або False.

Аналогія: розгалуження - стрілочник на залізниці. Поїзд (програма) доїжджає до стрілки (умова), і стрілочник дивиться на одне питання «так чи ні?». Залежно від відповіді поїзд іде однією колією, а друга для нього в цей раз не існує.

17 цукерок розкладаємо в пакети по 5: повних пакетів 17 // 5 = 3, лишилось 17 % 5 = 2, бо 17 = 3 · 5 + 2. Завжди a == (a // b) * b + a % b (ЛР1, с. 3). 20 / 5 дає 4.0, а не 4: ділення / завжди повертає float (ЛР1, с. 2). int(9.6) = 9: дробова частина відкидається, а не округлюється.

Цифри числа без рядків (Лекція 3, с. 3; ЛР1, с. 3): n % 10 - остання цифра, n // 10 - число без останньої цифри, n % 100 - дві останні. Для 25: 25 // 10 = 2, 25 % 10 = 5, сума 7.

Відʼємні числа (у лекції нема, стандартний Python): // округлює вниз, тобто до меншого числа: -7 // 2 = -4 (бо -3.5 вниз - це -4), а -7 % 2 = 1 (бо -7 = -4 · 2 + 1). Знак остачі - як у дільника.

Розгалуження if / elif / else

if умова:              # двокрапка обовʼязкова
    гілка_так          # відступ 4 пробіли = «це всередині if»
elif інша_умова:       # перевіряється, лише якщо перша хибна
    гілка_2
else:                  # якщо жодна умова не спрацювала
    гілка_інакше

Виконується рівно одна гілка: перша, чия умова істинна. else і elif необовʼязкові: if без else - «захищена інструкція» (с. 18). Каскад elif - те саме, що вкладені if/else (с. 20), але без «трикутника смерті» з відступів.

Кусково-задана функція з лекції (с. 20): f(x) = -x² + 1 при x < -1; 0 при |x| ≤ 1; x² - 1 при x > 1.

# ввід: -2
x = float(input("x = "))
if x < -1:
    f = -x ** 2 + 1
elif abs(x) <= 1:
    f = 0
else:
    f = x ** 2 - 1
print("f(", x, ")= ", f)

x = -2
f( -2.0 )=  -3.0

Для x = -2.0: перша умова -2.0 < -1 істинна. Тепер пріоритет: -x ** 2 = -(x ** 2). x ** 2 = (-2.0) ** 2 = 4.0 (мінус сидить усередині значення змінної), потім унарний мінус дає -4.0, плюс 1 = -3.0. Решта гілок пропускається. У гілці elif abs(x) <= 1 уже відомо, що x >= -1 (бо перша умова не спрацювала), тому окремо це не перевіряють (с. 20).

2. Розібраний приклад

Умова. Розвʼязати квадратне рівняння a·x² + b·x + c = 0 (a ≠ 0) для введених коефіцієнтів: два корені, один корінь або повідомлення, що дійсних коренів нема.

# ввід: 1 | -3 | 2
import math

coef_a = float(input("a = "))
coef_b = float(input("b = "))
coef_c = float(input("c = "))
discriminant = coef_b ** 2 - 4 * coef_a * coef_c
if discriminant > 0:
    root_1 = (-coef_b + math.sqrt(discriminant)) / (2 * coef_a)
    root_2 = (-coef_b - math.sqrt(discriminant)) / (2 * coef_a)
    print("Два корені:", root_1, root_2)
elif discriminant == 0:
    root = -coef_b / (2 * coef_a)
    print("Один корінь:", root)
else:
    print("Дійсних коренів нема, D =", discriminant)

b = -3
c = 2
Два корені: 2.0 1.0

    :param side_b: друга сторона
    :param side_c: третя сторона
    :return: назва виду трикутника

    >>> triangle_type(3, 4, 5)
    'прямокутний'
    >>> triangle_type(13, 5, 12)
    'прямокутний'
    >>> triangle_type(2, 2, 2)
    'рівносторонній'
    >>> triangle_type(2, 3, 2)
    'рівнобедрений'
    >>> triangle_type(4, 5, 6)
    'різносторонній'
    >>> triangle_type(1, 2, 3)
    'не трикутник'
    >>> triangle_type(0, 0, 0)
    'не трикутник'

    # Умова існування - з Лекції 3, с. 14-15. Нерівності строгі:
    # для 1, 2, 3 маємо 1 + 2 = 3, а не > 3, тобто трикутник
    # «сплющений» в відрізок. Нулі й від'ємні сторони теж не
    # пройдуть: 0 + 0 > 0 - хибно.
    exists = (side_a + side_b > side_c
              and side_a + side_c > side_b
              and side_b + side_c > side_a)
    # Теорема Піфагора для всіх трьох варіантів «яка сторона -
    # гіпотенуза». Сторони цілі, тому == тут працює точно
    # (з float так порівнювати не можна, див. урок).

                or side_a ** 2 + side_c ** 2 == side_b ** 2
                or side_b ** 2 + side_c ** 2 == side_a ** 2)

    # перевіряється. Тому «не трикутник» стоїть першим: для
    # (0, 0, 0) усі сторони рівні, але відповідь - не трикутник.
    if not exists:
        return "не трикутник"
    elif side_a == side_b == side_c:
        return "рівносторонній"
    elif is_right:
        return "прямокутний"
    elif side_a == side_b or side_b == side_c or side_a == side_c:
        return "рівнобедрений"
    else:
        return "різносторонній"

    Прискорення: a = G * (sin α - μ * cos α), де α - кут нахилу,
    μ - коефіцієнт тертя. Кут задано в градусах, а math.sin і
    math.cos чекають радіани.
    Некоректні дані: тертя від'ємне або кут поза межами 0..90
    (межі 0 і 90 допустимі) - "Некоректні дані".
    Якщо a <= 0 - "Брусок стоїть", інакше - рядок з a,
    округленим до двох знаків після коми.

    :param angle_degrees: кут нахилу площини, градуси
    :param friction: коефіцієнт тертя μ
    :return: опис руху

    >>> incline_motion(30.0, 0.0)
    'Брусок ковзає з a = 4.90 м/с²'
    >>> incline_motion(60.0, 0.2)
    'Брусок ковзає з a = 7.51 м/с²'
    >>> incline_motion(90.0, 0.5)
    'Брусок ковзає з a = 9.80 м/с²'

    >>> incline_motion(45.0, 1.0)
    'Брусок стоїть'

    'Некоректні дані'
    >>> incline_motion(95.0, 0.1)
    'Некоректні дані'

    if friction < 0 or not 0 <= angle_degrees <= 90:

    if acceleration <= 0:
        return "Брусок стоїть"
    return f"Брусок ковзає з a = {acceleration:.2f} м/с²"

7. Поясни чому

1. Чому -7 // 2 дає -4, а не -3?

Еталон

// округлює частку вниз, до меншого цілого, а не «відкидає дріб». -7 / 2 = -3.5, менше ціле - це -4. Так зроблено, щоб завжди виконувалось a = (a // b) · b + a % b з остачею того ж знака, що й дільник: -7 = (-4) · 2 + 1. «Відкинути дріб» робить інша функція - int(-3.5) = -3 або math.trunc.

2. Чому 0.1 + 0.2 == 0.3 дає False, і як правильно порівнювати дійсні числа?

Еталон

Дійсні числа зберігаються у двійковому вигляді з обмеженою кількістю цифр. 0.1 і 0.2 у двійковій системі - нескінченні дроби, їх обрізають, і сума виходить 0.30000000000000004 (Лекція 3, с. 4-5). == порівнює точно, до останнього біта. Правильно - перевіряти, що різниця дуже мала: abs(a - b) < 1e-9. Цілі числа (int) точні, для них == безпечне.

3. Чому в каскаді elif важливий порядок умов, а в x != 0 and 10 / x > 1 - порядок частин?

Еталон

Обидва рази Python іде зліва направо і зупиняється, щойно відповідь відома. У каскаді виконується перша істинна гілка, решта навіть не перевіряються, тому широка умова (>= 60) попереду «зʼїдає» вужчі (>= 90). У and - якщо ліва частина хибна, права не обчислюється (лінивість, с. 11). Тому захисну перевірку (x != 0) ставлять ліворуч: до ділення на нуль справа не дійде.

8. Що запамʼятати

  • / - завжди float; // - ціла частина вниз; % - остача; a == (a // b) * b + a % b.
  • n % 10 - остання цифра, n // 10 - без останньої, n % 100 - дві останні.
  • Пріоритет: ** → * / // % → + - → порівняння → not → and → or. -3 ** 2 = -9.
  • Дійсні числа неточні: не ==, а abs(a - b) < 1e-9.
  • math працює в радіанах: math.radians(градуси) перед sin/cos.
  • and/or ліниві: захисну умову - ліворуч. Ланцюжок 0 <= x <= 90 можна.
  • True = 1, False = 0: "текст" * (умова) - розгалуження без if.
  • Каскад if/elif/else: виконується перша істинна гілка; від вузької умови до широкої.
  • Тернарний a if умова else b - вираз (має значення), if - інструкція.
