1. Ідея

Лекція 4 починається з жарту (с. 1): 15 рядків print(5) підряд. Набирати так 1000 рядків ніхто не буде. Цикл - це «повтори цей шматок коду кілька разів». Лекція називає його третьою базовою конструкцією програмування, поруч з лінійною програмою і розгалуженням if (с. 2).

У Python два цикли (с. 2-3):

цикл як читати коли брати
while умова: «поки умова True - роби тіло» не знаєш наперед, скільки буде кроків (цифри числа, «поки не знайду»)
for x in колекція: «для кожного x з колекції - роби тіло» знаєш, що перебирати (числа від 1 до N, елементи списку)

while крок за кроком (правило з с. 3): 1) Python рахує умову; 2) якщо True - виконує тіло і повертається до пункту 1; 3) якщо False - цикл закінчено, ідемо далі.

countdown = 3
while countdown > 0:
    print("залишилось", countdown)
    countdown -= 1
print("старт!")

Вивід:

залишилось 3
залишилось 2
залишилось 1
старт!

Умова перевіряється 4 рази: при 3, 2, 1 вона True, при 0 - False, і цикл закінчується. Рядок countdown -= 1 - це countdown = countdown - 1. Якщо його забути, countdown назавжди 3, умова назавжди True, програма «зависає». Лекція називає це зациклюванням (с. 3, і ще раз Лекція 5, с. 18). Правило: тіло while мусить змінювати те, від чого залежить умова.

range - «лінійка» чисел для for (с. 8-9). range(b, c, d) - це арифметична прогресія: починаємо з b, крок d, зупиняємось ДО c (саме c не входить).

range(2, 6) 2 3 4 5 6 не входить
range(1, 10, 2) 1 3 5 7 9 крок 2
range(1, N + 1) 1 ... N щоб N увійшло, пишемо N + 1
range(10, 0, -3) 10 7 4 1 від'ємний крок - спадаємо (с. 11-12, подвійний факторіал)

for number in range(3):
    print("крок", number)

list(...) тут лише щоб побачити числа (так робить лекція на с. 7). Сам range чисел не зберігає, а видає їх по одному «на льоту», тому навіть range(10**9) не з'їдає пам'ять (с. 9).

Накопичувач, лічильник, прапорець - три змінні, які живуть майже в кожному циклі:

  • накопичувач суми: suma = 0 ДО циклу, suma += i у тілі (с. 7). Чому 0: додати 0 - нічого не змінити.
  • накопичувач добутку: p = 1 ДО циклу, p = p * k у тілі (подвійний факторіал, с. 11-12). Чому 1: помножити на 1 - нічого не змінити. Почнеш з 0 - весь добуток буде 0.
  • лічильник: i = 2, потім i = i + 1 (перевірка на простоту, с. 4).
  • прапорець: prime = True («поки що вважаємо простим»), а в циклі prime = False, коли знайшли дільник (с. 4).

Скорочені присвоєння: suma += 3 це suma = suma + 3; так само -=, *=, //=, %= (лекція показує suma %= 3 = suma = suma % 3, с. 2).

break і continue (с. 12-13). break - вийти з циклу зовсім, прямо зараз. continue - кинути решту тіла і перейти до наступного кроку. Приклад з лекції (с. 12): у тілі print(i), потім continue, потім print("hello") - hello не надрукується ніколи, бо до нього не доходить.

else у циклі (с. 13-14) - найзаплутаніша річ лекції. Блок else після for або while виконується, якщо цикл закінчився сам, без break. Це НЕ «якщо цикл не виконався жодного разу». Типове використання - пошук: знайшли - break; не знайшли - цикл дійшов до кінця, і спрацьовує else.

Ледачий and (с. 2 і с. 4). A and B: якщо A хибне, Python вже знає відповідь (False) і B навіть не обчислює. Лекція показує це на діленні на нуль:

number = 0
print(number != 0 and 10 / number > 1)
print(10 / number > 1 and number != 0)

False
Traceback (most recent call last):
  ...
ZeroDivisionError: division by zero

Перший рядок: number != 0 дає False, ділення не робиться, друкується False. Другий рядок: ділення стоїть першим, і програма падає. Порядок у and важливий! З or те саме навпаки: якщо ліва частина True, права не рахується (у Лекції 4 показано лише and). Тому в лекції оптимізація while (i <= N - 1) and prime: (с. 4): щойно prime став False, цикл зупиняється.

Ще дві дрібниці з лекції. 1) Тернарний вираз у циклі: max_value = a if a > max_value else max_value - «онови максимум» (с. 11-12). 2) Рядки на кшталт "НСД(%d, %d) = %d" % (N, M, U) (с. 6) - старий спосіб форматування: %d - ціле, %f - дробове, значення беруться з кортежу праворуч. f-рядок з уроку 2 робить те саме. І зверни увагу: на с. 11 лекція назвала змінну max, а на с. 12 перейменувала в max_value. Правильно: імена max, sum, min ховають вбудовані функції, після цього max(3, 7) вже не працює.

2. Розібраний приклад

Умова. Напиши функцію max_digit(number), яка ПОВЕРТАЄ найбільшу цифру натурального числа. Наприклад, для 4096 - це 9. (Це поєднання двох прийомів лекції: розклад числа на цифри через % 10 і // 10, с. 5, і оновлення максимуму, с. 11.)

def max_digit(number: int) -> int:
    """Повертає найбільшу цифру натурального числа.

    >>> max_digit(4096)
    9
    >>> max_digit(7)
    7
    """
    largest = 0
    while number > 0:
        digit = number % 10
        largest = digit if digit > largest else largest
        number //= 10
    return largest


print(max_digit(4096))
print(max_digit(7))
print(max_digit(30500))

4. Знайди помилку

Кожна функція нижче має помилку, яку doctest ловить. Знайди її, перш ніж відкривати відповідь.

# БАГ
def sum_up_to(limit: int) -> int:
    """Повертає суму 1 + 2 + ... + limit.

    >>> sum_up_to(4)
    10
    """
    for number in range(1, limit + 1):
        total = 0
        total += number
    return total
Що не так

total = 0 стоїть ВСЕРЕДИНІ циклу, тож на кожному кроці накопичувач обнуляється. Після останнього кроку там лише останнє число: sum_up_to(4) повертає 4, а не 10. Ще гірше: sum_up_to(0) впаде з UnboundLocalError, бо цикл не виконався ні разу і total взагалі не створено. Правило: накопичувач створюють ДО циклу, а в циклі лише додають.

# ВИПРАВЛЕНО
def sum_up_to(limit: int) -> int:
    """Повертає суму 1 + 2 + ... + limit.

    >>> sum_up_to(4)
    10
    >>> sum_up_to(0)
    0
    """
    total = 0
    for number in range(1, limit + 1):
        total += number
    return total

# БАГ
def sum_odd_up_to(limit: int) -> int:
    """Повертає суму непарних чисел від 1 до limit включно.

    >>> sum_odd_up_to(7)
    16
    """
    total = 0
    for number in range(1, limit, 2):
        total += number
    return total
Що не так

Межа range: range(1, 7, 2) дає 1, 3, 5 - число 7 НЕ входить, бо stop завжди «до, не включно». Повертається 9, а треба 1 + 3 + 5 + 7 = 16. «Включно до limit» - це range(1, limit + 1, 2) (так лекція робить у сумі парних: range(2, N + 1, 2), с. 9).

# ВИПРАВЛЕНО
def sum_odd_up_to(limit: int) -> int:

    16
    >>> sum_odd_up_to(8)
    16

# БАГ
def count_digits(number: int) -> int:

    >>> count_digits(507) + 1
    4

Що не так

print замість return. Функція друкує 3, але повертає None, і None + 1 дає TypeError. Підступне: якби doctest був просто >>> count_digits(507) / 3, він би ПРОЙШОВ - doctest бачить надруковане «3» і задоволений. Тому викладач і вимагає return: функцію, що друкує, не можна використати далі (додати, порівняти, передати в іншу функцію). Цикл тут правильний.

    >>> count_digits(507) + 1
    4
    >>> count_digits(9)
    1
    """
    count = 0
    while number > 0:
        count += 1
        number //= 10
    return count

Задача 1. alternating_sum(count) - знакозмінна сума 1 - 2 + 3 - 4 + ... ± count. Наприклад, alternating_sum(5) = 1 - 2 + 3 - 4 + 5 = 3. Обмеження: без ** і без if.

Підказка-план
  1. Накопичувач total = 0 і змінна знаку sign = 1 - ДО циклу.
  2. for number in range(1, count + 1): - щоб count увійшло.
  3. У тілі: додати sign * number, потім перевернути знак: sign = -sign.
  4. Після циклу return total.

Знак через sign = -sign замість (-1) ** n - саме те, що треба в ЛР5, завд. 1 (там заборонено піднесення до степеня).

Задача 2. collatz_steps(number) - гра «3n + 1» (у лекціях нема, це відома задача). Беремо число. Якщо воно парне - ділимо навпіл, якщо непарне - множимо на 3 і додаємо 1. Повторюємо, доки не отримаємо 1. Функція повертає, скільки кроків для цього треба. Для 6: 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1, тобто 8 кроків.

Підказка-план
  1. Скільки буде кроків - невідомо, тому while number != 1:.
  2. Лічильник steps = 0 до циклу, steps += 1 у кінці тіла.
  3. У тілі if number % 2 == 0: ... else: ... - нове значення number.
  4. Ділення - лише //, інакше вийде дробове число 3.0, і тести не пройдуть.
  5. Для number = 1 цикл не виконується ні разу - повертається 0. Це граничний випадок у тестах.

"""Урок 4. Задачі з doctest (розвʼязок).

import doctest


def alternating_sum(count: int) -> int:
    """Повертає знакозмінну суму 1 - 2 + 3 - 4 + ... ± count.

    Знак чергується: непарні числа додаються, парні віднімаються.
    Обмеження: без ** і без if (знак тримай в окремій змінній).

    :param count: останнє число суми (0 або більше)
    :return: значення суми; для count = 0 сума порожня, тобто 0

    >>> alternating_sum(1)
    1
    >>> alternating_sum(2)
    -1
    >>> alternating_sum(5)
    3
    >>> alternating_sum(10)
    -5
    >>> alternating_sum(0)
    0
    """
    # Накопичувач суми - з 0 (додати 0 нічого не змінює), ДО циклу.
    total = 0
    # Перший доданок (1) іде з плюсом.
    sign = 1
    # count + 1, бо range не включає верхню межу, а count має увійти.
    for number in range(1, count + 1):
        total += sign * number
        # Перевертаємо знак для наступного числа: 1 -> -1 -> 1 -> ...
        sign = -sign
    # count = 0: range(1, 1) порожній, цикл не виконався, total = 0.
    return total


def collatz_steps(number: int) -> int:
    """Повертає кількість кроків гри «3n + 1», щоб дійти до 1.

    Крок: парне число ділимо навпіл, непарне множимо на 3 і додаємо 1.
    Для 6: 6 -> 3 -> 10 -> 5 -> 16 -> 8 -> 4 -> 2 -> 1, тобто 8 кроків.

    :param number: натуральне число (1 або більше)
    :return: кількість кроків до 1; для number = 1 це 0

    >>> collatz_steps(1)
    0
    >>> collatz_steps(2)
    1
    >>> collatz_steps(6)
    8
    >>> collatz_steps(7)
    16
    >>> collatz_steps(27)
    111
    """
    steps = 0
    # Скільки буде кроків - невідомо наперед, тому while, а не for.
    while number != 1:
        if number % 2 == 0:
            # //, а не /: інакше вийде 3.0 (float) замість 3.
            number //= 2
        else:
            number = 3 * number + 1
        steps += 1
    return steps


if __name__ == "__main__":
    doctest.testmod(verbose=True)

7. Поясни чому

1. Чому в сумі цифр (с. 5) лекція бере while, а в сумі парних чисел до N (с. 9) - for?

Відповідь-еталон

Для суми парних наперед відомо, що перебирати: числа 2, 4, ..., N - це готова колекція range(2, N + 1, 2). Для цифр невідомо, скільки їх (у 7 одна цифра, у 4096 чотири). Ми знаємо лише умову зупинки: «число стало 0». Коли відома колекція - for, коли відома лише умова - while.

2. Чому else після циклу пошуку - це не «якщо цикл не виконався», і що він надрукує для порожньої послідовності?

Відповідь-еталон

else циклу означає «цикл закінчився без break» (с. 14). Для порожньої послідовності тіло не виконається жодного разу, break не буде - отже else спрацює і надрукує «не знайдено». І це правильно: у порожній послідовності шуканого числа справді нема. Плутанина - від аналогії з if-else, лекція прямо попереджає про неї.

3. Чому в while (i <= N - 1) and prime: (с. 4) цикл зупиняється одразу, щойно знайдено дільник, і що зміниться, якщо поміняти частини and місцями?

Відповідь-еталон

Коли prime стає False, весь and стає False, і цикл закінчується - зайві ділення не робляться. Якщо поміняти місцями (prime and i <= N - 1), результат той самий, бо обидві частини безпечні. Порядок стає критичним, коли права частина може «впасти»: a != 0 and 1 / a > 0 працює, а 1 / a > 0 and a != 0 при a = 0 дає ZeroDivisionError (с. 2). Ледачий and рахує праву частину, лише коли ліва True, тому «запобіжник» ставлять зліва.

4. Чому накопичувач суми починають з 0, а добутку - з 1?

Відповідь-еталон

Стартове значення не має «зіпсувати» результат. 0 + будь-що = те саме, тому для суми 0. 1 · будь-що = те саме, тому для добутку 1. Якби добуток почався з 0, то 0 · 3 · 5 · ... = 0 завжди. Порожня сума (жодного кроку) природно дорівнює 0, порожній добуток - 1 (тому 0! = 1).

8. Що запам'ятати

  • while умова: - поки умова True; тіло мусить змінювати умову, інакше зациклення.
  • for x in колекція: - для кожного елемента; range(b, c, d) - від b з кроком d, c не входить; «до N включно» = range(1, N + 1).
  • Накопичувач створюють ДО циклу: сума з 0, добуток з 1, лічильник з 0, прапорець з True/False.
  • Цифри числа: digit = number % 10, number //= 10, while number > 0.
  • break - вийти з найближчого циклу; continue - на наступний крок; else циклу - «не було break».
  • A and B: якщо A хибне, B не рахується - «запобіжник» ставлять зліва.
  • Функція рахує і робить return; друкує програма, яка її викликала.

Де в лабах: - ЛР3, завд. 1 - паліндром числа без рядків: цифри через % 10 і // 10, нове число result * 10 + digit (ЛР3, с. 2). - ЛР3, завд. 2 - is_prime (перебір дільників у циклі, return False, щойно знайшли) і digit_sum (той самий цикл, що в розібраному прикладі, лише сума замість максимуму). - ЛР3, завд. 3 - НСД за Евклідом: while, доки остача не 0 (Лекція 4, с. 6). - ЛР4, завд. 1 - кожен візерунок: for i in range(36): ..., групи через i // 20. - ЛР5, завд. 1 - суми й добутки в циклі, знак через sign = -sign (задача 1 цього уроку). - ЛР6, завд. 1 - щасливі числа: цифри числа в while, без списків; перебір дільників до √n.
