1.1. Список - змінювана послідовність (Лекція 4, с. 15-18)

Список - це ряд значень у квадратних дужках. У кожного є номер (індекс), і відлік з нуля. Від'ємний індекс рахує з кінця: -1 - останній. Список можна міняти: замінити елемент, дописати новий у кінець через .append(). len() - кількість елементів. Зріз [start:stop:step] - шматок списку, stop не входить (як у range).

        10   20   30   40   50
індекс:  0    1    2    3    4
        -5   -4   -3   -2   -1

numbers = [10, 20, 30, 40, 50]
print(numbers[0], numbers[4], numbers[-1])
numbers[1] = 25
numbers.append(60)
print(numbers, len(numbers))
print(numbers[1:4], numbers[::2])

10 50 50
[10, 25, 30, 40, 50, 60] 6
[25, 30, 40] [10, 30, 50]

numbers[1:4] - індекси 1, 2, 3 (4 не входить). numbers[::2] - від початку до кінця з кроком 2: індекси 0, 2, 4. Головний прийом лекції - накопичувати результати в циклі (с. 16): values = [] до циклу, values.append(...) у тілі. Це той самий накопичувач з уроку 4, тільки збирає не суму, а всі значення.

1.5. matplotlib - графік з двох списків (Лекція 5, с. 6-17)

Графік - це лише два списки однакової довжини: x-и і y-и. Точка номер i - це (x_values[i], y_values[i]). А в ЛР3 (с. 5-6) - «короткий» стиль: функції plt. прямо, вони малюють на поточних осях.

Вигляд лінії: linewidth=2, linestyle="--", marker="o" (с. 14-15). Межі осей: ax.set_xlim(-5, 5) (с. 15).

1.6. turtle - черепашка зі станом (Лекція 5, с. 18-34)

Ідея з 1960-х (мова Logo, с. 18): робот-черепашка повзає по підлозі з маркером. У кожен момент у неї є стан: позиція (x, y), напрямок «носа» (кут у градусах), перо (опущене - лишає слід, підняте - ні), колір і товщина пера. Кожна команда змінює стан. Програма = послідовність змін стану (с. 18-19).

Координати (с. 21): (0, 0) - центр вікна, x праворуч, y вгору (як у математиці). Кут 0° - праворуч (схід), 90° - вгору, 180° - ліворуч, 270° - вниз. left повертає проти годинникової стрілки, right - за.

Що рахують «розповідні» команди (с. 22-23). Черепашка з (0, 0) пройшла 100 праворуч, повернула ліворуч на 90° і пройшла 50 вгору. Лекція друкує: позиція (100.00,50.00), кут 90.0, відстань до початку 111.8, кут на початок 206.6. Звідки числа: відстань - теорема Піфагора, √(100² + 50²) = √12500 ≈ 111.8. Кут на початок: з точки (100, 50) треба дивитися вліво-вниз, а це 180° + arctg(50 / 100) ≈ 180° + 26.6° = 206.6°. Після setheading(206.6) і forward(111.8) вона опиняється в (0.00,-0.00): мінус перед нулем - це залишок округлення дробових чисел, насправді там щось на кшталт -0.000000000000002.

Головні команди (детально - у довіднику курсу і в _У_ЗОШИТ\Програмування - turtle шпаргалка.md): рух forward/backward/left/right/goto/setheading; перо penup/pendown/pensize/pencolor; заливка fillcolor + begin_fill() ... end_fill(); фігури circle(r), circle(r, 180) (півколо), circle(r, steps=5) (п'ятикутник), dot(d, color); текст write; швидкість speed(0); hideturtle().

Головна математика turtle (с. 26): щоб обійти фігуру й повернутися в той самий напрямок, черепашка мусить сумарно повернутися на 360°. Тому в правильному n-кутнику кожен поворот = 360° / n: трикутник 120°, квадрат 90°, п'ятикутник 72°, шестикутник 60°.

# не запускати: turtle
import turtle

def polygon(t, n, side):
    """Малює правильний n-кутник зі стороною side (Лекція 5, с. 26)."""
    angle = 360 / n            # сума поворотів 360°, поворотів n
    for _ in range(n):         # _ - лічильник, значення якого не потрібне
        t.forward(side)        # сторона
        t.left(angle)          # поворот на вершині

screen = turtle.Screen()       # вікно
t = turtle.Turtle()            # черепашка-об'єкт
t.speed(0)                     # без анімації - найшвидше
colors = ["red", "orange", "gold", "green", "dodgerblue", "purple"]
for n in range(3, 9):          # 3-кутник ... 8-кутник
    t.color(colors[n - 3])     # n = 3 -> colors[0], ... n = 8 -> colors[5]
    polygon(t, n, 360 / n)     # однаковий периметр 360
screen.exitonclick()           # вікно чекає клацання, потім закривається

Прийоми з лекції, які потрібні в ЛР4: - colors[i % len(colors)] - ходити по списку кольорів по колу (с. 25): остача від ділення на len завжди від 0 до len - 1, тож індекс ніколи не вилетить за межі. - «квітка»: малюємо фігуру і після неї повертаємо на 360° / кількість (36 кіл × 10°, с. 27-28). - спіраль: довжина кроку залежить від лічильника, t.forward(i * 1.5) (с. 28-29); товщина «сходинками» 1 + i // 40 (с. 29). - while t.distance(0, 0) < 250: - малюй, доки не відійшла далеко (с. 29-30); while True + break (с. 30). - вкладені цикли: 36 квадратів × 4 сторони = 144 кроки (с. 30-31); шахова дошка (row + col) % 2 == 0 (с. 32). - screen.tracer(0) на початку і screen.update() в кінці - малюнок з'являється миттєво (с. 32).

Допоміжні функції лекції new_screen, new_turtle, jump (с. 19-20): jump = penup, goto, setheading, pendown - перейти без лінії. Рядок turtle.TurtleScreen._RUNNING = True у new_screen - захист від помилки turtle.Terminator, яка буває в Jupyter, коли закрив вікно хрестиком і запускаєш знову (с. 19).

Нове тут:

  • python3 - запускає Python: твій файл .py, один рядок коду або вбудований інструмент. Назва: Python - на честь комедійного шоу «Monty Python», 3 - третя версія мови. -m - запусти модуль Python (вбудований чи поставлений через pip) як програму, напр. python3 -m venv (module - «модуль»).

  • Слово з мінусом (як -m тут) - прапорець: уточнює, що саме зробити команді.

Задача 1. count_grades(grades) - повертає словник «оцінка: скільки разів трапилась». Ключі - у порядку першої появи. count_grades([5, 4, 5, 3, 5]) → {5: 3, 4: 1, 3: 1}.

Підказка-план
  1. Порожній словник counts = {} до циклу.
  2. for grade in grades: - для кожної оцінки збільшити лічильник.
  3. counts[grade] += 1 впаде з KeyError для нової оцінки (її ще нема в словнику). Візьми get із запасним 0: «було стільки (або 0) плюс один».
  4. return counts. Порожній список → порожній словник {}.

Задача 2. final_position(commands) - черепашка «на папері», без вікна. Команди - список кортежів: ("F", 100) - вперед на 100, ("L", 90) - ліворуч на 90°, ("R", 90) - праворуч. Старт у (0, 0), дивиться праворуч. Функція повертає кінцеву позицію (x, y), округлену до сотих.

Підказка-план
  1. Стан черепашки - три змінні: x = 0.0, y = 0.0, heading = 0.0.
  2. for action, value in commands: - розпаковуємо кортеж.
  3. "L" - heading += value; "R" - heading -= value.

"""Урок 5. Задачі з doctest (розвʼязок).

import doctest
import math


def count_grades(grades: list[int]) -> dict[int, int]:
    """Повертає словник «оцінка: скільки разів вона трапилась».

    Ключі йдуть у порядку першої появи оцінки в списку.

    :param grades: список оцінок (може бути порожнім)
    :return: словник {оцінка: кількість}

    >>> count_grades([5, 4, 5, 3, 5])
    {5: 3, 4: 1, 3: 1}
    >>> count_grades([2])
    {2: 1}
    >>> count_grades([4, 4, 4, 4])
    {4: 4}
    >>> count_grades([])
    {}
    """
    counts = {}
    for grade in grades:
        # counts[grade] += 1 впало б з KeyError для нової оцінки.
        # get(grade, 0): «скільки вже було, а якщо ще не було - 0».
        counts[grade] = counts.get(grade, 0) + 1
    # Словник памʼятає порядок додавання ключів, тому 5 перша, 4 друга.
    return counts


def final_position(commands: list[tuple[str, float]]) -> tuple[float, float]:
    """Повертає, де опиниться черепашка після команд (без вікна turtle).

    Старт у (0, 0), черепашка дивиться праворуч (кут 0°).
    Команди: ("F", d) - вперед на d, ("L", a) - ліворуч на a градусів,
    ("R", a) - праворуч на a градусів.
    Знадобляться math.radians, math.cos, math.sin (import math -
    на початку файлу).

    :param commands: список кортежів (команда, число)
    :return: кортеж (x, y), кожне число округлене до сотих

    >>> final_position([("F", 100), ("L", 90), ("F", 50)])
    (100.0, 50.0)
    >>> final_position([("L", 60), ("F", 10)])
    (5.0, 8.66)
    >>> final_position([("R", 90), ("F", 20)])
    (0.0, -20.0)
    >>> final_position([("F", 30), ("L", 90)] * 4)
    (0.0, 0.0)
    >>> final_position([])
    (0.0, 0.0)
    """
    # Стан черепашки: позиція і напрямок (як у Лекції 5, с. 18).
    x = 0.0
    y = 0.0
    heading = 0.0
    for action, value in commands:
        if action == "F":
            # math.cos і math.sin працюють з радіанами, а кут - у градусах.
            angle = math.radians(heading)
            x += value * math.cos(angle)
            y += value * math.sin(angle)
        elif action == "L":
            heading += value
        elif action == "R":
            heading -= value
    # cos(90°) у компʼютері не рівно 0, а 6e-17. Після квадрата x може
    # стати -0.000000000000002, і round дасть -0.0. Додавання 0.0
    # перетворює -0.0 на 0.0 (у лекції, с. 23, видно (0.00,-0.00)).
    return (round(x, 2) + 0.0, round(y, 2) + 0.0)

7. Поясни чому

1. Чому figsize=(8, 5) - кортеж, а x_values - список?

Відповідь-еталон

Розмір рисунка - фіксований набір параметрів: ширина і висота задаються один раз і не міняються. Кортеж це гарантує і показує читачу «тут нічого не зміниться». x_values формується поступово в циклі через append - йому потрібна змінюваність, тому список. Це принцип лекції (Лекція 5, с. 1).

2. Чому colors[i % len(colors)] ніколи не дає IndexError, навіть коли i = 1000?

Відповідь-еталон

Остача від ділення на n завжди від 0 до n - 1. Для 4 кольорів: 1000 % 4 = 0, 1001 % 4 = 1 ... - індекси 0, 1, 2, 3 по колу. А допустимі індекси списку довжини 4 - саме 0..3. len(colors) замість числа 4 робить код правильним для будь-якої кількості кольорів (ЛР4, с. 4).

3. Чому в правильному n-кутнику черепашка повертає на 360° / n, а не на внутрішній кут?

Відповідь-еталон

Команда left(a) повертає ВІД поточного напрямку руху, тобто задає, на скільки відхилитися від прямої. Це зовнішній кут, він дорівнює 180° мінус внутрішній. Обійшовши фігуру, черепашка дивиться туди ж, звідки почала, - отже повернулася рівно на 360°, і ці 360° розділені порівну на n вершин. Для трикутника внутрішній кут 60°, а поворот 120°.

4. Чому student["gpa"] і student.get("gpa") поводяться по-різному, і коли що брати?

Відповідь-еталон

Квадратні дужки означають «я впевнений, що ключ є» - якщо нема, це помилка в програмі, і Python кричить KeyError. get означає «ключа може не бути - тоді дай запасне значення» (None або друге аргументом). Для лічильників нових ключів - get(key, 0), для обов'язкових полів - [], щоб помилку було видно одразу.
